# فصل 50 - `bind`، `call` و `apply`

## مقدمه

در فصل قبل با مفهوم `this` آشنا شدیم و یاد گرفتیم که مقدار `this` به **نحوه‌ی فراخوانی تابع** بستگی دارد، نه محل تعریف آن.

اما گاهی لازم است خودمان تعیین کنیم که `this` به چه چیزی اشاره کند. برای این کار JavaScript سه متد قدرتمند در اختیار ما قرار داده است:

* `call()`
* `apply()`
* `bind()`

این سه متد روی تمام توابع JavaScript وجود دارند و به ما اجازه می‌دهند مقدار `this` را به صورت دستی مشخص کنیم.

در پروژه‌های واقعی Node.js، مخصوصاً هنگام کار با کلاس‌ها، Callbackها، Eventها و کتابخانه‌های مختلف، استفاده صحیح از این سه متد بسیار مهم است.

---

# 50.1 - این سه متد متعلق به چه چیزی هستند؟

هر تابع در JavaScript در واقع یک شیء است و متدهای مختلفی دارد.

```js
function greet() {}

console.log(typeof greet); // function
```

به همین دلیل می‌توانیم بنویسیم:

```js
greet.call(...)

greet.apply(...)

greet.bind(...)
```

---

# 50.2 - چرا به این متدها نیاز داریم؟

فرض کنید:

```js
const user = {
    name: "Ali",

    greet() {
        console.log(this.name);
    }
};

const fn = user.greet;

fn();
```

خروجی:

```text
undefined
```

چون تابع دیگر توسط `user` اجرا نشده است.

برای حل این مشکل از `bind`، `call` یا `apply` استفاده می‌کنیم.

---

# 50.3 - متد `call()`

ساده‌ترین روش برای تعیین مقدار `this` است.

ساختار:

```js
functionName.call(thisArg, arg1, arg2, arg3);
```

مثال:

```js
function greet() {
    console.log(`Hello ${this.name}`);
}

const user = {
    name: "Sara"
};

greet.call(user);
```

خروجی:

```text
Hello Sara
```

---

# 50.4 - ارسال آرگومان با `call`

```js
function introduce(city, age) {
    console.log(this.name);
    console.log(city);
    console.log(age);
}

const user = {
    name: "Reza"
};

introduce.call(user, "Tehran", 25);
```

خروجی:

```text
Reza
Tehran
25
```

---

# 50.5 - متد `apply()`

`apply()` تقریباً مشابه `call()` است.

تنها تفاوت آن در نحوه ارسال آرگومان‌ها است.

ساختار:

```js
functionName.apply(thisArg, [arg1, arg2, arg3]);
```

مثال:

```js
function introduce(city, age) {
    console.log(this.name);
    console.log(city);
    console.log(age);
}

const user = {
    name: "Ali"
};

introduce.apply(user, ["Tabriz", 30]);
```

---

# 50.6 - تفاوت `call` و `apply`

`call`

```js
sum.call(obj, 5, 10);
```

`apply`

```js
sum.apply(obj, [5, 10]);
```

تنها تفاوت:

* `call` آرگومان‌ها را جداگانه می‌گیرد.
* `apply` آرگومان‌ها را داخل آرایه دریافت می‌کند.

---

# 50.7 - متد `bind()`

`bind()` متفاوت از دو متد قبلی است.

این متد تابع را اجرا نمی‌کند.

بلکه یک تابع جدید برمی‌گرداند.

```js
const newFunction = oldFunction.bind(thisArg);
```

مثال:

```js
const user = {
    name: "Sara",

    greet() {
        console.log(this.name);
    }
};

const fn = user.greet.bind(user);

fn();
```

خروجی:

```text
Sara
```

---

# 50.8 - تفاوت مهم `bind`

```js
function hello() {
    console.log(this.name);
}

const user = {
    name: "Ali"
};

hello.call(user);
```

تابع همان لحظه اجرا می‌شود.

اما:

```js
const fn = hello.bind(user);

fn();
```

ابتدا تابع ساخته می‌شود و بعداً هر زمان خواستیم اجرا می‌شود.

---

# 50.9 - استفاده از `bind` با آرگومان‌ها

```js
function add(a, b) {
    console.log(this.title);
    console.log(a + b);
}

const obj = {
    title: "Calculator"
};

const sum = add.bind(obj, 5);

sum(10);
```

خروجی:

```text
Calculator
15
```

در اینجا:

عدد 5 از قبل ذخیره شده است.

به این قابلیت **Partial Application** گفته می‌شود.

---

# 50.10 - مثال واقعی در کلاس‌ها

```js
class User {

    constructor(name) {
        this.name = name;
    }

    greet() {
        console.log(this.name);
    }

}

const user = new User("Mohammad");

const fn = user.greet.bind(user);

fn();
```

---

# 50.11 - مثال در Callback

```js
class Counter {

    constructor() {
        this.count = 0;
    }

    increment() {
        this.count++;
        console.log(this.count);
    }

}

const counter = new Counter();

setTimeout(counter.increment.bind(counter), 1000);
```

اگر `bind` را حذف کنیم:

```js
setTimeout(counter.increment, 1000);
```

معمولاً `this` از بین می‌رود و برنامه دچار خطا می‌شود.

---

# 50.12 - استفاده از `call` برای Borrowing

گاهی می‌خواهیم متد یک شیء را برای شیء دیگری استفاده کنیم.

```js
const person1 = {
    name: "Ali",

    greet() {
        console.log(`Hello ${this.name}`);
    }
};

const person2 = {
    name: "Sara"
};

person1.greet.call(person2);
```

خروجی:

```text
Hello Sara
```

به این کار **Method Borrowing** گفته می‌شود.

---

# 50.13 - مثال کاربردی

```js
function printPrice(currency) {
    console.log(`${this.name}: ${this.price} ${currency}`);
}

const laptop = {
    name: "Laptop",
    price: 1200
};

const phone = {
    name: "Phone",
    price: 800
};

printPrice.call(laptop, "USD");

printPrice.call(phone, "EUR");
```

---

# 50.14 - استفاده از `apply` برای آرایه‌ها

در گذشته یکی از کاربردهای مهم `apply` این بود:

```js
const numbers = [10, 20, 50, 30];

console.log(Math.max.apply(null, numbers));
```

امروزه بهتر است از Spread Operator استفاده کنیم:

```js
console.log(Math.max(...numbers));
```

کد دوم خواناتر و مدرن‌تر است.

---

# 50.15 - مقایسه کامل

| ویژگی               | call    | apply | bind                        |
| ------------------- | ------- | ----- | --------------------------- |
| اجرا شدن فوری       | ✅       | ✅     | ❌                           |
| برگرداندن تابع جدید | ❌       | ❌     | ✅                           |
| تعیین this          | ✅       | ✅     | ✅                           |
| آرگومان‌ها           | جداگانه | آرایه | جداگانه (هنگام bind و اجرا) |
| مناسب Callback      | ❌       | ❌     | ✅                           |

---

# 50.16 - چه زمانی از کدام استفاده کنیم؟

از `call`

* اجرای فوری
* تغییر موقت `this`
* Borrow کردن متد

از `apply`

* وقتی آرگومان‌ها داخل آرایه هستند.

از `bind`

* Callback
* Event
* کلاس‌ها
* حفظ همیشگی `this`

---

# 50.17 - مثال واقعی در Node.js

```js
class Logger {

    constructor(prefix) {
        this.prefix = prefix;
    }

    log(message) {
        console.log(`[${this.prefix}] ${message}`);
    }

}

const logger = new Logger("SERVER");

setTimeout(
    logger.log.bind(logger),
    1000,
    "Server Started"
);
```

---

# 50.18 - اشتباهات رایج

## 1) استفاده از `bind` و انتظار اجرای فوری

اشتباه:

```js
hello.bind(user);
```

تابع اجرا نمی‌شود.

باید:

```js
hello.bind(user)();
```

یا:

```js
const fn = hello.bind(user);

fn();
```

---

## 2) استفاده از `call` به جای `bind`

در Callbackها معمولاً باید از `bind` استفاده شود.

---

## 3) فراموش کردن آرایه در `apply`

اشتباه:

```js
sum.apply(obj, 5, 10);
```

صحیح:

```js
sum.apply(obj, [5, 10]);
```

---

## 4) استفاده بیش از حد از `bind`

اگر همیشه مجبور به استفاده از `bind` هستید، احتمالاً طراحی کلاس نیاز به بازبینی دارد.

---

## 5) استفاده از `apply` برای آرایه‌ها در پروژه‌های جدید

امروزه Spread Operator انتخاب مناسب‌تری است.

---

# 50.19 - نکات حرفه‌ای

* همیشه قبل از استفاده از این سه متد، بررسی کن آیا واقعاً به تغییر `this` نیاز داری یا خیر.
* برای Callbackها تقریباً همیشه `bind` انتخاب مناسبی است.
* برای اجرای فوری از `call` استفاده کن.
* اگر آرگومان‌ها به صورت آرایه هستند، `apply` یا Spread را در نظر بگیر.
* در پروژه‌های جدید، برای توابعی مانند `Math.max` از Spread Operator استفاده کن.
* از `bind` می‌توان برای ساخت توابع تخصصی با آرگومان‌های از پیش تعیین‌شده (Partial Application) استفاده کرد.
* در کلاس‌های Node.js اگر متدی قرار است به EventEmitter یا `setTimeout` ارسال شود، `bind` را فراموش نکن.

# 50.21 - پاسخ تشریحی

## پاسخ تمرین 1

```js
function sayHello() {
    console.log(`سلام ${this.name}`);
}

const ali = { name: "Ali" };
const sara = { name: "Sara" };

sayHello.call(ali);
sayHello.call(sara);
```

**توضیح:**
با `call` مقدار `this` برای هر بار اجرا تغییر می‌کند و تابع همان لحظه اجرا می‌شود.

---

## پاسخ تمرین 2

```js
function sayHello(city) {
    console.log(`${this.name} از ${city}`);
}

const user = {
    name: "Reza"
};

sayHello.apply(user, ["Mashhad"]);
```

**توضیح:**
تنها تفاوت با `call` این است که آرگومان‌ها در قالب یک آرایه ارسال می‌شوند.

---

## پاسخ تمرین 3

```js
class Counter {
    constructor() {
        this.count = 0;
    }

    increment() {
        this.count++;
        console.log(this.count);
    }
}

const counter = new Counter();

setTimeout(counter.increment.bind(counter), 1000);
```

**توضیح:**
بدون `bind` مقدار `this` در زمان اجرای Callback از بین می‌رود و متد به نمونه کلاس دسترسی نخواهد داشت.

---

## پاسخ تمرین 4

```js
function showPrice(currency) {
    console.log(`${this.name}: ${this.price} ${currency}`);
}

const mouse = {
    name: "Mouse",
    price: 25
};

const keyboard = {
    name: "Keyboard",
    price: 80
};

showPrice.call(mouse, "USD");
showPrice.call(keyboard, "USD");
```

**توضیح:**
از یک تابع برای چند شیء مختلف استفاده شده است و `call` تنها مقدار `this` را تغییر داده است.

---

## پاسخ تمرین 5

```js
function multiply(a, b) {
    return a * b;
}

const multiplyBy10 = multiply.bind(null, 10);

console.log(multiplyBy10(5)); // 50
console.log(multiplyBy10(8)); // 80
```

**توضیح:**
در این مثال از `bind` برای ساخت یک تابع جدید استفاده شده که اولین آرگومان آن همیشه برابر `10` است. این تکنیک را **Partial Application** می‌نامند.

# 50.22 - مینی‌پروژه

## ساخت سیستم مدیریت دستورات (Command Manager)

در این پروژه یک کلاس طراحی می‌کنیم که بتواند چند دستور مختلف را ثبت کرده و بعداً آن‌ها را اجرا کند. برای جلوگیری از از بین رفتن `this`، هنگام ثبت دستورات از `bind` استفاده می‌کنیم.

```js
class CommandManager {
    constructor() {
        this.commands = [];
    }

    register(command) {
        this.commands.push(command);
    }

    run() {
        for (const command of this.commands) {
            command();
        }
    }
}

class UserService {
    constructor(name) {
        this.name = name;
    }

    welcome() {
        console.log(`Welcome ${this.name}`);
    }

    goodbye() {
        console.log(`Goodbye ${this.name}`);
    }
}

const manager = new CommandManager();
const user = new UserService("Sobhan");

manager.register(user.welcome.bind(user));
manager.register(user.goodbye.bind(user));

manager.run();
```

### ایده‌هایی برای توسعه پروژه

* اضافه کردن امکان حذف دستورات
* اجرای دستورات به‌صورت Async
* زمان‌بندی اجرای دستورات
* ثبت لاگ اجرای هر دستور
* مدیریت خطاهای هر Command
* ساخت سیستم Undo و Redo برای دستورات

# جمع‌بندی

متدهای `call`، `apply` و `bind` از مهم‌ترین ابزارهای JavaScript برای کنترل مقدار `this` هستند. `call` و `apply` تابع را بلافاصله اجرا می‌کنند و تنها در نحوه ارسال آرگومان‌ها تفاوت دارند، در حالی که `bind` تابع جدیدی با `this` ثابت ایجاد می‌کند و برای Callbackها، کلاس‌ها و رویدادها بهترین انتخاب است. تسلط بر این سه متد باعث می‌شود رفتار `this` را به‌طور کامل کنترل کرده و کدهایی منعطف، قابل‌استفاده‌مجدد و حرفه‌ای در پروژه‌های Node.js بنویسید.
