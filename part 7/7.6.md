# فصل 46 - Polymorphism

در فصل قبل با **Inheritance (وراثت)** آشنا شدیم و یاد گرفتیم که یک کلاس می‌تواند ویژگی‌ها و رفتارهای کلاس دیگری را به ارث ببرد.

اما سؤال مهمی مطرح می‌شود:

اگر چند کلاس از یک کلاس والد ارث‌بری کنند، آیا همه باید رفتار یکسانی داشته باشند؟

پاسخ **خیر** است.

هر کلاس فرزند می‌تواند رفتار مخصوص به خودش را داشته باشد.

به این مفهوم **Polymorphism** یا **چندریختی** گفته می‌شود.

Polymorphism یکی از چهار اصل مهم برنامه‌نویسی شیءگرا (OOP) است.

---

# Polymorphism چیست؟

کلمه **Polymorphism** از دو واژه یونانی تشکیل شده است:

* Poly → چند
* Morph → شکل

یعنی:

> **یک رابط (Interface) یا متد واحد، اما رفتارهای متفاوت.**

به عبارت ساده‌تر:

چند کلاس مختلف می‌توانند متدی با نام یکسان داشته باشند، اما هر کدام آن را به شکل متفاوتی پیاده‌سازی کنند.

---

# اولین مثال

```js id="q1v9am"
class Animal {

    sound() {
        console.log("Unknown Sound");
    }

}

class Dog extends Animal {

    sound() {
        console.log("Bark");
    }

}

class Cat extends Animal {

    sound() {
        console.log("Meow");
    }

}

const dog = new Dog();
const cat = new Cat();

dog.sound();
cat.sound();
```

خروجی:

```txt id="h8k2xp"
Bark
Meow
```

نام متد یکسان است، اما رفتار آن متفاوت است.

---

# چرا Polymorphism مهم است؟

بدون Polymorphism مجبور می‌شویم برای هر کلاس شرط‌های زیادی بنویسیم.

مثال نامناسب:

```js id="z7m5tr"
if (animal.type === "dog") {
    console.log("Bark");
}

if (animal.type === "cat") {
    console.log("Meow");
}
```

روش صحیح:

```js id="r2c8nf"
animal.sound();
```

خود Object تصمیم می‌گیرد چه رفتاری انجام دهد.

---

# مثال با Vehicle

```js id="t4n6qy"
class Vehicle {

    move() {
        console.log("Moving...");
    }

}

class Car extends Vehicle {

    move() {
        console.log("Driving...");
    }

}

class Plane extends Vehicle {

    move() {
        console.log("Flying...");
    }

}

class Boat extends Vehicle {

    move() {
        console.log("Sailing...");
    }

}
```

---

# اجرای متد

```js id="b5y1kd"
const vehicles = [

    new Car(),
    new Plane(),
    new Boat()

];

for (const vehicle of vehicles) {
    vehicle.move();
}
```

خروجی:

```txt id="u6x3ep"
Driving...
Flying...
Sailing...
```

# Override

Polymorphism معمولاً با Override کردن متدها پیاده‌سازی می‌شود.

```js id="n9j4wh"
class Shape {

    area() {
        return 0;
    }

}

class Rectangle extends Shape {

    area() {
        return 50;
    }

}

class Circle extends Shape {

    area() {
        return 78.5;
    }

}
```

---

# استفاده از super

گاهی علاوه بر رفتار جدید، به رفتار والد نیز نیاز داریم.

```js id="m3r8zt"
class Animal {

    sound() {
        console.log("Animal");
    }

}

class Dog extends Animal {

    sound() {

        super.sound();

        console.log("Bark");

    }

}

const dog = new Dog();

dog.sound();
```

خروجی:

```txt id="g7q5la"
Animal
Bark
```

# Polymorphism و Array

یکی از کاربردهای مهم Polymorphism استفاده از Objectهای مختلف داخل یک Array است.

```js id="x8p2cv"
class User {

    login() {
        console.log("User Login");
    }

}

class Admin extends User {

    login() {
        console.log("Admin Login");
    }

}

class Guest extends User {

    login() {
        console.log("Guest Login");
    }

}

const users = [

    new User(),
    new Admin(),
    new Guest()

];

for (const user of users) {

    user.login();

}
```

# Polymorphism در پروژه‌های واقعی

فرض کنید چند روش ارسال پیام داریم.

```js id="j6w4bn"
    send() {}

class EmailNotification extends Notification {

    send() {
        console.log("Email Sent");
    }
```

```js id="v1m9qe"
const notifications = [

    new EmailNotification(),

    new PushNotification()

notifications.forEach(notification => {

    notification.send();

});
```

# مثال با Logger

```js id="f8n3dr"
class Logger {
```

هر Logger رفتار متفاوتی دارد.

# Abstract Behavior

جاوااسکریپت کلاس Abstract واقعی ندارد.

اما می‌توان رفتار مشابه ایجاد کرد.

```js id="y7q1hf"
class Animal {

    sound() {
        throw new Error("Must Override");
    }

}
```

اگر کلاس فرزند متد را Override نکند:

```js id="n5m8az"
const animal = new Animal();

animal.sound();
```

خطا رخ می‌دهد.

---

# Duck Typing

جاوااسکریپت یک زبان Dynamic است.

بنابراین بیشتر از نوع کلاس، به وجود متد توجه می‌کند.

```js id="u4c9kl"
class Dog {

    sound() {
        console.log("Bark");
    }

}

class Robot {

    sound() {
        console.log("Digital Sound");
    }

}

function playSound(obj) {
    obj.sound();
}

playSound(new Dog());
playSound(new Robot());
```

هر دو Object قابل استفاده هستند.

---

# Polymorphism و instanceof

گاهی لازم است نوع Object را بررسی کنیم.

```js id="d9r3tp"
class Animal {}

class Dog extends Animal {}

const dog = new Dog();

console.log(dog instanceof Animal);
```

اما در بسیاری از موارد، به جای بررسی نوع، بهتر است متد مشترک را مستقیماً فراخوانی کنیم تا از مزایای Polymorphism بهره ببریم.

---

# Polymorphism در Node.js

در پروژه‌های Node.js معمولاً این مفهوم در موارد زیر استفاده می‌شود:

* Logger
* Database Driver
* Cache Driver
* Payment Gateway
* Authentication Provider
* File Storage
* Notification Service

مثال:

```js id="c7k6mq"
class Storage {

    save(file) {}

}

class LocalStorage extends Storage {

    save(file) {
        console.log("Saved Locally");
    }

}

class CloudStorage extends Storage {

    save(file) {
        console.log("Saved On Cloud");
    }

}
```

کد اصلی فقط متد `save()` را صدا می‌زند و نیازی به دانستن نوع Storage ندارد.

---

# مزایای Polymorphism

* حذف شرط‌های اضافی
* توسعه آسان پروژه
* خوانایی بیشتر
* نگهداری بهتر
* قابلیت افزودن کلاس‌های جدید بدون تغییر کدهای قبلی
* پیروی بهتر از اصل **Open/Closed Principle** (باز برای توسعه، بسته برای تغییر)

---

# اشتباهات رایج

## 1. استفاده زیاد از if و switch

اشتباه:

```js id="e3t8vw"
if (type === "car") {}

if (type === "plane") {}
```

بهتر است هر کلاس رفتار خودش را داشته باشد.

---

## 2. Override نکردن متد

اگر کلاس فرزند رفتار متفاوتی دارد، باید متد مناسب را Override کند.

---

## 3. تغییر کامل منطق والد بدون نیاز

گاهی فقط لازم است بخشی از رفتار تغییر کند.

در این حالت از `super` استفاده کنید.

---

## 4. وابستگی به نوع کلاس

اشتباه:

```js id="w2n7qy"
if (obj instanceof Dog)
```

تا جای ممکن از متدهای مشترک استفاده کنید، نه بررسی نوع.

---

## 5. طراحی کلاس والد با مسئولیت‌های زیاد

کلاس پایه باید ساده و عمومی باشد تا فرزندان بتوانند آن را به‌راحتی گسترش دهند.

---

# نکات حرفه‌ای

* کلاس والد را عمومی و قابل توسعه طراحی کنید.
* Override را فقط زمانی انجام دهید که رفتار واقعاً متفاوت است.
* از `super` برای استفاده از منطق مشترک کلاس والد بهره ببرید.
* از شرط‌های زیاد برای تشخیص نوع Object اجتناب کنید.
* کلاس‌های جدید را بدون تغییر کدهای موجود به پروژه اضافه کنید.
* برای سرویس‌هایی مانند پرداخت، ذخیره‌سازی و ارسال پیام از Polymorphism استفاده کنید.
* در جاوااسکریپت بیشتر به رفتار Object توجه کنید تا نوع آن (Duck Typing).

```js id="r1v8pc"
[new Dog(), new Cat()].forEach(animal => animal.sound());
```

---

## پاسخ تمرین ۲

```js id="k9m4ty"
class Shape {

    area() {
        return 0;
    }

}

class Rectangle extends Shape {

    constructor(width, height) {
        super();
        this.width = width;
        this.height = height;
    }

    area() {
        return this.width * this.height;
    }

}

class Circle extends Shape {

    constructor(radius) {
        super();
        this.radius = radius;
    }

    area() {
        return Math.PI * this.radius ** 2;
    }

}

console.log(new Rectangle(5, 10).area());
console.log(new Circle(5).area());
```

# مینی‌پروژه

## مینی‌پروژه ۱: سیستم پرداخت

کلاس پایه `Payment` ایجاد کنید.

روش‌های پرداخت:

* نقدی
* کارت بانکی
* ارز دیجیتال

را به صورت کلاس‌های جداگانه پیاده‌سازی کنید.

---

## مینی‌پروژه ۲: سیستم ارسال اعلان

یک کلاس پایه `Notification` طراحی کنید.

کلاس‌های زیر را از آن ارث‌بری دهید:

* EmailNotification
* SMSNotification
* PushNotification

همه باید متد `send()` را به شکل مخصوص خود پیاده‌سازی کنند.

---

## مینی‌پروژه ۳: سیستم ذخیره‌سازی فایل

کلاس پایه `Storage` ایجاد کنید.

پیاده‌سازی‌های مختلف:

* LocalStorage
* CloudStorage
* MemoryStorage

را با متد `save()` و `delete()` طراحی کنید.

---

## مینی‌پروژه ۴: سیستم گزارش‌گیری

کلاس پایه `Logger` ایجاد کنید.

کلاس‌های زیر را از آن ارث‌بری دهید:

* ConsoleLogger
* FileLogger
* DatabaseLogger

سپس مجموعه‌ای از Loggerها را در یک آرایه قرار دهید و همه را با یک حلقه اجرا کنید تا یک پیام را ثبت کنند.

---

# جمع‌بندی

در این فصل با **Polymorphism (چندریختی)** آشنا شدیم و یاد گرفتیم:

* Polymorphism چیست.
* چگونه با Override رفتارهای متفاوت ایجاد کنیم.
* از `super` برای استفاده از رفتار کلاس والد بهره ببریم.
* چندین Object مختلف را با یک رابط مشترک مدیریت کنیم.
* مفهوم Duck Typing را در جاوااسکریپت بشناسیم.
* Polymorphism را در پروژه‌های واقعی Node.js مانند سیستم‌های پرداخت، اعلان، ذخیره‌سازی و گزارش‌گیری به‌کار ببریم.

Polymorphism باعث می‌شود کدهای ما انعطاف‌پذیر، قابل توسعه و ساده‌تر شوند. به جای نوشتن شرط‌های متعدد برای تشخیص نوع Object، هر Object مسئول اجرای رفتار خودش است؛ رویکردی که یکی از پایه‌های طراحی نرم‌افزارهای حرفه‌ای و مقیاس‌پذیر محسوب می‌شود.
