# فصل 42 - Prototype

در فصل قبل با **Object Oriented Programming** آشنا شدیم و یاد گرفتیم که چگونه با `class` شیء بسازیم.

اما یک نکته مهم وجود دارد:

**کلاس‌ها در جاوااسکریپت در واقع فقط یک ظاهر (Syntax Sugar) هستند.**

در پشت صحنه، جاوااسکریپت از سیستمی به نام **Prototype** استفاده می‌کند.

اگر Prototype را به خوبی یاد بگیرید:

* رفتار Objectها را بهتر درک می‌کنید.
* عملکرد `class` برایتان شفاف می‌شود.
* مفهوم Inheritance را بهتر می‌فهمید.
* هنگام کار با کتابخانه‌ها و پروژه‌های بزرگ Node.js دچار سردرگمی نمی‌شوید.

---

# Prototype چیست؟

هر Object در جاوااسکریپت یک شیء دیگر را به عنوان **Prototype** دارد.

وقتی به یک Property یا Method دسترسی پیدا می‌کنیم، جاوااسکریپت ابتدا داخل خود Object جستجو می‌کند.

اگر آن را پیدا نکند، داخل Prototype جستجو می‌کند.

اگر باز هم پیدا نشود، به Prototype بعدی می‌رود.

به این فرآیند **Prototype Chain** گفته می‌شود.

---

# اولین مثال

```js
const user = {
    name: "Ali"
};

console.log(user.name);
console.log(user.toString());
```

ممکن است تصور کنید `toString` داخل Object تعریف شده است.

اما:

```js
console.log(user);
```

خروجی:

```txt
{
    name: "Ali"
}
```

هیچ متدی به نام `toString` وجود ندارد.

پس از کجا آمده است؟

پاسخ:

از Prototype.

---

# مشاهده Prototype

برای مشاهده Prototype می‌توان از:

```js
Object.getPrototypeOf(obj);
```

استفاده کرد.

مثال:

```js
const user = {
    name: "Ali"
};

console.log(Object.getPrototypeOf(user));
```

خروجی نمونه:

```txt
[Object: null prototype] {}
```

Prototype این Object همان `Object.prototype` است.

---

# Object.prototype

تقریباً تمام Objectهای معمولی از `Object.prototype` ارث‌بری می‌کنند.

به همین دلیل متدهایی مانند:

* toString
* hasOwnProperty
* valueOf
* isPrototypeOf

برای همه Objectها در دسترس هستند.

مثال:

```js
const user = {
    name: "Sara"
};

console.log(user.hasOwnProperty("name"));
```

خروجی:

```txt
true
```

ما این متد را تعریف نکرده‌ایم.

از Prototype آمده است.

---

# Prototype Chain

فرض کنید:

```txt
user
   │
   ▼
Object.prototype
   │
   ▼
null
```

هنگام اجرای:

```js
user.toString();
```

جاوااسکریپت:

1. داخل user جستجو می‌کند.
2. پیدا نمی‌کند.
3. به Object.prototype می‌رود.
4. متد را پیدا می‌کند.
5. اجرا می‌کند.

---

# ساخت Prototype با Constructor Function

قبل از اضافه شدن Classها، از Constructor Function استفاده می‌شد.

```js
function User(name) {
    this.name = name;
}

const user = new User("Ali");

console.log(user.name);
```

---

# اضافه کردن Method به Prototype

اگر متد را داخل Constructor بنویسیم:

```js
function User(name) {
    this.name = name;

    this.sayHello = function () {
        console.log("Hello");
    };
}
```

برای هر شیء، یک نسخه جدید از تابع ساخته می‌شود.

راه بهتر:

```js
function User(name) {
    this.name = name;
}

User.prototype.sayHello = function () {
    console.log(`Hello ${this.name}`);
};

const user1 = new User("Ali");
const user2 = new User("Sara");

user1.sayHello();
user2.sayHello();
```

خروجی:

```txt
Hello Ali
Hello Sara
```

در این حالت فقط یک نسخه از `sayHello` در حافظه وجود دارد.

---

# بررسی Prototype

```js
function User() {}

console.log(User.prototype);
```

خروجی نمونه:

```txt
{
    constructor: User
}
```

---

# constructor Property

هر Prototype دارای Propertyای به نام constructor است.

```js
function User() {}

console.log(User.prototype.constructor);
```

خروجی:

```txt
[Function: User]
```

---

# بررسی ارتباط Prototype

```js
function User() {}

const user = new User();

console.log(user.__proto__ === User.prototype);
```

خروجی:

```txt
true
```

> **نکته:** استفاده از `__proto__` برای یادگیری مفید است، اما در کدهای جدید بهتر است از `Object.getPrototypeOf()` و `Object.setPrototypeOf()` استفاده شود.

---

# Prototype و Class

کلاس‌ها نیز از Prototype استفاده می‌کنند.

```js
class User {

    sayHello() {
        console.log("Hello");
    }

}

const user = new User();

user.sayHello();
```

در واقع:

```js
User.prototype.sayHello
```

ایجاد شده است.

---

# اثبات این موضوع

```js
class User {

    sayHello() {
        console.log("Hello");
    }

}

console.log(User.prototype);
```

---

# Prototype مشترک

```js
class User {

    sayHello() {
        console.log("Hello");
    }

}

const user1 = new User();
const user2 = new User();

console.log(user1.sayHello === user2.sayHello);
```

خروجی:

```txt
true
```

هر دو شیء از یک متد مشترک استفاده می‌کنند.

---

# اضافه کردن Property به Prototype

```js
function User(name) {
    this.name = name;
}

User.prototype.country = "Iran";

const user = new User("Ali");

console.log(user.country);
```

خروجی:

```txt
Iran
```

---

# بازنویسی Property

```js
function User(name) {
    this.name = name;
}

User.prototype.country = "Iran";

const user = new User("Ali");

user.country = "Germany";

console.log(user.country);
```

خروجی:

```txt
Germany
```

Prototype تغییر نکرده است.

---

# بررسی hasOwnProperty

```js
function User(name) {
    this.name = name;
}

User.prototype.country = "Iran";

const user = new User("Ali");

console.log(user.hasOwnProperty("name"));
console.log(user.hasOwnProperty("country"));
```

خروجی:

```txt
true
false
```

زیرا `country` داخل Prototype قرار دارد.

# Object.create()

با `Object.create()` می‌توان شیئی با Prototype دلخواه ساخت.

```js
const person = {
    sayHello() {
        console.log("Hello");
    }
};

const user = Object.create(person);

user.sayHello();
```

خروجی:

```txt
Hello
```

---

# بررسی Prototype

```js
const person = {};

const user = Object.create(person);

console.log(Object.getPrototypeOf(user) === person);
```

خروجی:

```txt
true
```

---

# تغییر Prototype

```js
const animal = {
    eat() {
        console.log("Eating...");
    }
};

const dog = {};

Object.setPrototypeOf(dog, animal);

dog.eat();
```

خروجی:

```txt
Eating...
```

---

# Prototype Chain چندمرحله‌ای

```js
const livingThing = {
    live() {
        console.log("Living");
    }
};

const animal = Object.create(livingThing);

animal.eat = function () {
    console.log("Eating");
};

const dog = Object.create(animal);

dog.live();
dog.eat();
```

جاوااسکریپت در چند مرحله Propertyها را پیدا می‌کند.

---

# متدهای داخلی Object.prototype

```js
console.log(obj.valueOf());
console.log(obj.hasOwnProperty("name"));
```

# Prototype در پروژه‌های Node.js

در پروژه‌های امروزی معمولاً از `class` استفاده می‌شود.

اما دانستن Prototype اهمیت زیادی دارد زیرا:

* Class بر پایه Prototype ساخته شده است.
* بسیاری از کتابخانه‌ها از Prototype استفاده می‌کنند.
* هنگام Debug کردن پروژه‌ها با آن روبه‌رو می‌شوید.

---

# Prototype یا Class؟

در پروژه‌های جدید:

* برای توسعه روزمره از `class` استفاده کنید.
* Prototype را برای درک بهتر جاوااسکریپت یاد بگیرید.

---

# اشتباهات رایج

## 1. تعریف Method داخل Constructor

اشتباه:

```js
function User() {
    this.sayHello = function () {};
}
```

برای هر شیء یک تابع جدید ساخته می‌شود.

بهتر:

```js
User.prototype.sayHello = function () {};
```

---

## 2. استفاده بیش از حد از **proto**

```js
user.__proto__
```

برای یادگیری مناسب است اما در پروژه‌های واقعی از APIهای استاندارد استفاده کنید.

---

## 3. تغییر مستقیم Object.prototype

اشتباه:

```js
Object.prototype.test = function () {};
```

این تغییر روی تمام Objectهای برنامه اثر می‌گذارد و می‌تواند باعث بروز رفتارهای غیرمنتظره شود.

---

## 4. اشتباه گرفتن Propertyهای Prototype با Propertyهای خود شیء

```js
user.hasOwnProperty("country");
```

همیشه بررسی کنید مقدار واقعاً متعلق به خود شیء است یا از Prototype به ارث رسیده است.

---

## 5. استفاده نادرست از Object.setPrototypeOf

تغییر Prototype بعد از ساخت تعداد زیادی شیء می‌تواند روی عملکرد برنامه تأثیر منفی بگذارد.

---

# نکات حرفه‌ای

* در پروژه‌های جدید از `class` استفاده کنید و Prototype را به عنوان پایه آن بشناسید.
* متدهای مشترک را روی Prototype قرار دهید تا حافظه کمتری مصرف شود.
* برای بررسی Prototype از `Object.getPrototypeOf()` استفاده کنید.
* از `Object.create()` برای ساخت Objectهایی با Prototype سفارشی استفاده کنید.
* تا حد امکان از تغییر `Object.prototype` خودداری کنید.
* هنگام کار با کتابخانه‌های قدیمی، شناخت Prototype بسیار ارزشمند است.
* Prototype Chain را در زمان Debug کردن به خاطر داشته باشید.

# مینی‌پروژه

## مینی‌پروژه ۱: Prototype User System

یک Constructor Function طراحی کنید که:

* name
* age

را دریافت کند.

متدهای زیر را روی Prototype قرار دهید:

* `showInfo`
* `isAdult`

---

## مینی‌پروژه ۲: کتابخانه اشکال هندسی

یک Constructor Function برای `Shape` بسازید.

سپس Prototype آن را گسترش دهید و متدهایی مانند:

* `area`
* `perimeter`

را برای اشکال مختلف پیاده‌سازی کنید.

---

## مینی‌پروژه ۳: Prototype Chain

یک زنجیره Prototype با سه سطح ایجاد کنید:

* LivingThing
* Animal
* Dog

و نشان دهید که شیء `Dog` به تمام متدهای والدین دسترسی دارد.

---

## مینی‌پروژه ۴: بازسازی Class با Prototype

کلاسی که در فصل قبل نوشته بودید (مثلاً `BankAccount` یا `User`) را این بار بدون استفاده از `class` و فقط با Constructor Function و Prototype پیاده‌سازی کنید.

در این فصل یاد گرفتیم که:

* Prototype چیست.

* چرا تمام Objectها به متدهایی مانند `toString()` دسترسی دارند.
