# فصل 43 - Class

در فصل قبل با **Prototype** آشنا شدیم و دیدیم که جاوااسکریپت در پشت صحنه چگونه Objectها را مدیریت می‌کند.

اما نوشتن کد با Prototype و Constructor Function همیشه ساده نیست.

به همین دلیل از نسخه **ES6 (ES2015)**، جاوااسکریپت قابلیت **Class** را معرفی کرد.

> **نکته مهم:**
> Class یک قابلیت جدید برای مدیریت بهتر کد است، اما در پشت صحنه همچنان از Prototype استفاده می‌کند.

در این فصل به صورت کامل با Class آشنا می‌شویم.

---

# Class چیست؟

Class یک **الگو (Blueprint)** برای ساخت Object است.

به جای اینکه هر بار Object را به صورت دستی ایجاد کنیم، یک Class تعریف می‌کنیم و هر زمان که نیاز داشتیم از روی آن Object می‌سازیم.

مثال:

```js id="x0r81a"
class User {}

const user1 = new User();
const user2 = new User();
```

هر دو Object از یک Class ساخته شده‌اند.

---

# مزایای Class

استفاده از Class باعث می‌شود:

* کد خواناتر شود.
* نگهداری پروژه آسان‌تر شود.
* از تکرار کد جلوگیری شود.
* پروژه ساختار منظم‌تری داشته باشد.
* توسعه پروژه ساده‌تر شود.

# Static Method

گاهی متد متعلق به خود Class است، نه Object.

برای این کار از `static` استفاده می‌کنیم.

```js id="z4b2xp"
class MathTool {

    static sum(a, b) {
        return a + b;
    }

}

console.log(MathTool.sum(5, 8));
```

# Getter

Getter برای دریافت مقدار استفاده می‌شود.

```js id="g6m9jk"
class User {

    constructor(name) {
        this.name = name;
    }

    get upperName() {
        return this.name.toUpperCase();
    }

}

const user = new User("Ali");

console.log(user.upperName);
```

# Setter

Setter برای تغییر مقدار استفاده می‌شود.

```js id="p3h8rn"
class User {

    constructor(name) {
        this.name = name;
    }

    set changeName(value) {
        this.name = value;
    }

}

const user = new User("Ali");

user.changeName = "Sara";

console.log(user.name);
```

# Inheritance

با استفاده از `extends` می‌توان از Class دیگر ارث‌بری کرد.

```js id="x7m6bn"
class Animal {

    eat() {
        console.log("Eating");
    }

}

class Dog extends Animal {

    bark() {
        console.log("Bark");
    }

}

const dog = new Dog();

dog.eat();

dog.bark();
```

---

# super

برای استفاده از Constructor والد از `super()` استفاده می‌کنیم.

```js id="t4p1vy"
class Animal {

    constructor(name) {
        this.name = name;
    }

}

class Dog extends Animal {

    constructor(name, age) {

        super(name);

        this.age = age;

    }

}

const dog = new Dog("Rocky", 3);

console.log(dog.name);

console.log(dog.age);
```

---

# Override

# استفاده از super داخل Method

```js id="c3n6wx"

    }

    sound() {

        super.sound();

    }

```

## 1. فراموش کردن new

## 3. قرار دادن منطق زیاد داخل Constructor

## 4. استفاده بی‌دلیل از Static

Static فقط زمانی مناسب است که متد وابسته به Object نباشد.

---

## 5. شکستن اصل مسئولیت واحد

هر Class باید فقط یک مسئولیت مشخص داشته باشد.

---

## 6. دسترسی مستقیم به داده‌های حساس

اگر داده‌ای نباید از بیرون تغییر کند، از Private Field یا متدهای مناسب استفاده کنید.

---

# نکات حرفه‌ای

* برای مدل‌سازی موجودیت‌های اصلی پروژه از Class استفاده کنید.
* Classها را کوچک و مسئولیت‌محور نگه دارید.
* از Getter و Setter فقط زمانی استفاده کنید که نیاز به اعتبارسنجی یا پردازش دارید.
* متدهای عمومی را روی Prototype (که Class به‌صورت خودکار انجام می‌دهد) نگه دارید.
* از Inheritance فقط زمانی استفاده کنید که رابطه «یک نوع از» وجود داشته باشد.
* برای منطق‌های مشترک از Composition نیز استفاده کنید و همیشه به ارث‌بری وابسته نباشید.
* از Private Field برای محافظت از داده‌های حساس استفاده کنید.
* برای Utilityها که نیازی به ساخت Object ندارند، از متدهای Static استفاده کنید.

# جمع‌بندی

در این فصل با Class در جاوااسکریپت به‌صورت کامل آشنا شدیم و یاد گرفتیم:

* Class چیست.
* چگونه Object بسازیم.
* از Constructor و `this` استفاده کنیم.
* متد، Getter، Setter و Static Member ایجاد کنیم.
* از Private Field برای محافظت از داده‌ها استفاده کنیم.
* با `extends` و `super` ارث‌بری را پیاده‌سازی کنیم.
* متدهای والد را Override کنیم.
* از `instanceof` برای بررسی نوع Object استفاده کنیم.
* Classها را در پروژه‌های واقعی Node.js به‌کار بگیریم.

اگرچه Class ظاهر ساده‌تر و خواناتری نسبت به Prototype دارد، اما در پشت صحنه همچنان بر پایه Prototype کار می‌کند. تسلط بر Class یکی از مهم‌ترین مهارت‌ها برای توسعه پروژه‌های حرفه‌ای Node.js و فریم‌ورک‌هایی مانند NestJS است.
