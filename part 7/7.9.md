# فصل 49 - `this`

## مقدمه

یکی از مهم‌ترین و در عین حال گیج‌کننده‌ترین مفاهیم JavaScript، کلمه‌ی کلیدی **`this`** است.

تقریباً هر برنامه‌نویسی که JavaScript را شروع می‌کند، دیر یا زود با سوالاتی مثل این روبه‌رو می‌شود:

* چرا مقدار `this` اینجا `undefined` است؟
* چرا داخل Arrow Function مقدار `this` تغییر نمی‌کند؟
* چرا وقتی یک متد را داخل متغیر ذخیره می‌کنم، دیگر کار نمی‌کند؟
* چرا در Node.js رفتار `this` با مرورگر متفاوت است؟

دلیل این سوال‌ها این است که برخلاف بسیاری از زبان‌های برنامه‌نویسی، در JavaScript مقدار `this` **به محل تعریف تابع بستگی ندارد**؛ بلکه **به نحوه‌ی فراخوانی (Call Site)** بستگی دارد.

اگر این قانون را به خوبی درک کنید، تقریباً تمام رفتارهای `this` برایتان قابل پیش‌بینی خواهد بود.

---

# 49.1 - `this` چیست؟

`this` یک متغیر معمولی نیست.

بلکه یک **Reference** است که در زمان اجرای برنامه مشخص می‌شود و به یک شیء اشاره می‌کند.

نکته مهم:

> مقدار `this` هنگام تعریف تابع مشخص نمی‌شود، بلکه هنگام اجرای آن تعیین می‌شود.

مثال:

```js
function hello() {
    console.log(this);
}

hello();
```

مقدار چاپ شده به نحوه اجرای تابع بستگی دارد.

---

# 49.2 - قانون طلایی `this`

همیشه از خودت این سوال را بپرس:

> **این تابع چگونه فراخوانی شده است؟**

نه اینکه:

> این تابع کجا نوشته شده است؟

این مهم‌ترین اصل برای درک `this` است.

---

# 49.3 - `this` در سطح فایل (Node.js)

در Node.js هر فایل یک Module مستقل است.

بنابراین:

```js
console.log(this);
```

خروجی:

```js
{}
```

چون `this` در بالاترین سطح فایل به `module.exports` اشاره می‌کند.

مثال:

```js
console.log(this === module.exports);
```

خروجی:

```text
true
```

---

# 49.4 - `this` در تابع معمولی

```js
function greet() {
    console.log(this);
}

greet();
```

در حالت Strict Mode:

```js
"use strict";

function greet() {
    console.log(this);
}

greet();
```

خروجی:

```text
undefined
```

در Node.js بهتر است همیشه انتظار داشته باشید که در تابع معمولی و Strict Mode مقدار `this` برابر `undefined` باشد.

---

# 49.5 - `this` داخل Object

```js
const user = {
    name: "Ali",

    greet() {
        console.log(this.name);
    }
};

user.greet();
```

خروجی:

```text
Ali
```

در اینجا:

```text
this === user
```

زیرا تابع توسط `user` فراخوانی شده است.

---

# 49.6 - از دست رفتن `this`

یکی از رایج‌ترین مشکلات JavaScript

```js
const user = {
    name: "Sara",

    greet() {
        console.log(this.name);
    }
};

const fn = user.greet;

fn();
```

خروجی:

```text
undefined
```

چرا؟

چون دیگر تابع توسط `user` اجرا نشده است.

بلکه به صورت مستقل اجرا شده است.

---

# 49.7 - استفاده از `bind`

برای ثابت نگه داشتن `this` از `bind` استفاده می‌کنیم.

```js
const user = {
    name: "Sara",

    greet() {
        console.log(this.name);
    }
};

const fn = user.greet.bind(user);

fn();
```

خروجی:

```text
Sara
```

---

# 49.8 - استفاده از `call`

```js
function greet() {
    console.log(this.name);
}

const user = {
    name: "Reza"
};

greet.call(user);
```

خروجی:

```text
Reza
```

---

# 49.9 - استفاده از `apply`

```js
function sum(a, b) {
    console.log(this.title);
    console.log(a + b);
}

const obj = {
    title: "Calculator"
};

sum.apply(obj, [5, 7]);
```

خروجی:

```text
Calculator
12
```

تفاوت `apply` و `call`

```text
call(arg1,arg2,arg3)

apply([arg1,arg2,arg3])
```

---

# 49.10 - Arrow Function و `this`

Arrow Function مقدار `this` مخصوص خودش را ندارد.

بلکه مقدار `this` را از محیط اطراف می‌گیرد.

```js
const user = {
    name: "Ali",

    show() {
        const print = () => {
            console.log(this.name);
        };

        print();
    }
};

user.show();
```

خروجی:

```text
Ali
```

---

اگر از Function معمولی استفاده کنیم:

```js
const user = {
    name: "Ali",

    show() {

        function print() {
            console.log(this.name);
        }

        print();
    }
};

user.show();
```

خروجی:

```text
undefined
```

---

# 49.11 - `this` داخل کلاس

```js
class User {

    constructor(name) {
        this.name = name;
    }

    greet() {
        console.log(this.name);
    }

}

const user = new User("Mohammad");

user.greet();
```

خروجی:

```text
Mohammad
```

---

# 49.12 - مشکل رایج کلاس‌ها

```js
class Counter {

    constructor() {
        this.count = 0;
    }

    increment() {
        this.count++;
    }

}

const counter = new Counter();

const fn = counter.increment;

fn();
```

خطا:

```text
Cannot read properties of undefined
```

---

راه‌حل:

```js
const fn = counter.increment.bind(counter);

fn();
```

---

# 49.13 - Arrow Function داخل کلاس

```js
class Counter {

    count = 0;

    increment = () => {
        this.count++;
    };

}

const counter = new Counter();

const fn = counter.increment;

fn();

console.log(counter.count);
```

خروجی:

```text
1
```

زیرا Arrow Function مقدار `this` را حفظ می‌کند.

---

# 49.14 - `this` و Constructor

```js
class Product {

    constructor(name, price) {

        this.name = name;
        this.price = price;

    }

}

const p = new Product("Mouse", 50);

console.log(p);
```

خروجی:

```text
Product {
    name: 'Mouse',
    price: 50
}
```

---

# 49.15 - `this` در Prototype

```js
function Person(name) {
    this.name = name;
}

Person.prototype.sayHello = function () {
    console.log(this.name);
};

const p = new Person("Ali");

p.sayHello();
```

خروجی:

```text
Ali
```

---

# 49.16 - ترتیب تعیین `this`

JavaScript برای تعیین `this` تقریباً این ترتیب را دنبال می‌کند:

1. اگر با `new` فراخوانی شود → شیء جدید
2. اگر `call` یا `apply` یا `bind` وجود داشته باشد → شیء مشخص شده
3. اگر به صورت متد فراخوانی شود → شیء قبل از نقطه
4. اگر Arrow Function باشد → محیط بیرونی
5. در غیر این صورت → `undefined` (در Strict Mode)

---

# 49.17 - مثال واقعی در Node.js

```js
class Logger {

    constructor(prefix) {
        this.prefix = prefix;
    }

    log(message) {
        console.log(`[${this.prefix}] ${message}`);
    }

}

const logger = new Logger("APP");

logger.log("Server Started");
```

خروجی:

```text
[APP] Server Started
```

---

# 49.18 - اشتباهات رایج

## 1) تصور اینکه `this` به محل تعریف تابع وابسته است

اشتباه.

`this` به **محل فراخوانی** وابسته است.

---

## 2) جدا کردن متد از شیء

```js
const fn = obj.method;

fn();
```

در این حالت معمولاً `this` از بین می‌رود.

---

## 3) استفاده اشتباه از Arrow Function

Arrow Function برای همه جا مناسب نیست.

مثلاً به عنوان متد Prototype معمولاً انتخاب مناسبی نیست، چون `this` مخصوص خود را ندارد.

---

## 4) فراموش کردن `bind`

در Callbackها مخصوصاً در Node.js یکی از رایج‌ترین مشکلات همین است.

---

## 5) استفاده از `this` داخل تابع معمولی تو در تو

```js
method() {

    function test() {

        console.log(this);

    }

}
```

در این حالت معمولاً `this` چیزی نیست که انتظار دارید.

---

# 49.19 - نکات حرفه‌ای

* همیشه قبل از استفاده از `this`، نحوه فراخوانی تابع را بررسی کن.
* برای Callbackها از `bind` یا Arrow Function استفاده کن.
* در کلاس‌ها اگر قرار است متد را جداگانه ارسال کنی، `bind` را فراموش نکن.
* از Arrow Function زمانی استفاده کن که می‌خواهی `this` محیط بیرونی حفظ شود.
* برای جلوگیری از خطا، پروژه‌های Node.js را در Strict Mode اجرا کن.
* اگر نیازی به `this` نداری، از آن استفاده نکن و توابع را مستقل طراحی کن.

---

# 49.20 - تمرین

## تمرین 1

کلاسی به نام `Student` بساز که دارای متد `introduce()` باشد و با استفاده از `this.name` نام دانش‌آموز را نمایش دهد.

---

## تمرین 2

یک شیء `Car` ایجاد کن که متد `start()` داشته باشد. سپس متد را در یک متغیر ذخیره کن و بررسی کن چرا `this` از بین می‌رود. با `bind` مشکل را حل کن.

---

## تمرین 3

یک کلاس `Counter` بنویس که دارای متد `increment()` باشد. سپس آن را به صورت Callback ارسال کن و با استفاده از Arrow Function یا `bind` مشکل را برطرف کن.

---

## تمرین 4

یک تابع `showPrice()` بنویس که با استفاده از `call` و `apply` قیمت محصولات مختلف را نمایش دهد.

---

# 49.21 - پاسخ تشریحی

## پاسخ تمرین 1

```js
class Student {
    constructor(name) {
        this.name = name;
    }

    introduce() {
        console.log(`سلام، من ${this.name} هستم.`);
    }
}

const student = new Student("Ali");
student.introduce();
```

**توضیح:**
زمانی که متد از طریق شیء فراخوانی می‌شود، `this` به همان نمونه کلاس اشاره می‌کند.

---

## پاسخ تمرین 2

```js
const car = {
    brand: "BMW",

    start() {
        console.log(`${this.brand} started`);
    }
};

const fn = car.start;

// fn(); // خطا یا undefined

const fixed = car.start.bind(car);

fixed();
```

**توضیح:**
با `bind` مقدار `this` برای همیشه به شیء `car` متصل می‌شود.

---

## پاسخ تمرین 3

```js
class Counter {
    constructor() {
        this.count = 0;
    }

    increment = () => {
        this.count++;
    };
}

const counter = new Counter();

const callback = counter.increment;

callback();

console.log(counter.count);
```

**توضیح:**
Arrow Function مقدار `this` را از کلاس می‌گیرد و هنگام ارسال به‌عنوان Callback نیز آن را حفظ می‌کند.

---

## پاسخ تمرین 4

```js
function showPrice(currency) {
    console.log(`${this.name}: ${this.price} ${currency}`);
}

const product1 = {
    name: "Keyboard",
    price: 120
};

const product2 = {
    name: "Monitor",
    price: 450
};

showPrice.call(product1, "USD");
showPrice.apply(product2, ["EUR"]);
```

**توضیح:**
`call` آرگومان‌ها را به‌صورت جداگانه دریافت می‌کند، اما `apply` آن‌ها را در قالب یک آرایه می‌گیرد.

---

# 49.22 - مینی‌پروژه

## ساخت یک Logger حرفه‌ای

در این پروژه یک کلاس `Logger` طراحی می‌کنیم که پیام‌ها را همراه با نام برنامه و زمان ثبت نمایش دهد. سپس متد ثبت لاگ را به‌عنوان Callback نیز استفاده می‌کنیم و با کمک `bind` از از دست رفتن `this` جلوگیری می‌کنیم.

```js
class Logger {
    constructor(appName) {
        this.appName = appName;
    }

    log(message) {
        const time = new Date().toLocaleTimeString();

        console.log(`[${this.appName}] [${time}] ${message}`);
    }
}

const logger = new Logger("Node App");

logger.log("Server started");

const callback = logger.log.bind(logger);

callback("Database connected");
```

### ایده‌هایی برای توسعه پروژه

* ذخیره لاگ‌ها در فایل با ماژول `fs`
* اضافه کردن سطح لاگ (`info`، `warn`، `error`)
* رنگی کردن خروجی ترمینال
* ثبت تاریخ کامل و شناسه درخواست
* ساخت Logger به‌صورت Singleton
* ارسال لاگ‌ها به یک سرویس مانیتورینگ

---

# جمع‌بندی

`this` یکی از مهم‌ترین مفاهیم JavaScript است و درک صحیح آن برای نوشتن کدهای حرفه‌ای در Node.js ضروری است. مهم‌ترین نکته این است که مقدار `this` به **نحوه فراخوانی تابع** بستگی دارد، نه محل تعریف آن. با شناخت رفتار `this` در توابع معمولی، متدهای اشیاء، کلاس‌ها، Arrow Functionها و همچنین ابزارهایی مانند `bind`، `call` و `apply` می‌توانید از بسیاری از خطاهای رایج جلوگیری کرده و کدهایی خواناتر و قابل‌اعتمادتر بنویسید.
