# فصل 92 - Upload File

تقریباً تمام برنامه‌های تحت وب به نوعی با آپلود فایل سروکار دارند.

برای مثال:

* آپلود تصویر پروفایل
* ارسال مدارک
* آپلود فایل PDF
* ارسال ویدئو
* ارسال فایل‌های صوتی
* بارگذاری تصاویر محصولات فروشگاه
* ذخیره فایل‌های پروژه

در Node.js نیز آپلود فایل یکی از رایج‌ترین قابلیت‌هایی است که در اکثر پروژه‌های واقعی پیاده‌سازی می‌شود.

در این فصل یاد می‌گیریم چگونه فایل‌ها را از مرورگر دریافت کنیم، آن‌ها را اعتبارسنجی کنیم، ذخیره کنیم و از بروز مشکلات امنیتی جلوگیری کنیم.

---

# چرا آپلود فایل با Body معمولی انجام نمی‌شود؟

# راه‌اندازی اولیه

```javascript
const express = require("express");
const multer = require("multer");

const app = express();

const upload = multer({
    dest: "uploads/"
});

app.listen(3000);
```

# ذخیره با نام دلخواه

به جای `dest` از `diskStorage` استفاده می‌کنیم.

```javascript
const storage = multer.diskStorage({

    destination(req, file, cb) {

        cb(null, "uploads/");
    },

    filename(req, file, cb) {

        cb(null, Date.now() + "-" + file.originalname);

    }

});

const upload = multer({ storage });
```

# بررسی نوع فایل

```javascript
const upload = multer({

    storage,

    fileFilter(req, file, cb) {

        if (!file.mimetype.startsWith("image/")) {

            return cb(new Error("Only images"));

        }

        cb(null, true);

    }

});
```

# اشتباهات رایج

### اعتماد به پسوند فایل

بررسی فقط `.jpg` یا `.png` کافی نیست؛ نوع فایل (`mimetype`) را نیز بررسی کنید.

---

### نداشتن محدودیت حجم

اگر محدودیت تعیین نشود، کاربران می‌توانند فایل‌های بسیار بزرگ ارسال کنند و منابع سرور را مصرف کنند.

---

### استفاده از نام اصلی فایل

استفاده مستقیم از `originalname` می‌تواند باعث تداخل نام فایل‌ها یا مشکلات امنیتی شود.

---

### ذخیره فایل در مسیر عمومی بدون اعتبارسنجی

فایل‌های تأییدنشده را مستقیماً در مسیر قابل دسترس عموم قرار ندهید.

---

### فراموش کردن حذف فایل‌های بلااستفاده

اگر هنگام حذف رکوردهای پایگاه داده فایل‌ها پاک نشوند، فضای ذخیره‌سازی به‌مرور پر خواهد شد.

---

# نکات حرفه‌ای

* برای نام فایل‌ها از UUID یا Timestamp استفاده کنید.
* نوع فایل، اندازه و تعداد فایل‌ها را قبل از ذخیره بررسی کنید.
* تصاویر را قبل از ذخیره فشرده یا Resize کنید.
* برای فایل‌های حجیم از Streaming استفاده کنید.
* در پروژه‌های Production فایل‌ها را در سرویس‌های ابری مانند AWS S3 یا Cloudinary ذخیره کنید.
* مسیر ذخیره فایل را از ورودی کاربر دریافت نکنید.
* فایل‌های موقت را پس از پایان پردازش حذف کنید.

## پاسخ تمرین ۴

```javascript

    dest: "uploads/",

    fileFilter(req, file, cb) {

            "image/jpeg"

    }

});
```

# مینی‌پروژه

## سیستم آپلود تصویر پروفایل

### هدف

پیاده‌سازی سیستمی که کاربران بتوانند تصویر پروفایل خود را آپلود کنند، فایل اعتبارسنجی شود، با نامی یکتا ذخیره گردد و آدرس آن برای استفاده در پروفایل کاربر بازگردانده شود.

---

## امکانات پروژه

* آپلود یک تصویر پروفایل
* اعتبارسنجی نوع فایل (PNG و JPEG)
* محدودیت حجم فایل (۲ مگابایت)
* تولید نام یکتا برای فایل
* ذخیره فایل در پوشه `uploads`
* ارائه فایل از طریق `express.static`
* حذف تصویر قبلی هنگام بارگذاری تصویر جدید
* بازگرداندن URL تصویر ذخیره‌شده

## اهداف آموزشی

پس از پایان این پروژه، خواهید توانست:

* با `multer` فایل‌ها را در Express دریافت و مدیریت کنید.
* انواع مختلف فایل و محدودیت‌های آن‌ها را اعتبارسنجی کنید.
* فایل‌ها را با نامی یکتا ذخیره و در اختیار کاربران قرار دهید.
* فایل‌های اضافی را حذف و فضای ذخیره‌سازی را مدیریت کنید.
* زیرساخت لازم برای آپلود فایل در پروژه‌های واقعی و مهاجرت به سرویس‌های ذخیره‌سازی ابری را پیاده‌سازی کنید.
