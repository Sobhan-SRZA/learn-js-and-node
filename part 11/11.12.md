# فصل 93 - Logging

هر برنامه‌ای که در محیط واقعی اجرا می‌شود، دیر یا زود با مشکلات مختلفی روبه‌رو خواهد شد.

مثلاً:

* چرا سرور Crash کرده است؟
* چه کسی وارد سیستم شده است؟
* چه زمانی یک خطا رخ داده است؟
* کدام API بیشترین استفاده را دارد؟
* چرا درخواست کاربر با خطای 500 مواجه شده است؟

اگر هیچ اطلاعاتی از اتفاقات برنامه ثبت نشود، پیدا کردن دلیل مشکلات تقریباً غیرممکن خواهد بود.

اینجاست که **Logging** اهمیت پیدا می‌کند.

Logging یکی از مهم‌ترین بخش‌های توسعه نرم‌افزار است و تقریباً تمام برنامه‌های حرفه‌ای از سیستم ثبت لاگ استفاده می‌کنند.

در این فصل یاد می‌گیریم چگونه لاگ‌های مناسب تولید کنیم، آن‌ها را مدیریت کنیم و از ابزارهای حرفه‌ای برای ثبت و تحلیل آن‌ها استفاده کنیم.

---

# Logging چیست؟

Logging یعنی ثبت اطلاعات مربوط به اجرای برنامه.

این اطلاعات می‌توانند شامل موارد زیر باشند:

* درخواست‌های کاربران
* خطاها
* هشدارها
* اطلاعات سیستم
* عملیات کاربران
* وضعیت سرویس‌ها

---

# چرا Logging مهم است؟

فرض کنید برنامه شما روی یک سرور در حال اجراست.

کاربر گزارش می‌دهد:

```text
سایت باز نمی‌شود.
```

اگر هیچ Logی نداشته باشید:

```text
دلیل مشکل مشخص نیست.
```

اما اگر Logging فعال باشد:

```text
[ERROR]

Database Connection Failed
```

دلیل مشکل به راحتی مشخص خواهد شد.

---

# مشکل console.log

برای آموزش مناسب است.

* مدیریت مناسبی ندارد.

به همین دلیل از Loggerهای حرفه‌ای استفاده می‌شود.

# Winston

یکی از معروف‌ترین Loggerهای Node.js

نصب:

```bash
npm install winston
```

---

# ساخت Logger

```javascript
const winston = require("winston");

const logger = winston.createLogger({

    level: "info",

    transports: [

        new winston.transports.Console()

    ]

});
```

---

# ثبت Log

```javascript
logger.info("Server Started");
```

---

```javascript
logger.error("Database Error");
```

---

```javascript
logger.warn("Token Expired");
```

---

# ذخیره در فایل

```javascript
const logger = winston.createLogger({

    transports: [

        new winston.transports.File({

            filename: "app.log"

        })

    ]

});
```

---

# چند Transport

```javascript
transports: [

new winston.transports.Console(),

new winston.transports.File({

filename:"app.log"

})

]
```

---

# قالب Log

```javascript
const { combine, timestamp, printf } = winston.format;

const format = printf(({ level, message, timestamp }) => {

    return `${timestamp} ${level}: ${message}`;

});
```

---

# اضافه کردن Timestamp

```javascript
format: combine(

    timestamp(),

    format

)
```

---

# لاگ گرفتن از Error

```javascript
try {

    throw new Error("Something Wrong");

catch(err){

    logger.error(err.message);
```

# اشتباهات رایج

### استفاده بیش از حد از `console.log`

در پروژه‌های واقعی بهتر است از Loggerهای حرفه‌ای مانند Winston یا Pino استفاده شود.

---

### ثبت اطلاعات حساس

هرگز رمز عبور، Token، Session ID یا اطلاعات بانکی را در Log ذخیره نکنید.

---

### نداشتن سطح‌بندی

اگر همه پیام‌ها با یک سطح ثبت شوند، تشخیص خطاهای مهم بسیار دشوار خواهد شد.

---

### ثبت نکردن زمان

بدون Timestamp بررسی ترتیب رخدادها تقریباً غیرممکن است.

---

### رشد بی‌نهایت فایل‌های Log

در صورت استفاده نکردن از Log Rotation، فضای دیسک ممکن است پر شود.

---

# نکات حرفه‌ای

* برای هر محیط (Development و Production) سطح Log متفاوتی تنظیم کنید.
* از Structured Logging (مانند JSON) برای سیستم‌های بزرگ استفاده کنید.
* شناسه درخواست (Request ID) را در Logها ثبت کنید تا بتوان مسیر هر درخواست را دنبال کرد.
* Logهای امنیتی را از Logهای عمومی جدا نگهداری کنید.
* برای خطاها علاوه بر پیام، Stack Trace را نیز ثبت کنید.
* از Log Rotation و آرشیو فایل‌های قدیمی استفاده کنید.
* در پروژه‌های بزرگ از ابزارهایی مانند ELK Stack، Grafana Loki یا Graylog برای تحلیل Logها استفاده کنید.

---

### تمرین ۲

تمام Logها را در فایل `app.log` نیز ذخیره کنید.

---

### تمرین ۳

از Morgan برای ثبت درخواست‌های HTTP استفاده کنید.

---

### تمرین ۴

در یک بلوک `try...catch`، خطا را با `logger.error()` ثبت کنید.

---

### تمرین ۵

Logger را طوری تنظیم کنید که همراه هر پیام، زمان ثبت نیز نمایش داده شود.

# پاسخ تشریحی

## پاسخ تمرین ۱

```javascript
const winston = require("winston");

const logger = winston.createLogger({

    level: "info",

    transports: [

        new winston.transports.Console()

    ]

});

logger.info("Application Started");

logger.error("Database Error");
```

---

## پاسخ تمرین ۲

```javascript
const logger = winston.createLogger({

    transports: [

        new winston.transports.Console(),

        new winston.transports.File({

            filename: "app.log"

        })

    ]

});
```

---

## پاسخ تمرین ۳

```javascript
const express = require("express");
const morgan = require("morgan");

const app = express();

app.use(morgan("dev"));
```

---

## پاسخ تمرین ۴

```javascript
try {

    throw new Error("Unexpected Error");

} catch (err) {

    logger.error(err.stack);

}
```

---

## پاسخ تمرین ۵

```javascript
const { combine, timestamp, printf } = winston.format;

const logger = winston.createLogger({

    format: combine(

        timestamp(),

        printf(({ timestamp, level, message }) => {

            return `${timestamp} ${level}: ${message}`;

        })

    ),

    transports: [

        new winston.transports.Console()

    ]

});
```

# مینی‌پروژه

## سیستم Logging حرفه‌ای برای API

### هدف

ساخت یک سیستم Logging برای یک API که تمام درخواست‌ها، خطاها و رویدادهای مهم را ثبت کند و امکان بررسی مشکلات سیستم را فراهم آورد.

---

## امکانات پروژه

* ثبت لاگ درخواست‌های HTTP با Morgan
* ثبت Logهای برنامه با Winston
* ذخیره Logها در Console و فایل
* ثبت Timestamp در تمام Logها
* ثبت سطح Log (`INFO`، `WARN`، `ERROR`)
* ثبت خطاهای کنترل‌نشده
* ثبت زمان شروع و پایان اجرای سرور
* جداسازی فایل Log خطاها از Logهای عمومی

---
