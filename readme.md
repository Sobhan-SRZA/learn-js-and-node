# Learn JavaScript for Node.js

> جامع‌ترین آموزش JavaScript مخصوص Node.js به زبان فارسی

اگر هدفت یادگیری Node.js است، لازم نیست تمام JavaScript مرورگر را یاد بگیری.

در این آموزش فقط چیزهایی را یاد می‌گیری که در دنیای واقعی Node.js، Express، NestJS، Fastify، Discord Bot، Telegram Bot، REST API، WebSocket، CLI Tools و Backend Development استفاده می‌شوند.

---

# این آموزش برای چه کسانی است؟

- کسانی که هیچ تجربه‌ای از JavaScript ندارند.
- کسانی که می‌خواهند Backend Developer شوند.
- کسانی که قصد یادگیری Node.js دارند.
- کسانی که می‌خواهند ربات Discord یا Telegram بنویسند.
- کسانی که می‌خواهند REST API توسعه دهند.
- کسانی که قصد ورود به بازار کار را دارند.

---
