قبل از این فصل یاد گرفتید که چگونه متغیر تعریف کنید، انواع داده را بشناسید، عملگرها را به‌کار ببرید و از کاربر ورودی دریافت کنید.

اما تا اینجا تمام برنامه‌هایی که نوشته‌ایم، از ابتدا تا انتها دقیقاً یک مسیر مشخص را طی می‌کردند. مهم نیست کاربر چه مقداری وارد کند، برنامه همیشه تمام خطوط را اجرا می‌کرد.

برنامه‌های واقعی این‌گونه نیستند.

یک برنامه باید بتواند **تصمیم بگیرد**.

مثلاً:

* اگر رمز عبور درست بود، اجازه ورود بدهد.
* اگر سن کاربر کمتر از ۱۸ سال بود، ثبت‌نام را محدود کند.
* اگر موجودی حساب کافی نبود، عملیات خرید را متوقف کند.
* اگر کاربر مدیر بود، بخش مدیریت را نمایش دهد.

به این فرآیند **کنترل جریان برنامه (Control Flow)** گفته می‌شود و مهم‌ترین ابزار برای انجام آن، **شرط‌ها (Conditional Statements)** هستند.

در این فصل تمام ساختارهای شرطی JavaScript را یاد می‌گیرید که تقریباً در تمام پروژه‌های Node.js از آن‌ها استفاده خواهید کرد.

---

# فصل 14 - شرط‌ها (Conditional Statements)

شرط‌ها به برنامه اجازه می‌دهند که بر اساس یک **شرط (Condition)** تصمیم بگیرد.

اگر شرط برقرار باشد، یک بخش از کد اجرا می‌شود و در غیر این صورت، بخش دیگری اجرا خواهد شد.

در JavaScript پنج ساختار اصلی برای تصمیم‌گیری وجود دارد:

* `if`
* `else`
* `else if`
* Nested if
* `switch`

---

# شرط (Condition) چیست؟

شرط عبارتی است که نتیجه آن همیشه یکی از دو مقدار زیر است:

```text
true
```

یا

```text
false
```

مثال:

```javascript
10 > 5
```

نتیجه:

```text
true
```

---

```javascript
20 < 15
```

نتیجه:

```text
false
```

---

تمام شرط‌ها در نهایت به یک مقدار Boolean تبدیل می‌شوند.

---

# if

ساده‌ترین ساختار شرطی JavaScript، دستور `if` است.

ساختار:

```javascript
if (condition) {

    // Code

}
```

اگر شرط برابر `true` باشد، کد داخل بلوک اجرا می‌شود.

---

مثال:

```javascript
const age = 20;

if (age >= 18) {
    console.log("Access Granted");
}
```

خروجی:

```text
Access Granted
```

---

اگر شرط برقرار نباشد:

```javascript
const age = 15;

if (age >= 18) {
    console.log("Access Granted");
}
```

خروجی:

```text
(هیچ خروجی ندارد)
```

---

# استفاده از چند شرط

```javascript
const score = 85;

if (score >= 50) {
    console.log("Passed");
}

if (score >= 80) {
    console.log("Excellent");
}
```

خروجی:

```text
Passed
Excellent
```

هر شرط مستقل از شرط دیگر بررسی می‌شود.

---

# استفاده از Boolean

```javascript
const isAdmin = true;

if (isAdmin) {
    console.log("Welcome Admin");
}
```

---

همچنین می‌توان نوشت:

```javascript
if (isAdmin === true)
```

اما این روش اضافی است و معمولاً توصیه نمی‌شود.

---

# else

اگر شرط برقرار نباشد، می‌توانیم از `else` استفاده کنیم.

ساختار:

```javascript
if (condition) {

}
else {

}
```

---

مثال:

```javascript
const age = 17;

if (age >= 18) {
    console.log("Adult");
}
else {
    console.log("Minor");
}
```

خروجی:

```text
Minor
```

---

مثال دیگر:

```javascript
const loggedIn = false;

if (loggedIn) {
    console.log("Dashboard");
}
else {
    console.log("Login Page");
}
```

---

# else if

گاهی فقط دو حالت وجود ندارد.

مثلاً نمره دانش‌آموز:

* مردود
* قبول
* عالی

برای این شرایط از `else if` استفاده می‌کنیم.

ساختار:

```javascript
if (condition1) {

}
else if (condition2) {

}
else {

}
```

---

مثال:

```javascript
const score = 92;

if (score >= 90) {

    console.log("Excellent");

}
else if (score >= 70) {

    console.log("Good");

}
else if (score >= 50) {

    console.log("Passed");

}
else {

    console.log("Failed");

}
```

خروجی:

```text
Excellent
```

---

نکته بسیار مهم:

به محض برقرار شدن اولین شرط، بقیه شرط‌ها بررسی نمی‌شوند.

---

مثال:

```javascript
const number = 15;

if (number > 0) {

    console.log("Positive");

}
else if (number > 10) {

    console.log("Greater than 10");

}
```

خروجی:

```text
Positive
```

اگرچه عدد از ۱۰ نیز بزرگ‌تر است، اما چون اولین شرط برقرار شده است، شرط دوم بررسی نمی‌شود.

---

# ترتیب شرط‌ها

ترتیب نوشتن شرط‌ها بسیار مهم است.

مثال اشتباه:

```javascript
const score = 95;

if (score >= 50) {

    console.log("Passed");

}
else if (score >= 90) {

    console.log("Excellent");

}
```

خروجی:

```text
Passed
```

در حالی که انتظار داریم:

```text
Excellent
```

---

روش صحیح:

```javascript
if (score >= 90) {

    console.log("Excellent");

}
else if (score >= 50) {

    console.log("Passed");

}
```

---

# شرط‌های تو در تو (Nested if)

گاهی لازم است داخل یک شرط، شرط دیگری بررسی شود.

مثال:

```javascript
const age = 22;
const hasLicense = true;

if (age >= 18) {

    if (hasLicense) {

        console.log("Can Drive");

    }

}
```

---

مثال کامل‌تر:

```javascript
const username = "Sobhan";
const password = "123456";

if (username === "Sobhan") {

    if (password === "123456") {

        console.log("Login Successful");

    }
    else {

        console.log("Wrong Password");

    }

}
else {

    console.log("User Not Found");

}
```

---

اگر تعداد Nestedها زیاد شود، خواندن کد سخت خواهد شد.

در فصل‌های آینده یاد می‌گیریم چگونه این کدها را ساده‌تر بنویسیم.

---

# استفاده از عملگرهای منطقی

گاهی به جای Nested if می‌توان از عملگرهای منطقی استفاده کرد.

مثال:

```javascript
const age = 20;
const hasLicense = true;

if (age >= 18 && hasLicense) {

    console.log("Can Drive");

}
```

این روش معمولاً خواناتر است.

---

# Switch

اگر مقدار یک متغیر را با چند مقدار مشخص مقایسه کنیم، استفاده از `switch` مناسب‌تر است.

ساختار:

```javascript
switch (value) {

    case ...:
        break;

    default:

}
```

---

مثال:

```javascript
const day = 3;

switch (day) {

    case 1:
        console.log("Saturday");
        break;

    case 2:
        console.log("Sunday");
        break;

    case 3:
        console.log("Monday");
        break;

    default:
        console.log("Unknown");

}
```

خروجی:

```text
Monday
```

---

# نقش break

اگر `break` را فراموش کنیم:

```javascript
const day = 1;

switch (day) {

    case 1:
        console.log("Saturday");

    case 2:
        console.log("Sunday");

}
```

خروجی:

```text
Saturday
Sunday
```

زیرا اجرای برنامه به Case بعدی نیز ادامه پیدا می‌کند.

---

# default

اگر هیچ Case برقرار نباشد:

```javascript
const color = "Blue";

switch (color) {

    case "Red":
        console.log("Stop");
        break;

    case "Green":
        console.log("Go");
        break;

    default:
        console.log("Unknown Color");

}
```

---

# if یا switch؟

از `if` زمانی استفاده کنید که:

* مقایسه‌های منطقی انجام می‌دهید.
* از `<`، `>`، `<=`، `>=` استفاده می‌کنید.
* شرط‌های پیچیده دارید.

از `switch` زمانی استفاده کنید که:

* فقط یک متغیر را با چند مقدار ثابت مقایسه می‌کنید.

---

# Truthy و Falsy در شرط‌ها

همه شرط‌ها لزوماً Boolean نیستند.

مثال:

```javascript
const username = "";

if (username) {

    console.log("Has Username");

}
else {

    console.log("Username is Empty");

}
```

چون رشته خالی Falsy است، خروجی:

```text
Username is Empty
```

خواهد بود.

---

# شرط‌های ترکیبی

```javascript
const age = 25;
const isVerified = true;

if (age >= 18 && isVerified) {

    console.log("Access Granted");

}
```

---

```javascript
const role = "admin";

if (role === "admin" || role === "owner") {

    console.log("Admin Panel");

}
```

---

# اشتباهات رایج

### ❌ استفاده از `=` به جای `===`

```javascript
if (age = 18)
```

این کد مقدار را تغییر می‌دهد، نه اینکه مقایسه کند.

---

### ❌ استفاده از `==`

در پروژه‌های حرفه‌ای همیشه از `===` و `!==` استفاده کنید.

---

### ❌ فراموش کردن آکولاد `{}`

حتی اگر فقط یک خط کد دارید، همیشه از آکولاد استفاده کنید.

---

### ❌ ترتیب اشتباه `else if`

همیشه شرط‌های خاص‌تر را قبل از شرط‌های کلی‌تر بنویسید.

---

### ❌ فراموش کردن `break` در `switch`

باعث اجرای Caseهای بعدی می‌شود.

---

### ❌ استفاده بیش از حد از Nested if

اگر بتوان با عملگرهای منطقی همان نتیجه را گرفت، کد خواناتر خواهد بود.

---

# نکات حرفه‌ای

* همیشه از `===` و `!==` استفاده کنید.
* شرط‌های ساده را کوتاه و خوانا بنویسید.
* از Nestedهای عمیق خودداری کنید.
* اگر بیش از سه یا چهار `else if` دارید و فقط یک مقدار را مقایسه می‌کنید، به استفاده از `switch` فکر کنید.
* ترتیب شرط‌ها را از خاص‌ترین به عمومی‌ترین بنویسید.
* نام متغیرهای Boolean را به گونه‌ای انتخاب کنید که در شرط‌ها طبیعی خوانده شوند؛ مانند `isAdmin`، `hasPermission` و `isLoggedIn`.

* ورود انجام شده یا خیر

# مینی‌پروژه

## سیستم ورود کاربران (Login System CLI)

در این پروژه یک سیستم ورود ساده در محیط ترمینال می‌سازید.

### مراحل پروژه

1. پوشه‌ای با نام `login-system-cli` ایجاد کنید.
2. فایل `index.js` را بسازید.
3. با استفاده از `readline` اطلاعات زیر را دریافت کنید:

   * نام کاربری
   * رمز عبور
4. اطلاعات را با مقادیر فرضی مقایسه کنید.
5. اگر اطلاعات صحیح بود:

   * پیام خوش‌آمدگویی نمایش دهید.
   * نقش کاربر (`admin` یا `user`) را با `switch` بررسی کنید.
6. اگر اطلاعات اشتباه بود، پیام خطا نمایش دهید.
7. اگر کاربر مدیر بود، پیام جداگانه‌ای برای دسترسی به پنل مدیریت نمایش دهید.

نمونه خروجی:

```text
==============================
Login System

Username: Sobhan
Password: ********

Login Successful

Role: admin
Welcome to Admin Panel
==============================
```

نمونه خروجی ناموفق:

```text
==============================
Login Failed

Invalid Username or Password
==============================
```

### هدف پروژه

در پایان این مینی‌پروژه، می‌توانید با استفاده از `if`، `else`، `else if`، شرط‌های تو در تو، عملگرهای منطقی و `switch`، مسیر اجرای برنامه را کنترل کنید. این مفاهیم پایه‌ی توسعه تقریباً تمام برنامه‌های واقعی Node.js هستند؛ از سیستم‌های احراز هویت گرفته تا APIها، پنل‌های مدیریتی، ربات‌ها و برنامه‌های خط فرمان.

این فصل یکی از مهم‌ترین فصل‌های کل دوره است. از اینجا به بعد تقریباً هیچ برنامه‌ای بدون استفاده از شرط‌ها نوشته نخواهد شد. قبل از ورود به فصل بعد، تلاش کنید تمام تمرین‌ها و مینی‌پروژه را بدون مراجعه به پاسخ‌ها حل کنید؛ این کار باعث می‌شود مفهوم کنترل جریان برنامه کاملاً برای شما جا بیفتد.
