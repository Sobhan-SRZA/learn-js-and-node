قبل از این فصل یاد گرفتید که برنامه چگونه تصمیم بگیرد و مسیرهای مختلفی را اجرا کند. اما هنوز یک مشکل بزرگ وجود دارد.

فرض کنید بخواهید عبارت **"Hello World"** را ۱۰۰ بار چاپ کنید.

آیا باید ۱۰۰ بار بنویسید؟

```javascript
console.log("Hello World");
console.log("Hello World");
console.log("Hello World");
// ...
```

قطعاً خیر.

یا فرض کنید بخواهید تمام اعداد بین ۱ تا ۱۰۰۰ را نمایش دهید، فایل‌های یک پوشه را پردازش کنید، کاربران یک پایگاه داده را بررسی کنید یا روی تمام پیام‌های یک ربات Discord عملیات انجام دهید.

در چنین شرایطی از **حلقه‌ها (Loops)** استفاده می‌کنیم.

حلقه‌ها به برنامه اجازه می‌دهند یک یا چند دستور را تا زمانی که لازم است، بارها اجرا کند.

تقریباً تمام پروژه‌های Node.js از حلقه‌ها استفاده می‌کنند؛ از خواندن فایل‌ها گرفته تا پردازش درخواست‌های API، کار با دیتابیس، پردازش آرایه‌ها و ساخت ابزارهای خط فرمان (CLI).

# فصل 15 - حلقه‌ها (Loops)

حلقه‌ها یکی از مهم‌ترین مفاهیم برنامه‌نویسی هستند.

Loop یعنی:

> اجرای چندباره‌ی یک یا چند دستور تا زمانی که شرط مشخصی برقرار باشد.

بدون حلقه‌ها، بسیاری از برنامه‌های امروزی عملاً قابل پیاده‌سازی نیستند.

---

# چرا به حلقه نیاز داریم؟

فرض کنید می‌خواهیم اعداد 1 تا 5 را نمایش دهیم.

بدون حلقه:

```javascript
console.log(1);
console.log(2);
console.log(3);
console.log(4);
console.log(5);
```

این روش فقط برای چند عدد مناسب است.

اگر بخواهیم تا 1000 چاپ کنیم چه؟

به جای نوشتن هزار خط کد، از حلقه استفاده می‌کنیم.

# ساختار کلی حلقه

```text
  │

 ▼
اجرای کد
 │
 ▼

 │
 └────────────► بررسی شرط
```

# حلقه for

پرکاربردترین حلقه JavaScript، حلقه `for` است.

ساختار:

```javascript
for (initialization; condition; update) {

    // Code

}
```

---

مثال:

```javascript
for (let i = 1; i <= 5; i++) {

    console.log(i);

}
```

```text
2
3
4
5
```

```javascript
let i = 1;
```

فقط یک بار اجرا می‌شود.

```javascript
i <= 5
```

قبل از هر تکرار بررسی می‌شود.

---

```javascript
i++
```

بعد از پایان هر تکرار اجرا می‌شود.

# while

گاهی تعداد دفعات اجرای حلقه از قبل مشخص نیست.

در این شرایط معمولاً از `while` استفاده می‌کنیم.

ساختار:

```javascript
while (condition) {

    // Code

}
```

---

مثال:

```javascript
let i = 1;

while (i <= 5) {

    console.log(i);

    i++;

}
```

---

مثال شمارش معکوس:

```javascript
let count = 5;

while (count > 0) {

    console.log(count);

    count--;

}
```

---

# do...while

این حلقه حداقل **یک بار** اجرا می‌شود.

سپس شرط بررسی خواهد شد.

ساختار:

```javascript
do {

    // Code

}
while (condition);
```

---

مثال:

```javascript
let number = 1;

do {

    console.log(number);

    number++;

}
while (number <= 5);
```

---

تفاوت با while:

```javascript
let number = 10;

while (number < 5) {

    console.log(number);

}
```

هیچ خروجی ندارد.

اما:

```javascript
let number = 10;

do {

    console.log(number);

}
while (number < 5);
```

خروجی:

```text
10
```

زیرا یک بار اجرا شده است.

---

# حلقه for...of

این حلقه برای پیمایش داده‌های قابل تکرار (Iterable) استفاده می‌شود.

در فصل آرایه‌ها بیشتر با آن کار خواهیم کرد.

مثال:

```javascript
const text = "Node";

for (const letter of text) {

    console.log(letter);

}
```

خروجی:

```text
N
o
d
e
```

---

مثال دیگر:

```javascript
const numbers = [10, 20, 30];

for (const number of numbers) {

    console.log(number);

}
```

---

# حلقه for...in

این حلقه برای پیمایش کلیدهای یک شیء (Object) استفاده می‌شود.

در فصل Objectها به طور کامل آن را بررسی خواهیم کرد.

مثال:

```javascript
const user = {

    name: "Sobhan",
    age: 20,
    city: "Tehran"

};

for (const key in user) {

    console.log(key);

}
```

خروجی:

```text
name
age
city
```

اگر مقدار را نیز بخواهیم:

```javascript
const user = {

    name: "Sobhan",
    age: 20

};

for (const key in user) {

    console.log(`${key}: ${user[key]}`);

}
```

# break

برای خروج فوری از حلقه استفاده می‌شود.

```javascript
for (let i = 1; i <= 10; i++) {

    if (i === 5) {

        break;

    }

    console.log(i);

}
```

خروجی:

```text
1
2
3
4
```

# continue

برای رد شدن از یک تکرار استفاده می‌شود.

```javascript
for (let i = 1; i <= 5; i++) {

    if (i === 3) {

        continue;

    }

    console.log(i);

}
```

خروجی:

```text
1
2
4
5
```

# حلقه بی‌نهایت (Infinite Loop)

اگر شرط هیچ‌وقت `false` نشود، برنامه هرگز متوقف نمی‌شود.

مثال خطرناک:

```javascript
while (true) {

    console.log("Running...");

}
```

یا:

```javascript
let i = 1;

while (i <= 10) {

    console.log(i);

}
```

در این مثال مقدار `i` هرگز تغییر نمی‌کند.

---

# انتخاب حلقه مناسب

| حلقه       | زمان استفاده                         |
| ---------- | ------------------------------------ |
| for        | تعداد تکرار مشخص است                 |
| while      | تعداد تکرار مشخص نیست                |
| do...while | حداقل یک بار باید اجرا شود           |
| for...of   | پیمایش آرایه، رشته و سایر Iterableها |
| for...in   | پیمایش کلیدهای Object                |

---

# کاربرد حلقه‌ها در Node.js

در پروژه‌های واقعی Node.js از حلقه‌ها برای کارهای زیر استفاده می‌شود:

* پردازش آرایه کاربران
* خواندن فایل‌ها
* پردازش داده‌های API
* بررسی پیام‌های ربات
* پیمایش پوشه‌ها
* ساخت ابزارهای CLI
* تولید گزارش‌ها
* اعتبارسنجی داده‌ها
* پردازش نتایج دیتابیس

---

# اشتباهات رایج

### ❌ فراموش کردن تغییر مقدار متغیر

```javascript
let i = 1;

while (i <= 5) {

    console.log(i);

}
```

این کد وارد حلقه بی‌نهایت می‌شود.

---

### ❌ استفاده از `<` به جای `<=`

همیشه بررسی کنید آخرین مقدار نیز باید چاپ شود یا خیر.

---

### ❌ تغییر متغیر اشتباه

```javascript
for (let i = 1; i <= 10; j++) {

}
```

متغیر `j` وجود ندارد و حلقه به درستی کار نخواهد کرد.

---

### ❌ استفاده از `for...in` برای آرایه‌ها

برای آرایه‌ها معمولاً از `for` یا `for...of` استفاده کنید.

---

### ❌ استفاده نادرست از `break`

گاهی به اشتباه به جای `continue` از `break` استفاده می‌شود و کل حلقه متوقف می‌شود.

---

### ❌ ایجاد حلقه‌های تو در تو بدون نیاز

Nested Loopها می‌توانند باعث کاهش کارایی و سخت شدن خواندن کد شوند.

---

# نکات حرفه‌ای

* اگر تعداد تکرار مشخص است، `for` بهترین انتخاب است.
* برای آرایه‌ها و رشته‌ها، `for...of` خواناتر از `for` است.
* برای Objectها از `for...in` استفاده کنید.
* قبل از اجرای حلقه مطمئن شوید شرط خروج وجود دارد.
* از نام‌های معنی‌دار برای متغیرهای شمارنده در صورت نیاز استفاده کنید؛ هرچند `i`، `j` و `k` برای حلقه‌های کوتاه رایج هستند.
* از ایجاد حلقه‌های تو در تو تا حد امکان خودداری کنید، مگر اینکه واقعاً به آن نیاز داشته باشید.
