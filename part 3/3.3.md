قبل از این فصل با انواع حلقه‌ها آشنا شدید و یاد گرفتید چگونه یک بخش از کد را بارها اجرا کنید.

اما همیشه لازم نیست یک حلقه تا انتها اجرا شود.

گاهی در میانه‌ی اجرای حلقه متوجه می‌شویم که دیگر نیازی به ادامه نیست.

مثلاً:

* عدد مورد نظر را پیدا کرده‌ایم.
* کاربر دستور خروج داده است.
* خطایی رخ داده و باید پردازش متوقف شود.
* می‌خواهیم فقط از اجرای یک تکرار خاص صرف‌نظر کنیم.

برای چنین شرایطی JavaScript ابزارهایی برای **کنترل اجرای حلقه (Loop Control)** در اختیار ما قرار می‌دهد.

در این فصل با سه دستور مهم آشنا می‌شوید:

* `break`
* `continue`
* `label`

این دستورات تقریباً در تمام پروژه‌های Node.js، از پردازش فایل‌ها و دیتابیس گرفته تا APIها و ابزارهای CLI، کاربرد دارند.

---

# فصل 16 - کنترل حلقه (Loop Control)

گاهی لازم نیست یک حلقه تمام تکرارهای خود را انجام دهد.

ممکن است بخواهیم:

* حلقه را زودتر متوقف کنیم.
* فقط از یک تکرار عبور کنیم.
* از چند حلقه تو در تو خارج شویم.

JavaScript برای این کار سه ابزار مهم دارد:

* `break`
* `continue`
* `label`

---

# دستور break

`break` اجرای حلقه را **کاملاً متوقف** می‌کند.

به محض رسیدن برنامه به `break`، حلقه پایان می‌یابد و اجرای برنامه از اولین خط بعد از حلقه ادامه پیدا می‌کند.

---

ساختار:

```javascript id="6jv9gh"
break;
```

---

مثال:

```javascript id="9r1mkt"
for (let i = 1; i <= 10; i++) {

    if (i === 5) {
        break;
    }

    console.log(i);

}
```

خروجی:

```text id="v8r4dy"
1
2
3
4
```

وقتی `i` برابر ۵ شد، حلقه متوقف شد.

---

# break در while

```javascript id="g3wz2q"
let number = 1;

while (true) {

    console.log(number);

    if (number === 5) {
        break;
    }

    number++;

}
```

خروجی:

```text id="q2kp6a"
1
2
3
4
5
```

در این مثال اگر `break` وجود نداشت، حلقه بی‌نهایت اجرا می‌شد.

---

# استفاده از break برای جستجو

فرض کنید دنبال یک عدد هستیم.

```javascript id="t8x7mw"
const numbers = [12, 8, 25, 30, 41];

for (const number of numbers) {

    if (number === 25) {

        console.log("Found!");

        break;

    }

}
```

به محض پیدا شدن عدد، دیگر نیازی به ادامه بررسی نیست.

---

# دستور continue

`continue` برخلاف `break` حلقه را متوقف نمی‌کند.

فقط **همان تکرار فعلی** را رد می‌کند و حلقه به تکرار بعدی می‌رود.

---

مثال:

```javascript id="h5yn8b"
for (let i = 1; i <= 5; i++) {

    if (i === 3) {
        continue;
    }

    console.log(i);

}
```

خروجی:

```text id="u7mj3c"
1
2
4
5
```

عدد ۳ چاپ نشد اما حلقه ادامه پیدا کرد.

---

# continue برای اعداد زوج

```javascript id="r4tp1d"
for (let i = 1; i <= 10; i++) {

    if (i % 2 !== 0) {
        continue;
    }

    console.log(i);

}
```

خروجی:

```text id="m8fd2p"
2
4
6
8
10
```

---

# continue در while

```javascript id="y9qv4n"
let i = 0;

while (i < 5) {

    i++;

    if (i === 3) {
        continue;
    }

    console.log(i);

}
```

خروجی:

```text id="g5h3xy"
1
2
4
5
```

---

# تفاوت break و continue

فرض کنید حلقه زیر را داریم.

```javascript id="v3tc6r"
for (let i = 1; i <= 5; i++) {

}
```

اگر:

```javascript id="n4jd2a"
break;
```

اجرا شود:

```text id="n9ut4e"
کل حلقه پایان می‌یابد.
```

اما اگر:

```javascript id="s6rz8w"
continue;
```

اجرا شود:

```text id="z2p7vm"
فقط همان تکرار رد می‌شود.
```

# دستور label

گاهی چند حلقه تو در تو داریم.

```javascript id="p2dh4m"
for (...) {

    for (...) {

    }

}
```

اگر داخل حلقه داخلی از `break` استفاده کنیم:

```javascript id="t6kw9j"
break;
```

فقط همان حلقه داخلی متوقف می‌شود.

---

مثال:

```javascript id="e1hz5q"
for (let i = 1; i <= 3; i++) {

    for (let j = 1; j <= 3; j++) {

        if (j === 2) {

            break;

        }

        console.log(i, j);

    }

}
```

خروجی:

```text id="o4kx9m"
1 1
2 1
3 1
```

---

اما اگر بخواهیم **هر دو حلقه** متوقف شوند چه؟

اینجاست که `label` کاربرد دارد.

---

# ساخت Label

```javascript id="f8cp3u"
outer:

for (...) {

}
```

---

مثال:

```javascript id="w3ng9v"
outer:

for (let i = 1; i <= 3; i++) {

    for (let j = 1; j <= 3; j++) {

        if (j === 2) {

            break outer;

        }

        console.log(i, j);

    }

}
```

خروجی:

```text id="j7rd5s"
1 1
```

به محض اجرای `break outer` هر دو حلقه پایان پیدا می‌کنند.

---

# continue با Label

همچنین می‌توان از:

```javascript id="d2zp6r"
continue outer;
```

استفاده کرد.

مثال:

```javascript id="g7qw1x"
outer:

for (let i = 1; i <= 3; i++) {

    for (let j = 1; j <= 3; j++) {

        if (j === 2) {

            continue outer;

        }

        console.log(i, j);

    }

}
```

خروجی:

```text id="s5xh8n"
1 1
2 1
3 1
```

در این حالت، حلقه داخلی متوقف نمی‌شود؛ بلکه اجرای آن تکرار از حلقه بیرونی ادامه پیدا می‌کند.

---

# آیا از Label زیاد استفاده می‌شود؟

خیر.

در پروژه‌های حرفه‌ای معمولاً استفاده از `label` بسیار کم است.

زیرا اغلب می‌توان با:

* تابع‌ها
* `return`
* ساختار مناسب برنامه
* تقسیم کد به بخش‌های کوچک‌تر

بدون نیاز به Label همان نتیجه را گرفت.

با این حال دانستن آن ضروری است.

---

# کاربردهای واقعی

در پروژه‌های Node.js از `break` و `continue` بسیار استفاده می‌شود.

نمونه‌ها:

* جستجوی یک کاربر در دیتابیس
* پیدا کردن فایل مورد نظر
* توقف پردازش هنگام وقوع خطا
* رد کردن داده‌های نامعتبر
* پردازش درخواست‌های API
* ساخت ابزارهای CLI
* خواندن فایل‌های بزرگ
* اعتبارسنجی داده‌ها

`label` معمولاً فقط در الگوریتم‌های خاص یا حلقه‌های چندلایه استفاده می‌شود.

---

# مقایسه دستورات

| دستور          | عملکرد               |
| -------------- | -------------------- |
| break          | پایان کامل حلقه      |
| continue       | رد کردن تکرار فعلی   |
| break label    | خروج از حلقه مشخص‌شده |
| continue label | ادامه حلقه مشخص‌شده   |

---

# اشتباهات رایج

### ❌ استفاده از break به جای continue

اگر فقط می‌خواهید از یک تکرار عبور کنید، از `continue` استفاده کنید.

---

### ❌ فراموش کردن افزایش شمارنده در while

```javascript id="u5v8pn"
let i = 0;

while (i < 10) {

    if (i === 5) {
        continue;
    }

}
```

این کد وارد حلقه بی‌نهایت می‌شود، زیرا مقدار `i` هرگز تغییر نمی‌کند.

---

### ❌ استفاده بیش از حد از Label

در بیشتر پروژه‌ها استفاده از `label` نشانه طراحی نامناسب کد است.

---

### ❌ نوشتن کد پیچیده بعد از continue

کدهای بعد از `continue` در همان تکرار هرگز اجرا نمی‌شوند.

---

### ❌ فراموش کردن اینکه break فقط نزدیک‌ترین حلقه را متوقف می‌کند

اگر Label استفاده نشده باشد، `break` فقط از همان حلقه‌ای که داخل آن قرار دارد خارج می‌شود.

---

# نکات حرفه‌ای

* از `break` زمانی استفاده کنید که دیگر ادامه پردازش هیچ فایده‌ای ندارد.
* از `continue` برای نادیده گرفتن داده‌های نامعتبر یا موارد غیرضروری استفاده کنید.
* تا حد امکان از `label` دوری کنید و کد را با استفاده از تابع‌ها ساده‌تر کنید.
* اگر احساس کردید به چندین `break` یا `continue` نیاز دارید، طراحی الگوریتم خود را دوباره بررسی کنید.
* همیشه مطمئن شوید که در حلقه‌های `while` و `do...while` شرط خروج وجود دارد.

## تمرین ۱۱

---

## تمرین ۱۲

برنامه‌ای بنویسید که تمام اعداد بین ۱ تا ۵۰ را چاپ کند اما:

* مضرب‌های ۳ را رد کند.
* هنگام رسیدن به ۴۰ حلقه را متوقف کند.

# مینی‌پروژه

## جستجوی هوشمند در لیست کاربران (User Search CLI)

در این پروژه یک ابزار خط فرمان می‌سازید که در یک لیست از کاربران جستجو انجام می‌دهد.

### مراحل پروژه

1. پوشه‌ای با نام `user-search-cli` ایجاد کنید.
2. فایل `index.js` را بسازید.
3. یک آرایه از نام کاربران ایجاد کنید.
4. با استفاده از `readline` نام موردنظر را از کاربر دریافت کنید.
5. با استفاده از حلقه `for...of` کاربران را بررسی کنید.
6. اگر نام موردنظر پیدا شد:

   * پیام موفقیت نمایش دهید.
   * با `break` جستجو را متوقف کنید.
7. اگر یکی از نام‌ها رشته‌ای خالی یا نامعتبر بود، با `continue` از آن عبور کنید.
8. اگر جستجو تا پایان لیست انجام شد و کاربر پیدا نشد، پیام مناسبی نمایش دهید.

نمونه خروجی:

User Found ✓
==============================
```

نمونه خروجی دیگر:

User Not Found
==============================
```

### هدف پروژه

در پایان این مینی‌پروژه، یاد می‌گیرید چگونه اجرای حلقه‌ها را به‌صورت هوشمند کنترل کنید، هنگام پیدا شدن نتیجه پردازش را متوقف کنید، داده‌های نامعتبر را نادیده بگیرید و الگوریتم‌هایی کارآمدتر بنویسید. این مهارت در پروژه‌های واقعی Node.js برای جستجو، اعتبارسنجی، پردازش فایل‌ها، پیمایش داده‌های دیتابیس و ساخت ابزارهای خط فرمان بسیار پرکاربرد است.

> **نکته مهم:** در پروژه‌های حرفه‌ای، بیش از ۹۵٪ مواقع فقط از `break` و `continue` استفاده می‌شود. `label` قابلیت مفیدی است، اما به‌ندرت در کدهای واقعی دیده می‌شود. اگر احساس کردید به `label` نیاز دارید، ابتدا بررسی کنید آیا می‌توانید با تقسیم کد به تابع‌های کوچک‌تر یا تغییر ساختار الگوریتم، همان مسئله را ساده‌تر حل کنید.
