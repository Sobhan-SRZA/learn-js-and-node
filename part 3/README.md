# بخش ۳ - تصمیم‌گیری و کنترل جریان برنامه

در این بخش با مفاهیم **تصمیم‌گیری و کنترل جریان اجرای برنامه** در JavaScript آشنا می‌شویم.

تا اینجا با متغیرها، انواع داده و عملگرها آشنا شده‌ایم. حالا یاد می‌گیریم چگونه بر اساس شرایط مختلف تصمیم بگیریم، بخش‌های مختلف برنامه را اجرا یا متوقف کنیم و عملیات تکراری را با استفاده از حلقه‌ها انجام دهیم.

این مفاهیم از پایه‌ای‌ترین مهارت‌های برنامه‌نویسی هستند و در تمام پروژه‌های Node.js مورد استفاده قرار می‌گیرند.

# 🎯 هدف بخش ۳

در پایان این بخش باید بتوانید:

* با استفاده از `if` و `else` برای برنامه تصمیم‌گیری کنید.
* چند شرط را با `else if` مدیریت کنید.
* از `switch` برای تصمیم‌گیری بر اساس چند حالت استفاده کنید.
* شرط‌های تو در تو ایجاد کنید.
* با حلقه `for` عملیات تکراری انجام دهید.
* از `while` و `do while` استفاده کنید.
* با `for...of` روی مقادیر قابل پیمایش کار کنید.
* با `for...in` روی کلیدهای یک Object پیمایش کنید.
* اجرای حلقه را با `break` متوقف کنید.
* با `continue` از اجرای یک iteration عبور کنید.
* با `label` جریان اجرای حلقه‌های تو در تو را کنترل کنید.
* منطق تصمیم‌گیری و تکرار را در برنامه‌های Node.js به کار ببرید.
