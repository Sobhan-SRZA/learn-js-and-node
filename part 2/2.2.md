قبل از اینکه بتوانیم برنامه‌های واقعی بنویسیم، باید بتوانیم اطلاعات را در برنامه ذخیره کنیم. درست مانند یک انسان که برای انجام کارها اطلاعات را در ذهن خود نگه می‌دارد، برنامه‌ها نیز به محلی برای نگهداری داده‌ها نیاز دارند. در JavaScript این کار با **متغیرها (Variables)** انجام می‌شود. این فصل یکی از مهم‌ترین فصل‌های کل دوره است؛ زیرا تقریباً در تمام برنامه‌هایی که در آینده خواهید نوشت، از متغیرها استفاده خواهید کرد.

# فصل 8 - متغیرها (Variables)

تا اینجای دوره فقط توانستیم اطلاعات را مستقیماً داخل `console.log()` بنویسیم.

مثال:

```javascript
console.log("Sobhan");
console.log(20);
console.log("Computer Engineering");
```

اما این روش یک مشکل بزرگ دارد.

فرض کنید بخواهید نام کاربر را در ۵۰ قسمت مختلف برنامه نمایش دهید.

اگر نام او تغییر کند باید هر ۵۰ قسمت را ویرایش کنید.

راه‌حل چیست؟

**متغیرها.**

---

# متغیر چیست؟

متغیر (Variable) محلی در حافظه کامپیوتر است که برای ذخیره اطلاعات استفاده می‌شود.

می‌توان آن را مانند یک جعبه در نظر گرفت.

داخل این جعبه می‌توان هر نوع اطلاعاتی قرار داد.

مثلاً:

* نام
* سن
* شماره تلفن
* قیمت
* وضعیت
* متن
* نتیجه محاسبات

هر زمان لازم باشد می‌توان مقدار داخل این جعبه را خواند یا (در برخی موارد) تغییر داد.

---

# مثال دنیای واقعی

فرض کنید روی میز خود چند برچسب دارید.

روی هر برچسب یک نام نوشته شده است.

```
Name
Age
City
```

حالا داخل هر جعبه مقداری قرار می‌دهید.

```
Name  → Sobhan
Age   → 20
City  → Tehran
```

در برنامه‌نویسی نیز دقیقاً همین اتفاق می‌افتد.

---

# چرا به متغیر نیاز داریم؟

بدون متغیرها:

* برنامه‌ها بسیار طولانی می‌شوند.
* تغییر اطلاعات سخت می‌شود.
* استفاده مجدد از اطلاعات ممکن نیست.
* مدیریت داده‌ها تقریباً غیرممکن می‌شود.

متغیرها باعث می‌شوند:

* کد خواناتر شود.
* اطلاعات فقط یک بار تعریف شوند.
* تغییر داده‌ها ساده باشد.
* برنامه انعطاف‌پذیرتر شود.

---

# ساخت اولین متغیر

در JavaScript سه روش برای تعریف متغیر وجود دارد:

* `let`
* `const`
* `var`

در ادامه هر کدام را بررسی می‌کنیم.

---

# let

امروزه رایج‌ترین روش تعریف متغیر استفاده از `let` است.

ساختار:

```javascript
let variableName = value;
```

مثال:

```javascript
let name = "Sobhan";

console.log(name);
```

خروجی:

```text
Sobhan
```

---

# تغییر مقدار متغیر

یکی از ویژگی‌های `let` این است که مقدار آن قابل تغییر است.

```javascript
let city = "Tehran";

console.log(city);

city = "Tabriz";

console.log(city);
```

خروجی:

```text
Tehran
Tabriz
```

---

مثال دیگر:

```javascript
let score = 10;

score = 20;

console.log(score);
```

خروجی:

```text
20
```

---

# تعریف چند متغیر

```javascript
let firstName = "Sobhan";
let age = 20;
let country = "Iran";

console.log(firstName);
console.log(age);
console.log(country);
```

---

# const

گاهی اطلاعاتی داریم که نباید تغییر کنند.

برای این کار از `const` استفاده می‌کنیم.

ساختار:

```javascript
const variableName = value;
```

مثال:

```javascript
const pi = 3.14159;

console.log(pi);
```

---

# آیا مقدار const قابل تغییر است؟

خیر.

```javascript
const country = "Iran";

country = "Turkey";
```

خروجی:

```text
TypeError: Assignment to constant variable.
```

---

# چه زمانی از const استفاده کنیم؟

برای اطلاعاتی که نباید تغییر کنند.

مانند:

* مقدار π
* آدرس API
* شماره نسخه
* تنظیمات برنامه
* رنگ‌های ثابت
* کلیدهای تنظیمات

مثال:

```javascript
const appName = "Node Course";

console.log(appName);
```

---

# آیا const همیشه ثابت است؟

این سؤال یکی از رایج‌ترین سؤالات مبتدیان است.

`const` یعنی **مرجع (Reference)** قابل تغییر نیست، نه لزوماً محتوای هر مقداری.

فعلاً چون هنوز Object و Array را یاد نگرفته‌ایم، این موضوع را ساده در نظر بگیرید:

برای مقادیر ساده مانند متن، عدد و مقدارهای منطقی، `const` بعد از مقداردهی دیگر قابل تغییر نیست.

در فصل Objectها دوباره به این موضوع برمی‌گردیم.

---

# var

قبل از معرفی `let` و `const`، تنها روش تعریف متغیر در JavaScript استفاده از `var` بود.

مثال:

```javascript
var name = "Sobhan";

console.log(name);
```

---

همچنین:

```javascript
var age = 20;

age = 21;

console.log(age);
```

---

# چرا امروزه کمتر از var استفاده می‌شود؟

`var` رفتارهای قدیمی و گاهی گیج‌کننده‌ای دارد.

از جمله:

* Scope متفاوت
* Hoisting متفاوت
* امکان تعریف مجدد متغیر

به همین دلیل در پروژه‌های مدرن تقریباً همیشه از `let` و `const` استفاده می‌شود.

در این دوره نیز تا حد امکان از `var` استفاده نخواهیم کرد، اما باید آن را بشناسید؛ زیرا هنوز در پروژه‌های قدیمی دیده می‌شود.

---

# مقایسه let، const و var

| ویژگی                | let | const | var |
| -------------------- | --- | ----- | --- |
| قابل تغییر           | ✅   | ❌     | ✅   |
| قابل تعریف مجدد      | ❌   | ❌     | ✅   |
| Scope بلوکی          | ✅   | ✅     | ❌   |
| مناسب پروژه‌های جدید | ✅   | ✅     | ❌   |

---

# قوانین نام‌گذاری متغیرها

انتخاب نام مناسب برای متغیرها بسیار مهم است.

نام خوب باعث خواناتر شدن برنامه می‌شود.

---

## قانون اول

نام متغیر می‌تواند شامل:

* حروف انگلیسی
* اعداد
* `_`
* `$`

باشد.

نمونه صحیح:

```javascript
let username;
let user1;
let first_name;
let $price;
```

---

## قانون دوم

نام متغیر نباید با عدد شروع شود.

❌

```javascript
let 1name = "Ali";
```

✅

```javascript
let name1 = "Ali";
```

---

## قانون سوم

بین نام متغیر فاصله وجود ندارد.

❌

```javascript
let first name = "Ali";
```

✅

```javascript
let firstName = "Ali";
```

---

## قانون چهارم

از کلمات رزرو شده JavaScript استفاده نکنید.

مثلاً:

❌

```javascript
let let = 10;
```

❌

```javascript
let const = 20;
```

---

# نام مناسب چیست؟

بد:

```javascript
let a = "Sobhan";
```

بهتر:

```javascript
let firstName = "Sobhan";
```

---

بد:

```javascript
let x = 500;
```

بهتر:

```javascript
let productPrice = 500;
```

---

# استاندارد Camel Case

در JavaScript تقریباً تمام متغیرها با **camelCase** نوشته می‌شوند.

نمونه:

```javascript
firstName
lastName
phoneNumber
userAge
productPrice
isLoggedIn
```

این استاندارد را از همین ابتدای مسیر رعایت کنید.

---

# Scope اولیه

Scope یعنی محدوده‌ای که یک متغیر در آن قابل دسترسی است.

فعلاً فقط یک آشنایی اولیه خواهیم داشت و در فصل‌های بعد به‌صورت کامل آن را بررسی می‌کنیم.

---

## متغیر خارج از بلوک

```javascript
let name = "Sobhan";

console.log(name);
```

متغیر در همان محدوده قابل استفاده است.

---

## متغیر داخل بلوک

```javascript
{
    let age = 20;

    console.log(age);
}
```

کد بالا بدون مشکل اجرا می‌شود.

اما:

```javascript
{
    let age = 20;
}

console.log(age);
```

باعث خطا می‌شود.

زیرا `let` فقط داخل همان بلوک قابل دسترسی است.

به این رفتار **Block Scope** گفته می‌شود.

---

## Scope در const

رفتار `const` نیز مشابه `let` است.

```javascript
{
    const country = "Iran";

    console.log(country);
}
```

---

## Scope در var

`var` رفتار متفاوتی دارد.

فعلاً فقط بدانید که `var` محدود به بلوک نیست و به همین دلیل استفاده از آن در پروژه‌های جدید توصیه نمی‌شود.

جزئیات این موضوع را در فصل Scope بررسی خواهیم کرد.

---

# بهترین روش استفاده از متغیرها

یک قانون ساده که بسیاری از تیم‌های حرفه‌ای رعایت می‌کنند:

* اگر مقدار قرار نیست تغییر کند → `const`
* اگر مقدار قرار است تغییر کند → `let`
* از `var` استفاده نکنید، مگر برای مطالعه یا نگهداری پروژه‌های قدیمی.

---

# اشتباهات رایج

### ❌ استفاده از var در پروژه‌های جدید

در پروژه‌های مدرن، `let` و `const` انتخاب‌های مناسب‌تری هستند.

---

### ❌ استفاده از const برای مقادیری که تغییر می‌کنند

```javascript
const score = 10;

score = 20;
```

این کد خطا تولید می‌کند.

---

### ❌ استفاده از نام‌های نامفهوم

```javascript
let x = 100;
```

بهتر است بنویسید:

```javascript
let totalPrice = 100;
```

---

### ❌ شروع نام متغیر با عدد

```javascript
let 123name = "Ali";
```

این کد معتبر نیست.

---

### ❌ استفاده از فاصله در نام متغیر

```javascript
let first name = "Ali";
```

این نیز نامعتبر است.

---

### ❌ استفاده بی‌دلیل از نام‌های بسیار کوتاه

نام متغیر باید مفهوم داشته باشد و هدف آن را مشخص کند.

---

# نکات حرفه‌ای

* تا زمانی که نیاز به تغییر مقدار ندارید، از `const` استفاده کنید.
* از نام‌هایی استفاده کنید که هدف متغیر را بدون نیاز به کامنت توضیح دهند.
* همیشه از استاندارد `camelCase` استفاده کنید.
* هر متغیر فقط یک مسئولیت داشته باشد.
* از نام‌های کلی مانند `data`، `value` یا `temp` فقط زمانی استفاده کنید که واقعاً مناسب باشند.
* در پروژه‌های تیمی، نام‌گذاری مناسب یکی از مهم‌ترین عوامل خوانایی کد است.

3. حداقل ۲۰ متغیر با نام‌های مناسب تعریف کنید. اطلاعات پیشنهادی:

   * نام
   * نام خانوادگی
   * سن
   * شهر
   * کشور
   * رشته تحصیلی
   * دانشگاه
   * شغل
   * ایمیل
   * شماره تلفن (نمونه)
   * قد
   * وزن
   * زبان برنامه‌نویسی مورد علاقه
   * سال شروع برنامه‌نویسی
   * هدف شغلی
   * رنگ مورد علاقه
   * سرگرمی
   * وضعیت تأهل
   * نام پروژه
   * نسخه پروژه
4. برای مقادیری که تغییر نخواهند کرد از `const` و برای مقادیری که ممکن است در آینده تغییر کنند از `let` استفاده کنید.
5. تمام اطلاعات را با استفاده از `console.log()` به‌صورت خوانا نمایش دهید.
