قبل از این فصل با متغیرها و انواع داده آشنا شدیم. اما تنها ذخیره کردن اطلاعات کافی نیست. یک برنامه باید بتواند **محاسبه کند، تصمیم بگیرد، مقادیر را با هم مقایسه کند، شرط‌ها را بررسی کند و داده‌ها را تغییر دهد.**

تمام این کارها با استفاده از **عملگرها (Operators)** انجام می‌شود.

تقریباً در هر برنامه JavaScript، از ساده‌ترین پروژه‌ها تا بزرگ‌ترین پروژه‌های Node.js، عملگرها دائماً استفاده می‌شوند. اگر متغیرها را مانند اسم‌ها در زبان فارسی در نظر بگیریم، عملگرها همان فعل‌ها و ابزارهایی هستند که به برنامه قدرت انجام کار می‌دهند.

# فصل 10 - عملگرها (Operators)

عملگرها (Operators) نمادها یا کلمات ویژه‌ای هستند که روی یک یا چند مقدار عملیاتی انجام می‌دهند.

مثلاً:

* دو عدد را جمع می‌کنند.
* دو مقدار را مقایسه می‌کنند.
* چند شرط را با هم ترکیب می‌کنند.
* مقدار یک متغیر را تغییر می‌دهند.
* در صورت نبود مقدار، مقدار پیش‌فرض قرار می‌دهند.
* به ویژگی‌های یک شیء بدون ایجاد خطا دسترسی پیدا می‌کنند.

در این فصل تقریباً تمام عملگرهایی که روزانه در پروژه‌های Node.js استفاده خواهید کرد را یاد می‌گیریم.

# عملگر شرطی (Ternary Operator)

گاهی می‌خواهیم یک شرط ساده را در یک خط بنویسیم.

```javascript

```

```javascript

```

خروجی:



# عملگر Nullish (??)

یکی از بهترین ویژگی‌های JavaScript مدرن.

اگر مقدار سمت چپ فقط `null` یا `undefined` باشد، مقدار سمت راست استفاده می‌شود.

---

مثال:

```javascript
let username = null;

console.log(username ?? "Guest");
```

خروجی:

```text
Guest
```

---

مثال:

```javascript
let username = "Sobhan";

console.log(username ?? "Guest");
```

خروجی:

```text
Sobhan
```

---

# تفاوت || و ??

یکی از مهم‌ترین نکات JavaScript.

```javascript
let value = 0;

console.log(value || 100);
```

خروجی:

```text
100
```

---

اما:

```javascript
let value = 0;

console.log(value ?? 100);
```

خروجی:

```text
0
```

زیرا `0` مقدار معتبری است و فقط `null` و `undefined` باعث فعال شدن `??` می‌شوند.

---

# Optional Chaining (?.)

گاهی می‌خواهیم به ویژگی یک شیء دسترسی داشته باشیم.

اما اگر آن شیء وجود نداشته باشد، برنامه خطا می‌دهد.

در آینده Objectها را کامل یاد می‌گیریم، اما اکنون فقط با مفهوم Optional Chaining آشنا شوید.

---

بدون Optional Chaining:

```javascript
let user = null;

console.log(user.name);
```

خروجی:

```text
TypeError
```

---

با Optional Chaining:

```javascript
let user = null;

console.log(user?.name);
```

خروجی:

```text
undefined
```

برنامه بدون خطا ادامه پیدا می‌کند.

---

مثال دیگر:

```javascript
const user = {
    name: "Sobhan"
};

console.log(user?.name);
```

خروجی:

```text
Sobhan
```

# اشتباهات رایج

### ❌ استفاده از `==` به جای `===`

در پروژه‌های حرفه‌ای تقریباً همیشه از `===` و `!==` استفاده کنید تا تبدیل خودکار نوع داده باعث ایجاد باگ نشود.

---

### ❌ اشتباه گرفتن `=` با `===`

```javascript
if (age = 20)
```

این انتساب است، نه مقایسه.

---

### ❌ استفاده از `||` به جای `??`

اگر مقدار `0`، `false` یا رشته خالی معتبر باشد، از `??` استفاده کنید.

---

### ❌ استفاده بیش از حد از Ternary

برای شرط‌های ساده عالی است، اما برای شرط‌های پیچیده، خوانایی کد را کاهش می‌دهد.

---

### ❌ فراموش کردن Optional Chaining

دسترسی مستقیم به ویژگی شیء ممکن است باعث `TypeError` شود.

---

### ❌ فراموش کردن اولویت عملگرها

همیشه برای واضح‌تر شدن محاسبات از پرانتز استفاده کنید.

---

# نکات حرفه‌ای

* همیشه `===` و `!==` را به `==` و `!=` ترجیح دهید.
* از `??` برای مقدارهای پیش‌فرض استفاده کنید، نه `||`، مگر اینکه دقیقاً همان رفتار را بخواهید.
* از Ternary فقط برای شرط‌های کوتاه استفاده کنید.
* Optional Chaining در پروژه‌های Node.js و APIها بسیار پرکاربرد است.
* برای خواناتر شدن محاسبات پیچیده، از پرانتز استفاده کنید.
* هنگام نوشتن شرط‌ها، خوانایی کد را مهم‌تر از کوتاه بودن آن بدانید.

# مینی‌پروژه

## سیستم ارزیابی دانش‌آموز

در این پروژه یک برنامه کوچک می‌نویسید که وضعیت یک دانش‌آموز را بررسی کند.

### مراحل پروژه

1. فایل `index.js` را ایجاد کنید.
2. متغیرهای زیر را تعریف کنید:

   * نام دانش‌آموز
   * نمره
   * حضور در کلاس (Boolean)
   * انجام پروژه (Boolean)
3. با استفاده از عملگرهای مقایسه و منطقی مشخص کنید:

   * آیا دانش‌آموز قبول شده است؟ (نمره ≥ 50)
   * آیا واجد شرایط دریافت گواهی است؟ (قبولی + حضور + انجام پروژه)
4. اگر نام دانش‌آموز `null` یا `undefined` بود، با `??` مقدار `"Unknown Student"` را نمایش دهید.
5. با استفاده از Ternary پیام مناسب چاپ کنید:

   * `Passed`
   * `Failed`
6. در صورت وجود شیء `student`، با Optional Chaining نام آن را نمایش دهید.

نمونه خروجی:

```text

====================================
```
