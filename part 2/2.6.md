قبل از معرفی **شرط‌ها، توابع و رشته‌ها**، لازم است با یکی از بهترین قابلیت‌های JavaScript مدرن آشنا شوید.

در نسخه‌های قدیمی JavaScript، برای کنار هم قرار دادن متن‌ها و متغیرها از عملگر `+` استفاده می‌شد. این روش در برنامه‌های کوچک قابل قبول بود، اما در پروژه‌های بزرگ Node.js باعث کاهش خوانایی کد می‌شد.

برای حل این مشکل، در نسخه **ES6 (ECMAScript 2015)** قابلیت **Template String** یا **Template Literal** معرفی شد. امروزه تقریباً تمام پروژه‌های مدرن Node.js از این قابلیت استفاده می‌کنند و یادگیری آن برای هر برنامه‌نویس JavaScript ضروری است.

# فصل 12 - Template String (Template Literal)

Template String یکی از قابلیت‌های مدرن JavaScript است که برای ساخت رشته‌ها (Stringها) به شکلی خواناتر، قدرتمندتر و انعطاف‌پذیرتر استفاده می‌شود.

با استفاده از Template String می‌توان:

* متن و متغیرها را به‌راحتی کنار هم قرار داد.
* چند خط متن را بدون کاراکترهای خاص نوشت.
* داخل رشته، کد JavaScript اجرا کرد.
* رشته‌های طولانی را بسیار خواناتر نوشت.

در پروژه‌های Node.js تقریباً همیشه به جای استفاده از عملگر `+` از Template String استفاده می‌شود.

---

# مشکل روش قدیمی

فرض کنید بخواهیم نام و سن یک کاربر را نمایش دهیم.

روش قدیمی:

```javascript id="u7f4m1"
const name = "Sobhan";
const age = 20;

console.log("Name: " + name + ", Age: " + age);
```

خروجی:

```text id="x3d8p2"
Name: Sobhan, Age: 20
```

کد بالا درست کار می‌کند.

اما اگر تعداد متغیرها زیاد شود، خواندن آن سخت خواهد شد.

---

مثال:

```javascript id="r5n2v8"
const firstName = "Sobhan";
const lastName = "SRZA";
const age = 20;
const city = "Tehran";

console.log(
    "User: " +
    firstName +
    " " +
    lastName +
    " Age: " +
    age +
    " City: " +
    city
);
```

خواندن چنین کدی دشوار است.

---

# Template String چیست؟

Template String نوعی رشته است که با **Backtick** نوشته می‌شود.

Backtick این کاراکتر است:

```text id="t8m6p3"
`
```

نه کوتیشن:

```text id="n2v4x9"
"
'
```

---

ساختار:

```javascript id="k9a5f2"
`Hello`
```

---

مثال:

```javascript id="w1q7h6"
const message = `Hello Node.js`;

console.log(message);
```

---

# قرار دادن متغیر داخل رشته

برای قرار دادن متغیر داخل Template String از:

```text id="g3r8m4"
${}
```

استفاده می‌کنیم.

---

مثال:

```javascript id="p6x2j1"
const name = "Sobhan";

console.log(`Hello ${name}`);
```

خروجی:

```text id="y8n1c5"
Hello Sobhan
```

---

مثال دیگر:

```javascript id="d7v9k4"
const age = 20;

console.log(`Age: ${age}`);
```

خروجی:

```text id="f4q2w8"
Age: 20
```

---

چند متغیر:

```javascript id="m8b5r7"
const firstName = "Sobhan";
const lastName = "SRZA";
const city = "Tehran";

console.log(`${firstName} ${lastName} lives in ${city}`);
```

---

# اجرای عبارت‌های JavaScript

داخل `${}` فقط متغیر قرار نمی‌گیرد.

هر عبارت معتبر JavaScript قابل اجرا است.

---

مثال:

```javascript id="h4z8p6"
console.log(`${5 + 10}`);
```

خروجی:

```text id="c9t1v2"
15
```

---

مثال:

```javascript id="a2m6q9"
const price = 250;
const tax = 50;

console.log(`Total: ${price + tax}`);
```

خروجی:

```text id="e5w3k7"
Total: 300
```

---

حتی می‌توان از عملگرها استفاده کرد.

```javascript id="b1f7n3"
const score = 85;

console.log(`${score >= 50}`);
```

خروجی:

```text id="j6r4x8"
true
```

---

# استفاده از توابع

در آینده با توابع آشنا خواهیم شد.

اما بدانید که داخل `${}` حتی می‌توان تابع نیز اجرا کرد.

```javascript id="v5c2m9"
const name = "sobhan";

console.log(`${name.toUpperCase()}`);
```

خروجی:

```text id="l8q7n1"
SOBHAN
```

---

# رشته‌های چندخطی (Multi-line String)

قبل از Template String نوشتن متن چندخطی دشوار بود.

---

روش قدیمی:

```javascript id="x7m3k5"
console.log("Line 1\nLine 2\nLine 3");
```

---

با Template String:

```javascript id="n4b9t6"
console.log(`
Line 1
Line 2
Line 3
`);
```

خروجی:

```text id="s2w5h8"
Line 1
Line 2
Line 3
```

# ساخت متن‌های طولانی

```javascript id="q8v4r1"
const name = "Sobhan";
const language = "JavaScript";
const framework = "Node.js";

const message = `
Hello ${name}

Welcome to the ${framework} course.

Your favorite language is ${language}.
`;

console.log(message);
```

---

# استفاده در Node.js

در پروژه‌های Node.js از Template String بسیار استفاده می‌شود.

برای مثال:

* ساخت پیام‌های خطا
* ساخت گزارش (Report)
* ساخت Log
* نمایش اطلاعات کاربران
* تولید فایل‌های HTML
* ساخت Queryهای SQL (البته با رعایت اصول امنیتی)
* تولید ایمیل
* ساخت فایل‌های متنی
* تولید پیام برای ربات‌های تلگرام و Discord

---

مثال:

```javascript id="t3k8f2"
const username = "Sobhan";

console.log(`User ${username} logged in successfully.`);
```

---

# Template String و رشته‌های معمولی

رشته معمولی:

```javascript id="r2j5v7"
const text = "Hello";
```

---

Template String:

```javascript id="m6q1x4"
const text = `Hello`;
```

هر دو معتبر هستند.

اما زمانی که نیاز به:

* متغیر
* چند خط
* عبارت JavaScript

دارید، از Template String استفاده کنید.

---

# استفاده از Expression

داخل `${}` هر عبارت معتبر JavaScript اجرا می‌شود.

---

مثال:

```javascript id="f9b3w6"
const a = 10;
const b = 5;

console.log(`${a * b}`);
```

---

```javascript id="k5t8m1"
console.log(`${10 > 5}`);
```

---

```javascript id="z1p7q4"
console.log(`${Boolean(0)}`);
```

---

# استفاده از Ternary

```javascript id="y4m2r9"
const score = 60;

console.log(`${score >= 50 ? "Pass" : "Fail"}`);
```

---

# استفاده از Optional Chaining

```javascript id="h8c6v5"
const user = {
    name: "Sobhan"
};

console.log(`${user?.name}`);
```

---

# استفاده از Nullish Coalescing

```javascript id="p3n5k8"
const username = null;

console.log(`${username ?? "Guest"}`);
```

---

# خوانایی کد

همیشه سعی کنید رشته‌های طولانی را با Template String بنویسید.

این کار:

* خوانایی را افزایش می‌دهد.
* نگهداری پروژه را آسان‌تر می‌کند.
* احتمال خطا را کاهش می‌دهد.

---

# اشتباهات رایج

### ❌ استفاده از کوتیشن به جای Backtick

```javascript id="u6v2q4"
"Hello ${name}"
```

این کد متغیر را جایگزین نمی‌کند.

---

کد صحیح:

```javascript id="b4x9m7"
`Hello ${name}`
```

---

### ❌ فراموش کردن `${}`

```javascript id="e7t1n3"
`Hello name`
```

متغیر نمایش داده نمی‌شود.

---

### ❌ استفاده بیش از حد از عملگر +

```javascript id="q5m8v2"
"Hello " + name + " Age " + age
```

در پروژه‌های مدرن بهتر است از Template String استفاده کنید.

---

### ❌ قرار دادن Backtick اشتباه

همیشه Template String با کاراکتر:

```text id="n8k4r5"
`
```

شروع و تمام می‌شود.

---

### ❌ نوشتن کدهای بسیار پیچیده داخل `${}`

اگر عبارت داخل `${}` بیش از حد طولانی یا پیچیده است، ابتدا آن را در یک متغیر محاسبه کنید و سپس متغیر را داخل Template String قرار دهید.

---

# نکات حرفه‌ای

* در پروژه‌های مدرن Node.js، برای ساخت رشته‌های پویا همیشه Template String را ترجیح دهید.
* از `${}` فقط برای عبارت‌های ساده استفاده کنید؛ محاسبات پیچیده را خارج از رشته انجام دهید.
* برای ساخت متن‌های چندخطی از Template String استفاده کنید و از `\n` فقط در مواقع ضروری بهره ببرید.
* از Template String برای ساخت Logها و پیام‌های خطا استفاده کنید؛ این کار کد را بسیار خواناتر می‌کند.
* اگر نیازی به متغیر یا چند خط ندارید، استفاده از رشته معمولی نیز کاملاً مناسب است.

# مینی‌پروژه

## ساخت گزارش اطلاعات سیستم (System Report)

در این پروژه یک گزارش حرفه‌ای از اطلاعات سیستم یا کاربر تولید می‌کنید و آن را با استفاده از Template String در ترمینال نمایش می‌دهید.

### مراحل پروژه

1. پوشه‌ای با نام `system-report` ایجاد کنید.
2. فایل `index.js` را بسازید.
3. متغیرهای زیر را تعریف کنید:

   * نام کاربر
   * سن
   * کشور
   * شهر
   * زبان برنامه‌نویسی
   * نسخه Node.js (می‌توانید از `process.version` استفاده کنید.)
   * سیستم‌عامل (می‌توانید از `process.platform` استفاده کنید.)
4. با استفاده از Template String یک گزارش چندخطی و خوانا ایجاد کنید.
5. در گزارش:

   * از `${}` برای نمایش متغیرها استفاده کنید.
   * یک عبارت محاسباتی (مثلاً سال تولد تقریبی) نمایش دهید.
   * در صورت خالی بودن نام کاربر، با `??` مقدار `"Guest"` را نمایش دهید.

نمونه خروجی:

```text id="v2q8m4"
====================================
Node.js System Report

User: Sobhan
Age: 20
Country: Iran
City: Tehran
Favorite Language: JavaScript

Node Version: v22.0.0
Platform: win32

Estimated Birth Year: 2005
====================================
```

### هدف پروژه

در پایان این مینی‌پروژه، می‌توانید رشته‌های پویا و چندخطی تولید کنید، متغیرها و عبارت‌های JavaScript را داخل متن قرار دهید و از قابلیت‌های مدرن مانند **Template String**، **Nullish Coalescing (`??`)** و **Optional Chaining (`?.`)** برای تولید خروجی‌های خوانا و حرفه‌ای استفاده کنید. این مهارت در توسعه برنامه‌های Node.js، ساخت Logها، گزارش‌ها، پیام‌های خطا، ایمیل‌ها، فایل‌های متنی و خروجی‌های CLI بسیار پرکاربرد است.

در فصل‌های بعدی، تقریباً تمام پیام‌هایی که در ترمینال نمایش می‌دهیم، با استفاده از **Template String** نوشته خواهند شد؛ بنابراین از همین ابتدا عادت کنید به‌جای اتصال رشته‌ها با `+`، از این قابلیت مدرن JavaScript استفاده کنید.
