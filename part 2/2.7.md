قبل از این فصل، تمام برنامه‌هایی که نوشتیم فقط اطلاعات را نمایش می‌دادند و خروجی آن‌ها از قبل مشخص بود. اما برنامه‌های واقعی این‌گونه نیستند.

یک برنامه واقعی باید بتواند با کاربر ارتباط برقرار کند؛ از او اطلاعات بگیرد، آن‌ها را پردازش کند و نتیجه را نمایش دهد.

در Node.js این ارتباط معمولاً از طریق **ترمینال (Terminal)** انجام می‌شود. کاربر اطلاعاتی را وارد می‌کند، برنامه آن‌ها را دریافت می‌کند و پس از پردازش، خروجی مناسب را نمایش می‌دهد.

در این فصل با سه مفهوم بسیار مهم آشنا می‌شوید:

* **`process.stdin`** برای دریافت ورودی
* **`process.stdout`** برای نمایش خروجی
* **`readline`** برای دریافت ورودی به روشی ساده و استاندارد

این سه مفهوم، پایه‌ی ساخت تمام برنامه‌های خط فرمان (CLI) در Node.js هستند و بعدها در پروژه‌های واقعی بارها از آن‌ها استفاده خواهیم کرد.

# فصل 13 - ورودی و خروجی در Node.js

هر برنامه به طور کلی سه مرحله دارد:

1. دریافت اطلاعات (Input)
2. پردازش اطلاعات (Process)
3. نمایش نتیجه (Output)

در Node.js نیز دقیقاً همین ساختار وجود دارد.

```
User
   │
   ▼
Input (stdin)
   │
   ▼
Node.js Program
   │
   ▼
Output (stdout)
```

در این فصل یاد می‌گیریم چگونه اطلاعات را از کاربر دریافت کنیم و نتیجه را در ترمینال نمایش دهیم.

---

# استانداردهای ورودی و خروجی (Standard Streams)

هر برنامه Node.js به طور پیش‌فرض سه جریان استاندارد دارد.

| Stream         | توضیح        |
| -------------- | ------------ |
| process.stdin  | دریافت ورودی |
| process.stdout | نمایش خروجی  |
| process.stderr | نمایش خطاها  |

در این فصل با دو مورد اول کار خواهیم کرد.

---

# process.stdout

`stdout` مخفف:

```
Standard Output
```

است.

تمام چیزی که با `console.log()` چاپ می‌کنیم در حقیقت به `process.stdout` ارسال می‌شود.

---

مثال:

```javascript
console.log("Hello Node.js");
```

معادل ساده‌تر آن:

```javascript
process.stdout.write("Hello Node.js");
```

خروجی:

```
Hello Node.js
```

---

# تفاوت console.log و process.stdout.write

در نگاه اول مشابه هستند، اما تفاوت مهمی دارند.

---

## console.log

```javascript
console.log("Hello");
console.log("World");
```

خروجی:

```
Hello
World
```

بعد از هر چاپ، یک خط جدید ایجاد می‌شود.

---

## process.stdout.write

```javascript
process.stdout.write("Hello");
process.stdout.write("World");
```

خروجی:

```
HelloWorld
```

زیرا خط جدید ایجاد نمی‌شود.

---

اگر بخواهیم خط جدید ایجاد شود:

```javascript
process.stdout.write("Hello\n");
process.stdout.write("World\n");
```

---

# چه زمانی از process.stdout استفاده می‌کنیم؟

در بیشتر برنامه‌ها از `console.log()` استفاده می‌شود.

اما در برنامه‌های CLI حرفه‌ای معمولاً از `process.stdout.write()` برای موارد زیر استفاده می‌شود:

* نمایش Progress
* ساخت منو
* بروزرسانی یک خط
* نمایش Loading
* چاپ بدون رفتن به خط بعد

---

مثال:

```javascript
process.stdout.write("Loading...");
```

---

# process.stdin

`stdin` مخفف:

```
Standard Input
```

است.

این شیء مسئول دریافت اطلاعات از کاربر است.

---

در ساده‌ترین حالت:

```javascript
process.stdin.on("data", (data) => {
    console.log(data);
});
```

اگر کاربر بنویسد:

```
Hello
```

خروجی چیزی شبیه این خواهد بود:

```
<Buffer 48 65 6c 6c 6f 0a>
```

چرا؟

زیرا اطلاعات به صورت Buffer دریافت می‌شوند.

---

# Buffer چیست؟

Node.js اطلاعات ورودی را ابتدا به صورت Buffer دریافت می‌کند.

برای تبدیل آن به متن از:

```javascript
data.toString()
```

استفاده می‌کنیم.

---

مثال:

```javascript
process.stdin.on("data", (data) => {
    console.log(data.toString());
});
```

اگر کاربر وارد کند:

```
Node.js
```

خروجی:

```
Node.js
```

---

# حذف Enter

وقتی Enter زده می‌شود، یک کاراکتر جدید (`\n`) نیز ارسال می‌شود.

برای حذف آن از:

```javascript
trim()
```

استفاده می‌کنیم.

---

```javascript
process.stdin.on("data", (data) => {
    const text = data.toString().trim();

    console.log(text);
});
```

# readline

اگر بخواهیم به شکل استاندارد از کاربر سؤال بپرسیم، بهتر است از ماژول داخلی `readline` استفاده کنیم.

این ماژول همراه Node.js نصب شده است و نیازی به نصب جداگانه ندارد.

---

# وارد کردن readline

```javascript
const readline = require("node:readline");
```

در فصل‌های آینده درباره `require()` و سیستم ماژول‌ها به طور کامل صحبت خواهیم کرد. فعلاً فقط بدانید که این دستور ماژول `readline` را در اختیار برنامه قرار می‌دهد.

---

# ساخت Interface

```javascript
const readline = require("node:readline");

const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
});
```

اکنون آماده دریافت ورودی هستیم.

---

# پرسیدن سؤال

```javascript
const readline = require("node:readline");

const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
});

rl.question("What is your name? ", (name) => {
    console.log(`Hello ${name}`);

    rl.close();
});
```

نمونه اجرا:

```
What is your name? Sobhan

Hello Sobhan
```

---

# دریافت عدد

تمام ورودی‌های دریافت‌شده از `readline` از نوع String هستند.

مثال:

```javascript
rl.question("Age: ", (age) => {
    console.log(typeof age);

    rl.close();
});
```

خروجی:

```
string
```

---

اگر بخواهیم محاسبه انجام دهیم:

```javascript
rl.question("Age: ", (age) => {

    const result = Number(age);

    console.log(result + 10);

    rl.close();

});
```

---

# چند سؤال پشت سر هم

```javascript
const readline = require("node:readline");

const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
});

rl.question("Name: ", (name) => {

    rl.question("Age: ", (age) => {

        console.log(`Name: ${name}`);
        console.log(`Age: ${age}`);

        rl.close();

    });

});
```

بعدها روش‌های بسیار بهتری برای این کار یاد خواهید گرفت.

---

# بستن Interface

بعد از پایان دریافت اطلاعات باید بنویسیم:

```javascript
rl.close();
```

در غیر این صورت برنامه همچنان منتظر دریافت ورودی باقی می‌ماند.

---

# process.stderr

علاوه بر stdout، Node.js یک خروجی مخصوص خطا نیز دارد.

```javascript
process.stderr.write("Something went wrong\n");
```

در آینده هنگام مدیریت خطاها از آن استفاده خواهیم کرد.

---

# ساخت اولین برنامه تعاملی

```javascript
const readline = require("node:readline");

const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
});

rl.question("First Number: ", (first) => {

    rl.question("Second Number: ", (second) => {

        const result = Number(first) + Number(second);

        console.log(`Result: ${result}`);

        rl.close();

    });

});
```

نمونه اجرا:

```
First Number: 10
Second Number: 15

Result: 25
```

# چه زمانی از هر کدام استفاده کنیم؟

| ابزار                | کاربرد                                 |
| -------------------- | -------------------------------------- |
| console.log          | نمایش ساده اطلاعات                     |
| process.stdout.write | چاپ حرفه‌ای بدون رفتن به خط بعد         |
| process.stdin        | دریافت مستقیم داده                     |
| readline             | دریافت ورودی از کاربر به روش استاندارد |

# اشتباهات رایج

### ❌ فراموش کردن `rl.close()`

باعث می‌شود برنامه بسته نشود و همچنان منتظر ورودی بماند.

---

### ❌ انجام محاسبات روی String

```javascript
"20" + "10"
```

نتیجه:

```
2010
```

در حالی که انتظار داریم:

```
30
```

---

### ❌ فراموش کردن `Number()`

ورودی‌های `readline` همیشه String هستند.

---

### ❌ فراموش کردن `trim()`

گاهی Enter انتهای متن باعث ایجاد خطا در مقایسه رشته‌ها می‌شود.

---

### ❌ استفاده از process.stdin برای همه برنامه‌ها

در اکثر برنامه‌های CLI بهتر است از `readline` استفاده کنید، زیرا خواناتر و استانداردتر است.

---

### ❌ استفاده از process.stdout.write بدون `\n`

در این حالت خروجی‌ها پشت سر هم چاپ می‌شوند.

---

# نکات حرفه‌ای

* برای برنامه‌های ساده از `console.log()` استفاده کنید.
* برای برنامه‌های تعاملی از `readline` استفاده کنید.
* همیشه داده‌های دریافتی را اعتبارسنجی و در صورت نیاز به نوع مناسب تبدیل کنید.
* بعد از پایان دریافت اطلاعات، `rl.close()` را فراموش نکنید.
* اگر نیاز دارید خروجی را بدون ایجاد خط جدید نمایش دهید، از `process.stdout.write()` استفاده کنید.
* در پروژه‌های حرفه‌ای CLI، معمولاً `readline` اولین انتخاب است.

### مراحل پروژه

1. پوشه‌ای با نام `user-registration-cli` ایجاد کنید.
2. فایل `index.js` را بسازید.
3. با استفاده از `readline` اطلاعات زیر را دریافت کنید:

   * نام
   * نام خانوادگی
   * سن
   * شهر
   * شغل
4. سن را با `Number()` به عدد تبدیل کنید.

```text
City: Tehran
Job: Backend Developer

Status: Adult

Registration Completed Successfully
====================================
```

### هدف پروژه

در پایان این مینی‌پروژه، می‌توانید با استفاده از `readline` اطلاعات را از کاربر دریافت کنید، ورودی‌ها را پردازش و تبدیل کنید و با استفاده از `process.stdout` و Template String خروجی‌های خوانا و حرفه‌ای تولید کنید. این مهارت، پایه‌ی ساخت ابزارهای خط فرمان (CLI)، اسکریپت‌های مدیریتی و بسیاری از برنامه‌های واقعی Node.js است.

**نکته آموزشی مهم:** از نسخه‌های جدید Node.js (به‌ویژه Node.js 22 و بالاتر)، علاوه بر `require` می‌توان از نسخه Promise-محور ماژول `node:readline/promises` نیز استفاده کرد که نوشتن برنامه‌های تعاملی را ساده‌تر می‌کند. با این حال، در این مرحله از دوره از API کلاسیک `readline` استفاده کردیم تا ابتدا مفاهیم پایه را به‌خوبی یاد بگیرید. در فصل‌های پیشرفته‌تر، روش Promise و `async/await` را به‌طور کامل آموزش خواهیم داد.
