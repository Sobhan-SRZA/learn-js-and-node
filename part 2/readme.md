# بخش ۲ - شروع برنامه‌نویسی با JavaScript

در این بخش، برنامه‌نویسی با **JavaScript در محیط Node.js** را به‌صورت عملی شروع می‌کنیم.

هدف این بخش این است که مفاهیم پایه JavaScript را از صفر یاد بگیریم؛ به شکلی که در ادامه بتوانیم از همین مفاهیم برای ساخت برنامه‌های واقعی با Node.js استفاده کنیم.

# 🎯 هدف بخش ۲

در پایان این بخش باید بتوانید:

* اولین برنامه JavaScript خود را با Node.js اجرا کنید.
* با `console` و Commentها کار کنید.
* متغیر تعریف کنید.
* تفاوت `let`، `const` و `var` را بشناسید.
* انواع داده اصلی JavaScript را تشخیص دهید.
* از عملگرهای مختلف استفاده کنید.
* داده‌ها را به انواع مختلف تبدیل کنید.
* از Template String استفاده کنید.
* از کاربر ورودی دریافت کنید.
* خروجی را در Terminal نمایش دهید.
* برنامه‌های ساده و تعاملی با Node.js بنویسید.
