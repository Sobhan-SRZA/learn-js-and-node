قبل از این فصل یاد گرفتیم که با استفاده از متغیرها می‌توان اطلاعات را در حافظه ذخیره کرد. اما یک سؤال مهم وجود دارد:

**چه نوع اطلاعاتی را می‌توان داخل یک متغیر قرار داد؟**

آیا متن با عدد تفاوت دارد؟ آیا مقدار «درست» و «نادرست» نیز نوع خاصی از داده هستند؟ اگر متغیری مقداری نداشته باشد چه اتفاقی می‌افتد؟

در این فصل با **انواع داده (Data Types)** در JavaScript آشنا می‌شویم. شناخت انواع داده یکی از مهم‌ترین پایه‌های برنامه‌نویسی است، زیرا تقریباً تمام مفاهیم بعدی مانند شرط‌ها، حلقه‌ها، توابع، آرایه‌ها، آبجکت‌ها و حتی کار با پایگاه داده بر اساس همین مفاهیم ساخته شده‌اند.

# فصل 9 - انواع داده (Data Types)

هر اطلاعاتی که داخل یک برنامه وجود دارد، دارای **نوع (Type)** مشخصی است.

برای مثال:

* عدد، یک نوع داده است.
* متن، نوع داده دیگری است.
* مقدار درست یا نادرست، نوع داده متفاوتی دارد.

JavaScript برای مدیریت داده‌ها از چندین نوع داده داخلی استفاده می‌کند.

در این فصل با تمام **Primitive Data Types** آشنا می‌شویم.

---

# نوع داده (Data Type) چیست؟

نوع داده مشخص می‌کند که یک مقدار **چه ماهیتی دارد** و JavaScript چگونه باید با آن رفتار کند.

برای مثال:

```javascript id="n2a7x1"
10
```

یک عدد است.

اما:

```javascript id="m5k8r2"
"10"
```

یک متن است.

این دو مقدار کاملاً متفاوت هستند، حتی اگر ظاهر مشابهی داشته باشند.

---

# انواع داده‌های اصلی JavaScript

JavaScript دارای هفت نوع داده Primitive است.

| نوع داده  | توضیح            |
| --------- | ---------------- |
| Number    | اعداد            |
| String    | متن              |
| Boolean   | درست یا نادرست   |
| Null      | مقدار خالی       |
| Undefined | بدون مقدار       |
| BigInt    | اعداد بسیار بزرگ |
| Symbol    | شناسه‌های یکتا    |

در فصل‌های آینده با **Object** نیز آشنا خواهیم شد که یک نوع داده غیر Primitive است.

---

# Null

گاهی عمداً می‌خواهیم بگوییم:

**این متغیر هیچ مقداری ندارد.**

برای این کار از `null` استفاده می‌کنیم.

---

## مثال

```javascript id="g8x5j1"
let user = null;

console.log(user);
```

---

فرض کنید هنوز کاربری وارد سایت نشده است.

```javascript id="f6v9z3"
let currentUser = null;
```

بعداً می‌توان مقدار واقعی را داخل آن قرار داد.

---

## بررسی نوع داده

```javascript id="c9q2m8"
console.log(typeof null);
```

خروجی:

```text id="u5w7n1"
object
```

ممکن است این خروجی عجیب به نظر برسد.

این رفتار یک **اشتباه تاریخی (Historical Bug)** در JavaScript است که به دلایل سازگاری هنوز تغییر نکرده است.

پس:

* مقدار `null` یک Primitive Type است.
* اما `typeof null` مقدار `"object"` را برمی‌گرداند.

# BigInt

نوع داده Number محدودیت اندازه دارد.

اگر عدد بسیار بزرگی داشته باشیم باید از BigInt استفاده کنیم.

---

## مثال

```javascript id="z5n2q4"
const bigNumber = 123456789012345678901234567890n;

console.log(bigNumber);
```

وجود حرف `n` در انتهای عدد نشان می‌دهد که این مقدار از نوع BigInt است.

---

## نوع داده

```javascript id="u9f1m6"
console.log(typeof 999999999999999999999n);
```

خروجی:

```text id="k7v3e2"
bigint
```

---

## چه زمانی از BigInt استفاده می‌شود؟

در پروژه‌های معمولی کمتر از BigInt استفاده می‌شود.

اما در موارد زیر کاربرد دارد:

* محاسبات علمی
* رمزنگاری
* سیستم‌های مالی خاص
* پردازش داده‌های بسیار بزرگ


## آیا Symbol را باید یاد بگیریم؟

فعلاً فقط با آن آشنا شوید.

در پروژه‌های معمولی کمتر با آن سروکار خواهید داشت.

در فصل Objectها دوباره به Symbol بازخواهیم گشت.

# Primitive و Reference

تمام نوع داده‌هایی که در این فصل یاد گرفتید از نوع **Primitive** هستند.

در فصل‌های آینده با نوع داده‌های **Reference** مانند:

* Object
* Array
* Function

آشنا خواهیم شد.

---

# اشتباهات رایج

### ❌ اشتباه گرفتن عدد و متن

```javascript id="g4y2k8"
let age = "20";
```

این مقدار یک String است، نه Number.

---

### ❌ نوشتن Boolean داخل کوتیشن

```javascript id="x5r1v6"
let status = "true";
```

این مقدار String است.

مقدار صحیح:

```javascript id="d9f7p4"
let status = true;
```

---

### ❌ اشتباه گرفتن Null و Undefined

`null` یعنی عمداً مقدار را خالی کرده‌ایم.

`undefined` یعنی هنوز مقداری وجود ندارد.

---

### ❌ فراموش کردن حرف n در BigInt

```javascript id="p8c4m1"
12345678901234567890
```

این مقدار از نوع Number خواهد بود و ممکن است دقت خود را از دست بدهد.

---

### ❌ تصور اینکه typeof null مقدار null برمی‌گرداند

در JavaScript:

```javascript id="l2v8q5"
typeof null
```

خروجی:

```text id="s3n7k1"
object
```

این یک رفتار تاریخی زبان است.

---

# نکات حرفه‌ای

* همیشه بدانید متغیر شما چه نوع داده‌ای را نگهداری می‌کند.
* هنگام اشکال‌زدایی، استفاده از `typeof` می‌تواند بسیاری از خطاها را سریع مشخص کند.
* از Boolean برای نمایش وضعیت‌ها استفاده کنید، نه از رشته‌هایی مانند `"yes"` یا `"no"`، مگر اینکه واقعاً با متن سروکار داشته باشید.
* از `null` زمانی استفاده کنید که عمداً می‌خواهید نشان دهید مقداری وجود ندارد.
* تا زمانی که واقعاً به اعداد بسیار بزرگ نیاز ندارید، از `Number` استفاده کنید.
* با وجود اینکه `Symbol` کمتر استفاده می‌شود، شناخت آن برای درک کامل JavaScript ضروری است.

# مینی‌پروژه

## ساخت پروفایل کامل یک دانشجو

در این پروژه، با استفاده از تمام انواع داده‌ای که تا اینجا یاد گرفته‌اید، اطلاعات یک دانشجو را مدل‌سازی می‌کنید.

### مراحل پروژه

1. پوشه‌ای با نام `student-profile` ایجاد کنید.
2. فایل `index.js` را بسازید.
3. متغیرهای زیر را تعریف کنید:

   * نام (String)
   * نام خانوادگی (String)
   * سن (Number)
   * معدل (Number)
   * وضعیت دانشجو بودن (Boolean)
   * وضعیت ورود به سیستم (Boolean)
   * شماره دانشجویی (BigInt)
   * شناسه داخلی (Symbol)
   * استاد راهنما (Null)
   * شماره خوابگاه (Undefined)
4. با استفاده از `console.log()` مقدار و نوع داده (`typeof`) هر متغیر را نمایش دهید.
5. خروجی را بررسی کنید و تفاوت بین `null` و `undefined` را مشاهده کنید.

### هدف پروژه

در پایان این مینی‌پروژه، با تمام انواع داده Primitive در JavaScript آشنا می‌شوید و یاد می‌گیرید که هر نوع داده در چه موقعیتی استفاده می‌شود. همچنین استفاده از `typeof`، تفاوت `null` و `undefined`، و کاربردهای اولیه `BigInt` و `Symbol` را در عمل تجربه خواهید کرد. این مفاهیم پایه‌ای برای یادگیری عملگرها، شرط‌ها، توابع، آرایه‌ها و آبجکت‌ها در فصل‌های بعدی خواهند بود.

می‌توان این فصل را در نسخه نهایی حتی کامل‌تر کرد و بخش‌های پیشرفته‌تری مانند **NaN**، **Infinity**، **-Infinity**، **Number.MAX_SAFE_INTEGER**، **Number.MIN_SAFE_INTEGER**، **دقت اعداد اعشاری (Floating Point Precision)** و تفاوت **Primitive** و **Reference** را با مثال‌های عملی‌تر اضافه کرد؛ چون این موارد در پروژه‌های واقعی Node.js بسیار کاربردی هستند.
