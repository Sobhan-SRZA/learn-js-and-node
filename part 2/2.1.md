## console

کلمه `console` یک شیء (Object) داخلی در JavaScript است.

وظیفه آن ارتباط با ترمینال و نمایش اطلاعات است.

در این دوره بارها و بارها از آن استفاده خواهیم کرد.

---

## log

بعد از `console` تابعی به نام `log` قرار دارد.

وظیفه آن نمایش اطلاعات در خروجی است.

هر چیزی داخل `log()` قرار بگیرد، در ترمینال نمایش داده می‌شود.

# console چیست؟

`console` یکی از مهم‌ترین ابزارهای هر برنامه‌نویس JavaScript است.

تقریباً هنگام نوشتن هر برنامه از آن استفاده خواهید کرد.

کاربردهای آن:

* نمایش متن
* نمایش متغیرها
* بررسی مقدار داده‌ها
* پیدا کردن خطاها
* اشکال‌زدایی (Debug)

# Comment چیست؟

گاهی لازم است داخل کد توضیح بنویسیم.

این توضیحات برای برنامه نیستند، بلکه برای برنامه‌نویس نوشته می‌شوند.

به این توضیحات **Comment** یا **کامنت** گفته می‌شود.

Node.js کامنت‌ها را اجرا نمی‌کند.

# کامنت تک‌خطی

برای نوشتن کامنت تک‌خطی از دو اسلش استفاده می‌کنیم.

متن بعد از `//` اجرا نمی‌شود.

# کامنت چندخطی

# چرا باید کامنت بنویسیم؟

* توضیح منطق پیچیده
* یادداشت برای آینده
* مستندسازی کد
* همکاری تیمی
* غیرفعال کردن موقت بخشی از کد

# چه زمانی کامنت ننویسیم؟

کامنت برای توضیح **چرا** نوشته می‌شود، نه **چه چیزی**.

نمونه بد:

```javascript id="a9d3y5"

```

این کامنت هیچ اطلاعات مفیدی اضافه نمی‌کند.

---

نمونه بهتر:

```javascript id="l4x8u2"
// این مقدار فقط برای تست اولیه برنامه استفاده می‌شود.
```

# نکات حرفه‌ای

* از همان ابتدا به نوشتن کدهای تمیز و خوانا عادت کنید.
* هنگام یادگیری، از `console.log()` زیاد استفاده کنید تا رفتار برنامه را بهتر درک کنید.
* نام فایل‌ها را با حروف کوچک و معنی‌دار انتخاب کنید.
* برای توضیح منطق پیچیده یا تصمیم‌های مهم از کامنت استفاده کنید، نه برای توضیح بدیهیات.
* هر تغییر کوچکی که در کد ایجاد می‌کنید، برنامه را دوباره اجرا کنید و نتیجه را بررسی کنید. این کار به شما کمک می‌کند ارتباط بین کد و خروجی را سریع‌تر درک کنید.
