قبل از این فصل با **متغیرها، انواع داده و عملگرها** آشنا شدیم. اما JavaScript یک ویژگی بسیار مهم دارد که آن را از بسیاری از زبان‌های برنامه‌نویسی متمایز می‌کند:

**JavaScript یک زبان Dynamic و Weakly Typed است.**

یعنی در بسیاری از مواقع، خودش سعی می‌کند نوع داده‌ها را به نوع مناسب تبدیل کند. این ویژگی اگر به‌درستی درک نشود، می‌تواند باعث ایجاد باگ‌های پیچیده و غیرمنتظره در برنامه شود.

در این فصل یاد می‌گیریم که JavaScript چگونه نوع داده‌ها را به‌صورت خودکار تغییر می‌دهد، چگونه خودمان این تبدیل را انجام دهیم و چه زمانی باید از هر روش استفاده کنیم.

# فصل 11 - تبدیل نوع داده (Type Conversion)

گاهی لازم است یک مقدار را از یک نوع داده به نوع دیگری تبدیل کنیم.

برای مثال:

* تبدیل متن `"25"` به عدد `25`
* تبدیل عدد `100` به متن `"100"`
* تبدیل یک مقدار به `true` یا `false`

به این فرآیند **Type Conversion** یا **تبدیل نوع داده** گفته می‌شود.

در JavaScript دو روش اصلی برای تبدیل نوع داده وجود دارد:

* Implicit Conversion (تبدیل خودکار)
* Explicit Conversion (تبدیل دستی)

---

# چرا تبدیل نوع داده اهمیت دارد؟

فرض کنید سن کاربر از ورودی دریافت شده است.

```javascript
const age = "20";
```

کاربر عدد وارد کرده، اما ورودی‌ها همیشه از نوع **String** هستند.

اگر بخواهیم محاسبه انجام دهیم:

```javascript
console.log(age + 5);
```

خروجی:

```text
205
```

اما انتظار ما:

```text
25
```

است.

پس ابتدا باید متن را به عدد تبدیل کنیم.

---

# تبدیل خودکار (Implicit Conversion)

گاهی JavaScript خودش تصمیم می‌گیرد نوع داده را تغییر دهد.

به این کار **Implicit Conversion** یا **Type Coercion** گفته می‌شود.

---

## مثال

```javascript
console.log("5" * 2);
```

خروجی:

```text
10
```

در اینجا JavaScript رشته `"5"` را به عدد تبدیل کرده است.

---

مثال دیگر:

```javascript
console.log("10" - 4);
```

خروجی:

```text
6
```

---

اما:

```javascript
console.log("10" + 4);
```

خروجی:

```text
104
```

چرا؟

زیرا عملگر `+` علاوه بر جمع، برای **چسباندن رشته‌ها (Concatenation)** نیز استفاده می‌شود.

---

مثال دیگر:

```javascript
console.log(10 + true);
```

خروجی:

```text
11
```

زیرا:

```text
true → 1
```

---

```javascript
console.log(10 + false);
```

خروجی:

```text
10
```

زیرا:

```text
false → 0
```

---

# Explicit Conversion

گاهی بهتر است خودمان نوع داده را مشخص کنیم.

به این روش **Explicit Conversion** می‌گویند.

این روش بسیار خواناتر و قابل اعتمادتر از تبدیل خودکار است.

---

# NaN چیست؟

NaN مخفف:

```text
Not a Number
```

است.

به این معنی که JavaScript نتوانسته مقدار را به عدد تبدیل کند.

مثال:


# Boolean()

برای تبدیل مقدار به Boolean از `Boolean()` استفاده می‌کنیم.

---

## مقادیر Truthy و Falsy

در JavaScript همه مقادیر یا **Truthy** هستند یا **Falsy**.

Falsy یعنی هنگام تبدیل به Boolean مقدار `false` تولید می‌کنند.

---

## مقادیر Falsy

```javascript
false
0
-0
0n
""
null
undefined
NaN
```

همه این مقادیر:

```javascript
Boolean(value)
```

را برابر `false` می‌کنند.

---

## مثال

```javascript
console.log(Boolean(0));
```

خروجی:

```text
false
```

---

```javascript
console.log(Boolean(""));
```

خروجی:

```text
false
```

---

```javascript
console.log(Boolean(null));
```

خروجی:

```text
false
```

---

```javascript
console.log(Boolean(undefined));
```

خروجی:

```text
false
```

---

## مقادیر Truthy

تقریباً تمام مقادیر دیگر Truthy هستند.

---

مثال:

```javascript
console.log(Boolean(10));
```

خروجی:

```text
true
```

---

```javascript
console.log(Boolean("Hello"));
```

خروجی:

```text
true
```

---

```javascript
console.log(Boolean("0"));
```

خروجی:

```text
true
```

نکته مهم:

```javascript
"0"
```

یک رشته است، نه عدد.

---

```javascript
console.log(Boolean("false"));
```

خروجی:

```text
true
```

چون این مقدار یک رشته غیرخالی است.

---

# خلاصه تبدیل‌ها

| مقدار       | Number() | String()    | Boolean() |
| ----------- | -------- | ----------- | --------- |
| `"20"`      | 20       | "20"        | true      |
| `"Hello"`   | NaN      | "Hello"     | true      |
| `20`        | 20       | "20"        | true      |
| `0`         | 0        | "0"         | false     |
| `true`      | 1        | "true"      | true      |
| `false`     | 0        | "false"     | false     |
| `null`      | 0        | "null"      | false     |
| `undefined` | NaN      | "undefined" | false     |
| `""`        | 0        | ""          | false     |

---

# چه زمانی تبدیل دستی بهتر است؟

همیشه زمانی که نوع داده برای برنامه مهم است.

مثلاً:

* دریافت اطلاعات از کاربر
* خواندن فایل
* دریافت داده از API
* خواندن متغیرهای محیطی
* خواندن اطلاعات از پایگاه داده

در Node.js بسیاری از داده‌های ورودی به‌صورت String دریافت می‌شوند.

---

# اشتباهات رایج

### ❌ تصور اینکه `"5" + 5` برابر 10 می‌شود

```javascript
console.log("5" + 5);
```

خروجی:

```text
55
```

---

### ❌ فراموش کردن Number()

```javascript
const age = "20";

console.log(age + 10);
```

خروجی:

```text
2010
```

---

### ❌ تصور اینکه `"false"` مقدار false است

```javascript
Boolean("false")
```

خروجی:

```text
true
```

چون رشته غیرخالی است.

---

### ❌ تصور اینکه `"0"` مقدار false است

```javascript
Boolean("0")
```

خروجی:

```text
true
```

---

### ❌ اشتباه گرفتن NaN با Undefined

`NaN` یعنی تبدیل به عدد ناموفق بوده است.

`undefined` یعنی هنوز مقداری وجود ندارد.

---

### ❌ اعتماد بیش از حد به تبدیل خودکار

Type Coercion گاهی نتیجه‌ای متفاوت از انتظار ایجاد می‌کند. در پروژه‌های واقعی بهتر است تبدیل نوع را به‌صورت صریح انجام دهید.

---

# نکات حرفه‌ای

* در پروژه‌های حرفه‌ای، همیشه تبدیل نوع را به‌صورت Explicit انجام دهید.
* هنگام دریافت ورودی از کاربر یا API، نوع داده را بررسی و در صورت نیاز تبدیل کنید.
* قبل از انجام محاسبات روی داده‌های متنی، آن‌ها را با `Number()` تبدیل کنید.
* از `Boolean()` برای بررسی Truthy و Falsy بودن مقادیر استفاده کنید.
* هنگام مشاهده `NaN`، ابتدا ورودی‌ها را بررسی کنید؛ معمولاً مشکل از تبدیل ناموفق داده است.
* نوشتن کدی که نوع داده در آن واضح باشد، خوانایی و قابلیت نگهداری برنامه را افزایش می‌دهد.

# مینی‌پروژه

## سیستم پردازش اطلاعات کاربر

در این پروژه، اطلاعات کاربر را که به‌صورت رشته دریافت شده‌اند، به نوع مناسب تبدیل می‌کنید.

### مراحل پروژه

1. پوشه‌ای با نام `user-data-converter` ایجاد کنید.
2. فایل `index.js` را بسازید.
3. متغیرهای زیر را به‌صورت String تعریف کنید:

   * نام
   * سن
   * قد
   * وزن
   * وضعیت اشتراک (`"true"` یا `"false"`)
4. سن، قد و وزن را با `Number()` به عدد تبدیل کنید.
5. وضعیت اشتراک را با مقایسه مقدار رشته با `"true"` به یک مقدار Boolean واقعی تبدیل کنید.
6. نوع داده تمام مقادیر را قبل و بعد از تبدیل با `typeof` نمایش دهید.
7. شاخص توده بدنی (BMI) را با استفاده از مقادیر تبدیل‌شده محاسبه کنید.

نمونه خروجی:

```text
========== User Data ==========
Age: 20 (number)
Height: 1.75 (number)
Weight: 70 (number)
Subscribed: true (boolean)

BMI: 22.86
===============================
```

### هدف پروژه

در پایان این مینی‌پروژه، یاد می‌گیرید چگونه داده‌های ورودی را قبل از استفاده در برنامه به نوع مناسب تبدیل کنید. این مهارت در توسعه برنامه‌های Node.js بسیار مهم است؛ زیرا داده‌های دریافتی از ورودی کاربر، فایل‌ها، متغیرهای محیطی (`process.env`)، APIها و بسیاری از منابع دیگر معمولاً به‌صورت رشته دریافت می‌شوند و قبل از پردازش باید به نوع مناسب تبدیل شوند.

در فصل بعد با **شرط‌ها (Conditional Statements)** آشنا می‌شوید و یاد می‌گیرید چگونه بر اساس نتیجه مقایسه‌ها و مقادیر Boolean، مسیر اجرای برنامه را کنترل کنید.
