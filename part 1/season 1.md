# بخش اول — آشنایی با Node.js

# فصل ۱ — Node.js چیست؟

---

# مقدمه

اگر تا امروز با JavaScript کار کرده باشید، احتمالاً آن را فقط در مرورگر (Browser) دیده‌اید؛ زبانی که برای ساخت صفحات پویا، انیمیشن‌ها، اعتبارسنجی فرم‌ها و تعامل با کاربر استفاده می‌شود.

اما JavaScript سال‌هاست که فقط یک زبان سمت مرورگر نیست.

امروزه میلیون‌ها سرور، API، ربات، ابزار خط فرمان (CLI)، سیستم‌های Real-Time، سرویس‌های ابری و حتی نرم‌افزارهای Desktop با JavaScript نوشته شده‌اند.

دلیل این تحول، **Node.js** است.

Node.js به JavaScript اجازه داد برای اولین بار خارج از مرورگر اجرا شود.

به همین دلیل، اگر هدف شما تبدیل شدن به یک Backend Developer، ساخت REST API، توسعه ربات‌های Discord و Telegram، ساخت ابزارهای اتوماسیون، توسعه Microserviceها یا حتی برنامه‌های Desktop باشد، یادگیری Node.js یکی از مهم‌ترین قدم‌های مسیر شما خواهد بود.

---

# JavaScript قبل از Node.js

قبل از سال ۲۰۰۹، JavaScript تقریباً فقط داخل مرورگر اجرا می‌شد.

```
JavaScript
      │
      ▼
 Browser
      │
 DOM
      │
 HTML + CSS
```

در آن زمان JavaScript محدودیت‌های زیادی داشت.

مثلاً نمی‌توانست:

* فایل‌های سیستم را بخواند.
* سرور ایجاد کند.
* به پورت‌های شبکه گوش دهد.
* با دیتابیس ارتباط برقرار کند.
* برنامه‌های Command Line بنویسد.
* فرآیندهای سیستم عامل را مدیریت کند.
* نرم‌افزارهای Backend ایجاد کند.

به همین دلیل برای Backend معمولاً از زبان‌هایی مانند:

* PHP
* Java
* C#
* Python
* Ruby

استفاده می‌شد.

# تولد Node.js

در سال **۲۰۰۹**، برنامه‌نویسی به نام **Ryan Dahl** پروژه‌ای را معرفی کرد که بعدها یکی از مهم‌ترین ابزارهای دنیای برنامه‌نویسی شد.

ایده بسیار ساده بود:

> اگر مرورگر می‌تواند JavaScript را اجرا کند، چرا سیستم عامل نتواند؟

برای رسیدن به این هدف، Ryan Dahl موتور JavaScript مرورگر Chrome یعنی **V8 Engine** را برداشت و آن را همراه با امکاناتی برای ارتباط با سیستم‌عامل ترکیب کرد.

نتیجه این پروژه، Node.js بود.

---

# Node.js چیست؟

**Node.js یک Runtime Environment برای اجرای JavaScript خارج از مرورگر است.**

به بیان ساده‌تر:

Node.js خودش یک زبان برنامه‌نویسی نیست.

Node.js جایگزین JavaScript هم نیست.

Node.js فقط محیطی است که اجازه می‌دهد JavaScript مستقیماً روی سیستم‌عامل اجرا شود.

---

## تصور ساده

بدون Node.js:

```
JavaScript
     │
     ▼
Browser
```

با Node.js:

```
JavaScript
      │
      ▼
 Node.js Runtime
      │
      ▼
Operating System
```

در نتیجه JavaScript می‌تواند به منابع سیستم دسترسی داشته باشد.

---

# Runtime چیست؟

Runtime یعنی محیطی که مسئول اجرای برنامه است.

فرض کنید کدی مانند زیر دارید:

```javascript
console.log("Hello World");
```

این کد خودش به تنهایی قابل اجرا نیست.

باید برنامه‌ای وجود داشته باشد که:

* کد را بخواند.
* آن را تفسیر یا کامپایل کند.
* حافظه را مدیریت کند.
* توابع داخلی را فراهم کند.
* خروجی را نمایش دهد.

این مجموعه را Runtime می‌گویند.

در مرورگر، Runtime همان Browser است.

در Node.js، Runtime همان Node است.

---

# تفاوت Browser و Runtime

| Browser          | Node.js                 |
| ---------------- | ----------------------- |
| اجرای JavaScript | اجرای JavaScript        |
| دارای DOM        | بدون DOM                |
| دارای Window     | بدون Window             |
| دارای Document   | بدون Document           |
| محدود به مرورگر  | دسترسی به سیستم عامل    |
| مخصوص Front-End  | مناسب Backend و ابزارها |

---

# آیا Node.js جای JavaScript را می‌گیرد؟

خیر.

Node.js فقط JavaScript را اجرا می‌کند.

همان قوانینی که در JavaScript یاد می‌گیرید، در Node.js نیز وجود دارند.

مثلاً:

```javascript
let age = 20;

console.log(age);
```

یا

```javascript
function sum(a, b) {
    return a + b;
}
```

دقیقاً همان JavaScript هستند.

اما Node امکانات بیشتری نیز اضافه می‌کند.

---

# Node.js چه امکاناتی اضافه می‌کند؟

Node.js کتابخانه‌هایی در اختیار ما قرار می‌دهد که در مرورگر وجود ندارند.

برای مثال:

* مدیریت فایل‌ها
* ساخت سرور
* ساخت API
* ارتباط با دیتابیس
* ارتباط TCP
* ارتباط UDP
* ساخت WebSocket
* ساخت ابزارهای CLI
* اجرای Processها
* مدیریت حافظه
* رمزنگاری
* Streamها
* Bufferها
* مدیریت سیستم عامل

# اولین برنامه Node.js

فایل زیر را ایجاد کنید.

```javascript
console.log("Hello Node.js");
```

آن را با دستور زیر اجرا کنید.

```bash
node index.js
```

خروجی:

```text
Hello Node.js
```

اگر همین فایل را داخل مرورگر اجرا کنید، به ترمینال سیستم دسترسی نخواهید داشت؛ اما در Node.js خروجی مستقیماً در ترمینال نمایش داده می‌شود.

---

# Node.js چگونه کار می‌کند؟

به صورت ساده:

```
Developer
      │
      ▼
JavaScript Code
      │
      ▼
Node.js
      │
      ▼
V8 Engine
      │
      ▼
Machine Code
      │
      ▼
CPU
```

اما Node فقط V8 نیست.

Node همچنین شامل:

* Runtime
* Event Loop
* Thread Pool
* استانداردهای داخلی (Core Modules)
* APIهای سیستم عامل

نیز می‌شود.

در فصل‌های بعدی هر کدام را به‌صورت کامل بررسی خواهیم کرد.

# چرا Node.js محبوب شد؟

دلایل محبوبیت Node عبارت‌اند از:

* سرعت بالا
* استفاده از موتور V8
* برنامه‌نویسی ناهمگام (Asynchronous)
* مدیریت هم‌زمان تعداد زیادی اتصال
* اکوسیستم بزرگ npm
* استفاده از یک زبان در Front-End و Back-End
* جامعه کاربری گسترده
* متن‌باز بودن

✅ اکوسیستم بسیار بزرگ npm

✅ مناسب برای API

✅ مناسب برای پروژه‌های Real-Time

✅ مناسب برای ربات‌ها

✅ مناسب برای CLI

✅ جامعه کاربری بسیار بزرگ

# معایب

❌ مناسب نبودن برای پردازش‌های سنگین CPU محور بدون استفاده از Worker Threads یا معماری مناسب

❌ ماهیت تک‌نخی (Single Thread) در Event Loop که نیازمند شناخت صحیح مدل اجرای Node است

❌ وابستگی برخی پروژه‌ها به کیفیت و نگهداری Packageهای ثالث

> این موارد به معنی «بد بودن» Node.js نیستند؛ بلکه نشان می‌دهند برای هر مسئله باید ابزار مناسب را انتخاب کرد.

# جمع‌بندی

در این فصل یاد گرفتیم که:

* Node.js یک زبان برنامه‌نویسی نیست.
* Node.js یک Runtime برای اجرای JavaScript است.
* JavaScript قبل از Node فقط در مرورگر اجرا می‌شد.
* Node.js امکان اجرای JavaScript روی سیستم‌عامل را فراهم می‌کند.
* با Node.js می‌توان سرور، API، ابزارهای CLI، ربات، برنامه‌های Real-Time و بسیاری از انواع نرم‌افزارها را توسعه داد.
* Node.js امکاناتی مانند مدیریت فایل، شبکه، رمزنگاری و تعامل با سیستم‌عامل را در اختیار توسعه‌دهنده قرار می‌دهد.

در فصل بعد، محیط توسعه را آماده می‌کنیم، Node.js و ابزارهای مرتبط را نصب می‌کنیم و اولین پروژه واقعی خود را ایجاد خواهیم کرد.

# پروژه کوچک

## پروژه: Hello Node

### هدف

آشنایی با اجرای یک فایل JavaScript در محیط Node.js.

### مراحل

1. یک پوشه جدید به نام `hello-node` ایجاد کنید.
2. داخل آن فایلی به نام `index.js` بسازید.
3. کد زیر را در فایل قرار دهید:

```javascript
console.log("Hello Node.js!");
console.log("I'm learning Node.js.");
console.log(`Node version: ${process.version}`);
```

4. در ترمینال دستور زیر را اجرا کنید:

```bash
node index.js
```

### چالش

بدون استفاده از اینترنت، برنامه را طوری تغییر دهید که علاوه بر نسخه Node.js، نام سیستم‌عامل (`process.platform`) و معماری پردازنده (`process.arch`) را نیز نمایش دهد. پاسخ این چالش را پس از مطالعه فصل‌های آینده نیز می‌توانید تکمیل‌تر کنید.
