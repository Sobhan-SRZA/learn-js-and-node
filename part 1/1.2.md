قبل از اینکه برنامه‌نویسی را به‌صورت جدی شروع کنیم، باید با محیطی که قرار است روزانه ساعت‌ها در آن کدنویسی کنیم آشنا شویم. یک برنامه‌نویس حرفه‌ای فقط زبان برنامه‌نویسی را نمی‌شناسد؛ بلکه ابزارهای خود را نیز به‌خوبی می‌شناسد. در این فصل با Visual Studio Code، امکانات آن و تنظیماتی که باعث افزایش سرعت و کیفیت کدنویسی می‌شوند آشنا خواهید شد.

# فصل 5 - آشنایی با VS Code

Visual Studio Code یا به اختصار **VS Code** محبوب‌ترین ویرایشگر کد در جهان است.

این نرم‌افزار توسط Microsoft توسعه داده شده و به دلیل سرعت بالا، امکانات گسترده، افزونه‌های فراوان و پشتیبانی عالی از JavaScript و Node.js، انتخاب اول بسیاری از توسعه‌دهندگان است.

در این دوره تمام مثال‌ها، تمرین‌ها و پروژه‌ها با VS Code انجام می‌شوند.

---

# چرا VS Code؟

شاید این سؤال برای شما پیش بیاید که چرا از VS Code استفاده می‌کنیم؟

دلایل زیادی برای این انتخاب وجود دارد:

* رایگان و متن‌باز
* نصب آسان
* سرعت بالا
* مصرف حافظه مناسب
* پشتیبانی عالی از JavaScript و Node.js
* دارای ترمینال داخلی
* دارای Debugger داخلی
* پشتیبانی از Git
* هزاران Extension کاربردی
* بروزرسانی منظم
* اجرا روی Windows، Linux و macOS

به همین دلایل، VS Code به استاندارد دنیای توسعه وب تبدیل شده است.

---

ترمینال داخلی VS Code.

# نصب Extensionها

یکی از مهم‌ترین قابلیت‌های VS Code، پشتیبانی از افزونه‌ها (Extensions) است.

افزونه‌ها امکانات جدیدی به VS Code اضافه می‌کنند.

برای نصب افزونه:

1. روی آیکون Extensions کلیک کنید.
2. نام افزونه را جستجو کنید.
3. روی Install کلیک کنید.

# Extensionهای ضروری این دوره

## ESLint

بررسی خطاهای کدنویسی و رعایت استانداردهای JavaScript.

مزایا:

* پیشنهاد اصلاح
* افزایش کیفیت کد

فرمت‌کننده خودکار کد.

کاربرد:

* مرتب کردن فاصله‌ها
* مرتب کردن تورفتگی‌ها

تقریباً تمام تیم‌های حرفه‌ای از Prettier استفاده می‌کنند.

## Error Lens

نمایش خطاها مستقیماً داخل فایل.

امکانات:

* مقایسه نسخه‌ها
* مدیریت Git

باعث خواناتر شدن پروژه می‌شود.

افزونه هوشمند Microsoft برای پیشنهاد بهتر کدها.

## DotENV

## npm IntelliSense

تکمیل خودکار نام Packageها هنگام Import.

## Code Spell Checker

بررسی غلط‌های املایی در کد و کامنت‌ها.

# تنظیمات کاربردی

## Word Wrap

مطالعه کد را بسیار راحت‌تر می‌کند.

## Tab Size

تعداد فاصله‌های هر Tab.

نمای کوچکی از کل فایل در سمت راست Editor.

برای فایل‌های بزرگ بسیار کاربردی است.

## Font Size

# Debug چیست؟

یکی از مهم‌ترین قابلیت‌های VS Code، Debugger داخلی آن است.

به جای استفاده از `console.log()` در همه جا، می‌توانید برنامه را مرحله‌به‌مرحله اجرا کنید.

# Breakpoint

Breakpoint یعنی توقف اجرای برنامه در یک خط مشخص.

برای ایجاد Breakpoint:

روی سمت چپ شماره خط کلیک کنید.

یک دایره قرمز ظاهر می‌شود.

اکنون هنگام اجرای برنامه، اجرای کد در همان نقطه متوقف می‌شود.

---

# امکانات Debugger

در هنگام Debug می‌توانید:

* مقدار متغیرها را ببینید.

* وارد توابع شوید.
* از توابع خارج شوید.
* مقدار Expressionها را بررسی کنید.
* Call Stack را مشاهده کنید.

# اشتباهات رایج

### ❌ نصب تعداد زیادی Extension

هر افزونه مقداری از حافظه و پردازنده را مصرف می‌کند.

تنها افزونه‌هایی را نصب کنید که واقعاً به آن‌ها نیاز دارید.

---

### ❌ غیرفعال بودن Format On Save

در پروژه‌های تیمی باعث ناهماهنگی ظاهر کدها می‌شود.

---

### ❌ استفاده نکردن از Debugger

بسیاری از مبتدیان فقط از `console.log()` استفاده می‌کنند، در حالی که Debugger ابزار بسیار قدرتمندتری است.

---

### ❌ باز کردن فایل به جای پوشه پروژه

همیشه پوشه پروژه را باز کنید تا VS Code بتواند امکاناتی مانند Git، IntelliSense و Debug را به درستی مدیریت کند.

---

### ❌ ذخیره نکردن Workspace

اگر روی چند پروژه کار می‌کنید، Workspace باعث صرفه‌جویی زیادی در زمان خواهد شد.

---

# نکات حرفه‌ای

* از همان ابتدا به استفاده از میانبرهای صفحه‌کلید عادت کنید؛ سرعت کدنویسی شما به‌طور محسوسی افزایش خواهد یافت.
* افزونه‌های خود را به‌روز نگه دارید، اما پیش از به‌روزرسانی پروژه‌های حساس، تغییرات نسخه جدید را بررسی کنید.
* از تنظیمات همگام‌سازی (Settings Sync) برای انتقال تنظیمات، افزونه‌ها و میانبرها بین چند دستگاه استفاده کنید.
* فایل‌های تنظیمات پروژه (`.vscode`) را فقط زمانی در Git قرار دهید که برای همه اعضای تیم مفید باشند.
* Debugger را بخشی از فرایند توسعه بدانید، نه ابزاری فقط برای زمان بروز خطا.

# پاسخ تشریحی

## پاسخ تمرین ۱

اگر افزونه‌ها در بخش **Extensions** با وضعیت **Installed** نمایش داده شوند، نصب با موفقیت انجام شده است.

## پاسخ تمرین ۲

در صفحه تنظیمات، گزینه‌های خواسته‌شده را فعال کنید تا فایل‌ها به‌صورت خودکار ذخیره و قالب‌بندی شوند و پرانتزهای متناظر با رنگ‌های مختلف نمایش داده شوند.

## پاسخ تمرین ۳

اگر خروجی برنامه در ترمینال نمایش داده شود، VS Code و Node.js به‌درستی با یکدیگر کار می‌کنند.

## پاسخ تمرین ۴

با کلیک روی حاشیه سمت چپ شماره خط، یک Breakpoint ایجاد می‌شود. سپس برنامه را از بخش **Run and Debug** اجرا کنید تا اجرای آن در همان نقطه متوقف شود و بتوانید مقادیر متغیرها را بررسی کنید.

# مینی‌پروژه

## آماده‌سازی محیط توسعه حرفه‌ای

در این پروژه، VS Code را برای ادامه دوره به یک محیط توسعه استاندارد تبدیل می‌کنید.

### مراحل پروژه

1. یک Workspace جدید با نام `learn-js-and-node` ایجاد کنید.
2. پوشه‌های زیر را به Workspace اضافه کنید:

```text
learn-js-and-node
│
├── lessons
├── exercises
├── mini-projects
├── playground
└── notes
```

3. افزونه‌های معرفی‌شده در این فصل را نصب کنید.
4. گزینه‌های زیر را فعال کنید:

   * Auto Save
   * Format On Save
   * Bracket Pair Colorization
   * Sticky Scroll
5. یک پروژه Node.js را داخل پوشه `playground` ایجاد کنید.
6. فایل `index.js` را بسازید و برنامه‌ای بنویسید که عبارت زیر را چاپ کند:

```text
VS Code is ready for development!
```

7. برنامه را از طریق ترمینال داخلی اجرا کنید.
8. روی خط `console.log` یک Breakpoint قرار دهید و برنامه را با Debugger اجرا کنید.

### هدف پروژه

در پایان این مینی‌پروژه، محیط توسعه شما به‌صورت استاندارد پیکربندی شده است، با مهم‌ترین امکانات VS Code آشنا شده‌اید و می‌توانید از ترمینال، افزونه‌ها، Debugger و Workspace برای توسعه پروژه‌های Node.js به شکلی حرفه‌ای استفاده کنید.

در فصل بعد، از محیط توسعه فاصله می‌گیریم و با **Command Line (خط فرمان)** آشنا می‌شویم؛ ابزاری که یکی از مهم‌ترین مهارت‌های هر توسعه‌دهنده Node.js است و در طول این دوره بارها از آن استفاده خواهیم کرد.
