# بخش ۱ - نصب و آماده‌سازی محیط

در این بخش، محیط توسعه را برای شروع برنامه‌نویسی با **JavaScript در Node.js** آماده می‌کنیم.

اگر هیچ تجربه‌ای در برنامه‌نویسی ندارید، نگران نباشید؛ در این بخش از پایه با ابزارهایی که در ادامه دوره به آن‌ها نیاز داریم آشنا می‌شوید و اولین پروژه Node.js خود را اجرا می‌کنید.

---

## 📚 فهرست فصل‌ها

### فصل ۴ - نصب ابزارها

در این فصل ابزارهای اصلی موردنیاز برای برنامه‌نویسی با Node.js را نصب و آماده می‌کنیم.

- نصب Node.js
- نصب VS Code
- نصب Git
- آشنایی با npm
- نصب pnpm
- نصب Yarn
- ساخت اولین پروژه Node.js
- اجرای اولین برنامه

**تمرین**

[مشاهده فصل ۴ ←](./1.1.md)

---

### فصل ۵ - آشنایی با VS Code

در این فصل با محیط توسعه VS Code آشنا می‌شویم و تنظیمات و امکاناتی را یاد می‌گیریم که در طول دوره از آن‌ها استفاده خواهیم کرد.

- آشنایی با محیط VS Code
- نصب Extensionها
- تنظیمات کاربردی
- استفاده از Terminal
- Debug کردن برنامه
- ساخت و مدیریت Workspace

**تمرین**

[مشاهده فصل ۵ ←](./1.2.md)

---

### فصل ۶ - Command Line

در این فصل با خط فرمان آشنا می‌شویم؛ ابزاری که در دنیای Node.js و توسعه Backend بسیار پرکاربرد است.

- مفهوم Command Line
- پوشه‌ها
- فایل‌ها
- دستورات مهم
- مسیرها
- مسیر نسبی و مطلق
- متغیرهای محیطی
- اجرای فایل‌ها
- کار با پروژه از طریق Terminal

## 🎯 هدف بخش ۱

در پایان این بخش باید بتوانید:

* Node.js را روی سیستم خود نصب کنید.
* نسخه Node.js و npm را بررسی کنید.
* VS Code را برای توسعه Node.js آماده کنید.
* Git را نصب و آماده استفاده کنید.
* با npm، pnpm و Yarn آشنایی اولیه داشته باشید.
* یک پروژه Node.js ایجاد کنید.
* اولین فایل JavaScript خود را اجرا کنید.
* با Terminal و Command Line کار کنید.
* فایل‌ها و پوشه‌ها را از طریق خط فرمان مدیریت کنید.
* مسیرهای فایل‌ها را درک کنید.
* دستورات پایه موردنیاز توسعه Node.js را اجرا کنید.
