# نصب Node.js

اولین و مهم‌ترین ابزار این دوره، Node.js است.

Node.js همان Runtime است که کدهای JavaScript را اجرا می‌کند.

بدون نصب Node.js امکان اجرای برنامه‌های این دوره وجود ندارد.

---

## دانلود Node.js

برای دانلود Node.js همیشه از وب‌سایت رسمی استفاده کنید.

نسخه‌های Node.js معمولاً در دو شاخه منتشر می‌شوند:

### LTS (Long-Term Support)

* پایدار
* مناسب پروژه‌های واقعی
* مناسب یادگیری
* پشتیبانی بلندمدت

### Current

* جدیدترین قابلیت‌ها
* مناسب تست ویژگی‌های جدید
* احتمال تغییر بیشتر

**برای این دوره همیشه نسخه LTS پیشنهاد می‌شود.**

---

## نصب در Windows

1. فایل نصب را دانلود کنید.
2. فایل را اجرا کنید.
3. گزینه **Next** را انتخاب کنید.
4. شرایط استفاده را تأیید کنید.
5. مسیر نصب را تغییر ندهید.
6. نصب را کامل کنید.
7. سیستم را در صورت نیاز Restart کنید.

---

## نصب در Linux

بسته به توزیع لینوکس، روش نصب متفاوت است.

در پروژه‌های واقعی معمولاً از ابزارهایی مانند **nvm** برای مدیریت نسخه‌های مختلف Node.js استفاده می‌شود که در فصل‌های بعد با آن آشنا خواهیم شد.

---

## نصب در macOS

در macOS نیز می‌توان از Installer رسمی یا ابزارهای مدیریت بسته مانند Homebrew استفاده کرد.

# نصب npm

یکی از رایج‌ترین سؤال‌های افراد تازه‌کار این است:

> آیا npm را باید جداگانه نصب کنیم؟

پاسخ:

**خیر.**

npm به صورت پیش‌فرض همراه Node.js نصب می‌شود.

پس از نصب Node.js، npm نیز آماده استفاده خواهد بود.

دستور زیر را اجرا کنید:


نمونه خروجی:

```text

```

# npm چیست؟

npm مخفف عبارت زیر است:

**Node Package Manager**

npm دو وظیفه مهم دارد:

* مدیریت کتابخانه‌ها (Packages)
* مدیریت پروژه

تقریباً تمام پروژه‌های Node.js از npm استفاده می‌کنند.

در فصل‌های آینده به طور کامل با npm آشنا خواهیم شد.

# نصب Visual Studio Code

برای نوشتن کد به یک ویرایشگر (Code Editor) نیاز داریم.

در این دوره از **Visual Studio Code** استفاده خواهیم کرد.

دلایل انتخاب VS Code:

* سریع
* متن‌باز
* افزونه‌های فراوان
* پشتیبانی بسیار خوب از JavaScript و Node.js
* Debugger داخلی
* Terminal داخلی
* Git داخلی

## نصب VS Code

3. گزینه‌های پیش‌فرض را تغییر ندهید.

   * Open with Code

# نصب Git

Git سیستم کنترل نسخه (Version Control System) است.

تقریباً تمام پروژه‌های نرم‌افزاری دنیا از Git استفاده می‌کنند.

با Git می‌توانید:

* تاریخچه پروژه را ذخیره کنید.
* تغییرات را مدیریت کنید.
* به نسخه‌های قبلی بازگردید.
* با سایر توسعه‌دهندگان همکاری کنید.

---

# اشتباهات رایج

### ❌ نصب نسخه Current به جای LTS

برای یادگیری و پروژه‌های واقعی، نسخه LTS انتخاب مناسب‌تری است.

---

### ❌ دانلود Node.js از منابع غیررسمی

همیشه نرم‌افزارها را از وب‌سایت رسمی دریافت کنید تا از امنیت و به‌روز بودن آن‌ها مطمئن باشید.

---

### ❌ نصب هم‌زمان چند نسخه Node.js بدون مدیریت نسخه

این کار می‌تواند باعث ناسازگاری پروژه‌ها شود. در آینده با ابزارهایی مانند nvm این مشکل را مدیریت خواهیم کرد.

---

### ❌ اجرا کردن فایل JavaScript با دوبار کلیک

فایل‌های Node.js باید از طریق ترمینال و دستور `node` اجرا شوند، نه با دوبار کلیک روی فایل.

---

### ❌ ایجاد فایل با نام اشتباه

دقت کنید فایل را با پسوند `.js` ذخیره کنید، نه `.txt` یا پسوندهای دیگر.

---

### ❌ نادیده گرفتن پیام‌های خطا

اگر هنگام نصب یا اجرای برنامه خطایی مشاهده کردید، متن خطا را با دقت بخوانید. بسیاری از مشکلات با همان پیام قابل حل هستند.
