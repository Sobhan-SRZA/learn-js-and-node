قبل از اینکه به سراغ مفاهیم اصلی JavaScript برویم، باید با یکی از مهم‌ترین ابزارهای هر برنامه‌نویس آشنا شویم: **Command Line** یا **خط فرمان**. بسیاری از توسعه‌دهندگان تازه‌کار در ابتدا از ترمینال می‌ترسند، اما بعد از مدتی متوجه می‌شوند که تقریباً تمام کارهای حرفه‌ای در Node.js از طریق ترمینال انجام می‌شود. در این فصل، Command Line را از پایه و بدون هیچ پیش‌نیازی یاد می‌گیریم.

# فصل 6 - Command Line

اگر تا امروز بیشتر با محیط‌های گرافیکی (GUI) کار کرده باشید، احتمالاً برای باز کردن پوشه‌ها، ساخت فایل‌ها یا اجرای برنامه‌ها از ماوس استفاده کرده‌اید.

اما در دنیای برنامه‌نویسی، مخصوصاً در Node.js، بخش بزرگی از کارها از طریق **Command Line** انجام می‌شود.

در ابتدا ممکن است کار با ترمینال سخت به نظر برسد، اما پس از مدتی متوجه خواهید شد که بسیاری از کارها با چند دستور ساده، سریع‌تر و راحت‌تر از محیط گرافیکی انجام می‌شوند.

تقریباً تمام پروژه‌های Node.js، فریمورک‌ها، ابزارهای Build، سیستم‌های استقرار (Deployment) و حتی سرورهای لینوکسی بر پایه Command Line کار می‌کنند.

در این فصل یاد می‌گیریم چگونه با ترمینال کار کنیم و فایل‌ها و پروژه‌های خود را مدیریت کنیم.

---

# Command Line چیست؟

Command Line یا CLI (Command Line Interface) محیطی است که به جای استفاده از دکمه‌ها و منوها، دستورات متنی را وارد می‌کنید.

مثلاً به جای اینکه روی پوشه کلیک کنید، می‌نویسید:

```bash
cd projects
```

یا به جای ساخت فایل از منوی راست کلیک، می‌نویسید:

```bash
touch index.js
```

ترمینال دستور را دریافت می‌کند و آن را اجرا می‌کند.

---

# چرا باید Command Line را یاد بگیریم؟

تقریباً تمام ابزارهای Node.js از طریق ترمینال اجرا می‌شوند.

برای مثال:

* اجرای برنامه
* نصب Packageها
* ساخت پروژه
* اجرای Git
* اجرای تست‌ها
* Build پروژه
* اجرای Docker
* اجرای ابزارهای CI/CD

اگر Command Line را بلد نباشید، کار کردن با Node.js بسیار سخت خواهد شد.

# اشتباهات رایج

### ❌ اجرا کردن دستورات در پوشه اشتباه

### ❌ بستن برنامه به جای متوقف کردن آن

اگر برنامه در ترمینال در حال اجراست، برای توقف آن از `Ctrl + C` استفاده کنید، نه بستن ناگهانی پنجره ترمینال.

---

### ❌ تایپ اشتباه نام فایل

سیستم‌عامل‌هایی مانند Linux و macOS به بزرگی و کوچکی حروف حساس هستند. `Index.js` و `index.js` دو فایل متفاوت محسوب می‌شوند.

* یادگیری ترمینال فقط برای Node.js نیست؛ این مهارت در Git، Docker، Linux، Cloud و بسیاری از فناوری‌های دیگر نیز کاربرد دارد.

# مینی‌پروژه

## مدیریت یک پروژه فقط با Command Line

در این پروژه، بدون استفاده از محیط گرافیکی فایل‌ها و پوشه‌های یک پروژه را مدیریت می‌کنید.

### مراحل پروژه

1. پوشه‌ای با نام `node-cli-project` ایجاد کنید.
2. وارد آن شوید.
3. ساختار زیر را تنها با استفاده از Command Line ایجاد کنید:

```text
node-cli-project
│
├── src
│   ├── index.js
│   └── server.js
├── config
│   └── app.js
├── public
├── package.json
└── README.md
```

4. با استفاده از `npm init -y` فایل `package.json` را ایجاد کنید.
5. داخل فایل `src/index.js` برنامه‌ای بنویسید که عبارت زیر را چاپ کند:

```text
Node.js Command Line Project
```

6. برنامه را از طریق ترمینال اجرا کنید.
7. فایل `server.js` را به `main.js` تغییر نام دهید.
8. در پایان، ساختار نهایی پروژه را با دستور مناسب در ترمینال بررسی کنید.

### هدف پروژه

در پایان این مینی‌پروژه، بدون وابستگی به رابط گرافیکی می‌توانید فایل‌ها و پوشه‌ها را ایجاد، مدیریت، تغییر نام و اجرا کنید. این مهارت پایه‌ای، در تمام مسیر یادگیری Node.js، کار با Git، Docker، سرورهای لینوکسی و پروژه‌های حرفه‌ای مورد استفاده قرار خواهد گرفت.

این فصل پایان بخش آماده‌سازی محیط توسعه است. از فصل بعد، وارد **JavaScript واقعی در محیط Node.js** می‌شویم و نوشتن کد را از پایه آغاز خواهیم کرد؛ از اولین دستورها، متغیرها، انواع داده و مفاهیمی که پایه تمام پروژه‌های آینده هستند.
