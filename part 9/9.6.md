# فصل 72 - ساخت Package

## مقدمه

یکی از قدرت‌های اصلی اکوسیستم Node.js قابلیت ساخت و انتشار Packageهای شخصی است.

در Node.js فقط مصرف‌کننده Packageهای دیگر نیستیم؛ بلکه می‌توانیم:

* کتابخانه‌های کاربردی بسازیم.
* ابزارهای CLI ایجاد کنیم.
* کدهای قابل استفاده مجدد تولید کنیم.
* Package خودمان را در npm منتشر کنیم.
* برای دیگر برنامه‌نویسان ابزار بسازیم.

بسیاری از ابزارهای معروف Node.js مانند:

* Express
* Lodash
* Axios
* Jest

به شکل Package ساخته شده‌اند.

در این فصل یاد می‌گیریم چگونه از صفر یک Package استاندارد Node.js بسازیم.

# جمع‌بندی

ساخت Package یکی از مهارت‌های سطح بالای Node.js است.

با ساخت Package یاد می‌گیریم:

* کد قابل استفاده مجدد تولید کنیم.
* ابزارهای شخصی بسازیم.
* پروژه‌ها را ماژولار کنیم.
* در اکوسیستم npm مشارکت کنیم.

یک توسعه‌دهنده حرفه‌ای Node.js فقط Package مصرف نمی‌کند؛ بلکه توانایی ساخت و انتشار Packageهای استاندارد را نیز دارد.
