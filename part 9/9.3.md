# فصل 69 - package-lock

## مقدمه

در پروژه‌های Node.js مدیریت Dependencyها یکی از مهم‌ترین بخش‌های توسعه نرم‌افزار است.

وقتی یک Package نصب می‌کنیم، آن Package معمولاً خودش Dependencyهای دیگری دارد.

مثلاً:

```text
 id="f6k9rp"
Project

 |
 ↓

Express

 |
 ↓

body-parser

 |
 ↓

Other Packages
```

اگر فقط نام Packageها را در `package.json` ذخیره کنیم، ممکن است در سیستم‌های مختلف نسخه‌های متفاوتی نصب شوند.

اینجا فایل:

```text
package-lock.json
```

وارد می‌شود.

این فایل وظیفه دارد:

* نسخه دقیق Packageها را ثبت کند.
* ساختار کامل Dependencyها را ذخیره کند.
* نصب پروژه را قابل تکرار کند.
* از اختلاف محیط‌ها جلوگیری کند.

---

# 69.1 - package-lock چیست؟

`package-lock.json` یک فایل خودکار ساخته شده توسط npm است که اطلاعات دقیق Dependencyهای پروژه را ذخیره می‌کند.

مثال:

package.json:

```json id="m9q2ks"
{
  "dependencies": {
    "express": "^5.0.0"
  }
}
```

ممکن است package-lock ذخیره کند:

```json id="z4n7bd"
{
  "express": {
    "version": "5.0.1"
  }
}
```

یعنی دقیقاً مشخص می‌کند چه نسخه‌ای نصب شده است.

# جمع‌بندی

فایل **package-lock.json** یکی از مهم‌ترین بخش‌های مدیریت پروژه‌های Node.js است.

این فایل تضمین می‌کند که:

* همه اعضای تیم یک Dependency یکسان داشته باشند.
* Deployment قابل پیش‌بینی باشد.
* نسخه Packageها ناخواسته تغییر نکند.
* امنیت و پایداری پروژه بیشتر شود.

در پروژه‌های حرفه‌ای Node.js، ترکیب:

```text
package.json
+
package-lock.json
+
npm ci
```

پایه یک مدیریت Dependency استاندارد و قابل اعتماد را تشکیل می‌دهد.
