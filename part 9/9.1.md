# فصل 67 - npm

## مقدمه

در دنیای واقعی توسعه نرم‌افزار، تقریباً هیچ پروژه بزرگی فقط با امکانات خام یک زبان ساخته نمی‌شود.

برنامه‌نویس‌ها برای حل مشکلات مختلف از **Package**ها و کتابخانه‌های آماده استفاده می‌کنند.

در اکوسیستم Node.js، ابزار اصلی مدیریت این Packageها، **npm** است.

npm مخفف:

```text
Node Package Manager
```

است و یکی از مهم‌ترین ابزارهای توسعه‌دهندگان Node.js محسوب می‌شود.

با npm می‌توانیم:

* Package نصب کنیم.
* وابستگی‌های پروژه را مدیریت کنیم.
* Script اجرا کنیم.
* نسخه Packageها را کنترل کنیم.
* پروژه را منتشر کنیم.
* ابزارهای توسعه نصب کنیم.

تقریباً تمام پروژه‌های حرفه‌ای Node.js با npm مدیریت می‌شوند.


---

# 67.9 - فایل package-lock.json

این فایل نسخه دقیق Packageها را ذخیره می‌کند.

مثلاً:

package.json:

```json
"express":"^5.0.0"
```

اما lock:

```json
"express":"5.0.1"
```

مزیت:

* نصب یکسان روی همه سیستم‌ها
* جلوگیری از اختلاف نسخه

# جمع‌بندی

npm قلب اکوسیستم Node.js است.

با npm می‌توانیم:

* کتابخانه‌های مورد نیاز را مدیریت کنیم.
* پروژه‌ها را استاندارد کنیم.
* Scriptهای حرفه‌ای بسازیم.
* Package منتشر کنیم.
* امنیت Dependencyها را بررسی کنیم.

تسلط بر npm یکی از مهارت‌های ضروری برای هر توسعه‌دهنده حرفه‌ای Node.js است، زیرا تقریباً تمام پروژه‌های واقعی Node.js به شکل مستقیم با npm مدیریت می‌شوند.
