# فصل 71 - نصب Package

## مقدمه

یکی از مهم‌ترین قابلیت‌های Node.js، استفاده از Packageهای آماده است.

در پروژه‌های واقعی، برنامه‌نویس‌ها معمولاً همه چیز را از صفر پیاده‌سازی نمی‌کنند.

به جای ساختن دوباره:

* HTTP Server
* Authentication
* Validation
* Database Connection
* Logging System
* Testing Tools

از Packageهای موجود در اکوسیستم npm استفاده می‌کنند.

برای مثال:

* Express برای ساخت API
* Mongoose برای کار با MongoDB
* Jest برای تست
* Zod برای Validation
* Dotenv برای مدیریت Environment Variable

نصب و مدیریت درست Packageها یکی از مهارت‌های اصلی هر توسعه‌دهنده حرفه‌ای Node.js است.

---

# 71.1 - Package چیست؟

Package یک مجموعه کد آماده است که قابلیت خاصی را به پروژه اضافه می‌کند.

مثال:

بدون Package:

```js id="qz1m3f"
const http =
require("http");


const server =
http.createServer();
```

با Package:

```js id="5d9q2w"
const express =
require("express");


const app =
express();
```

---

# 71.2 - npm و نصب Package

npm ابزار اصلی نصب Package در Node.js است.

فرمان کلی:

```bash id="h7m2kx"
npm install package-name
```

یا کوتاه:

```bash id="p3w8yz"
npm i package-name
```

---

مثال:

```bash id="7f8q3m"
npm install express
```

بعد از نصب:

```text id="4n7tpx"
node_modules/

package.json

package-lock.json
```

ایجاد یا تغییر می‌کنند.

# 71.29 - نکات حرفه‌ای

* قبل از نصب Package آن را بررسی کن.
* نسخه Packageهای مهم را کنترل کن.
* در Production از npm ci استفاده کن.
* Dependencyهای اضافی را حذف کن.
* package-lock را Commit کن.
* از Packageهای معتبر استفاده کن.
* Vulnerabilityها را با npm audit بررسی کن.
* نصب Global را فقط برای ابزارهای CLI انجام بده.
* قبل از Update بزرگ تست اجرا کن.
