# فصل ۳۷ - Promise (وعده در جاوااسکریپت)

## مقدمه

در فصل قبل با **Callback** آشنا شدیم و دیدیم که چگونه می‌توان بعد از پایان یک عملیات، تابع دیگری را اجرا کرد.

اما Callbackها یک مشکل بزرگ داشتند:

* تو در تو شدن کدها (Callback Hell)
* مدیریت سخت خطاها
* خوانایی پایین
* دشوار شدن نگهداری پروژه

برای حل این مشکلات، جاوااسکریپت مفهوم **Promise** را معرفی کرد.

امروزه تقریباً تمام کتابخانه‌های مدرن Node.js و مرورگرها از Promise استفاده می‌کنند و حتی `async/await` نیز بر پایه Promise ساخته شده است.

اگر Promise را به خوبی یاد بگیرید، یادگیری Async/Await بسیار ساده خواهد شد.

---

# ۳۷.۱ - Promise چیست؟

Promise یک **شیء (Object)** است که نماینده نتیجه یک عملیات **ناهمزمان** در آینده است.

به زبان ساده:

> Promise قول می‌دهد که نتیجه یک عملیات را در آینده در اختیار شما قرار دهد.

این نتیجه ممکن است:

* موفق باشد.
* با خطا مواجه شود.

---

# ۳۷.۲ - چرا Promise به وجود آمد؟

فرض کنید بخواهیم:

* کاربر را احراز هویت کنیم.
* اطلاعات پروفایل را دریافت کنیم.
* لیست سفارش‌ها را بگیریم.
* فاکتور را تولید کنیم.

با Callbackها ممکن است به ساختاری مانند زیر برسیم:

```js id="gfwgkw"
login(() => {
  getProfile(() => {
    getOrders(() => {
      createInvoice(() => {
        console.log("Done");
      });
    });
  });
});
```

این ساختار خوانایی کمی دارد.

Promise این مشکل را با زنجیره‌ای کردن عملیات حل می‌کند.

---

# ۳۷.۳ - وضعیت‌های Promise

هر Promise فقط می‌تواند در یکی از سه حالت زیر باشد:

### Pending

عملیات هنوز در حال انجام است.

---

### Fulfilled

عملیات با موفقیت تمام شده است.

---

### Rejected

عملیات با خطا مواجه شده است.

---

به صورت نموداری:

```text id="wly2hk"
Pending

├── Fulfilled

└── Rejected
```

پس از تبدیل شدن Promise به `Fulfilled` یا `Rejected`، وضعیت آن دیگر تغییر نمی‌کند.

---

# ۳۷.۴ - ساخت Promise

ساختار کلی:

```js id="jfhm1g"
const promise = new Promise((resolve, reject) => {

});
```

تابع سازنده Promise دو آرگومان دریافت می‌کند:

* `resolve`
* `reject`

---

# ۳۷.۵ - resolve

اگر عملیات موفق باشد:

```js id="r33fqn"
const promise = new Promise((resolve) => {
  resolve("Success");
});
```

---

# ۳۷.۶ - reject

اگر عملیات با خطا مواجه شود:

```js id="c5dndf"
const promise = new Promise((resolve, reject) => {
  reject(new Error("Something went wrong"));
});
```

---

# ۳۷.۷ - استفاده از then()

برای دریافت نتیجه موفق:

```js id="n4t50i"
const promise = Promise.resolve("Hello");

promise.then((result) => {
  console.log(result);
});
```

خروجی:

```text id="0iwb77"
Hello
```

---

# ۳۷.۸ - استفاده از catch()

برای مدیریت خطا:

```js id="9wv6jp"
Promise.reject(new Error("Failed"))
  .catch((error) => {
    console.log(error.message);
  });
```

---

# ۳۷.۹ - استفاده از finally()

کدی که باید در هر حالت اجرا شود:

```js id="f4jqvf"
Promise.resolve()
  .finally(() => {
    console.log("Finished");
  });
```

`finally()` چه Promise موفق باشد و چه ناموفق، اجرا می‌شود.

---

# ۳۷.۱۰ - مثال کامل

```js id="qllwkc"
const login = new Promise((resolve, reject) => {
  const success = true;

  if (success) {
    resolve("Welcome");
  } else {
    reject(new Error("Login failed"));
  }
});

login
  .then((message) => {
    console.log(message);
  })
  .catch((error) => {
    console.log(error.message);
  })
  .finally(() => {
    console.log("Done");
  });
```

---

# ۳۷.۱۱ - Promise Chaining

یکی از مهم‌ترین قابلیت‌های Promise، زنجیره کردن عملیات است.

```js id="5ms9dg"
Promise.resolve(5)
  .then((value) => {
    return value * 2;
  })
  .then((value) => {
    return value + 10;
  })
  .then((value) => {
    console.log(value);
  });
```

خروجی:

```text id="9yfm4v"
20
```

هر `then()` نتیجه مرحله قبل را دریافت می‌کند.

---

# ۳۷.۱۲ - بازگرداندن Promise

داخل `then()` نیز می‌توان Promise جدید برگرداند.

```js id="44ceyq"
Promise.resolve(10)
  .then((value) => {
    return Promise.resolve(value * 3);
  })
  .then((result) => {
    console.log(result);
  });
```

---

# ۳۷.۱۳ - Promise و Event Loop

Callbackهای Promise مستقیماً اجرا نمی‌شوند.

آن‌ها وارد:

**Microtask Queue**

می‌شوند.

به همین دلیل معمولاً قبل از Callbackهای `setTimeout()` اجرا خواهند شد.

---

# ۳۷.۱۴ - Promise.resolve()

ساخت سریع Promise موفق:

```js id="j10pcv"
Promise.resolve("Node.js")
  .then(console.log);
```

---

# ۳۷.۱۵ - Promise.reject()

ساخت سریع Promise ناموفق:

```js id="2e66i6"
Promise.reject(new Error("Error"))
  .catch(console.error);
```

---

# ۳۷.۱۶ - Promise.all()

چند Promise را همزمان اجرا می‌کند.

```js id="tw3t42"
Promise.all([
  Promise.resolve(1),
  Promise.resolve(2),
  Promise.resolve(3)
]).then(console.log);
```

خروجی:

```text id="yjnnx7"
[1, 2, 3]
```

اگر حتی یکی از Promiseها رد (Rejected) شود، `Promise.all()` نیز رد خواهد شد.

---

# ۳۷.۱۷ - Promise.allSettled()

نتیجه تمام Promiseها را برمی‌گرداند؛ چه موفق باشند و چه ناموفق.

```js id="hmjlwm"
Promise.allSettled([
  Promise.resolve("OK"),
  Promise.reject("Error")
]).then(console.log);
```

---

# ۳۷.۱۸ - Promise.race()

اولین Promise که تعیین تکلیف شود (Resolve یا Reject)، نتیجه نهایی را مشخص می‌کند.

```js id="j7v3nh"
Promise.race([
  Promise.resolve("First"),
  new Promise(() => {})
]).then(console.log);
```

---

# ۳۷.۱۹ - Promise.any()

اولین Promise موفق را برمی‌گرداند.

```js id="9t5k6p"
Promise.any([
  Promise.reject("A"),
  Promise.resolve("B"),
  Promise.resolve("C")
]).then(console.log);
```

خروجی:

```text id="3w3s4n"
B
```

اگر همه Promiseها رد شوند، `Promise.any()` با خطا مواجه می‌شود.

---

# ۳۷.۲۰ - تبدیل Callback به Promise

فرض کنید API زیر را داریم:

```js id="dlj8r7"
function getData(callback) {
  setTimeout(() => {
    callback(null, "Data");
  }, 1000);
}
```

نسخه Promise:

```js id="sz2y4f"
function getData() {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve("Data");
    }, 1000);
  });
}
```

این روش خواناتر است و به‌راحتی با `then()` یا `async/await` ترکیب می‌شود.

---

# اشتباهات رایج

## ۱) فراموش کردن `return` در زنجیره Promise

اشتباه:

```js id="r0th1t"
Promise.resolve(5)
  .then((value) => {
    value * 2;
  })
  .then(console.log);
```

خروجی:

```text id="whz4qd"
undefined
```

زیرا مقدار بازگردانده نشده است.

---

## ۲) استفاده نکردن از `catch()`

اگر خطا مدیریت نشود، ممکن است Promise به صورت **Unhandled Rejection** باقی بماند.

---

## ۳) ایجاد Promise غیرضروری

گاهی یک API خودش Promise برمی‌گرداند و نیازی به ساخت Promise جدید نیست.

---

## ۴) استفاده همزمان از Callback و Promise

یک تابع بهتر است فقط از **یک الگوی ناهمزمان** استفاده کند، نه هر دو.

---

## ۵) تصور اینکه Promise عملیات را همزمان می‌کند

Promise فقط مدیریت عملیات ناهمزمان را ساده‌تر می‌کند؛ اجرای کد همچنان توسط Event Loop انجام می‌شود.

---

# نکات حرفه‌ای

* همیشه انتهای زنجیره Promise از `catch()` استفاده کنید.
* برای عملیات مستقل از `Promise.all()` استفاده کنید تا همه آن‌ها به صورت همزمان آغاز شوند.
* اگر نتیجه همه عملیات برایتان مهم است، از `Promise.allSettled()` استفاده کنید.
* از ایجاد Promiseهای تو در تو خودداری کنید؛ آن‌ها را زنجیره‌ای کنید.
* برای کدهای جدید، در صورت امکان از `async/await` استفاده کنید؛ زیرا خواناتر است.
* مستندات هر کتابخانه را بررسی کنید تا بدانید آیا متد موردنظر Promise برمی‌گرداند یا خیر.

## پاسخ ۳

* `then()` برای دریافت نتیجه موفق (`Fulfilled`) استفاده می‌شود.

* `Promise.all()` در صورت رد شدن حتی یک Promise، کل عملیات را رد می‌کند.

## پاسخ ۵

زیرا عملیات به صورت زنجیره‌ای و خطی نوشته می‌شوند و نیازی به تو در تو کردن Callbackها نیست. این موضوع خواندن، نگهداری و مدیریت خطاها را ساده‌تر می‌کند.

# مینی‌پروژه

## پروژه: شبیه‌ساز دانلود فایل با Promise

برنامه‌ای بنویسید که دانلود یک فایل را با استفاده از Promise شبیه‌سازی کند.

### مرحله اول

تابعی ایجاد کنید که یک Promise برگرداند.

```js id="9p6qct"
function downloadFile(fileName) {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve(`${fileName} downloaded`);
    }, 2000);
  });
}
```

### مرحله دوم

با استفاده از `then()` نتیجه را نمایش دهید.

### مرحله سوم

در صورتی که نام فایل خالی باشد، Promise را با `reject()` رد کنید و خطا را با `catch()` مدیریت کنید.

### مرحله چهارم

سه دانلود مختلف را با `Promise.all()` اجرا کنید و پس از پایان همه آن‌ها، پیام موفقیت نمایش دهید.

### اهداف پروژه

* ساخت Promise
* استفاده از `resolve` و `reject`
* مدیریت خطا با `catch()`
* استفاده از `finally()`
* آشنایی با `Promise.all()`
* درک بهتر زنجیره Promiseها

---

# جمع‌بندی

Promise یکی از مهم‌ترین ویژگی‌های مدرن جاوااسکریپت است که مدیریت عملیات ناهمزمان را بسیار ساده‌تر و خواناتر از Callbackها می‌کند. با استفاده از `then()`، `catch()` و `finally()` می‌توان نتیجه عملیات، خطاها و کدهای پایانی را به شکلی منظم مدیریت کرد. همچنین متدهایی مانند `Promise.all()`، `Promise.allSettled()`، `Promise.race()` و `Promise.any()` ابزارهای قدرتمندی برای هماهنگ کردن چندین عملیات ناهمزمان در اختیار ما قرار می‌دهند. در فصل بعد، خواهیم دید که چگونه **Async/Await** بر پایه Promise ساخته شده و نوشتن کدهای ناهمزمان را حتی ساده‌تر و شبیه به کدهای همزمان می‌کند.
