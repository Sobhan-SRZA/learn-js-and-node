# فصل ۳۶ - Callback (توابع بازگشتی)

## مقدمه

تا اینجا یاد گرفتیم که جاوااسکریپت چگونه کدها را اجرا می‌کند، Call Stack چیست و Event Loop چگونه عملیات ناهمزمان را مدیریت می‌کند.

اما هنوز یک سؤال مهم باقی مانده است:

**وقتی یک عملیات زمان‌بر مانند خواندن فایل یا ارسال درخواست شبکه تمام شد، چگونه جاوااسکریپت متوجه می‌شود که باید ادامه برنامه را اجرا کند؟**

پاسخ این سؤال، **Callback** است.

تقریباً تمام APIهای قدیمی Node.js بر پایه Callback نوشته شده‌اند و حتی امروزه نیز بسیاری از کتابخانه‌ها از آن استفاده می‌کنند. بنابراین، اگرچه امروزه Promise و Async/Await رایج‌تر هستند، یادگیری Callback همچنان برای درک کدهای قدیمی، کار با بسیاری از ماژول‌های Node.js و فهم بهتر Event Loop ضروری است.

---

# ۳۶.۱ - Callback چیست؟

Callback یک **تابع** است که به عنوان **آرگومان** به تابع دیگری ارسال می‌شود تا در زمان مناسب اجرا شود.

به عبارت دیگر:

> Callback یعنی «تابعی که بعداً توسط تابع دیگری فراخوانی می‌شود.»

مثال:

```js
function greet(callback) {
  console.log("Hello");

  callback();
}

function sayBye() {
  console.log("Bye");
}

greet(sayBye);
```

خروجی:

```text
Hello
Bye
```

در این مثال:

* `sayBye` به عنوان Callback ارسال شده است.
* تابع `greet` تصمیم می‌گیرد چه زمانی آن را اجرا کند.

---

# ۳۶.۲ - ارسال تابع به عنوان مقدار

در جاوااسکریپت، تابع نیز مانند سایر مقادیر است.

یعنی می‌توان آن را:

* داخل متغیر ذخیره کرد.
* به عنوان آرگومان ارسال کرد.
* از تابع دیگری بازگرداند.

مثال:

```js
function hello() {
  console.log("Hello");
}

const fn = hello;

fn();
```

---

# ۳۶.۳ - Callback ساده

```js
function calculate(a, b, callback) {
  const result = a + b;

  callback(result);
}

calculate(5, 10, function (sum) {
  console.log(sum);
});
```

خروجی:

```text
15
```

تابع ناشناس به عنوان Callback ارسال شده است.

---

# ۳۶.۴ - Arrow Function به عنوان Callback

امروزه بیشتر Callbackها با Arrow Function نوشته می‌شوند.

```js
calculate(5, 10, (result) => {
  console.log(result);
});
```

---

# ۳۶.۵ - Callback همزمان (Synchronous)

همه Callbackها ناهمزمان نیستند.

مثال:

```js
function run(callback) {
  callback();
}

console.log("A");

run(() => {
  console.log("B");
});

console.log("C");
```

خروجی:

```text
A
B
C
```

زیرا Callback بلافاصله اجرا شده است.

---

# ۳۶.۶ - Callback ناهمزمان (Asynchronous)

```js
console.log("Start");

setTimeout(() => {
  console.log("Timer");
}, 1000);

console.log("End");
```

خروجی:

```text
Start
End
Timer
```

در اینجا Callback بعداً توسط Event Loop اجرا می‌شود.

---

# ۳۶.۷ - Callback در Node.js

بسیاری از APIهای Node.js از Callback استفاده می‌کنند.

مثال:

```js
const fs = require("fs");

fs.readFile("data.txt", (err, data) => {
  if (err) {
    console.error(err);
    return;
  }

  console.log(data.toString());
});
```

وقتی فایل خوانده شد، Callback اجرا می‌شود.

---

# ۳۶.۸ - قرارداد Error-First Callback

تقریباً تمام APIهای قدیمی Node.js از یک قرارداد مشخص استفاده می‌کنند.

به آن می‌گویند:

> **Error-First Callback**

ساختار کلی:

```js
callback(error, result);
```

اگر خطا وجود داشته باشد:

```js
callback(error);
```

اگر موفق باشد:

```js
callback(null, result);
```

---

# ۳۶.۹ - مثال Error-First

```js
function divide(a, b, callback) {
  if (b === 0) {
    callback(new Error("Division by zero"));
    return;
  }

  callback(null, a / b);
}
```

استفاده:

```js
divide(10, 2, (err, result) => {
  if (err) {
    console.error(err.message);
    return;
  }

  console.log(result);
});
```

---

# ۳۶.۱۰ - Callback در Arrayها

متدهای آرایه نیز از Callback استفاده می‌کنند.

مثال:

```js
const numbers = [1, 2, 3];

numbers.forEach((item) => {
  console.log(item);
});
```

در اینجا تابع ارسال‌شده برای هر عضو آرایه اجرا می‌شود.

---

# ۳۶.۱۱ - Callback در map()

```js
const numbers = [1, 2, 3];

const doubled = numbers.map((item) => {
  return item * 2;
});

console.log(doubled);
```

خروجی:

```text
[2, 4, 6]
```

---

# ۳۶.۱۲ - Callback در filter()

```js
const numbers = [10, 15, 20, 25];

const result = numbers.filter((item) => {
  return item > 15;
});

console.log(result);
```

---

# ۳۶.۱۳ - Callback در sort()

```js
const numbers = [8, 2, 10, 1];

numbers.sort((a, b) => {
  return a - b;
});

console.log(numbers);
```

---

# ۳۶.۱۴ - Callback Hell چیست؟

گاهی Callbackها داخل یکدیگر قرار می‌گیرند.

مثال:

```js
login(() => {
  getProfile(() => {
    getPosts(() => {
      getComments(() => {
        console.log("Done");
      });
    });
  });
});
```

به این ساختار می‌گویند:

> **Callback Hell**

زیرا:

* خواندن کد سخت می‌شود.
* نگهداری دشوار می‌شود.
* احتمال خطا افزایش پیدا می‌کند.

---

# ۳۶.۱۵ - راه‌حل Callback Hell

امروزه معمولاً از:

* Promise
* Async/Await

استفاده می‌شود.

در فصل‌های بعدی این دو مفهوم را به طور کامل یاد خواهیم گرفت.

---

# ۳۶.۱۶ - Callback همیشه بهترین انتخاب نیست

Callbackها ساده و سریع هستند، اما برای عملیات پیچیده، Promise و Async/Await خواناتر و مدیریت خطا در آن‌ها آسان‌تر است.

انتخاب ابزار مناسب به نیاز پروژه بستگی دارد.

---

# ۳۶.۱۷ - مزایای Callback

* ساده و قابل فهم
* سرعت مناسب
* مصرف حافظه کم
* پشتیبانی گسترده در Node.js
* مناسب برای عملیات کوتاه

---

# ۳۶.۱۸ - معایب Callback

* ایجاد Callback Hell
* مدیریت سخت خطاها
* کاهش خوانایی در پروژه‌های بزرگ
* دشوار شدن دیباگ در ساختارهای تو در تو

---

# ۳۶.۱۹ - بهترین روش استفاده از Callback

* Callbackها را کوتاه نگه دارید.
* از تو در تو شدن بیش از حد جلوگیری کنید.
* همیشه خطا را بررسی کنید.
* در صورت پیچیده شدن منطق، از Promise یا Async/Await استفاده کنید.

---

# ۳۶.۲۰ - Callback و Event Loop

وقتی یک Callback ناهمزمان آماده اجرا شود:

۱. وارد صف مناسب می‌شود.

۲. Event Loop وضعیت Call Stack را بررسی می‌کند.

۳. اگر Stack خالی باشد، Callback را برای اجرا وارد Call Stack می‌کند.

به همین دلیل Callbackها بخش مهمی از معماری Event Loop هستند.

---

# اشتباهات رایج

## ۱) فراخوانی تابع به جای ارسال آن

اشتباه:

```js
run(callback());
```

در این حالت تابع **همان لحظه اجرا می‌شود**.

درست:

```js
run(callback);
```

---

## ۲) فراموش کردن بررسی خطا

در Error-First Callback همیشه ابتدا `err` را بررسی کنید.

---

## ۳) ایجاد Callback Hell

تو در تو شدن بیش از حد Callbackها باعث کاهش خوانایی کد می‌شود.

---

## ۴) تصور اینکه همه Callbackها ناهمزمان هستند

خیر.

بسیاری از Callbackها مانند `forEach()` و `map()` کاملاً همزمان هستند.

---

## ۵) نوشتن Callbackهای بسیار بزرگ

هر Callback باید فقط یک مسئولیت مشخص داشته باشد.

---

# نکات حرفه‌ای

* همیشه از قرارداد Error-First Callback در APIهای Node.js پیروی کنید.
* Callbackهای کوچک و قابل استفاده مجدد بنویسید.
* در پروژه‌های جدید، در صورت امکان از Promise و Async/Await استفاده کنید.
* از نام‌های معنادار برای Callbackها استفاده کنید تا هدف آن‌ها مشخص باشد.
* اگر چندین Callback پشت سر هم دارید، کد را به توابع کوچک‌تر تقسیم کنید.
* هنگام کار با APIهای قدیمی Node.js، ابتدا مستندات را بررسی کنید تا بدانید Callback در چه زمانی و با چه آرگومان‌هایی فراخوانی می‌شود.

# پاسخ تشریحی

## پاسخ ۱

خروجی:

```text
Hello
```

تابع ارسال‌شده به عنوان Callback توسط `execute` فراخوانی می‌شود.

---

## پاسخ ۲

یکی از پاسخ‌های صحیح:

```js
function add(a, b, callback) {
  callback(a + b);
}

add(5, 7, (result) => {
  console.log(result);
});
```

---

## پاسخ ۳

قراردادی در Node.js است که در آن اولین آرگومان Callback برای خطا (`err`) و آرگومان دوم برای نتیجه عملیات (`result`) استفاده می‌شود.

---

## پاسخ ۴

* Callback همزمان بلافاصله هنگام اجرای تابع فراخوانی می‌شود.
* Callback ناهمزمان پس از پایان یک عملیات مانند خواندن فایل، درخواست شبکه یا Timer اجرا می‌شود.

---

## پاسخ ۵

زیرا با تو در تو شدن Callbackها، کد خوانایی خود را از دست می‌دهد، مدیریت خطا دشوارتر می‌شود و نگهداری آن سخت‌تر خواهد شد.

# مینی‌پروژه

## پروژه: Task Runner با Callback

برنامه‌ای بنویسید که چند وظیفه را با استفاده از Callback اجرا کند.

### مرحله اول

تابعی به نام `runTask` ایجاد کنید که یک نام وظیفه و یک Callback دریافت کند.

```js
function runTask(taskName, callback) {
  console.log(`Starting: ${taskName}`);

  callback();

  console.log(`Finished: ${taskName}`);
}
```

### مرحله دوم

چند Callback مختلف ایجاد کنید.

نمونه:

* خواندن فایل (شبیه‌سازی)
* ارسال ایمیل (شبیه‌سازی)
* ذخیره اطلاعات (شبیه‌سازی)

### مرحله سوم

با استفاده از `setTimeout()` هر وظیفه را با تأخیر متفاوت اجرا کنید و ترتیب اجرای آن‌ها را بررسی کنید.

### مرحله چهارم

نسخه‌ای از پروژه را با Error-First Callback پیاده‌سازی کنید؛ به گونه‌ای که در صورت بروز خطا، اجرای مراحل بعدی متوقف شود.

### اهداف پروژه

* تمرین تعریف و ارسال Callback
* آشنایی با Callbackهای همزمان و ناهمزمان
* استفاده از Error-First Callback
* درک ارتباط Callback با Event Loop
* آماده شدن برای یادگیری Promise و Async/Await

---

# جمع‌بندی

Callback یکی از پایه‌ای‌ترین مفاهیم جاوااسکریپت و Node.js است. در واقع، بسیاری از قابلیت‌های ناهمزمان این زبان بر پایه ارسال و اجرای Callbackها ساخته شده‌اند. اگرچه امروزه Promise و Async/Await در پروژه‌های جدید رایج‌تر هستند، اما درک Callback برای خواندن کدهای موجود، کار با بسیاری از APIهای Node.js و فهم عمیق‌تر Event Loop ضروری است. در فصل بعد، با **Promise** آشنا خواهیم شد و خواهیم دید چگونه بسیاری از محدودیت‌های Callback را برطرف می‌کند.
