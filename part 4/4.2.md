قبل از این فصل با متغیرها و توابع آشنا شدید. اما هنوز یک سؤال مهم باقی مانده است:

اگر یک متغیر را داخل یک تابع تعریف کنیم، آیا خارج از آن تابع هم قابل استفاده است؟

اگر داخل یک `if` یا یک حلقه متغیری بسازیم، آیا در تمام برنامه قابل دسترسی خواهد بود؟

اگر دو متغیر همنام در بخش‌های مختلف برنامه داشته باشیم، JavaScript از کدام استفاده می‌کند؟

پاسخ تمام این سؤال‌ها به مفهومی به نام **Scope (محدوده دسترسی)** مربوط می‌شود.

Scope مشخص می‌کند که **هر متغیر، تابع یا ثابت از کدام قسمت برنامه قابل دسترسی است.**

درک Scope یکی از مهم‌ترین مهارت‌های هر برنامه‌نویس JavaScript است؛ زیرا بسیاری از خطاهای رایج، باگ‌های منطقی و حتی مشکلات امنیتی به دلیل درک نادرست Scope ایجاد می‌شوند.

در پروژه‌های واقعی Node.js، از APIها و ربات‌های تلگرام گرفته تا سرورهای Express و برنامه‌های CLI، مدیریت صحیح Scope باعث می‌شود کدهای شما تمیزتر، امن‌تر و قابل نگهداری‌تر باشند.

---

# فصل 18 - Scope (محدوده دسترسی)

Scope مشخص می‌کند که یک متغیر یا تابع در کدام قسمت‌های برنامه قابل دسترسی است.

به بیان ساده:

> Scope = محدوده‌ای که یک متغیر در آن زنده است و می‌توان به آن دسترسی داشت.

اگر خارج از Scope یک متغیر از آن استفاده کنیم، JavaScript خطا تولید می‌کند.

---

# چرا Scope مهم است؟

فرض کنید دو برنامه‌نویس روی یک پروژه بزرگ کار می‌کنند.

هر دو متغیری با نام `count` ساخته‌اند.

اگر Scope وجود نداشت، این دو متغیر روی یکدیگر تأثیر می‌گذاشتند و برنامه به‌راحتی دچار خطا می‌شد.

Scope باعث می‌شود هر بخش از برنامه فضای مخصوص خود را داشته باشد.

---

# انواع Scope

در JavaScript چهار نوع Scope مهم داریم:

* Global Scope
* Local Scope (Function Scope)
* Block Scope
* Lexical Scope

---

# Global Scope

متغیرهایی که خارج از هر تابع یا Block تعریف شوند، در **Global Scope** قرار می‌گیرند.

مثال:

```javascript id="8vpl1o"
const appName = "Node Course";

console.log(appName);
```

---

اگر تابعی داشته باشیم:

```javascript id="5xq4vw"
const appName = "Node Course";

function showName() {

    console.log(appName);

}

showName();
```

خروجی:

```text id="w1i5rd"
Node Course
```

زیرا متغیر Global از داخل تابع نیز قابل دسترسی است.

---

# ویژگی‌های Global Scope

* در تمام فایل (و در برخی شرایط کل برنامه) قابل استفاده است.
* تا پایان اجرای برنامه در حافظه باقی می‌ماند.
* استفاده بیش از حد از آن توصیه نمی‌شود.

---

# مشکل Global Variable

```javascript id="1tb3fw"
let score = 10;

function game() {

    score = 50;

}

game();

console.log(score);
```

خروجی:

```text id="avr61g"
50
```

تابع مقدار متغیر Global را تغییر داده است.

در پروژه‌های بزرگ این موضوع می‌تواند باعث ایجاد باگ‌های پیچیده شود.

---

# Local Scope (Function Scope)

هر تابع Scope مخصوص خود را دارد.

متغیرهایی که داخل یک تابع تعریف شوند، فقط داخل همان تابع قابل استفاده هستند.

```javascript id="qb2ndg"
function greet() {

    const message = "Hello";

    console.log(message);

}

greet();
```

---

اما:

```javascript id="epzk2m"
function greet() {

    const message = "Hello";

}

console.log(message);
```

خروجی:

```text id="f1b8gq"
ReferenceError
```

زیرا `message` فقط داخل تابع وجود دارد.

---

# متغیرهای هم‌نام

```javascript id="m8j2ca"
const name = "Global";

function test() {

    const name = "Local";

    console.log(name);

}

test();

console.log(name);
```

خروجی:

```text id="9s7npo"
Local
Global
```

متغیر محلی (Local) روی متغیر Global سایه انداخته است.

---

# Shadowing (سایه انداختن)

اگر یک متغیر محلی هم‌نام با متغیر Global باشد، تا زمانی که داخل همان Scope هستیم، متغیر محلی استفاده می‌شود.

```javascript id="l2q5ve"
const age = 20;

function showAge() {

    const age = 30;

    console.log(age);

}

showAge();

console.log(age);
```

خروجی:

```text id="6jtm2w"
30
20
```

به این رفتار **Variable Shadowing** گفته می‌شود.

---

# Block Scope

از ES6 به بعد، `let` و `const` دارای Block Scope هستند.

Block یعنی هر بخشی که داخل `{}` قرار دارد.

مانند:

* `if`
* `for`
* `while`
* `switch`
* بلوک‌های مستقل

---

مثال:

```javascript id="ymc4tx"
if (true) {

    const message = "Hello";

    console.log(message);

}
```

---

اما:

```javascript id="08ewma"
if (true) {

    const message = "Hello";

}

console.log(message);
```

خروجی:

```text id="qov07h"
ReferenceError
```

---

# Block Scope با let

```javascript id="75uc4x"
if (true) {

    let score = 100;

    console.log(score);

}
```

---

```javascript id="h0g3mj"

    var number = 10;

console.log(number);
```

خروجی:

```text id="e3zq4x"

```

# Lexical Scope

یکی از مهم‌ترین مفاهیم JavaScript است.

Lexical یعنی:

> تابع به Scope جایی که **تعریف شده** دسترسی دارد، نه جایی که **اجرا می‌شود**.

مثال:

```javascript id="ch7q8x"
const message = "Global";

function outer() {

    function inner() {

        console.log(message);

    }

    inner();

}

outer();
```

خروجی:

```text id="0mpjlwm"
Global
```

---

مثال کامل‌تر:

```javascript id="c0hdzs"
const city = "Tehran";

function first() {

    const name = "Sobhan";

    function second() {

        console.log(city);

        console.log(name);

    }

    second();

}

first();
```

خروجی:

```text id="0b6b1p"
Tehran
Sobhan
```

تابع `second` به متغیرهای Scopeهای بالاتر دسترسی دارد.

---

اما برعکس آن ممکن نیست.

```javascript id="w3n8qs"
function first() {

    const name = "Sobhan";

}

console.log(name);
```

خروجی:

```text id="8v5dlf"
ReferenceError
```

# زنجیره Scope (Scope Chain)

وقتی JavaScript به دنبال یک متغیر می‌گردد، مراحل زیر را طی می‌کند:

1. Scope فعلی
2. Scope والد
3. Scope والدِ والد
4. Global Scope

اگر پیدا نشود:

```text id="8p0h9v"
ReferenceError
```

---

مثال:

```javascript id="6n2r8b"
const app = "Node";

function first() {

    const version = "1.0";

    function second() {

        console.log(app);

        console.log(version);

    }

    second();

}

first();
```

به جای این:

در پروژه‌های واقعی Scope در تمام بخش‌ها دیده می‌شود:

* Middlewareهای Express

در فصل Moduleها خواهید دید که هر فایل در Node.js نیز Scope مخصوص خود را دارد.

# اشتباهات رایج

### ❌ استفاده زیاد از متغیرهای Global

متغیرهای Global باعث وابستگی شدید بخش‌های مختلف برنامه می‌شوند.

---

### ❌ استفاده از var

در پروژه‌های مدرن تقریباً همیشه از `let` و `const` استفاده کنید.

---

### ❌ دسترسی به متغیر خارج از Scope

```javascript id="j2q6rw"

    const age = 20;

}

console.log(age);
```

---

### ❌ تغییر دادن متغیرهای Global داخل Functionها

این کار باعث ایجاد باگ‌های سخت برای پیدا کردن می‌شود.

---

### ❌ استفاده از نام‌های یکسان در Scopeهای مختلف بدون دلیل

Shadowing بیش از حد باعث کاهش خوانایی کد می‌شود.

---

# نکات حرفه‌ای

* تا حد امکان از `const` استفاده کنید.
* متغیرها را در کوچک‌ترین Scope ممکن تعریف کنید.
* از متغیرهای Global فقط برای مقادیر واقعاً سراسری استفاده کنید.
* از `var` در پروژه‌های جدید استفاده نکنید.
* Functionهای کوچک معمولاً Scopeهای کوچک‌تر و مدیریت ساده‌تری دارند.
* اگر متغیری فقط داخل یک `if` یا یک حلقه استفاده می‌شود، همان‌جا آن را تعریف کنید.
