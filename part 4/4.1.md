قبل از این فصل، برنامه‌هایی نوشتید که از بالا به پایین اجرا می‌شدند. اگر بخشی از کد را چند بار نیاز داشتید، مجبور بودید آن را دوباره بنویسید یا از حلقه‌ها استفاده کنید.

اما تصور کنید در یک پروژه واقعی باید در ده‌ها قسمت مختلف، عملیات زیر را انجام دهید:

* محاسبه مالیات
* اعتبارسنجی ایمیل
* بررسی رمز عبور
* محاسبه سن
* ساخت پیام خوش‌آمدگویی
* تبدیل تاریخ

آیا باید هر بار همان کد را دوباره بنویسیم؟

قطعاً خیر.

در برنامه‌نویسی اصلی به نام **DRY (Don't Repeat Yourself)** وجود دارد که می‌گوید:

> یک منطق را فقط یک بار بنویس.

برای این کار از **تابع (Function)** استفاده می‌کنیم.

تابع یکی از مهم‌ترین مفاهیم JavaScript است و تقریباً تمام پروژه‌های Node.js بر پایه‌ی توابع ساخته می‌شوند. از ساده‌ترین برنامه‌های CLI گرفته تا Frameworkهایی مانند Express، NestJS و Fastify، همگی به شکل گسترده از Function استفاده می‌کنند.

اگر بخواهیم فقط یک مفهوم را به عنوان ستون فقرات JavaScript معرفی کنیم، بدون شک **Function** یکی از مهم‌ترین گزینه‌ها خواهد بود.

---

# فصل 17 - Function

تابع (Function) یک بلوک از کد است که فقط یک بار نوشته می‌شود اما می‌توان آن را هر تعداد بار که لازم باشد اجرا کرد.

به زبان ساده:

> Function = یک ماشین انجام کار

شما ورودی به آن می‌دهید، پردازش انجام می‌دهد و در صورت نیاز خروجی برمی‌گرداند.

---

# چرا به Function نیاز داریم؟

فرض کنید باید مجموع دو عدد را در قسمت‌های مختلف برنامه محاسبه کنیم.

بدون Function:

```javascript
const result1 = 10 + 20;
console.log(result1);

const result2 = 50 + 80;
console.log(result2);

const result3 = 7 + 12;
console.log(result3);
```

همین کد در پروژه‌های بزرگ صدها بار تکرار می‌شود.

اما با Function:

```javascript
function sum(a, b) {
    return a + b;
}

console.log(sum(10, 20));
console.log(sum(50, 80));
console.log(sum(7, 12));
```

کد کوتاه‌تر، خواناتر و قابل نگهداری‌تر است.

---

# مزایای استفاده از Function

* جلوگیری از تکرار کد
* خوانایی بیشتر
* نگهداری آسان‌تر
* تست ساده‌تر
* استفاده مجدد از کد
* تقسیم پروژه به بخش‌های کوچک‌تر

---

# ساختار کلی Function

```javascript
function functionName(parameters) {

    // Code

    return value;

}
```

هر Function چهار بخش دارد:

* نام تابع
* پارامترها (اختیاری)
* بدنه تابع
* مقدار بازگشتی (اختیاری)

---

# Function Declaration

رایج‌ترین روش ساخت تابع، Declaration است.

ساختار:

```javascript
function sayHello() {

    console.log("Hello");

}
```

اجرای تابع:

```javascript
sayHello();
```

خروجی:

```text
Hello
```

---

تابع را می‌توان هر تعداد بار اجرا کرد.

```javascript
sayHello();
sayHello();
sayHello();
```

خروجی:

```text
Hello
Hello
Hello
```

---

# پارامتر (Parameters)

پارامترها اطلاعاتی هستند که تابع هنگام اجرا دریافت می‌کند.

مثال:

```javascript
function greet(name) {

    console.log(`Hello ${name}`);

}

greet("Sobhan");
```

خروجی:

```text
Hello Sobhan
```

---

چند پارامتر:

```javascript
function sum(a, b) {

    console.log(a + b);

}

sum(10, 20);
```

خروجی:

```text
30
```

---

# آرگومان (Arguments)

وقتی تابع را تعریف می‌کنیم:

```javascript
function greet(name) {

}
```

`name`

یک **Parameter** است.

اما هنگام اجرا:

```javascript
greet("Ali");
```

`Ali`

یک **Argument** است.

به طور خلاصه:

* Parameter → هنگام تعریف Function
* Argument → هنگام اجرای Function

---

# مقدار پیش‌فرض پارامتر

می‌توان مقدار پیش‌فرض تعیین کرد.

```javascript
function greet(name = "Guest") {

    console.log(`Hello ${name}`);

}

greet();
greet("Sobhan");
```

خروجی:

```text
Hello Guest
Hello Sobhan
```

---

# Return

اکثر Functionها مقداری را برمی‌گردانند.

```javascript
function sum(a, b) {

    return a + b;

}
```

استفاده:

```javascript
const result = sum(5, 7);

console.log(result);
```

خروجی:

```text
12
```

---

اگر `return` وجود نداشته باشد:

```javascript
function test() {

    console.log("Hello");

}
```

تابع مقدار زیر را برمی‌گرداند:

```text
undefined
```

---

# تفاوت console.log و return

```javascript
function sum(a, b) {

    console.log(a + b);

}
```

این تابع فقط مقدار را چاپ می‌کند.

اما:

```javascript
function sum(a, b) {

    return a + b;

}
```

مقدار را برمی‌گرداند تا بتوان در بخش‌های دیگر برنامه از آن استفاده کرد.

---

مثال:

```javascript
const total = sum(20, 10);

console.log(total * 2);
```

---

# خروج زودهنگام

به محض اجرای `return`، تابع پایان پیدا می‌کند.

```javascript
function test() {

    console.log(1);

    return;

    console.log(2);

}
```

خروجی:

```text
1
```

---

# Function Expression

تابع را می‌توان داخل یک متغیر نیز قرار داد.

```javascript
const greet = function () {

    console.log("Hello");

};

greet();
```

---

مثال دیگر:

```javascript
const multiply = function (a, b) {

    return a * b;

};

console.log(multiply(5, 8));
```

---

# تفاوت Declaration و Expression

Declaration:

```javascript
function hello() {

}
```

Expression:

```javascript
const hello = function () {

};
```

هر دو تقریباً یک کار انجام می‌دهند اما تفاوت مهمی دارند که کمی جلوتر بررسی می‌کنیم.

---

# Hoisting

Function Declaration قبل از تعریف نیز قابل اجراست.

```javascript
hello();

function hello() {

    console.log("Hello");

}
```

این کد بدون مشکل اجرا می‌شود.

اما:

```javascript
hello();

const hello = function () {

};
```

باعث خطا خواهد شد.

---

# Arrow Function

از ES6 به بعد، روش جدیدی برای تعریف Function معرفی شد.

```javascript
const greet = () => {

    console.log("Hello");

};
```

---

با پارامتر:

```javascript
const greet = (name) => {

    console.log(`Hello ${name}`);

};

greet("Sobhan");
```

---

اگر فقط یک پارامتر داشته باشیم:

```javascript
const greet = name => {

    console.log(name);

};
```

پرانتز اختیاری است.

---

اگر فقط یک خط باشد:

```javascript
const square = number => number * number;
```

معادل:

```javascript
function square(number) {

    return number * number;

}
```

---

# چند پارامتر

```javascript
const sum = (a, b) => {

    return a + b;

};
```

---

یا کوتاه‌تر:

```javascript
const sum = (a, b) => a + b;
```

---

# چه زمانی از Arrow Function استفاده کنیم؟

در پروژه‌های امروزی Node.js، Arrow Function بسیار رایج است.

اما همیشه بهترین انتخاب نیست.

در فصل Objectها و `this` تفاوت‌های مهم آن را بررسی خواهیم کرد.

فعلاً کافی است بدانید:

* Declaration خواناتر است.
* Arrow Function کوتاه‌تر است.
* هر دو کاربرد زیادی دارند.

---

# محدوده (Scope) پارامترها

پارامترها فقط داخل همان تابع قابل استفاده هستند.

```javascript
function greet(name) {

    console.log(name);

}

console.log(name);
```

خروجی:

```text
ReferenceError
```

---

# Functionهای تو در تو

می‌توان داخل یک Function، Function دیگری ساخت.

```javascript
function outer() {

    function inner() {

        console.log("Hello");

    }

    inner();

}

outer();
```

این تکنیک در آینده کاربرد زیادی خواهد داشت.

---

# اصل تک‌وظیفه‌ای (Single Responsibility)

هر Function باید فقط یک کار انجام دهد.

اشتباه:

```javascript
function user() {

    // Login

    // Send Email

    // Save Database

    // Print Report

}
```

درست:

```javascript
login();

sendEmail();

saveUser();

printReport();
```

تابع‌های کوچک‌تر، خواناتر و قابل تست‌تر هستند.

---

# کاربرد Function در Node.js

تقریباً تمام بخش‌های Node.js بر پایه Function هستند.

نمونه‌ها:

* Routeهای Express
* Middlewareها
* Callbackها
* Eventها
* خواندن فایل‌ها
* کار با دیتابیس
* APIها
* Promiseها
* Async/Await
* Validation

در فصل‌های آینده بارها با Function سروکار خواهیم داشت.

### ❌ فراموش کردن return

```javascript

    a + b;
```

### ❌ استفاده از console.log به جای return

اگر قرار است نتیجه در جای دیگری استفاده شود، از `return` استفاده کنید.

---

### ❌ نام‌گذاری نامناسب

```javascript
function x() {

}
```

بهتر است:

```javascript
function calculateTotal() {

}
```

---

### ❌ ساخت Functionهای بسیار بزرگ

تابع‌های چندصد خطی نگهداری بسیار سختی دارند.

---

### ❌ استفاده بیش از حد از Arrow Function بدون شناخت تفاوت‌ها

در فصل Objectها خواهید دید که Arrow Function همیشه مناسب نیست.

---

# نکات حرفه‌ای

* برای نام Function از فعل استفاده کنید؛ مانند `calculatePrice`، `sendEmail` یا `createUser`.
* هر Function فقط یک مسئولیت داشته باشد.
* اگر Function مقداری تولید می‌کند، از `return` استفاده کنید.
* از نام‌های واضح برای پارامترها استفاده کنید.
* تا حد امکان از تکرار کد جلوگیری کنید و منطق مشترک را داخل Function قرار دهید.
* Functionهای کوچک و خوانا بهتر از Functionهای بزرگ و پیچیده هستند.

7. اگر عملگر نامعتبر بود، پیام خطا نمایش دهید.
