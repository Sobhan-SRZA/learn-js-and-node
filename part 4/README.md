# بخش ۴ - توابع

در این بخش با یکی از مهم‌ترین مفاهیم برنامه‌نویسی، یعنی **Functionها** آشنا می‌شویم.

توابع به ما کمک می‌کنند کدهای خود را به بخش‌های کوچک‌تر، قابل استفاده مجدد و قابل مدیریت تقسیم کنیم. یادگیری صحیح توابع، پایه‌ای مهم برای ورود به مباحث پیشرفته‌تر JavaScript و توسعه برنامه‌های واقعی با Node.js است.

# 🎯 هدف بخش ۴

در پایان این بخش باید بتوانید:

* Function ایجاد و اجرا کنید.
* Function Declaration و Function Expression را بشناسید.
* از Arrow Function استفاده کنید.
* برای Functionها Parameter تعریف کنید.
* از `return` برای برگرداندن نتیجه استفاده کنید.
* مفهوم Scope را درک کنید.
* تفاوت Global، Local و Block Scope را تشخیص دهید.
* مفهوم Lexical Scope را درک کنید.
* رفتار Hoisting را بشناسید.
* مفهوم Closure را درک کنید.
* از Closure در برنامه‌های JavaScript استفاده کنید.
* مفهوم Recursion را درک کنید.
* مسائل ساده را با استفاده از توابع بازگشتی حل کنید.
* کدهای خود را با Functionها به بخش‌های کوچک‌تر و قابل استفاده مجدد تقسیم کنید.
