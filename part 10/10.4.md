# فصل 77 - TCP/IP

## مقدمه

تمام ارتباطات اینترنتی بر پایه مجموعه‌ای از قوانین و پروتکل‌ها انجام می‌شود.

وقتی یک کاربر:

* یک سایت را باز می‌کند.
* به یک API درخواست ارسال می‌کند.
* یک فایل دانلود می‌کند.
* به یک Server متصل می‌شود.

در پشت صحنه، مجموعه‌ای از پروتکل‌ها مسئول انتقال اطلاعات هستند.

مهم‌ترین این مجموعه:

```text id="x7m2qp"
TCP/IP
```

است.

TCP/IP پایه اصلی اینترنت است و تقریباً تمام ارتباطات شبکه‌ای مدرن از آن استفاده می‌کنند.

چرخه ساده ارتباط:

```text id="m8q3xz"
Application

↓

Transport

↓

Internet

↓

Network Access
```

---

# 77.1 - TCP/IP چیست؟

TCP/IP مخفف:

```text id="p5m8qx"
Transmission Control Protocol / Internet Protocol
```

است.

TCP/IP مجموعه‌ای از پروتکل‌ها برای ارتباط بین دستگاه‌ها در شبکه است.

دو بخش اصلی:

## TCP

مسئول انتقال مطمئن داده.

---

## IP

مسئول آدرس‌دهی و مسیر‌یابی داده.

---

# 77.2 - چرا TCP/IP مهم است؟

بدون TCP/IP:

* کامپیوترها نمی‌توانند ارتباط برقرار کنند.
* اینترنت وجود نخواهد داشت.
* Serverها قابل دسترسی نیستند.

تمام سرویس‌های زیر از TCP/IP استفاده می‌کنند:

* HTTP
* HTTPS
* DNS
* FTP
* SSH

---

# 77.3 - مدل TCP/IP

مدل TCP/IP چهار لایه اصلی دارد:

```text id="q8m4xp"
Application Layer

Transport Layer

Internet Layer

Network Access Layer
```

---

# 77.4 - Application Layer

بالاترین لایه است.

وظیفه:

ارتباط مستقیم با برنامه‌ها.

پروتکل‌ها:

* HTTP
* HTTPS
* DNS
* FTP
* SMTP

مثال:

مرورگر درخواست:

```http id="w3m7qx"
GET /users
```

ارسال می‌کند.

---

# 77.5 - Transport Layer

مسئول انتقال داده بین برنامه‌ها است.

پروتکل‌های مهم:

* TCP
* UDP

---

## TCP

ویژگی‌ها:

* قابل اعتماد
* ترتیب داده حفظ می‌شود.
* خطا بررسی می‌شود.

---

## UDP

ویژگی‌ها:

* سریع‌تر
* بدون تضمین دریافت
* مناسب ارتباط Real-Time

---

# 77.6 - Internet Layer

مسئول پیدا کردن مسیر شبکه است.

پروتکل اصلی:

```text id="m4x8qp"
IP
```

وظایف:

* آدرس‌دهی
* Routing
* انتقال Packet

---

# 77.7 - Network Access Layer

پایین‌ترین لایه است.

مسئول:

* ارتباط فیزیکی
* انتقال Frame

مثال:

* Ethernet
* Wi-Fi

---

# 77.8 - IP چیست؟

IP یک آدرس برای شناسایی دستگاه در شبکه است.

مثال IPv4:

```text id="z5m2qx"
192.168.1.10
```

---

# 77.9 - IPv4

IPv4 دارای:

```text id="v8m3qp"
32 بیت
```

است.

مثال:

```text id="x4m7qz"
8.8.8.8
```

ساختار:

```text id="p3q8mx"
192.168.1.1

قسمت شبکه

+

قسمت دستگاه
```

---

# 77.10 - IPv6

برای حل کمبود IPv4 ساخته شد.

دارای:

```text id="m6q2xp"
128 بیت
```

مثال:

```text id="w9m3qx"
2001:db8::1
```

---

# 77.11 - Public IP و Private IP

## Public IP

آدرس قابل مشاهده در اینترنت.

مثال:

```text id="k7x4mq"
8.8.8.8
```

---

## Private IP

برای شبکه داخلی.

محدوده‌ها:

```text id="n5m8qp"
192.168.x.x

10.x.x.x

172.16.x.x
```

---

# 77.12 - Port چیست؟

یک Server می‌تواند چند سرویس داشته باشد.

Port مشخص می‌کند درخواست به کدام برنامه برسد.

مثال:

```text id="q4m8xz"
IP

+

Port

=

Connection
```

---

نمونه Portها:

| سرویس | Port |
| ----- | ---- |
| HTTP  | 80   |
| HTTPS | 443  |
| SSH   | 22   |
| DNS   | 53   |

---

# 77.13 - Socket چیست؟

Socket ترکیبی از:

```text id="r8m3qx"
IP Address

+

Port
```

است.

مثال:

```text id="x7p2mz"
192.168.1.10:3000
```

هر ارتباط شبکه‌ای یک Socket دارد.

---

# 77.14 - TCP چگونه کار می‌کند؟

TCP برای ایجاد ارتباط از:

```text id="m3q8xp"
Three Way Handshake
```

استفاده می‌کند.

مراحل:

---

## مرحله اول

Client:

```text id="w4m7qx"
SYN
```

ارسال می‌کند.

---

## مرحله دوم

Server:

```text id="p8m2xz"
SYN + ACK
```

ارسال می‌کند.

---

## مرحله سوم

Client:

```text id="z6q3mp"
ACK
```

ارسال می‌کند.

---

ارتباط برقرار می‌شود.

---

# 77.15 - TCP Three Way Handshake

تصویر مفهومی:

```text id="t9m4qx"
Client              Server

 SYN   ----------->

       <----------- SYN ACK

 ACK   ----------->

Connection Ready
```

---

# 77.16 - TCP Reliability

TCP ویژگی‌هایی دارد:

* بررسی خطا
* شماره‌گذاری Packetها
* ارسال مجدد داده گمشده
* کنترل سرعت

---

# 77.17 - Packet چیست؟

داده در شبکه به قسمت‌های کوچک تقسیم می‌شود.

هر قسمت:

```text id="m8q3xp"
Packet
```

نام دارد.

Packet شامل:

* Source IP
* Destination IP
* Data

است.

---

# 77.18 - Routing چیست؟

Routing یعنی انتخاب مسیر انتقال Packet.

Routerها تصمیم می‌گیرند:

```text id="q5m7xz"
Packet

↓

کدام مسیر؟

↓

Destination
```

---

# 77.19 - Router چیست؟

Router دستگاهی است که شبکه‌ها را به هم متصل می‌کند.

وظایف:

* انتقال Packet
* انتخاب مسیر
* مدیریت شبکه

---

HTTP روی TCP کار می‌کند.

```js id="w7m3qx"

require("net");
```

```js id="p5x8mq"

{

data.toString()
);

```

# 77.24 - TCP و UDP

مقایسه:

| TCP                | UDP                       |
| ------------------ | ------------------------- |
| قابل اعتماد        | سریع                      |
| Connection دارد    | بدون Connection           |
| کندتر              | سریع‌تر                    |
| HTTP استفاده می‌کند | بازی آنلاین استفاده می‌کند |

# 77.28 - اشتباهات رایج

## 1) تصور اینکه HTTP خودش ارتباط شبکه‌ای ایجاد می‌کند

HTTP روی TCP اجرا می‌شود.

---

## 2) اشتباه گرفتن IP و Port

IP دستگاه را مشخص می‌کند.

Port برنامه را مشخص می‌کند.

---

## 3) استفاده نادرست از TCP برای Real-Time

گاهی UDP مناسب‌تر است.

---

## 4) نادیده گرفتن Timeout

Connection ممکن است باز بماند.

---

## 5) ارسال داده بدون بررسی Error

باعث Crash می‌شود.

---

## 6) باز گذاشتن Socketهای زیاد

باعث مصرف منابع می‌شود.

---

# 77.29 - نکات حرفه‌ای

* تفاوت TCP و UDP را دقیق یاد بگیر.
* همیشه Timeout تنظیم کن.
* Connectionها را مدیریت کن.
* Packet Loss را در نظر بگیر.
* برای سرویس‌های حساس TCP مناسب است.
* برای Real-Time از UDP یا WebSocket استفاده کن.
* Network Debugging یاد بگیر.
* با ابزارهایی مانند Wireshark آشنا شو.
* معماری شبکه را در Backend درک کن.

# جمع‌بندی

TCP/IP پایه ارتباطات اینترنت است.

یک توسعه‌دهنده حرفه‌ای Node.js باید بداند:

* IP چگونه کار می‌کند.
* TCP چگونه ارتباط ایجاد می‌کند.
* Packet چیست.
* Port و Socket چه هستند.
* Node.js چگونه ارتباط TCP می‌سازد.

درک TCP/IP باعث می‌شود Backend Developer فقط مصرف‌کننده Framework نباشد و بتواند مشکلات واقعی شبکه را تحلیل و حل کند.
