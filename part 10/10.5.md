# فصل 78 - Socket

## مقدمه

در برنامه‌های سنتی HTTP، ارتباط معمولاً به شکل:

```text id="m7q2xp"
Client

↓

Request

↓

Server

↓

Response
```

انجام می‌شود.

یعنی Client درخواست می‌دهد و Server پاسخ می‌دهد.

اما بسیاری از برنامه‌های امروزی نیاز دارند که ارتباط **دوطرفه و لحظه‌ای** داشته باشند.

مثال:

* چت آنلاین
* بازی‌های آنلاین
* سیستم اعلان لحظه‌ای
* قیمت‌های لحظه‌ای بازار
* مانیتورینگ زنده
* همکاری آنلاین چند کاربر

در این نوع برنامه‌ها نمی‌توانیم همیشه منتظر Request جدید از سمت Client باشیم.

اینجا مفهوم:

```text id="x8m4qp"
Socket
```

وارد می‌شود.

Socket یک کانال ارتباطی دائمی بین Client و Server ایجاد می‌کند.

---

# 78.1 - Socket چیست؟

Socket یک نقطه ارتباطی در شبکه است که امکان ارسال و دریافت داده را فراهم می‌کند.

به زبان ساده:

Socket یعنی:

```text id="q5m8xz"
یک ارتباط باز و دائمی بین دو سیستم
```

برخلاف HTTP که معمولاً Request محور است، Socket ارتباط Event محور دارد.

---

# 78.2 - Socket چگونه کار می‌کند؟

در ارتباط Socket:

```text id="p8m3qx"
Client

<================>

Server
```

هر دو طرف می‌توانند هر زمان پیام ارسال کنند.

مثال:

Server:

```text id="w6m2qp"
New Message
```

Client:

```text id="k4x8mz"
Receive Message
```

بدون اینکه Client درخواست جدید ارسال کند.

---

# 78.3 - Socket در مدل TCP/IP

Socket روی TCP ساخته می‌شود.

ساختار:

```text id="z7m3qx"
Application

↓

Socket

↓

TCP

↓

IP
```

Socket خودش پروتکل انتقال نیست؛ بلکه یک Interface برای ارتباط شبکه‌ای است.

---

# 78.4 - Socket Address چیست؟

هر Socket معمولاً با ترکیب:

```text id="m5q8xp"
IP Address

+

Port
```

شناخته می‌شود.

مثال:

```text id="x3m7qp"
192.168.1.20:3000
```

---

# 78.5 - تفاوت Socket و HTTP

| HTTP                 | Socket          |
| -------------------- | --------------- |
| Request/Response     | ارتباط دائمی    |
| Client شروع‌کننده است | هر دو طرف       |
| مناسب API            | مناسب Real-Time |
| Stateless            | Stateful        |

# 78.7 - ساخت TCP Socket Server

مثال:

```js id="m8x3qp"
const net =
require("net");


const server =
net.createServer(
(socket)=>{

console.log(
"Client Connected"
);


socket.write(
"Welcome"
);


socket.on(
"data",
(data)=>{

console.log(
data.toString()
);

});

});


server.listen(
3000
);
```

---

# 78.8 - ساخت Socket Client

```js id="x5m2qp"
const net =
require("net");


const client =
net.createConnection(
{
port:3000
});

"data",
(data)=>{

data.toString()

});

"Hello Server"
);
```
