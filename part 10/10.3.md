# فصل 76 - DNS

## مقدمه

وقتی در مرورگر آدرس یک سایت را وارد می‌کنیم:

```text
https://example.com
```

کامپیوتر ما نمی‌داند باید به کدام Server متصل شود.

شبکه‌های کامپیوتری با IP Address کار می‌کنند.

مثال:

```text
142.250.190.14
```

اما به خاطر سپردن IP برای انسان‌ها سخت است.

اینجا DNS وارد می‌شود.

DNS وظیفه دارد:

```text
Domain Name

↓

IP Address
```

را تبدیل کند.

به زبان ساده:

DNS مانند دفترچه تلفن اینترنت است.

ما نام شخص را می‌دانیم:

```text
Ali
```

اما برای تماس به شماره نیاز داریم.

در اینترنت:

```text
google.com

↓

IP Server
```

تبدیل می‌شود.

---

# 76.1 - DNS چیست؟

DNS مخفف:

```text
Domain Name System
```

است.

یک سیستم توزیع‌شده برای تبدیل نام دامنه به IP است.

مثال:

ورودی:

```text
api.example.com
```

خروجی:

```text
192.168.1.10
```

---

# 76.2 - چرا DNS ساخته شد؟

قبل از DNS کاربران باید IP حفظ می‌کردند.

مثال:

```text
142.250.190.14
```

اما با DNS:

```text
google.com
```

کافی است.

---

# 76.3 - نقش DNS در درخواست HTTP

```text

↓

3. پیدا کردن IP

↓

4. اتصال TCP

↓

5. HTTPS Request

↓

6. دریافت Response
```

# 76.4 - ساختار DNS

ساختار:

```text
↓

TLD

↓

↓

```

مثال:

```text

```

# 76.5 - Root DNS Server

بالاترین سطح DNS است.

وظیفه:

پیدا کردن سرورهای TLD.

مثال:

برای:

```text
example.com
```

Root می‌گوید:

```
.com DNS Server
```

کجاست.

---

# 76.6 - TLD چیست؟

TLD مخفف:

```text
Top Level Domain
```

است.

بخش آخر دامنه:

مثال:

```text
google.com
       ^
       |
      TLD
```

نمونه‌ها:

```text
.com

.org

.net

.ir
```

---

# 76.7 - Authoritative DNS Server

آخرین مرجع اطلاعات دامنه است.

این Server اطلاعات واقعی دامنه را نگهداری می‌کند.

مثال:

```text
example.com

IP:
10.20.30.40
```

# 76.11 - TTL چیست؟

TTL مخفف:

```text
Time To Live
```

است.

مشخص می‌کند پاسخ DNS چقدر در Cache بماند.

مثال:

```text
TTL = 3600
```

یعنی:

```text
1 ساعت
```

---

# 76.12 - DNS Record چیست؟

DNS اطلاعات را با Record نگهداری می‌کند.

مهم‌ترین Recordها:

* A
* AAAA
* CNAME
* MX
* TXT
* NS

---

# 76.13 - A Record

برای اتصال دامنه به IPv4 استفاده می‌شود.

مثال:

```text
example.com

A

192.168.1.10
```

---

# 76.14 - AAAA Record

برای IPv6 استفاده می‌شود.

مثال:

```text
example.com

AAAA

2001:db8::1
```

---

# 76.15 - CNAME Record

یک دامنه را به دامنه دیگر متصل می‌کند.

مثال:

```text
www.example.com

↓

example.com
```

---

# 76.16 - MX Record

برای Email استفاده می‌شود.

مثال:

```text
example.com

MX

mail.example.com
```

---

# 76.17 - TXT Record

برای ذخیره متن استفاده می‌شود.

کاربرد:

* تایید مالکیت دامنه
* SPF
* DKIM
* Security


* Domain چگونه به IP تبدیل می‌شود.
* DNS Recordها چه هستند.
* DNS چگونه با HTTP و HTTPS کار می‌کند.
* چگونه در Node.js با DNS کار کند.

بدون DNS، سرویس‌های مدرن اینترنتی مانند:

* APIها
* Cloud Serviceها
* CDNها
* Microserviceها

قابل استفاده نبودند.
