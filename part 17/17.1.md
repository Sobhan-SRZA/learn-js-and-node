# فصل 135 - Express.js

## مقدمه

تا اینجا با JavaScript، Node.js Core، HTTP، ساخت Web Server، Routing، Middleware، REST API، Authentication، Database، Validation، Error Handling و بسیاری از مفاهیم موردنیاز Backend آشنا شدیم.

اما در پروژه‌های واقعی معمولاً نمی‌خواهیم تمام امکانات یک Backend را از صفر با APIهای خام Node.js پیاده‌سازی کنیم.

اینجاست که **Express.js** وارد می‌شود.

Express.js یکی از شناخته‌شده‌ترین فریمورک‌های Backend برای Node.js است که ساخت Web Server و API را ساده‌تر می‌کند.

در این فصل قرار است Express.js را از پایه یاد بگیریم و در نهایت یک پروژه نسبتاً کامل را مرحله‌به‌مرحله پیاده‌سازی کنیم.

> هدف این فصل این نیست که فقط چند دستور Express را حفظ کنیم؛ هدف این است که بفهمیم Express چگونه روی Node.js و HTTP قرار می‌گیرد و چگونه با استفاده از آن یک Backend قابل توسعه بسازیم.

---

# 1. Express.js چیست؟

Express.js یک فریمورک سبک برای Node.js است که امکانات و ابزارهای موردنیاز برای ساخت:

* Web Server
* REST API
* Backend
* Web Application
* Middleware
* Routing
* Authentication
* APIهای مختلف

را در اختیار ما قرار می‌دهد.

در Node.js می‌توانیم بدون هیچ فریمورکی یک HTTP Server بسازیم:

```js
const http = require("http");

const server = http.createServer((req, res) => {
  if (req.url === "/") {
    res.writeHead(200, {
      "Content-Type": "text/plain",
    });

    res.end("Hello World");
  }
});

server.listen(3000);
```

اما با بزرگ‌تر شدن پروژه، مدیریت دستی Routeها، Requestها، Responseها و Middlewareها سخت‌تر می‌شود.

Express این کارها را ساده‌تر می‌کند.

مثلاً همان Server را می‌توانیم با Express به شکل زیر بنویسیم:

```js
const express = require("express");

const app = express();

app.get("/", (req, res) => {
  res.send("Hello World");
});

app.listen(3000, () => {
  console.log("Server running on port 3000");
});
```

کد کوتاه‌تر و ساختار برنامه قابل مدیریت‌تر شده است.

---

# 2. Express چگونه با Node.js ارتباط دارد؟

Express جای Node.js را نمی‌گیرد.

رابطه آن‌ها را می‌توان این‌گونه تصور کرد:

```text
Application
    │
    ▼
Express.js
    │
    ▼
Node.js
    │
    ├── V8
    ├── libuv
    ├── HTTP
    ├── File System
    └── سایر قابلیت‌های Core
```

یعنی:

```text
Node.js
   ↓
Express.js
   ↓
Application
```

Node.js محیط اجرای JavaScript است.

Express یک فریمورک است که روی Node.js اجرا می‌شود.

# 3. چرا Express؟

Express چند مشکل رایج در ساخت Backend را ساده می‌کند.

مهم‌ترین آن‌ها:

* Routing
* Middleware
* Request handling
* Response handling
* Error handling
* ساخت API
* مدیریت ساختار Backend

مثلاً بدون Express ممکن است برای هر Route مجبور شویم با `req.url` و `req.method` کار کنیم.

اما Express اجازه می‌دهد بسیار واضح بنویسیم:

```js
app.get("/users", handler);
app.post("/users", handler);
app.put("/users/:id", handler);
app.delete("/users/:id", handler);
```

```js

```

متغیر `app` مرکز اصلی برنامه Express است.

با استفاده از آن می‌توانیم:

* Route تعریف کنیم
* Middleware اضافه کنیم
* Server را اجرا کنیم
* تنظیمات برنامه را انجام دهیم

مثلاً:

```js
app.get("/", handler);

app.use(middleware);

```

# 7. Request و Response

در Express دو شیء بسیار مهم داریم:

```js
req
res
```

مثلاً:

```js
app.get("/", (req, res) => {
  console.log(req);
  console.log(res);
});
```

`req` اطلاعات مربوط به Request را در اختیار ما قرار می‌دهد.

`res` برای ارسال Response استفاده می‌شود.

# 8. متدهای HTTP در Express

Express از متدهای HTTP مختلف پشتیبانی می‌کند.

## GET

برای دریافت اطلاعات:

```js
app.get("/users", (req, res) => {
  res.send("Get users");
});
```

## POST

برای ایجاد اطلاعات:

```js
app.post("/users", (req, res) => {
  res.send("Create user");
});
```

## PUT

برای جایگزین کردن یا ویرایش کامل:

```js
app.put("/users/:id", (req, res) => {
  res.send("Update user");
});
```

## PATCH

برای ویرایش بخشی از اطلاعات:

```js
app.patch("/users/:id", (req, res) => {
  res.send("Partial update");
});
```

## DELETE

برای حذف:

```js
app.delete("/users/:id", (req, res) => {
  res.send("Delete user");
});
```

# 9. Routing

Routing یکی از مهم‌ترین بخش‌های Express است.

مثلاً:

```js
app.get("/", (req, res) => {
  res.send("Home");
});

app.get("/about", (req, res) => {
  res.send("About");
});

app.get("/contact", (req, res) => {
  res.send("Contact");
});
```

هر Route از چند بخش تشکیل می‌شود:

```text
HTTP Method
+
Path
+
Handler
```

مثلاً:

```js
app.get("/users", handler);
```

یعنی:

```text
GET /users
```

---

# 10. Route Parameters

می‌توانیم بخشی از URL را به صورت Dynamic تعریف کنیم.

```js
app.get("/users/:id", (req, res) => {
  console.log(req.params.id);

  res.send(`User ID: ${req.params.id}`);
});
```

اگر درخواست زیر ارسال شود:

```text
GET /users/25
```

مقدار:

```js
req.params.id
```

برابر است با:

```text
25
```

مثال دیگر:

```js
app.get("/products/:productId", (req, res) => {
  const { productId } = req.params;

  res.json({
    productId,
  });
});
```

---

# 11. چند Route Parameter

می‌توانیم چند Parameter داشته باشیم:

```js
app.get("/users/:userId/posts/:postId", (req, res) => {
  const { userId, postId } = req.params;

  res.json({
    userId,
    postId,
  });
});
```

Request:

```text
/users/10/posts/50
```

Response:

```json
{
  "userId": "10",
  "postId": "50"
}
```

نکته مهم:

مقادیر `req.params` معمولاً String هستند.

بنابراین اگر عدد نیاز داریم:

```js
const id = Number(req.params.id);
```

# 12. Query String

Query String با `?` شروع می‌شود.

مثلاً:

```text
/users?page=2&limit=10
```

در Express:

```js
app.get("/users", (req, res) => {
  console.log(req.query);
});
```

نتیجه:

```js
{
  page: "2",
  limit: "10"
}
```

می‌توانیم:

```js
const page = Number(req.query.page) || 1;
const limit = Number(req.query.limit) || 10;
```

استفاده کنیم.

---

# 13. تفاوت Params و Query

### Params

برای شناسایی یک Resource:

```text
/users/10
```

```js
req.params.id
```

### Query

برای فیلتر، جستجو، مرتب‌سازی و Pagination:

```text
/users?page=2&limit=10
```

```js
req.query.page
req.query.limit
```

مثال:

```text
GET /users/10
```

برای User شماره 10.

اما:

```text
GET /users?page=2&limit=10
```

برای صفحه دوم با 10 User.

نمونه‌های مهم:

| Status | مفهوم           |
| ------ | --------------- |

| 201    | ایجاد شد        |

| 400    | درخواست نامعتبر |

# 16. Middleware چیست؟

Middleware یکی از مهم‌ترین مفاهیم Express است.

Middleware تابعی است که در مسیر Request قرار می‌گیرد.

ساختار ساده:

```js
const middleware = (req, res, next) => {
  console.log("Middleware");

  next();
};
```

استفاده:

```js
app.use(middleware);
```

ساختار کلی:

```text
Request
   ↓
Middleware
   ↓
Middleware
   ↓
Route Handler
   ↓
Response
```

---

# 17. next چیست؟

`next()` اجازه می‌دهد Request به Middleware یا Handler بعدی منتقل شود.

مثلاً:

```js
app.use((req, res, next) => {
  console.log("Middleware 1");

  next();
});

app.use((req, res, next) => {
  console.log("Middleware 2");

  next();
});

app.get("/", (req, res) => {
  res.send("Hello");
});
```

ترتیب اجرا:

```text
Middleware 1
      ↓
Middleware 2
      ↓
Route
```

اگر `next()` را صدا نزنیم و Response هم ارسال نکنیم، Request ممکن است در Middleware متوقف شود.

# 18. Middleware سراسری

مثلاً Logger:

```js
app.use((req, res, next) => {
  console.log(`${req.method} ${req.url}`);

  next();
});
```

اکنون برای هر Request اجرا می‌شود.

# 19. Middleware مخصوص Route

می‌توانیم Middleware را فقط برای یک Route استفاده کنیم:

```js
const authMiddleware = (req, res, next) => {
  console.log("Checking authentication");

  next();
};

app.get("/profile", authMiddleware, (req, res) => {
  res.json({
    message: "Profile",
```

# 20. Middleware داخلی Express

# 23. Router

در پروژه‌های کوچک می‌توانیم همه Routeها را در `app.js` بنویسیم.

اما در پروژه واقعی این کار مناسب نیست.

مثلاً:

```text
routes/
├── users.js
├── products.js
└── orders.js
```

برای ایجاد Router:

```js
const express = require("express");

const router = express.Router();

router.get("/", (req, res) => {
  res.json([]);
});

module.exports = router;
```

در `app.js`:

```js
const userRouter = require("./routes/users");

app.use("/users", userRouter);
```

اکنون Route:

```text
GET /users
```

خواهد بود.

# 25. Controller

به جای نوشتن منطق زیاد داخل Route:

```js
router.get("/users", (req, res) => {
  // lots of code
});
```

می‌توانیم Controller داشته باشیم:

```js
const getUsers = (req, res) => {
  res.json([]);
};

module.exports = {
  getUsers,
};
```

و سپس:

```js
router.get("/users", getUsers);
```

# 26. Service

Controller بهتر است مسئولیت زیادی نداشته باشد.

مثلاً:

```js
const getUsers = async () => {
  return [];
};

module.exports = {
  getUsers,
};
```

سپس Controller:

```js
const userService = require("../services/user.service");

const getUsers = async (req, res) => {
  const users = await userService.getUsers();

  res.json(users);
};
```

این جداسازی باعث می‌شود پروژه قابل نگهداری‌تر شود.

# 27. Error Handling

در پروژه واقعی نباید خطاها را در تمام Routeها به شکل جداگانه مدیریت کنیم.

Middleware مخصوص Error می‌سازیم:

```js
const errorHandler = (err, req, res, next) => {
  console.error(err);

  res.status(500).json({
    message: "Internal Server Error",
  });
};
```

در انتهای برنامه:

```js
app.use(errorHandler);
```

نکته مهم:

Error Middleware چهار Parameter دارد:

```js
(err, req, res, next)
```

---

# 28. مدیریت خطاهای Async

مثلاً:

```js
app.get("/users", async (req, res, next) => {
  try {
    const users = await getUsers();

    res.json(users);
  } catch (error) {
    next(error);
  }
});
```

با `next(error)` خطا به Error Handler منتقل می‌شود.

# 29. 404 Handler

اگر هیچ Routeای Request را پاسخ ندهد، می‌توانیم Middleware مخصوص 404 داشته باشیم:

```js
app.use((req, res) => {
  res.status(404).json({
    message: "Route not found",
  });
});
```

این Middleware باید بعد از Routeها قرار بگیرد.

# 30. ترتیب Middlewareها

ترتیب Middlewareها بسیار مهم است.

مثلاً:

```js

app.use(errorHandler);
```

```text

   ↓

```

اگر Error Handler را اشتباه در جای نامناسب قرار دهیم، ممکن است خطاها به درستی مدیریت نشوند.

# 31. REST API با Express

یک API ساده:

```js
const express = require("express");

const app = express();

app.use(express.json());

let users = [
  {
    id: 1,
    name: "Ali",
  },
  {
    id: 2,
    name: "Reza",
  },
];

app.get("/users", (req, res) => {
  res.json(users);
});

app.get("/users/:id", (req, res) => {
  const id = Number(req.params.id);

  const user = users.find((user) => user.id === id);

  if (!user) {
    return res.status(404).json({
      message: "User not found",
    });
  }

  res.json(user);
});

app.post("/users", (req, res) => {
  const user = {
    id: Date.now(),
    name: req.body.name,
  };

  users.push(user);

  res.status(201).json(user);
});

app.delete("/users/:id", (req, res) => {
  const id = Number(req.params.id);

  users = users.filter((user) => user.id !== id);

  res.status(204).send();
});

app.listen(3000);
```

این نمونه پایه‌ای یک REST API است.

# 32. Validation

هر داده‌ای که از Client دریافت می‌کنیم نباید مستقیماً قابل اعتماد باشد.

مثلاً:

```js
app.post("/users", (req, res) => {
  const { name, age } = req.body;

  if (!name) {
    return res.status(400).json({
      message: "Name is required",
    });
  }

  if (typeof age !== "number") {
    return res.status(400).json({
      message: "Age must be a number",
    });
  }

  // ...
});
```

در پروژه‌های بزرگ بهتر است Validation را در Middleware یا Schema Validator جدا کنیم.

کتابخانه‌هایی مانند Zod و Joi نیز برای این کار بسیار کاربردی هستند.

# 33. Authentication Middleware

یک Middleware ساده:

```js
const auth = (req, res, next) => {
  const token = req.headers.authorization;

  if (!token) {
    return res.status(401).json({
      message: "Unauthorized",
    });
  }

  next();
};
```

استفاده:

```js
app.get("/profile", auth, (req, res) => {
  res.json({
    message: "Private profile",
  });
});
```

در پروژه واقعی باید Token را به شکل صحیح اعتبارسنجی کنیم.

# 44. Service

فایل:

```text
src/services/task.service.js
```

```js
const tasks = require("../data/tasks");

const getAllTasks = ({ search, completed }) => {
  let result = [...tasks];

  if (search) {
    result = result.filter((task) =>
      task.title.toLowerCase().includes(search.toLowerCase())
    );
  }

  if (completed !== undefined) {
    result = result.filter(
      (task) => task.completed === (completed === "true")
    );
  }

  return result;
};

const getTaskById = (id) => {
  return tasks.find((task) => task.id === id);
};

const createTask = (title) => {
  const task = {
    id: Date.now(),
    title,
    completed: false,
  };

  tasks.push(task);

  return task;
};

const updateTask = (id, data) => {
  const task = getTaskById(id);

  if (!task) {
    return null;
  }

  if (data.title !== undefined) {
    task.title = data.title;
  }

  if (data.completed !== undefined) {
    task.completed = data.completed;
  }

  return task;
};

const deleteTask = (id) => {
  const index = tasks.findIndex((task) => task.id === id);

  if (index === -1) {
    return false;
  }

  tasks.splice(index, 1);

  return true;
};

module.exports = {
  getAllTasks,
  getTaskById,
  createTask,
  updateTask,
  deleteTask,
};
```

# 45. Controller

فایل:

```text
src/controllers/task.controller.js
```

```js
const taskService = require("../services/task.service");

const getTasks = (req, res) => {
  const tasks = taskService.getAllTasks(req.query);

  res.json({
    data: tasks,
  });
};

const getTask = (req, res) => {
  const id = Number(req.params.id);

  if (Number.isNaN(id)) {
    return res.status(400).json({
      message: "Invalid task id",
    });
  }

  const task = taskService.getTaskById(id);

  if (!task) {
    return res.status(404).json({
      message: "Task not found",
    });
  }

  res.json({
    data: task,
  });
};

const createTask = (req, res) => {
  const { title } = req.body;

  if (!title || typeof title !== "string") {
    return res.status(400).json({
      message: "Title is required",
    });
  }

  const task = taskService.createTask(title.trim());

  res.status(201).json({
    data: task,
  });
};

const updateTask = (req, res) => {
  const id = Number(req.params.id);

  if (Number.isNaN(id)) {
    return res.status(400).json({
      message: "Invalid task id",
    });
  }

  const task = taskService.updateTask(id, req.body);

  if (!task) {
    return res.status(404).json({
      message: "Task not found",
    });
  }

  res.json({
    data: task,
  });
};

const deleteTask = (req, res) => {
  const id = Number(req.params.id);

  if (Number.isNaN(id)) {
    return res.status(400).json({
      message: "Invalid task id",
    });
  }

  const deleted = taskService.deleteTask(id);

  if (!deleted) {
    return res.status(404).json({
      message: "Task not found",
    });
  }

  res.status(204).send();
};

module.exports = {
  getTasks,
  getTask,
  createTask,
  updateTask,
  deleteTask,
};
```

# 72. پاسخ مینی‌پروژه

ساختار پیشنهادی:

```text

```

داده اولیه:

```js
const books = [
  {
    id: 1,
    title: "Clean Code",
    author: "Robert C. Martin",
    publishedYear: 2008,
  },
  {
    id: 2,
    title: "The Pragmatic Programmer",
    author: "Andrew Hunt",
    publishedYear: 1999,
  },
];

module.exports = books;
```

Service:

```js
const books = require("../data/books");

const getBooks = ({ search, year }) => {
  let result = [...books];

  if (search) {
    const query = search.toLowerCase();

    result = result.filter(
      (book) =>
        book.title.toLowerCase().includes(query) ||
        book.author.toLowerCase().includes(query)
    );
  }

  if (year) {
    result = result.filter(
      (book) => book.publishedYear === Number(year)
    );
  }

  return result;
};

const getBookById = (id) => {
  return books.find((book) => book.id === id);
};

const createBook = (data) => {
  const book = {
    id: Date.now(),
    title: data.title,
    author: data.author,
    publishedYear: data.publishedYear,
  };

  books.push(book);

  return book;
};

const updateBook = (id, data) => {
  const book = getBookById(id);

  if (!book) {
    return null;
  }

  if (data.title !== undefined) {
    book.title = data.title;
  }

  if (data.author !== undefined) {
    book.author = data.author;
  }

  if (data.publishedYear !== undefined) {
    book.publishedYear = data.publishedYear;
  }

  return book;
};

const deleteBook = (id) => {
  const index = books.findIndex((book) => book.id === id);

  if (index === -1) {
    return false;
  }

  books.splice(index, 1);

  return true;
};

module.exports = {
  getBooks,
  getBookById,
  createBook,
  updateBook,
  deleteBook,
};
```

Controller:

```js
const bookService = require("../services/book.service");

const getBooks = (req, res) => {
  const books = bookService.getBooks(req.query);

  res.json({
    data: books,
  });
};

const getBook = (req, res) => {
  const id = Number(req.params.id);

  if (Number.isNaN(id)) {
    return res.status(400).json({
      message: "Invalid book id",
    });
  }

  const book = bookService.getBookById(id);

  if (!book) {
    return res.status(404).json({
      message: "Book not found",
    });
  }

  res.json({
    data: book,
  });
};

const createBook = (req, res) => {
  const { title, author, publishedYear } = req.body;

  if (!title || !author || typeof publishedYear !== "number") {
    return res.status(400).json({
      message: "Invalid book data",
    });
  }

  const book = bookService.createBook({
    title: title.trim(),
    author: author.trim(),
    publishedYear,
  });

  res.status(201).json({
    data: book,
  });
};

const updateBook = (req, res) => {
  const id = Number(req.params.id);

  if (Number.isNaN(id)) {
    return res.status(400).json({
      message: "Invalid book id",
    });
  }

  const book = bookService.updateBook(id, req.body);

  if (!book) {
    return res.status(404).json({
      message: "Book not found",
    });
  }

  res.json({
    data: book,
  });
};

const deleteBook = (req, res) => {
  const id = Number(req.params.id);

  if (Number.isNaN(id)) {
    return res.status(400).json({
      message: "Invalid book id",
    });
  }

  const deleted = bookService.deleteBook(id);

  if (!deleted) {
    return res.status(404).json({
      message: "Book not found",
    });
  }

  res.status(204).send();
};

module.exports = {
  getBooks,
  getBook,
  createBook,
  updateBook,
  deleteBook,
};
```

```text
   ↓

   ↓

   ↓
```

نیست.
