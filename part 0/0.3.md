قبل از شروع کدنویسی با JavaScript، باید بدانید این زبان دقیقاً چیست، Node.js چه نقشی دارد و چرا میلیون‌ها توسعه‌دهنده در سراسر دنیا از این فناوری استفاده می‌کنند. در این فصل با پایه‌های اکوسیستم JavaScript و Node.js آشنا می‌شوید.

# فصل 3 - آشنایی با JavaScript و Node.js

در فصل قبل یاد گرفتیم که کامپیوتر فقط دستور اجرا می‌کند و برای انجام هر کاری به یک برنامه نیاز دارد.

اما سؤال مهم اینجاست:

**این برنامه‌ها را با چه زبانی می‌نویسیم؟**

یکی از محبوب‌ترین پاسخ‌های این سؤال، **JavaScript** است.

امروزه JavaScript تنها یک زبان مخصوص صفحات وب نیست؛ بلکه با کمک Node.js به یکی از قدرتمندترین زبان‌های برنامه‌نویسی دنیا برای توسعه Backend، ابزارهای خط فرمان، سیستم‌های Real-Time، ربات‌ها و حتی برنامه‌های دسکتاپ تبدیل شده است.

در این فصل با JavaScript، Node.js و نحوه‌ی همکاری آن‌ها آشنا می‌شویم.

---

# JavaScript چیست؟

**JavaScript** یک زبان برنامه‌نویسی سطح بالا (High-Level)، پویا (Dynamic) و چندمنظوره (Multi-Paradigm) است که در سال ۱۹۹۵ توسط **Brendan Eich** در شرکت Netscape طراحی شد.

هدف اولیه JavaScript، ایجاد تعامل در صفحات وب بود.

قبل از JavaScript، صفحات وب تقریباً ثابت بودند و تنها متن و تصویر نمایش می‌دادند.

اما JavaScript امکان انجام کارهایی مانند موارد زیر را فراهم کرد:

* کلیک روی دکمه‌ها
* نمایش پیام
* اعتبارسنجی فرم‌ها
* ساخت انیمیشن
* ارتباط با سرور
* بروزرسانی بخشی از صفحه بدون رفرش کامل

با گذشت زمان، JavaScript به یکی از محبوب‌ترین زبان‌های برنامه‌نویسی دنیا تبدیل شد و امروزه تقریباً در تمام حوزه‌های توسعه نرم‌افزار کاربرد دارد.

---

# JavaScript امروزه چه کاربردهایی دارد؟

برخلاف گذشته، JavaScript فقط برای صفحات وب نیست.

امروزه می‌توان با JavaScript موارد زیر را توسعه داد:

* وب‌سایت
* Backend
* REST API
* GraphQL API
* برنامه‌های Real-Time
* ربات تلگرام
* ربات دیسکورد
* ربات واتساپ
* ابزارهای CLI
* Desktop Application
* Mobile Application
* Serverless Function
* سیستم‌های IoT
* ابزارهای DevOps
* Game Server
* برنامه‌های هوش مصنوعی (به عنوان Backend)

به همین دلیل JavaScript را یکی از کامل‌ترین زبان‌های برنامه‌نویسی دنیا می‌دانند.

---

# JavaScript چگونه اجرا می‌شود؟

کدی که شما می‌نویسید مستقیماً توسط پردازنده اجرا نمی‌شود.

ابتدا باید محیطی وجود داشته باشد که بتواند کد JavaScript را بخواند و اجرا کند.

این محیط می‌تواند یکی از موارد زیر باشد:

* مرورگر (Chrome، Firefox، Edge و ...)
* Node.js
* Deno
* Bun

در این مستند تمرکز اصلی ما روی **Node.js** خواهد بود.

---

# تفاوت JavaScript در مرورگر و Node.js

بسیاری از افراد تصور می‌کنند JavaScript و Node.js دو زبان متفاوت هستند.

این تصور کاملاً اشتباه است.

**JavaScript همیشه همان JavaScript است.**

تفاوت در محیط اجرای آن است.

---

## JavaScript در مرورگر

وقتی داخل مرورگر کد JavaScript اجرا می‌کنید، به امکانات مخصوص مرورگر دسترسی دارید.

برای مثال:

* DOM
* Window
* Document
* LocalStorage
* SessionStorage
* Navigator
* Alert
* Fetch
* Cookies

در این حالت JavaScript برای تعامل با صفحه وب طراحی شده است.

---

## JavaScript در Node.js

در Node.js خبری از صفحه وب نیست.

در عوض امکاناتی مانند:

* File System
* Process
* HTTP Server
* TCP
* UDP
* Streams
* Buffer
* Path
* OS
* Crypto
* EventEmitter

در اختیار شما قرار می‌گیرد.

به همین دلیل Node.js برای توسعه Backend بسیار مناسب است.

---

## مقایسه

| JavaScript در مرورگر | JavaScript در Node.js     |
| -------------------- | ------------------------- |
| اجرای داخل مرورگر    | اجرای خارج از مرورگر      |
| دسترسی به DOM        | بدون DOM                  |
| دسترسی به Window     | بدون Window               |
| مناسب Frontend       | مناسب Backend             |
| تعامل با صفحه وب     | تعامل با سیستم‌عامل و سرور |

نکته مهم:

**زبان برنامه‌نویسی تغییر نکرده است؛ فقط محیط اجرا تغییر کرده است.**

---

# Node.js چیست؟

Node.js یک **Runtime Environment** برای اجرای JavaScript خارج از مرورگر است.

قبل از معرفی Node.js، JavaScript فقط در مرورگر اجرا می‌شد.

اگر می‌خواستید Backend بنویسید باید از زبان‌هایی مانند:

* PHP
* Java
* C#
* Python
* Ruby

استفاده می‌کردید.

اما در سال ۲۰۰۹، **Ryan Dahl** پروژه Node.js را معرفی کرد.

از آن زمان، توسعه‌دهندگان توانستند با همان JavaScript که در Frontend استفاده می‌کردند، Backend نیز بنویسند.

این اتفاق دنیای توسعه وب را متحول کرد.

---

# Runtime چیست؟

Runtime به محیطی گفته می‌شود که مسئول اجرای برنامه است.

به بیان ساده:

وقتی فایل JavaScript را اجرا می‌کنید، Runtime آن را می‌خواند، پردازش می‌کند و نتیجه را اجرا می‌کند.

بدون Runtime، فایل JavaScript فقط یک فایل متنی است.

---

## مثال

فرض کنید کتاب آشپزی دارید.

خود کتاب غذا درست نمی‌کند.

برای تهیه غذا نیاز به آشپز دارید.

در این مثال:

* کتاب = فایل JavaScript
* آشپز = Runtime

Runtime همان چیزی است که دستورات JavaScript را اجرا می‌کند.

---

# V8 Engine چیست؟

قلب Node.js، موتور **V8** است.

V8 موتور اجرای JavaScript است که توسط شرکت Google توسعه داده شده و در مرورگر Chrome نیز استفاده می‌شود.

وظیفه V8:

* خواندن کد JavaScript
* تبدیل آن به کد ماشین
* اجرای سریع برنامه

به همین دلیل JavaScript امروزی بسیار سریع‌تر از نسخه‌های اولیه خود است.

---

## Node.js فقط V8 نیست

یکی از مهم‌ترین نکاتی که باید از همین ابتدا بدانید این است:

بسیاری از افراد فکر می‌کنند:

> Node.js = V8

اما این درست نیست.

Node.js از چند بخش تشکیل شده است:

* موتور V8
* کتابخانه libuv
* Node.js API
* ماژول‌های داخلی
* Event Loop

V8 فقط یکی از اجزای Node.js است.

در فصل‌های آینده همه این بخش‌ها را به صورت کامل بررسی خواهیم کرد.

---

# چرا Node.js ساخته شد؟

قبل از Node.js، JavaScript فقط در مرورگر اجرا می‌شد.

اما توسعه‌دهندگان می‌خواستند:

* Backend را نیز با JavaScript بنویسند.
* از یک زبان در کل پروژه استفاده کنند.
* برنامه‌های سریع و هم‌زمان توسعه دهند.
* بتوانند هزاران اتصال هم‌زمان را مدیریت کنند.

Node.js دقیقاً برای حل این مشکلات ساخته شد.

---

## پاسخ تمرین ۲

نمونه پاسخ:

* در مرورگر به DOM دسترسی داریم، اما در Node.js خیر.
* مرورگر برای توسعه Frontend استفاده می‌شود، Node.js برای توسعه Backend و برنامه‌های سمت سرور.
* Node.js به منابع سیستم‌عامل مانند فایل‌ها و پردازش‌ها دسترسی دارد، اما مرورگر به دلایل امنیتی چنین دسترسی مستقیمی ندارد.

## پاسخ تمرین ۴

این تمرین به شما کمک می‌کند قبل از ورود به مباحث عملی، دید بهتری نسبت به توانایی‌های Node.js و حوزه‌های استفاده از آن پیدا کنید. در فصل‌های آینده، بسیاری از این ایده‌ها را به پروژه‌های واقعی تبدیل خواهیم کرد.

در فصل بعد، محیط توسعه خود را آماده می‌کنیم؛ Node.js، VS Code و ابزارهای موردنیاز را نصب می‌کنیم و اولین پروژه JavaScript خود را اجرا خواهیم کرد.
