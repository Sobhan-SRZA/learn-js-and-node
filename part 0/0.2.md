قبل از نوشتن اولین برنامه، لازم است بدانیم اصلاً «برنامه‌نویسی» چیست و چرا کامپیوتر به آن نیاز دارد. در این فصل با مفاهیم پایه‌ای آشنا می‌شوید که در تمام طول مسیر یادگیری Node.js و JavaScript همراه شما خواهند بود.

# فصل 2 - برنامه‌نویسی چیست؟

اگر از یک برنامه‌نویس بپرسید «برنامه‌نویسی چیست؟»، احتمالاً پاسخ‌های متفاوتی خواهید شنید؛ اما همه آن‌ها یک مفهوم مشترک دارند:

> **برنامه‌نویسی یعنی آموزش دادن به کامپیوتر برای انجام یک کار.**

کامپیوتر به خودی خود هیچ تصمیمی نمی‌گیرد، هیچ چیزی را حدس نمی‌زند و هیچ خلاقیتی ندارد. هر کاری که انجام می‌دهد، نتیجه‌ی دستوراتی است که انسان برای آن نوشته است.

هر برنامه‌ای که روزانه از آن استفاده می‌کنید، از یک ماشین حساب ساده گرفته تا شبکه‌های اجتماعی، بازی‌ها، فروشگاه‌های اینترنتی و حتی هوش مصنوعی، همگی از میلیون‌ها دستور تشکیل شده‌اند که توسط برنامه‌نویسان نوشته شده‌اند.

در این فصل یاد می‌گیریم که کامپیوتر چگونه فکر می‌کند و چرا برنامه‌نویسی در واقع هنر حل مسئله است.

---

# کامپیوتر چگونه فکر می‌کند؟

پاسخ کوتاه این است:

**کامپیوتر فکر نمی‌کند.**

کامپیوتر فقط دستور اجرا می‌کند.

او نمی‌تواند منظور شما را حدس بزند، احساسات شما را درک کند یا خودش تصمیم بگیرد.

فرض کنید به دوستتان بگویید:

> لطفاً برایم یک لیوان آب بیاور.

دوست شما منظور شما را متوجه می‌شود، حتی اگر جمله کامل نباشد.

اما اگر همین جمله را به کامپیوتر بگویید، هیچ اتفاقی نمی‌افتد؛ زیرا کامپیوتر فقط زبان خودش را می‌فهمد.

کامپیوتر نیاز دارد دقیقاً بداند:

* کدام لیوان؟
* از کجا؟
* چه مقدار آب؟
* بعد از پر کردن چه کاری انجام دهد؟
* اگر آب نبود چه کند؟

برای کامپیوتر همه چیز باید کاملاً مشخص باشد.

به همین دلیل است که برنامه‌نویسی نیازمند دقت بسیار بالاست.

---

## کامپیوتر فقط دو حالت را می‌شناسد

در پایین‌ترین سطح، تمام اطلاعات داخل کامپیوتر به صورت صفر و یک ذخیره می‌شوند.

* 0
* 1

به این زبان، **زبان ماشین (Machine Language)** گفته می‌شود.

اما نوشتن میلیون‌ها صفر و یک برای انسان تقریباً غیرممکن است.

به همین دلیل زبان‌های برنامه‌نویسی مانند JavaScript ساخته شدند تا انسان بتواند به زبان ساده‌تر برنامه بنویسد و سپس این کدها توسط Node.js و موتور V8 به زبان قابل فهم برای کامپیوتر تبدیل شوند.

---

# برنامه چیست؟

برنامه (Program) مجموعه‌ای از دستورهاست که برای انجام یک هدف مشخص نوشته می‌شود.

برای مثال:

* ماشین حساب
* مرورگر اینترنت
* تلگرام
* اینستاگرام
* Discord
* Spotify
* VS Code

همگی برنامه هستند.

هر برنامه فقط مجموعه‌ای از دستورهاست.

مثلاً یک ماشین حساب:

1. عدد اول را دریافت کن.
2. عدد دوم را دریافت کن.
3. عملگر را دریافت کن.
4. عملیات را انجام بده.
5. نتیجه را نمایش بده.

همین چند مرحله ساده، یک برنامه را تشکیل می‌دهند.

---

# برنامه‌نویس چه کاری انجام می‌دهد؟

برنامه‌نویس کسی است که:

* مسئله را تحلیل می‌کند.
* برای حل آن راهکار پیدا می‌کند.
* راهکار را به صورت الگوریتم می‌نویسد.
* الگوریتم را به کد تبدیل می‌کند.
* برنامه را تست می‌کند.
* خطاها را برطرف می‌کند.
* برنامه را توسعه می‌دهد.

در واقع، بیشتر زمان یک برنامه‌نویس صرف **فکر کردن و حل مسئله** می‌شود، نه نوشتن کد.

---

# الگوریتم چیست؟

الگوریتم یعنی:

> **مجموعه‌ای از مراحل مرتب و مشخص برای حل یک مسئله.**

قبل از نوشتن کد، باید بدانیم دقیقاً قرار است چه کاری انجام دهیم.

مثال:

می‌خواهیم چای درست کنیم.

الگوریتم:

1. کتری را بردار.
2. داخل آن آب بریز.
3. کتری را روی گاز قرار بده.
4. صبر کن آب بجوشد.
5. چای را داخل قوری بریز.
6. آب جوش را اضافه کن.
7. چند دقیقه صبر کن.
8. چای را سرو کن.

این مراحل همان الگوریتم هستند.

---

## مثال برنامه‌نویسی

مسئله:

محاسبه مجموع دو عدد.

الگوریتم:

1. عدد اول را بگیر.
2. عدد دوم را بگیر.
3. دو عدد را جمع کن.
4. نتیجه را نمایش بده.

بعداً همین الگوریتم را با JavaScript پیاده‌سازی خواهیم کرد.

---

# ویژگی‌های یک الگوریتم خوب

یک الگوریتم مناسب باید:

* واضح باشد.
* ابهام نداشته باشد.
* ترتیب مراحل مشخص باشد.
* پایان مشخص داشته باشد.
* قابل اجرا باشد.
* تا حد امکان ساده باشد.

اگر الگوریتم درست طراحی شود، نوشتن کد بسیار ساده‌تر خواهد بود.

---

# فلوچارت چیست؟

گاهی نمایش مراحل به صورت متن سخت می‌شود.

در این حالت از **فلوچارت (Flowchart)** استفاده می‌کنیم.

فلوچارت نمایش تصویری الگوریتم است.

در فلوچارت، هر شکل معنی مشخصی دارد.

| شکل           | کاربرد            |
| ------------- | ----------------- |
| بیضی          | شروع یا پایان     |
| مستطیل        | انجام عملیات      |
| لوزی          | تصمیم‌گیری         |
| متوازی‌الأضلاع | ورودی یا خروجی    |
| فلش           | مسیر اجرای برنامه |

---

## مثال فلوچارت

فرض کنید می‌خواهیم بررسی کنیم آیا فرد می‌تواند گواهینامه بگیرد یا خیر.

```
شروع
   │
دریافت سن
   │
سن >= 18 ؟
  │      │
بله     خیر
 │        │
مجاز   غیرمجاز
 │        │
 پایان   پایان
```

بعدها همین منطق را با دستورهای `if` و `else` پیاده‌سازی خواهیم کرد.

---

# ورودی، پردازش و خروجی (Input → Process → Output)

تقریباً تمام برنامه‌های دنیا از سه مرحله تشکیل شده‌اند.

## 1. ورودی (Input)

اطلاعات از کاربر یا سیستم دریافت می‌شود.

مثال:

* نام کاربر
* رمز عبور
* عدد
* فایل
* تصویر

---

## 2. پردازش (Process)

روی داده‌ها عملیات انجام می‌شود.

مثلاً:

* جمع
* ضرب
* مرتب‌سازی
* جستجو
* اعتبارسنجی
* رمزنگاری

---

## 3. خروجی (Output)

نتیجه به کاربر نمایش داده می‌شود.

مثلاً:

* چاپ نتیجه
* ذخیره فایل
* نمایش پیام
* ارسال پاسخ API

---

## مثال

ماشین حساب

ورودی:

```
12
15
```

پردازش:

```
12 + 15
```

خروجی:

```
27
```

---

## مثال دیگر

سیستم ورود کاربران

ورودی:

```
Username
Password
```

پردازش:

* بررسی رمز
* بررسی کاربر

خروجی:

```
ورود موفق
```

یا

```
رمز اشتباه است.
```

تقریباً تمام نرم‌افزارهای دنیا از همین چرخه ساده پیروی می‌کنند.

---

# مفهوم منطق در برنامه‌نویسی

بزرگ‌ترین تفاوت یک برنامه‌نویس حرفه‌ای با یک مبتدی، میزان حفظ کردن دستورات نیست؛ بلکه **قدرت حل مسئله و منطق برنامه‌نویسی** است.

منطق برنامه‌نویسی یعنی بتوانید:

* مسئله را به بخش‌های کوچک‌تر تقسیم کنید.
* برای هر بخش یک راه‌حل مشخص پیدا کنید.
* مراحل را به ترتیب مناسب اجرا کنید.
* همه حالت‌های ممکن را در نظر بگیرید.

---

## مثال

اگر بخواهیم برنامه‌ای بنویسیم که تشخیص دهد فرد بالغ است یا خیر، باید منطق آن را مشخص کنیم.

```
اگر سن بزرگ‌تر یا مساوی 18 بود
    بالغ است
در غیر این صورت
    کودک است
```

قبل از نوشتن حتی یک خط کد، منطق برنامه باید مشخص شده باشد.

---

# چرا منطق از زبان برنامه‌نویسی مهم‌تر است؟

فرض کنید فردی JavaScript را به خوبی بلد باشد، اما نتواند مسئله را تحلیل کند.

آیا می‌تواند برنامه بنویسد؟

خیر.

از طرف دیگر، اگر کسی منطق برنامه‌نویسی را بلد باشد، یادگیری زبان‌های جدید برای او بسیار آسان خواهد بود.

به همین دلیل در این مستند تلاش می‌کنیم علاوه بر آموزش JavaScript، شیوه‌ی صحیح فکر کردن مانند یک برنامه‌نویس را نیز یاد بگیرید.

---

# اشتباهات رایج

### ❌ حفظ کردن کدها به جای درک مفاهیم

هدف از یادگیری برنامه‌نویسی، حفظ کردن دستورات نیست؛ بلکه فهمیدن دلیل استفاده از آن‌ها و توانایی حل مسئله است.

---

### ❌ شروع کدنویسی بدون طراحی الگوریتم

بسیاری از مبتدیان بلافاصله کدنویسی را آغاز می‌کنند. این کار معمولاً باعث پیچیده شدن پروژه و افزایش خطاها می‌شود.

---

### ❌ ترس از اشتباه

خطا بخش طبیعی برنامه‌نویسی است. حتی توسعه‌دهندگان باتجربه نیز روزانه با خطاهای مختلف روبه‌رو می‌شوند.

---

### ❌ تلاش برای یادگیری هم‌زمان چند زبان

در ابتدای مسیر روی یک زبان و یک مسیر مشخص تمرکز کنید. در این مستند، آن مسیر JavaScript و Node.js است.

---

### ❌ کپی کردن کد بدون تحلیل

اگر تنها کد دیگران را کپی کنید، شاید پروژه اجرا شود، اما مهارت برنامه‌نویسی در شما شکل نخواهد گرفت.

---

# نکات حرفه‌ای

* قبل از نوشتن کد، مسئله را روی کاغذ بنویسید.
* همیشه ابتدا الگوریتم طراحی کنید و سپس سراغ پیاده‌سازی بروید.
* سعی کنید هر مسئله را به چند مسئله کوچک‌تر تقسیم کنید.
* اگر الگوریتم پیچیده به نظر می‌رسد، احتمالاً می‌توان آن را ساده‌تر کرد.
* برای هر برنامه از خود بپرسید: «ورودی چیست؟»، «پردازش چیست؟» و «خروجی چیست؟».
* هنگام مطالعه مثال‌ها، ابتدا خودتان پاسخ را حدس بزنید و سپس ادامه آموزش را بخوانید.
* هرچه بیشتر مسئله حل کنید، منطق برنامه‌نویسی شما قوی‌تر خواهد شد.

# مینی‌پروژه

## طراحی الگوریتم دستگاه خودپرداز (ATM)

در این پروژه هنوز نیازی به نوشتن کد نیست. هدف، تمرین تفکر الگوریتمی است.

### صورت مسئله

فرض کنید قرار است نرم‌افزار یک دستگاه خودپرداز را طراحی کنید که فقط عملیات برداشت وجه را انجام می‌دهد.

### ورودی

* شماره کارت
* رمز عبور
* مبلغ برداشت

### پردازش

* بررسی معتبر بودن شماره کارت
* بررسی صحت رمز عبور
* بررسی موجود بودن حساب
* بررسی کافی بودن موجودی
* کسر مبلغ از حساب
* ثبت تراکنش

### خروجی

در صورت موفقیت:

* نمایش پیام «برداشت با موفقیت انجام شد.»
* نمایش موجودی جدید

در صورت بروز خطا:

* «رمز عبور اشتباه است.»
* «کارت نامعتبر است.»
* «موجودی کافی نیست.»
* «تراکنش ناموفق بود.»

### هدف پروژه

در این مرحله، تنها کافی است الگوریتم این سیستم را به صورت مرحله‌به‌مرحله طراحی کنید. در فصل‌های آینده، همین منطق را با استفاده از JavaScript و سپس در محیط Node.js به یک برنامه واقعی تبدیل خواهیم کرد.

در فصل بعد وارد دنیای JavaScript و Node.js می‌شویم و با تفاوت آن‌ها، نحوه اجرای کدها و نقش Node.js در اجرای JavaScript خارج از مرورگر آشنا خواهیم شد.
