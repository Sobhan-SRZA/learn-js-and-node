# 📚 بخش ۰ - قبل از شروع برنامه‌نویسی

این بخش نقطه شروع دوره جامع **JavaScript در Node.js** است و برای افرادی طراحی شده که می‌خواهند برنامه‌نویسی را از **سطح صفر** شروع کنند.

در این بخش، قبل از ورود به کدنویسی، با مفاهیم پایه‌ای برنامه‌نویسی، مسیر یادگیری و همچنین JavaScript و Node.js آشنا می‌شویم.
