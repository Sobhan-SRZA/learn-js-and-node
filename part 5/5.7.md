# فصل ۲۸ - Date

تقریباً تمام برنامه‌هایی که می‌نویسیم با **زمان** و **تاریخ** سروکار دارند.

چند مثال:

* ثبت زمان ایجاد حساب کاربری
* نمایش تاریخ انتشار یک مقاله
* محاسبه سن کاربران
* محاسبه مدت زمان اجرای یک عملیات
* ساخت سیستم لاگ (Log)
* تعیین زمان انقضای توکن‌ها
* زمان‌بندی اجرای کارها (Scheduler)
* ثبت تاریخ سفارش‌ها

در Node.js شیء `Date` برای کار با تاریخ و زمان استفاده می‌شود.

در این فصل به صورت کامل با Date آشنا می‌شویم.

---

# ساخت Date

ساده‌ترین روش:

```javascript
const now = new Date();

console.log(now);
```

خروجی نمونه:

```text
2026-07-31T17:25:42.512Z
```

هر بار اجرای برنامه مقدار متفاوت خواهد بود.

# Unix Timestamp

تمام تاریخ‌ها در جاوااسکریپت بر اساس تعداد میلی‌ثانیه از

**1 January 1970 UTC**

ذخیره می‌شوند.


# متدهای UTC

گاهی لازم است تاریخ را بدون وابستگی به منطقه زمانی سیستم دریافت کنیم.

```javascript
const now = new Date();

console.log(now.getUTCFullYear());
console.log(now.getUTCMonth());
console.log(now.getUTCDate());
console.log(now.getUTCHours());
console.log(now.getUTCMinutes());
```

همچنین متدهای `setUTCFullYear`، `setUTCMonth` و سایر متدهای مشابه نیز وجود دارند.

# اشتباهات رایج

## ۱. فراموش کردن اینکه ماه از صفر شروع می‌شود

اشتباه:

```javascript
new Date(2026, 7, 1);
```

بسیاری تصور می‌کنند این تاریخ مربوط به جولای است، در حالی که ماه هشتم (آگوست) ساخته می‌شود.

---

## ۲. استفاده از `getYear()`

اشتباه:

```javascript
date.getYear();
```

درست:

```javascript
date.getFullYear();
```

---

## ۳. مقایسه رشته‌های تاریخ

اشتباه:

```javascript
"2026/2/1" > "2026/10/1"
```

همیشه از شیء Date یا Timestamp برای مقایسه استفاده کنید.

---

## ۴. نادیده گرفتن منطقه زمانی (Time Zone)

تاریخ ذخیره‌شده با `toISOString()` بر اساس UTC است، اما `toLocaleString()` بر اساس منطقه زمانی سیستم کاربر نمایش داده می‌شود.

---

## ۵. فراموش کردن اینکه اختلاف تاریخ بر حسب میلی‌ثانیه است

```javascript
const diff = end - start;
```

این مقدار روز یا ساعت نیست و باید تبدیل شود.

---

# نکات حرفه‌ای

* برای اندازه‌گیری زمان اجرا از `Date.now()` استفاده کنید.
* برای ذخیره تاریخ در پایگاه داده، فرمت ISO (`toISOString()`) بهترین انتخاب است.
* برای نمایش به کاربر از `toLocaleDateString()` یا `toLocaleString()` استفاده کنید.
* هنگام کار با APIها معمولاً بهتر است همه زمان‌ها را به صورت UTC ذخیره کنید.
* اگر عملیات زیادی روی تاریخ انجام می‌دهید، از Timestamp استفاده کنید؛ مقایسه اعداد سریع‌تر از مقایسه رشته‌ها است.
* برای پروژه‌های پیچیده که نیاز به مدیریت تقویم، منطقه زمانی یا محاسبات پیشرفته دارند، معمولاً از کتابخانه‌هایی مانند Luxon یا date-fns استفاده می‌شود.

# مینی‌پروژه

## سیستم ثبت لاگ برنامه

برنامه‌ای بنویسید که هر بار اجرا شدن برنامه را همراه با تاریخ و ساعت ثبت کند.

```javascript
const logs = [];

function addLog(message) {
    logs.push({
        message,
        createdAt: new Date().toISOString()
    });
}

addLog("Server Started");
addLog("User Login");
addLog("Database Connected");

console.table(logs);
```

نمونه خروجی:

```text
┌─────────┬──────────────────────┬────────────────────────────┐
│ message │ createdAt            │
├─────────┼──────────────────────┼────────────────────────────┤
│ Server Started                 │ 2026-07-31T17:45:10.321Z │
│ User Login                     │ 2026-07-31T17:45:11.402Z │
│ Database Connected             │ 2026-07-31T17:45:12.110Z │
└─────────┴──────────────────────┴────────────────────────────┘
```

### ایده‌هایی برای توسعه پروژه

* ذخیره لاگ‌ها در فایل JSON
* نمایش لاگ‌ها بر اساس تاریخ
* حذف لاگ‌های قدیمی‌تر از تعداد روز مشخص
* نمایش مدت زمان سپری‌شده از هر لاگ (مثلاً «۵ دقیقه قبل»)
* اضافه کردن سطح لاگ (INFO، WARN، ERROR)
* ساخت یک Logger ساده برای پروژه‌های Node.js
