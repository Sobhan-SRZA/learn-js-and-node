# فصل ۲۷ - Map

`Map` یکی از ساختارهای داده قدرتمند جاوااسکریپت است که برای نگهداری داده‌ها به صورت **کلید (Key) و مقدار (Value)** استفاده می‌شود.

شاید در نگاه اول Map شبیه Object به نظر برسد، اما تفاوت‌های مهمی بین این دو وجود دارد که باعث می‌شود در بسیاری از پروژه‌های Node.js، استفاده از Map انتخاب بهتری باشد.

در این فصل با Map کاملاً آشنا می‌شویم، تفاوت آن را با Object بررسی می‌کنیم و یاد می‌گیریم چه زمانی باید از هر کدام استفاده کنیم.

---

# چرا Map به وجود آمد؟

قبل از معرفی Map، برنامه‌نویسان معمولاً از Object برای ذخیره اطلاعات استفاده می‌کردند.

مثلاً:

```javascript
const user = {
    name: "Ali",
    age: 22
};
```

اما Object محدودیت‌هایی دارد:

* کلیدها معمولاً رشته (String) یا Symbol هستند.
* اندازه آن به راحتی قابل دریافت نیست.
* ترتیب عناصر همیشه قابل اعتماد نیست.
* حذف و جستجو در بعضی شرایط مناسب نیست.
* ممکن است با propertyهای داخلی Object تداخل پیدا کند.

برای حل این مشکلات، Map معرفی شد.

---

# ساخت یک Map

```javascript
const map = new Map();

console.log(map);
```

خروجی:

```text
Map(0) {}
```

---

# افزودن مقدار

برای اضافه کردن داده از متد `set()` استفاده می‌کنیم.

```javascript
const users = new Map();

users.set("name", "Ali");
users.set("age", 25);

console.log(users);
```

خروجی:

```text
Map(2) {
  'name' => 'Ali',
  'age' => 25
}
```

---

# خواندن مقدار

```javascript
console.log(users.get("name"));
```

خروجی:

```text
Ali
```

---

اگر کلید وجود نداشته باشد:

```javascript
console.log(users.get("city"));
```

خروجی:

```text
undefined
```

# تعداد عناصر


# تبدیل Object به Map

```javascript
const obj = {
    name: "Ali",
    age: 20
};

```

# تبدیل Map به Object

```javascript
const map = new Map([
    ["name", "Ali"],
    ["age", 20]
]);

const obj = Object.fromEntries(map);

```

# مقایسه Map و Object

| ویژگی                | Map          | Object                |
| -------------------- | ------------ | --------------------- |
| کلید از هر نوع داده  | ✅            | ❌                     |
| size                 | ✅            | ❌                     |
| ترتیب ذخیره          | حفظ می‌شود   | همیشه قابل اتکا نیست  |
| مناسب برای Key-Value | ✅            | نسبتاً                |
| سرعت عملیات زیاد     | معمولاً بهتر | کمتر در داده‌های بزرگ |

---

# چه زمانی از Map استفاده کنیم؟

از Map استفاده کنید زمانی که:

* تعداد داده‌ها زیاد است.
* مرتباً حذف و اضافه انجام می‌شود.
* کلیدها فقط String نیستند.
* نیاز به اندازه واقعی دارید.
* داده‌ها حالت Dictionary دارند.

---

# نمونه واقعی در Node.js

فرض کنید اطلاعات کاربران آنلاین را نگهداری می‌کنیم.

```javascript
const onlineUsers = new Map();

onlineUsers.set(101, "Ali");
onlineUsers.set(102, "Sara");
onlineUsers.set(103, "Reza");

console.log(onlineUsers.get(102));
```

---

مثال دیگر:

```javascript
const cache = new Map();

cache.set("/users", {
    status: 200,
    data: []
});

console.log(cache.get("/users"));
```

در بسیاری از سیستم‌های Cache، Session، Rate Limiter و مدیریت اتصال کاربران از Map استفاده می‌شود.

# اشتباهات رایج

### ۱. استفاده از براکت (`[]`) به جای `set`

اشتباه:

```javascript
const map = new Map();

map["name"] = "Ali";
```

این مقدار به خود شیء Map اضافه می‌شود، نه به داده‌های داخلی Map.

درست:

```javascript
map.set("name", "Ali");
```

---

### ۲. استفاده از پراپرتی به جای `get`

اشتباه:

```javascript
console.log(map.name);
```

درست:

```javascript
console.log(map.get("name"));
```

---

### ۳. فراموش کردن اینکه کلیدهای آبجکت بر اساس مرجع مقایسه می‌شوند

```javascript
const map = new Map();

map.set({ id: 1 }, "Ali");

console.log(map.get({ id: 1 }));
```

خروجی:

```text
undefined
```

چون این دو آبجکت، دو مرجع متفاوت هستند.

---

### ۴. انتظار داشتن `length`

اشتباه:

```javascript
console.log(map.length);
```

درست:

```javascript
console.log(map.size);
```

---

### ۵. استفاده از Map وقتی Object کافی است

اگر فقط چند ویژگی ثابت با کلیدهای رشته‌ای دارید، استفاده از Object ساده‌تر و خواناتر است.

---

# نکات حرفه‌ای

* از Map برای پیاده‌سازی Cache استفاده کنید.
* اگر کلیدهای شما آبجکت هستند، Map بهترین انتخاب است.
* ترتیب ورود داده‌ها در Map حفظ می‌شود.
* برای تبدیل سریع بین Object و Map از `Object.entries()` و `Object.fromEntries()` استفاده کنید.
* اگر به حذف و اضافه مکرر نیاز دارید، Map معمولاً عملکرد بهتری نسبت به Object دارد.
* از `has()` قبل از `get()` استفاده کنید اگر لازم است وجود کلید را از مقدار `undefined` تشخیص دهید.

# مینی‌پروژه

## دفترچه تلفن با Map

برنامه‌ای بنویسید که شماره تلفن افراد را در یک Map ذخیره کند.

امکانات:

* افزودن مخاطب
* جستجوی شماره با نام
* حذف مخاطب
* نمایش تمام مخاطبان
* نمایش تعداد مخاطبان

نمونه:

```javascript
const contacts = new Map();

contacts.set("Ali", "09120000000");
contacts.set("Sara", "09123333333");
contacts.set("Reza", "09125555555");

console.log("شماره سارا:");
console.log(contacts.get("Sara"));

contacts.delete("Reza");

console.log("تعداد مخاطبان:");
console.log(contacts.size);

console.log("فهرست مخاطبان:");

for (const [name, phone] of contacts) {
    console.log(`${name}: ${phone}`);
}
```

### ایده برای توسعه پروژه

* جلوگیری از ثبت مخاطب تکراری
* امکان ویرایش شماره تماس
* جستجوی مخاطبان با بخشی از نام
* ذخیره و بازیابی اطلاعات از فایل JSON
* تبدیل پروژه به یک برنامه خط فرمان (CLI) در Node.js

اگر خواستید، در فصل بعد به **Set** می‌پردازیم که مکمل بسیار خوبی برای `Map` است و برای نگهداری مقادیر یکتا استفاده می‌شود.
