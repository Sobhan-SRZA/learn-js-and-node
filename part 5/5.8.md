# فصل ۲۹ - Math

در برنامه‌نویسی تقریباً هیچ پروژه‌ای وجود ندارد که به عملیات ریاضی نیاز نداشته باشد.

چند مثال:

* محاسبه قیمت نهایی سفارش
* محاسبه مالیات و تخفیف
* تولید عدد تصادفی
* محاسبه فاصله بین دو نقطه
* بازی‌ها
* الگوریتم‌های رمزنگاری
* تحلیل داده
* هوش مصنوعی
* شبیه‌سازی

جاوااسکریپت شیء سراسری **Math** را برای انجام محاسبات ریاضی در اختیار ما قرار می‌دهد.

نکته مهم:

**Math یک کلاس نیست و نیازی به ساختن آن با `new` وجود ندارد.**

تمام متدها و ثابت‌های آن به صورت مستقیم استفاده می‌شوند.

## ۲. انتظار داشتن عدد تصادفی بین ۱ تا ۱۰ از Math.random()

اشتباه:

```javascript

```

`Math.random()` فقط عددی بین ۰ و کمتر از ۱ تولید می‌کند.

---

## ۳. فراموش کردن floor

اشتباه:

```javascript
Math.random() * 10;
```

ممکن است خروجی اعشاری باشد.

درست:

```javascript
Math.floor(Math.random() * 10);
```

---

## ۴. استفاده از round به جای floor

اگر بخواهید عددی بین ۰ تا ۹ تولید کنید، استفاده از `Math.round()` باعث می‌شود بعضی اعداد احتمال بیشتری برای انتخاب شدن داشته باشند.

# نکات حرفه‌ای

* برای تولید عدد تصادفی در بازه مشخص، همیشه از فرمول استاندارد استفاده کنید.
* برای توان، عملگر `**` خواناتر از `Math.pow()` است.
* برای حذف قسمت اعشاری، `Math.trunc()` از نظر مفهوم مناسب‌تر از `Math.floor()` است؛ زیرا برای اعداد منفی رفتار متفاوتی دارد.
* برای محدود کردن مقدار بین حداقل و حداکثر، ترکیب `Math.max()` و `Math.min()` بسیار کاربردی است.
* `Math.random()` برای کاربردهای امنیتی مناسب نیست. برای تولید مقادیر تصادفی امن در Node.js از ماژول `crypto` استفاده کنید که در فصل‌های آینده با آن آشنا خواهیم شد.

# مینی‌پروژه

## بازی حدس عدد

در این پروژه، برنامه یک عدد تصادفی بین ۱ تا ۱۰۰ تولید می‌کند و کاربر باید آن را حدس بزند. در این فصل به دلیل اینکه هنوز ورودی از کاربر را یاد نگرفته‌ایم، چند حدس به صورت ثابت بررسی می‌کنیم.

```javascript
const secretNumber = Math.floor(Math.random() * 100) + 1;

const guesses = [25, 50, 75, 90];

console.log(`عدد مخفی: ${secretNumber}`);

for (const guess of guesses) {
    if (guess === secretNumber) {
        console.log(`${guess} درست است!`);
    } else if (guess < secretNumber) {
        console.log(`${guess} کوچک‌تر از عدد مخفی است.`);
    } else {
        console.log(`${guess} بزرگ‌تر از عدد مخفی است.`);
    }
}
```

نمونه خروجی:

```text
عدد مخفی: 63
25 کوچک‌تر از عدد مخفی است.
50 کوچک‌تر از عدد مخفی است.
75 بزرگ‌تر از عدد مخفی است.
90 بزرگ‌تر از عدد مخفی است.
```

### ایده‌هایی برای توسعه پروژه

* دریافت حدس از کاربر با ورودی خط فرمان
* شمارش تعداد تلاش‌ها
* تعیین سطح سختی (۱ تا ۱۰، ۱ تا ۱۰۰، ۱ تا ۱۰۰۰)
* نمایش امتیاز بر اساس تعداد حدس‌ها
* امکان بازی مجدد بدون خروج از برنامه
* ذخیره بهترین رکوردها در یک فایل JSON
