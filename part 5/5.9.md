# مقدمه فصل

در برنامه‌نویسی همیشه با داده‌های متنی سروکار داریم.

نام کاربران، ایمیل‌ها، شماره تلفن‌ها، رمزهای عبور، آدرس‌ها، فایل‌ها، لاگ‌های سرور و بسیاری از اطلاعات دیگر همگی به شکل متن ذخیره می‌شوند.

اما گاهی نیاز داریم روی این متن‌ها عملیات خاصی انجام دهیم:

* پیدا کردن یک الگوی خاص در متن
* بررسی معتبر بودن اطلاعات ورودی
* استخراج بخش‌هایی از یک متن
* جایگزین کردن قسمت‌هایی از متن
* حذف کاراکترهای اضافی
* جستجوی پیشرفته در فایل‌ها و داده‌ها

برای انجام این کارها در جاوااسکریپت از **RegExp** یا **Regular Expression** استفاده می‌کنیم.

RegExp یک ابزار قدرتمند برای تعریف الگوهای متنی است.

برای مثال:

می‌توانیم الگویی بسازیم که بررسی کند:

* آیا یک ایمیل معتبر است؟
* آیا رمز عبور شرایط لازم را دارد؟
* آیا شماره تلفن فرمت درستی دارد؟
* آیا یک متن شامل کلمه خاصی است؟
* تمام لینک‌های موجود در یک متن را پیدا کند.
* تمام اعداد داخل یک فایل را استخراج کند.

در Node.js نیز RegExp کاربرد بسیار زیادی دارد.

موارد استفاده در پروژه‌های واقعی:

* اعتبارسنجی اطلاعات کاربران
* پاک‌سازی داده‌ها (Data Cleaning)
* پردازش فایل‌های متنی
* تحلیل لاگ‌های سرور
* ساخت Middlewareهای اعتبارسنجی
* فیلتر کردن محتوا
* پردازش ورودی‌های API

در این فصل از پایه‌ترین مفاهیم RegExp شروع می‌کنیم و قدم‌به‌قدم به کاربردهای حرفه‌ای آن در پروژه‌های Node.js می‌رسیم.

# بخش ۱ - آشنایی با RegExp و مفاهیم پایه

## RegExp چیست؟

`RegExp` کوتاه‌شده‌ی عبارت:

```
Regular Expression
```

است.

Regular Expression یک روش برای تعریف الگوهای متنی است.

به جای اینکه فقط دنبال یک متن مشخص بگردیم، می‌توانیم یک قانون تعریف کنیم.

مثلاً:

به جای اینکه بگوییم:

```
دنبال کلمه Ali بگرد
```

می‌توانیم بگوییم:

```
هر متنی که با حرف A شروع می‌شود و بعد از آن سه حرف دارد را پیدا کن
```

این قدرت اصلی Regex است.

---

## مثال ساده

فرض کنید یک متن داریم:

```javascript
const text = "Hello Node.js";
```

می‌خواهیم بررسی کنیم آیا کلمه Node در متن وجود دارد یا نه.

بدون Regex:

```javascript
console.log(text.includes("Node"));
```

خروجی:

```text
true
```

اما با Regex:

```javascript
const regex = /Node/;

console.log(regex.test(text));
```

خروجی:

```text
true
```

* Validation انجام دهیم.

Regex انتخاب مناسب‌تری است.

## ۳۰.۸ - Character Classes

### مفهوم Character Class

گاهی نمی‌خواهیم فقط یک کاراکتر خاص را پیدا کنیم، بلکه می‌خواهیم یکی از چند کاراکتر مشخص را بررسی کنیم.

برای این کار از **Character Class** استفاده می‌کنیم.

Character Class داخل براکت‌ها نوشته می‌شود:

```regex
[]
```

مثلاً:

```javascript id="c8v1tn"
const regex = /[abc]/;

console.log(regex.test("apple"));
```

در این مثال، اگر متن شامل یکی از حروف `a`، `b` یا `c` باشد، نتیجه `true` می‌شود.

خروجی:

```text
true
```

---

### براکت‌ها `[]`

وقتی از براکت استفاده می‌کنیم، یعنی فقط یکی از کاراکترهای داخل آن قابل قبول است.

مثال:

```javascript id="q9jvkp"
const regex = /[xyz]/;

console.log(regex.test("hello x"));
```

خروجی:

```text
true
```

اگر متن هیچ‌کدام از این کاراکترها را نداشته باشد:

```javascript id="s7m1na"
console.log(regex.test("hello"));
```

خروجی:

```text
false
```

### محدوده کاراکترها

مثلاً:

## ۳۰.۱۲ - Greedy و Lazy Matching

### مفهوم Greedy

Regex به صورت پیش‌فرض **Greedy** است؛ یعنی تا جایی که بتواند بیشترین بخش ممکن را match می‌کند.

مثال:

```javascript id="c1t9af"
const text = "<b>hello</b><b>world</b>";
const regex = /<b>.*<\/b>/;

console.log(text.match(regex));
```

در این حالت ممکن است از اولین `<b>` تا آخرین `</b>` را بگیرد، نه فقط یک بخش کوچک.

---

### مشکل Matching زیاد

مثلاً در متن HTML، اگر از `.*` استفاده کنیم، ممکن است بیشتر از مقدار موردنظر match شود.

---

### استفاده از Lazy Quantifier

برای Lazy کردن quantifier از `?` بعد از آن استفاده می‌کنیم.

مثال:

```javascript id="l3q7dx"
const text = "<b>hello</b><b>world</b>";
const regex = /<b>.*?<\/b>/g;

console.log(text.match(regex));
```

خروجی:

```text
[ '<b>hello</b>', '<b>world</b>' ]
```

---

### تفاوت Greedy و Lazy

| حالت   | رفتار              |
| ------ | ------------------ |
| Greedy | بیشترین match ممکن |
| Lazy   | کمترین match ممکن  |

---

## ۳۰.۱۳ - Group ها

### ساخت گروه

گروه‌ها با پرانتز ساخته می‌شوند:

```regex
()
```

گروه‌ها برای:

* دسته‌بندی الگوها
* تکرار روی کل گروه
* استخراج بخش‌های مختلف متن

استفاده می‌شوند.

---

### مثال ساده

```javascript id="v8m4sy"
const regex = /(abc)/;

console.log(regex.test("123abc456"));
```

خروجی:

```text
true
```

---

### Capturing Groups

وقتی از `()` استفاده می‌کنیم، آن بخش capture می‌شود و می‌توانیم بعداً به آن دسترسی داشته باشیم.

مثال:

```javascript id="q2j6kl"

console.log(result);
```

خروجی:

```text

  'My name is Ali',
  'Ali',
  index: 0,
  input: 'My name is Ali',
  groups: undefined
]
```

---

### استخراج داده از گروه‌ها

```javascript id="s5p7dn"

const result = text.match(regex);

console.log(result[1]);
console.log(result[2]);
```

خروجی:

```text
Reza
23
```

---

### Nested Groups

گروه‌ها می‌توانند داخل هم قرار بگیرند.

```javascript id="a7d1qx"
const regex = /((\d{2})-(\d{2})-(\d{4}))/;
```

این نوع ساختار برای استخراج تاریخ، شماره‌ها و الگوهای پیچیده مفید است.

---

### مثال کاربردی

```javascript id="p1m8zc"

console.log(result[2]);
```

## ۳۰.۱۴ - Non Capturing Groups

### مفهوم

گاهی فقط می‌خواهیم گروه‌بندی انجام دهیم، ولی نمی‌خواهیم آن بخش ذخیره شود.

```regex

```

### مثال

```javascript id="u2t8hv"

```

این گروه capture می‌شود.

اما در Non Capturing Group:


* وقتی فقط اولویت‌بندی الگو مهم است
* وقتی نمی‌خواهیم داده اضافی capture شود
* وقتی عملکرد بهتر و خروجی تمیزتر می‌خواهیم

# ۳۰.۱۷ - متد matchAll()

# مقایسه متدهای مهم String

| متد            | کاربرد                                 |
| -------------- | -------------------------------------- |
| `match()`      | پیدا کردن Matchها                      |
| `matchAll()`   | دریافت تمام Matchها همراه اطلاعات کامل |
| `replace()`    | جایگزینی متن                           |
| `replaceAll()` | جایگزینی همه موارد                     |
| `search()`     | پیدا کردن موقعیت اولین Match           |
| `split()`      | تقسیم رشته بر اساس Regex               |

---

# جمع‌بندی بخش ۳

در این بخش با مهم‌ترین متدهای String که از Regular Expression پشتیبانی می‌کنند آشنا شدیم.

مفاهیم یادگرفته‌شده:

* استفاده از `match()` برای پیدا کردن Matchها
* استفاده از `matchAll()` برای دریافت اطلاعات کامل تمام Matchها
* جایگزینی متن با `replace()`
* جایگزینی همه موارد با `replaceAll()`
* پیدا کردن محل اولین Match با `search()`
* تقسیم رشته‌ها با `split()`

در بخش بعدی از فصل RegExp، این مفاهیم را در پروژه‌های واقعی Node.js به کار خواهیم گرفت و الگوهای کاربردی برای اعتبارسنجی ایمیل، شماره تلفن، رمز عبور، URL، IP و پردازش فایل‌های Log را پیاده‌سازی خواهیم کرد.
