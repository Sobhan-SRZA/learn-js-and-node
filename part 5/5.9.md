# مقدمه فصل

در برنامه‌نویسی همیشه با داده‌های متنی سروکار داریم.

نام کاربران، ایمیل‌ها، شماره تلفن‌ها، رمزهای عبور، آدرس‌ها، فایل‌ها، لاگ‌های سرور و بسیاری از اطلاعات دیگر همگی به شکل متن ذخیره می‌شوند.

اما گاهی نیاز داریم روی این متن‌ها عملیات خاصی انجام دهیم:

* پیدا کردن یک الگوی خاص در متن
* بررسی معتبر بودن اطلاعات ورودی
* استخراج بخش‌هایی از یک متن
* جایگزین کردن قسمت‌هایی از متن
* حذف کاراکترهای اضافی
* جستجوی پیشرفته در فایل‌ها و داده‌ها

برای انجام این کارها در جاوااسکریپت از **RegExp** یا **Regular Expression** استفاده می‌کنیم.

RegExp یک ابزار قدرتمند برای تعریف الگوهای متنی است.

برای مثال:

می‌توانیم الگویی بسازیم که بررسی کند:

* آیا یک ایمیل معتبر است؟
* آیا رمز عبور شرایط لازم را دارد؟
* آیا شماره تلفن فرمت درستی دارد؟
* آیا یک متن شامل کلمه خاصی است؟
* تمام لینک‌های موجود در یک متن را پیدا کند.
* تمام اعداد داخل یک فایل را استخراج کند.

در Node.js نیز RegExp کاربرد بسیار زیادی دارد.

موارد استفاده در پروژه‌های واقعی:

* اعتبارسنجی اطلاعات کاربران
* پاک‌سازی داده‌ها (Data Cleaning)
* پردازش فایل‌های متنی
* تحلیل لاگ‌های سرور
* ساخت Middlewareهای اعتبارسنجی
* فیلتر کردن محتوا
* پردازش ورودی‌های API

در این فصل از پایه‌ترین مفاهیم RegExp شروع می‌کنیم و قدم‌به‌قدم به کاربردهای حرفه‌ای آن در پروژه‌های Node.js می‌رسیم.

# بخش ۱ - آشنایی با RegExp و مفاهیم پایه

## RegExp چیست؟

`RegExp` کوتاه‌شده‌ی عبارت:

```
Regular Expression
```

است.

Regular Expression یک روش برای تعریف الگوهای متنی است.

به جای اینکه فقط دنبال یک متن مشخص بگردیم، می‌توانیم یک قانون تعریف کنیم.

مثلاً:

به جای اینکه بگوییم:

```
دنبال کلمه Ali بگرد
```

می‌توانیم بگوییم:

```
هر متنی که با حرف A شروع می‌شود و بعد از آن سه حرف دارد را پیدا کن
```

این قدرت اصلی Regex است.

---

## مثال ساده

فرض کنید یک متن داریم:

```javascript
const text = "Hello Node.js";
```

می‌خواهیم بررسی کنیم آیا کلمه Node در متن وجود دارد یا نه.

بدون Regex:

```javascript
console.log(text.includes("Node"));
```

خروجی:

```text
true
```

اما با Regex:

```javascript
const regex = /Node/;

console.log(regex.test(text));
```

خروجی:

```text
true
```

# چرا از RegExp استفاده می‌کنیم؟

روش‌های ساده مانند:

* includes()

برای جستجوهای ساده مناسب هستند.

* چند حالت مختلف را بررسی کنیم.
* الگوی خاصی پیدا کنیم.
* داده استخراج کنیم.
* Validation انجام دهیم.

Regex انتخاب مناسب‌تری است.

* پیدا کردن کلمات با ساختار مشخص

برای انجام این کارها باید با اجزای اصلی ساخت Regex آشنا شویم:

* Character Classes
* Quantifiers
* Groups
* Alternation
* Matching Rules

در این بخش قدم‌به‌قدم این مفاهیم را یاد می‌گیریم.

# ۳۰.۸ - Character Classes

## مفهوم Character Class

Character Class یکی از مهم‌ترین بخش‌های Regex است.

با استفاده از Character Class مشخص می‌کنیم که یک کاراکتر باید از چه مجموعه‌ای انتخاب شود.

برای ساخت Character Class از براکت استفاده می‌کنیم:

```regex
[]
```

هر چیزی که داخل این براکت قرار بگیرد یعنی:

«یکی از این کاراکترها را پیدا کن.»

---

## مثال ساده

فرض کنید می‌خواهیم بررسی کنیم متن شامل یکی از حروف زیر باشد:

```regex
[abc]
```

این Regex یعنی:

* حرف a
* یا حرف b
* یا حرف c

---

مثال:

```javascript
const regex = /[abc]/;

console.log(regex.test("apple"));
```

خروجی:

```text
true
```

چون کلمه `apple` شامل حرف `a` است.

---

مثال دیگر:

```javascript
const regex = /[abc]/;

console.log(regex.test("dog"));
```

خروجی:

```text
false
```

چون هیچ‌کدام از حروف:

```text
a
b
c
```

در متن وجود ندارند.

# چند کاراکتر پشت سر هم

# ۳۰.۹ - Negated Character Classes

## مفهوم مخالف کردن کلاس‌ها

گاهی به جای اینکه بگوییم:

«این کاراکترها مجاز هستند»

می‌خواهیم بگوییم:

«همه چیز به جز این کاراکترها مجاز هستند.»

برای این کار از `^` داخل براکت استفاده می‌کنیم.

ساختار:

```regex
[^...]
```

---

## مثال

```regex
[^0-9]
```

یعنی:

هر چیزی به جز عدد.

---

مثال:

```javascript
const regex = /[^0-9]/;

console.log(regex.test("123"));
```

خروجی:

```text
false
```

چون همه کاراکترها عدد هستند.

---

اما:

```javascript
console.log(regex.test("123a"));
```

خروجی:

```text
true
```

چون حرف `a` وجود دارد.

---

# تفاوت `[0-9]` و `[^0-9]`

| Regex    | معنی              |
| -------- | ----------------- |
| `[0-9]`  | فقط عدد           |
| `[^0-9]` | هر چیزی به جز عدد |

---

# مثال کاربردی

بررسی اینکه متن شامل کاراکتر غیرمجاز است یا نه:

```javascript
const regex = /[^a-zA-Z0-9]/;

console.log(regex.test("Ali123"));
```

خروجی:

```text
false
```

---

اما:

```javascript
console.log(regex.test("Ali@123"));
```

خروجی:

```text
true
```

---

const phone = "0912-123-4567";
