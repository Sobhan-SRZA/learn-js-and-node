# فصل ۲۳ - متدهای Array

آرایه‌ها (Array) یکی از مهم‌ترین ساختمان داده‌ها در JavaScript هستند. تا اینجا یاد گرفتید چگونه آرایه ایجاد کنید، به عناصر آن دسترسی داشته باشید، داده‌ای را اضافه یا حذف کنید و روی عناصر پیمایش انجام دهید.

اما قدرت واقعی آرایه‌ها زمانی مشخص می‌شود که از **متدهای داخلی (Array Methods)** استفاده کنید.

متدهای Array مجموعه‌ای از توابع آماده هستند که انجام بسیاری از عملیات متداول روی آرایه‌ها را تنها با یک خط کد ممکن می‌کنند؛ از فیلتر کردن داده‌ها گرفته تا تبدیل، مرتب‌سازی، جستجو، ترکیب، تجزیه و پردازش اطلاعات.

تقریباً تمام پروژه‌های Node.js از این متدها استفاده می‌کنند. اگر قصد دارید Backend Developer شوید، باید این متدها را به خوبی درک کنید؛ زیرا در پردازش داده‌های دریافتی از دیتابیس، فایل‌ها، APIها و ورودی کاربران دائماً با آن‌ها سروکار خواهید داشت.

در این فصل علاوه بر یادگیری نحوه استفاده از هر متد، با تفاوت آن‌ها، کاربردهای واقعی، اشتباهات رایج، نکات حرفه‌ای و پروژه‌های عملی نیز آشنا خواهید شد.

# بخش ۱

# پردازش داده‌ها با متدهای map، filter، reduce، find، some و every

این شش متد، پرکاربردترین متدهای Array در JavaScript هستند.

تقریباً در تمام پروژه‌های واقعی Node.js، هنگام کار با داده‌های دریافتی از پایگاه داده، فایل‌ها، APIها یا اطلاعات کاربران از این متدها استفاده می‌شود.

این متدها ویژگی‌های مشترکی دارند:

* روی تمام یا بخشی از عناصر آرایه عملیات انجام می‌دهند.
* از یک تابع (Callback Function) استفاده می‌کنند.
* باعث خواناتر شدن کد می‌شوند.
* در بسیاری از مواقع جایگزین حلقه‌های `for` و `while` هستند.

قبل از شروع، یک آرایه نمونه برای تمام مثال‌های این بخش در نظر می‌گیریم.

```javascript
const users = [
    {
        id: 1,
        name: "Ali",
        age: 21,
        active: true
    },
    {
        id: 2,
        name: "Sara",
        age: 17,
        active: false
    },
    {
        id: 3,
        name: "Reza",
        age: 30,
        active: true
    },
    {
        id: 4,
        name: "Maryam",
        age: 25,
        active: false
    }
];
```

در ادامه تمام متدها را با همین آرایه بررسی خواهیم کرد.

# متد map()

## map چیست؟

متد `map()` یکی از مهم‌ترین متدهای Array است.

وظیفه آن تبدیل عناصر یک آرایه به آرایه‌ای جدید است.

به بیان ساده:

هر عنصر وارد تابع می‌شود، تغییر می‌کند و مقدار جدید در آرایه خروجی قرار می‌گیرد.

بنابراین:

* آرایه اصلی تغییر نمی‌کند.
* همیشه یک آرایه جدید تولید می‌شود.
* تعداد عناصر خروجی دقیقاً برابر تعداد عناصر ورودی است.

---

## ساختار کلی

```javascript
array.map((element) => {
    return newValue;
});
```

---

## مثال اول

می‌خواهیم تمام اعداد را دو برابر کنیم.

```javascript
const numbers = [1, 2, 3, 4];

const result = numbers.map(number => number * 2);

console.log(result);
```

خروجی

```text
[2, 4, 6, 8]
```

---

آرایه اصلی همچنان بدون تغییر باقی مانده است.

```javascript
console.log(numbers);
```

خروجی

```text
[1, 2, 3, 4]
```

---

## مثال دوم

استخراج نام کاربران

```javascript
const names = users.map(user => user.name);

console.log(names);
```

خروجی

```text
[
    "Ali",
    "Sara",
    "Reza",
    "Maryam"
]
```

---

## مثال سوم

تولید آرایه‌ای جدید

```javascript
const result = users.map(user => {
    return {
        username: user.name,
        isActive: user.active
    };
});

console.log(result);
```

خروجی

```javascript
[
    {
        username: "Ali",
        isActive: true
    },
    {
        username: "Sara",
        isActive: false
    },
    {
        username: "Reza",
        isActive: true
    },
    {
        username: "Maryam",
        isActive: false
    }
]
```

---

## پارامترهای Callback

```javascript
array.map((element, index, array) => {})
```

پارامتر اول

```javascript
element
```

عنصر فعلی

پارامتر دوم

```javascript
index
```

شماره عنصر

پارامتر سوم

```javascript
array
```

خود آرایه

---

مثال

```javascript
const numbers = [10, 20, 30];

numbers.map((value, index) => {
    console.log(index, value);
});
```

خروجی

```text
0 10
1 20
2 30
```

---

## چه زمانی از map استفاده کنیم؟

زمانی که بخواهیم:

* داده‌ها را تبدیل کنیم.
* ساختار جدیدی ایجاد کنیم.
* فقط بخشی از اطلاعات را استخراج کنیم.
* روی همه عناصر تغییر مشابهی اعمال کنیم.

---

## چه زمانی از map استفاده نکنیم؟

اگر هدف شما فقط پیمایش روی آرایه است و خروجی جدیدی نیاز ندارید.

اشتباه

```javascript
numbers.map(number => {
    console.log(number);
});
```

در این حالت بهتر است از

```javascript
forEach()
```

استفاده شود.

# متد filter()

## filter چیست؟

متد `filter()` برای انتخاب تعدادی از عناصر آرایه استفاده می‌شود.

برخلاف `map()` که تعداد عناصر را حفظ می‌کند، `filter()` ممکن است تعداد عناصر را کمتر کند.

هر عنصر بررسی می‌شود.

اگر نتیجه Callback برابر `true` باشد، عنصر در خروجی قرار می‌گیرد.

اگر `false` باشد، حذف می‌شود.

---

## ساختار

```javascript
array.filter((element) => {
    return condition;
});
```

---

## مثال اول

افراد بزرگسال

```javascript
const adults = users.filter(user => user.age >= 18);

console.log(adults);
```

---

## مثال دوم

کاربران فعال

```javascript
const activeUsers = users.filter(user => user.active);

console.log(activeUsers);
```

---

## مثال سوم

اعداد زوج

```javascript
const numbers = [1,2,3,4,5,6];

const even = numbers.filter(number => number % 2 === 0);

console.log(even);
```

خروجی

```text
[2,4,6]
```

---

## map یا filter؟

اگر می‌خواهید

تعداد عناصر حفظ شود

از

```javascript
map()
```

اگر می‌خواهید

برخی عناصر حذف شوند

از

```javascript
filter()
```

استفاده کنید.

## find چیست؟

متد `find()` اولین عنصری را برمی‌گرداند که شرط مشخص‌شده را داشته باشد.

اگر هیچ عنصری پیدا نشود، مقدار

```javascript
undefined
```

برگردانده می‌شود.

---

## مثال

```javascript
const user = users.find(user => user.id === 3);

console.log(user);
```

---

## مثال دوم

```javascript
const user = users.find(user => user.name === "Sara");

console.log(user);
```

---

## تفاوت find و filter

```javascript
find()
```

اولین عنصر را برمی‌گرداند.

```javascript
filter()
```

تمام عناصر مطابق شرط را برمی‌گرداند.

# متد some()

## some چیست؟

بررسی می‌کند که

آیا حداقل یک عنصر شرط را دارد یا خیر.

خروجی همیشه Boolean است.

---

## مثال

```javascript
const result = users.some(user => user.age < 18);

console.log(result);
```

خروجی

```text
true
```

---

مثال دوم

```javascript
const result = users.some(user => user.active);

console.log(result);
```

---

# متد every()

## every چیست؟

بررسی می‌کند که

آیا تمام عناصر شرط را دارند یا خیر.

---

## مثال

```javascript
const result = users.every(user => user.age >= 18);

console.log(result);
```

خروجی

```text
false
```

---

مثال دوم

```javascript
const numbers = [2,4,6,8];

console.log(
    numbers.every(number => number % 2 === 0)
);
```

خروجی

```text
true
```

---

## تفاوت some و every

| متد   | نتیجه                           |
| ----- | ------------------------------- |
| some  | حداقل یک عنصر شرط را داشته باشد |
| every | تمام عناصر شرط را داشته باشند   |

# متد reduce()

## reduce چیست؟

`reduce()` یکی از قدرتمندترین متدهای Array است.

از این متد برای تبدیل کل آرایه به **یک مقدار نهایی** استفاده می‌شود.

این مقدار می‌تواند هر نوع داده‌ای باشد:

* Number
* String
* Boolean
* Object
* Array
* Map
* Set

به همین دلیل، `reduce()` کاربردهای بسیار گسترده‌ای دارد؛ از جمع کردن اعداد گرفته تا ساخت آبجکت، گروه‌بندی داده‌ها، شمارش عناصر و بسیاری از عملیات پیچیده.

---

## ساختار کلی

```javascript
array.reduce((accumulator, currentValue) => {
    return accumulator;
}, initialValue);
```

پارامترهای Callback:

* `accumulator` → مقدار تجمع‌یافته تا این مرحله
* `currentValue` → عنصر فعلی آرایه

پارامتر دوم متد (`initialValue`) مقدار اولیه `accumulator` است.

---

## مثال اول

جمع تمام اعداد

```javascript
const numbers = [10, 20, 30, 40];

const sum = numbers.reduce((total, number) => {
    return total + number;
}, 0);

console.log(sum);
```

خروجی

```text
100
```

در این مثال:

* مقدار اولیه `total` برابر `0` است.
* در هر مرحله، عدد فعلی به مجموع اضافه می‌شود.
* در پایان، مجموع کل عناصر برگردانده می‌شود.

---

## مراحل اجرای reduce

برای آرایه زیر:

```javascript
[10, 20, 30]
```

کد:

```javascript
const result = [10, 20, 30].reduce((total, number) => {
    return total + number;
}, 0);
```

مراحل اجرا:

| مرحله | total | number | مقدار بازگشتی |
| ----: | ----: | -----: | ------------: |
|     1 |     0 |     10 |            10 |
|     2 |    10 |     20 |            30 |
|     3 |    30 |     30 |            60 |

در پایان:

```text
60
```

---

## مثال دوم

محاسبه مجموع سن کاربران

```javascript
const totalAge = users.reduce((sum, user) => {
    return sum + user.age;
}, 0);

console.log(totalAge);
```

---

## مثال سوم

ساخت آرایه‌ای از نام کاربران

```javascript
const names = users.reduce((result, user) => {
    result.push(user.name);
    return result;
}, []);

console.log(names);
```

خروجی

```text
["Ali", "Sara", "Reza", "Maryam"]
```

اگرچه این مثال با `map()` نیز قابل انجام است، اما هدف آن آشنایی با انعطاف‌پذیری `reduce()` است.

---

## مثال چهارم

شمارش کاربران فعال

```javascript
const activeCount = users.reduce((count, user) => {
    return user.active ? count + 1 : count;
}, 0);

console.log(activeCount);
```

خروجی

```text
2
```

---

## چه زمانی از reduce استفاده کنیم؟

از `reduce()` زمانی استفاده کنید که قرار است کل آرایه به **یک نتیجه نهایی** تبدیل شود؛ مانند:

* محاسبه مجموع یا میانگین
* شمارش عناصر
* گروه‌بندی داده‌ها
* ساخت Object
* ساخت Array سفارشی
* تبدیل داده‌ها به ساختار جدید

اگر تنها قصد تبدیل هر عنصر یا فیلتر کردن آن را دارید، معمولاً `map()` یا `filter()` انتخاب مناسب‌تری هستند.

# بخش ۲

# مرتب‌سازی، برش و ترکیب آرایه‌ها

در بخش قبل با متدهایی آشنا شدید که برای **پردازش داده‌ها** استفاده می‌شوند؛ مانند `map`، `filter` و `reduce`.

در این بخش یاد می‌گیریم چگونه آرایه‌ها را:

* مرتب کنیم.
* بخشی از آن‌ها را جدا کنیم.
* عناصر جدید اضافه یا حذف کنیم.
* چند آرایه را با هم ترکیب کنیم.
* وجود یک مقدار را بررسی کنیم.
* موقعیت یک عنصر را پیدا کنیم.

این متدها تقریباً در تمام پروژه‌های واقعی استفاده می‌شوند و شناخت تفاوت آن‌ها اهمیت زیادی دارد.

در این بخش متدهای زیر را بررسی می‌کنیم:

* sort()
* splice()
* slice()
* concat()
* includes()
* indexOf()

# متد sort()

## sort چیست؟

متد `sort()` برای مرتب کردن عناصر یک آرایه استفاده می‌شود.

برخلاف بسیاری از متدهای دیگر، `sort()` **آرایه اصلی را تغییر می‌دهد** و مقدار بازگشتی آن نیز همان آرایه مرتب‌شده است.

به همین دلیل هنگام استفاده از این متد باید دقت کنید که اگر به آرایه اولیه نیاز دارید، ابتدا از آن کپی بگیرید.

---

## ساختار کلی

```javascript
array.sort();
```

یا

```javascript
array.sort((a, b) => {
    return a - b;
});
```

---

## مرتب‌سازی رشته‌ها

```javascript
const fruits = [
    "Orange",
    "Banana",
    "Apple",
    "Kiwi"
];

fruits.sort();

console.log(fruits);
```

خروجی

```text
[
    "Apple",
    "Banana",
    "Kiwi",
    "Orange"
]
```

---

## مرتب‌سازی اعداد (اشتباه رایج)

```javascript
const numbers = [5, 100, 8, 20];

numbers.sort();

console.log(numbers);
```

خروجی

```text
[100, 20, 5, 8]
```

این نتیجه برای بسیاری از افراد عجیب است.

دلیل آن این است که در حالت پیش‌فرض، JavaScript اعداد را به رشته تبدیل کرده و بر اساس ترتیب حروف مرتب می‌کند.

---

## مرتب‌سازی صحیح اعداد

```javascript
const numbers = [5, 100, 8, 20];

numbers.sort((a, b) => a - b);

console.log(numbers);
```

خروجی

```text
[5, 8, 20, 100]
```

---

## مرتب‌سازی نزولی

```javascript
const numbers = [5, 100, 8, 20];

numbers.sort((a, b) => b - a);

console.log(numbers);
```

خروجی

```text
[100, 20, 8, 5]
```

---

## مرتب‌سازی آبجکت‌ها

```javascript
const users = [
    { name: "Ali", age: 21 },
    { name: "Sara", age: 17 },
    { name: "Reza", age: 30 }
];

users.sort((a, b) => a.age - b.age);

console.log(users);
```

خروجی

```javascript
[
    { name: "Sara", age: 17 },
    { name: "Ali", age: 21 },
    { name: "Reza", age: 30 }
]
```

---

## مرتب‌سازی بر اساس رشته

```javascript
users.sort((a, b) => {
    return a.name.localeCompare(b.name);
});
```

---

## جلوگیری از تغییر آرایه اصلی

```javascript
const sorted = [...numbers].sort((a, b) => a - b);
```

یا

```javascript
const sorted = numbers.slice().sort((a, b) => a - b);
```

در این حالت، آرایه اصلی بدون تغییر باقی می‌ماند.

# متد splice()

## splice چیست؟

`splice()` یکی از قدرتمندترین متدهای Array است.

از این متد برای موارد زیر استفاده می‌شود:

* حذف عناصر
* اضافه کردن عناصر
* جایگزین کردن عناصر

برخلاف بسیاری از متدها، `splice()` مستقیماً آرایه اصلی را تغییر می‌دهد.

---

## ساختار

```javascript
array.splice(start, deleteCount);
```

یا

```javascript
array.splice(start, deleteCount, item1, item2, ...);
```

پارامترها

* `start` → محل شروع
* `deleteCount` → تعداد عناصر حذف‌شده
* `item` → عناصر جدید

---

## حذف عناصر

```javascript
const numbers = [10,20,30,40,50];

numbers.splice(2,1);

console.log(numbers);
```

خروجی

```text
[10,20,40,50]
```

---

## حذف چند عنصر

```javascript
const numbers = [10,20,30,40,50];

numbers.splice(1,3);

console.log(numbers);
```

خروجی

```text
[10,50]
```

---

## افزودن عنصر

```javascript
const numbers = [10,20,30];

numbers.splice(1,0,15);

console.log(numbers);
```

خروجی

```text
[10,15,20,30]
```

---

## جایگزین کردن

```javascript
const numbers = [10,20,30];

numbers.splice(1,1,200);

console.log(numbers);
```

خروجی

```text
[10,200,30]
```

---

## مقدار بازگشتی splice

```javascript
const numbers = [10,20,30,40];

const removed = numbers.splice(1,2);

console.log(removed);
```

خروجی

```text
[20,30]
```

متد `slice()` بخشی از آرایه را جدا می‌کند و در قالب یک آرایه جدید برمی‌گرداند.

این متد هیچ تغییری در آرایه اصلی ایجاد نمی‌کند.

## ساختار


نکته

پارامتر `end` در خروجی قرار نمی‌گیرد.

## مثال

```javascript

```

```text

```

## گرفتن کپی از کل آرایه

```javascript
const copy = numbers.slice();
```


# متد flat()

## flat چیست؟

گاهی اوقات داخل یک آرایه، آرایه‌های دیگری نیز قرار دارند.

به چنین آرایه‌هایی **Nested Array** یا آرایه تو در تو گفته می‌شود.

متد `flat()` برای باز کردن این آرایه‌ها و تبدیل آن‌ها به یک آرایه ساده استفاده می‌شود.

این متد آرایه اصلی را تغییر نمی‌دهد و همیشه یک آرایه جدید برمی‌گرداند.

---

## ساختار کلی

```javascript id="g8o31v"
array.flat(depth);
```

پارامتر `depth` مشخص می‌کند چند سطح از آرایه باز شود.

اگر این مقدار نوشته نشود، مقدار پیش‌فرض برابر `1` است.

---

## مثال اول

```javascript id="m2v61f"
const numbers = [
    1,
    2,
    [3, 4],
    5
];

const result = numbers.flat();

console.log(result);
```

خروجی

```text id="ew2c0j"
[1,2,3,4,5]
```

---

## مثال دوم

```javascript id="y6vz72"
const numbers = [
    1,
    [2,[3,[4]]]
];

console.log(numbers.flat());
```

خروجی

```text id="g4l9eo"
[1,2,[3,[4]]]
```

فقط یک سطح باز شده است.

---

## باز کردن دو سطح

```javascript id="l6n9y2"
console.log(
    numbers.flat(2)
);
```

خروجی

```text id="xlzk5z"
[1,2,3,[4]]
```

---

## باز کردن تمام سطوح

```javascript id="jprpfe"
console.log(
    numbers.flat(Infinity)
);
```

خروجی

```text id="r2rj0m"
[1,2,3,4]
```

---

## کاربرد واقعی

فرض کنید از یک API اطلاعات زیر را دریافت کرده‌ایم.

```javascript id="k9u3g7"
const tags = [

    ["Backend"],
    ["API", "REST"]
];
```

# اشتباه اول

## استفاده از map به جای forEach

اشتباه

```javascript
const numbers = [1,2,3];

numbers.map(number => {
    console.log(number);
});
```

در این مثال خروجی `map()` اصلاً استفاده نشده است.

هدف `map()` تولید یک آرایه جدید است.

اگر فقط می‌خواهید روی عناصر پیمایش انجام دهید از `forEach()` استفاده کنید.

درست

```javascript
numbers.forEach(number => {
```

هدف از این پروژه‌ها، تمرین استفاده هم‌زمان از چندین متد و آشنایی با سناریوهایی است که در پروژه‌های واقعی Node.js با آن‌ها روبه‌رو خواهید شد.

# مینی‌پروژه ۱

## سیستم مدیریت کاربران

آرایه‌ای از کاربران در اختیار دارید.

```javascript
const users = [
```

* میانگین سن کاربران را محاسبه کند.
* کاربران را بر اساس سن مرتب کند.
* بررسی کند آیا همه کاربران فعال هستند یا خیر.


برنامه‌ای بنویسید که:

* محصولات بالاتر از ۱۰۰ را پیدا کند.
* مجموع قیمت تمام محصولات را محاسبه کند.
* ارزان‌ترین و گران‌ترین محصول را پیدا کند.
* نام محصولات را به ترتیب حروف الفبا نمایش دهد.

# بخش ۷

# جمع‌بندی فصل

در این فصل با مهم‌ترین متدهای `Array` در JavaScript آشنا شدید؛ متدهایی که تقریباً در تمام پروژه‌های Node.js، از پردازش داده‌های API گرفته تا کار با پایگاه داده، فایل‌ها و اطلاعات کاربران استفاده می‌شوند.

در طول این فصل یاد گرفتید چگونه:

* داده‌ها را با `map()` تبدیل کنید.
* عناصر موردنیاز را با `filter()` انتخاب کنید.
* یک مقدار نهایی با `reduce()` محاسبه کنید.
* اولین نتیجه را با `find()` پیدا کنید.
* وجود یک شرط را با `some()` بررسی کنید.
* بررسی کنید آیا همه عناصر شرط مشخصی را دارند یا خیر با `every()`.
* آرایه‌ها را با `sort()` مرتب کنید.
* عناصر را با `splice()` حذف، اضافه یا جایگزین کنید.
* بدون تغییر آرایه اصلی با `slice()` از آن کپی بگیرید.
* چند آرایه را با `concat()` ترکیب کنید.
* وجود یک مقدار را با `includes()` بررسی کنید.
* اندیس یک عنصر را با `indexOf()` پیدا کنید.
* آرایه‌های تو در تو را با `flat()` ساده کنید.
* عملیات `map()` و `flat()` را با `flatMap()` ترکیب کنید.
* عناصر آرایه را با `join()` به یک رشته تبدیل کنید.
* ترتیب عناصر را با `reverse()` معکوس کنید.
* همه یا بخشی از آرایه را با `fill()` مقداردهی کنید.
* با `at()` از اندیس‌های منفی استفاده کنید.
* به کمک `entries()`، `keys()` و `values()` روی آرایه‌ها به شکل حرفه‌ای پیمایش انجام دهید.

اکنون ابزارهای لازم برای پردازش و مدیریت داده‌ها در آرایه‌ها را در اختیار دارید. در فصل‌های بعدی از این متدها به‌صورت مداوم در پروژه‌های واقعی، کار با فایل‌ها، پایگاه داده، APIها و توسعه برنامه‌های Node.js استفاده خواهید کرد؛ بنابراین تسلط بر آن‌ها یکی از مهم‌ترین مهارت‌های هر توسعه‌دهنده JavaScript و Node.js محسوب می‌شود.
