# فصل ۲۶

# Set

## مقدمه

تا اینجا با **Array** و **Object** آشنا شدید و یاد گرفتید چگونه مجموعه‌ای از داده‌ها را مدیریت کنید.

اما گاهی نیاز داریم مجموعه‌ای از داده‌ها را نگهداری کنیم که **هیچ مقدار تکراری** در آن وجود نداشته باشد.

برای مثال:

* لیست کاربران آنلاین
* شناسه کاربران
* تگ‌های یک مقاله
* دسته‌بندی محصولات
* لیست مجوزها (Permissions)
* نقش‌های کاربران (Roles)

اگر از Array استفاده کنیم، باید خودمان قبل از اضافه کردن هر مقدار بررسی کنیم که قبلاً وجود نداشته باشد.

JavaScript ساختمان داده‌ای به نام **Set** را برای حل این مشکل ارائه کرده است.

Set مجموعه‌ای از مقادیر **Unique** (غیرتکراری) است.

اگر یک مقدار چند بار به Set اضافه شود، فقط یک نسخه از آن نگهداری می‌شود.

در پروژه‌های واقعی Node.js، Set یکی از بهترین ابزارها برای حذف داده‌های تکراری، مدیریت شناسه‌ها، کش کردن اطلاعات، بررسی عضویت و افزایش سرعت جستجو است.

در این فصل تمام قابلیت‌های Set را از پایه تا کاربردهای واقعی یاد خواهید گرفت.

# بخش ۱

# آشنایی با Set

تا قبل از معرفی Set، برای نگهداری چند مقدار معمولاً از Array استفاده می‌کردیم.

```javascript id="d8r4mk"
const numbers = [10, 20, 30];
```

اما Array یک مشکل دارد.

می‌تواند مقادیر تکراری را نگهداری کند.

```javascript id="w7m1tx"
const numbers = [10, 20, 10, 30, 20];

console.log(numbers);
```

خروجی

```text id="g3q8pa"
[10, 20, 10, 30, 20]
```

گاهی وجود داده‌های تکراری باعث ایجاد مشکل در برنامه می‌شود.

برای مثال:

* لیست کاربران آنلاین
* شناسه محصولات
* تگ‌های یک مقاله
* ایمیل کاربران
* نقش‌های کاربر

در چنین شرایطی باید مطمئن باشیم هر مقدار فقط یک بار ذخیره شود.

اینجاست که **Set** وارد می‌شود.

---

# Set چیست؟

Set یک ساختمان داده (Data Structure) در JavaScript است که فقط **مقادیر یکتا (Unique Values)** را نگهداری می‌کند.

اگر یک مقدار چند بار به Set اضافه شود، فقط اولین مقدار ذخیره می‌شود.

---

# ایجاد Set

برای ساخت یک Set از کلاس `Set` استفاده می‌کنیم.

```javascript id="p4v9ka"
const numbers = new Set();
```

اکنون یک Set خالی ساخته شده است.

---

# نمایش Set

```javascript id="h6m2tw"

console.log(numbers);
```

خروجی


عدد داخل پرانتز تعداد اعضای Set را نشان می‌دهد.

# تفاوت Set و Array

| Array                    | Set                        |
| ------------------------ | -------------------------- |
| مقادیر تکراری مجاز هستند | مقادیر تکراری حذف می‌شوند   |
| دارای اندیس (Index) است  | اندیس ندارد                |
| دسترسی با شماره اندیس    | دسترسی با پیمایش           |
| مناسب نگهداری ترتیب      | مناسب نگهداری داده‌های یکتا |

# ویژگی‌های Set

یک Set دارای ویژگی‌های زیر است.

* فقط مقادیر یکتا را نگهداری می‌کند.
* ترتیب ورود اعضا حفظ می‌شود.
* اندیس ندارد.
* طول آن با `size` مشخص می‌شود.
* اعضا می‌توانند از هر نوع داده‌ای باشند.

---

# مقایسه مقدارهای اولیه و Objectها

در مقدارهای اولیه (Primitive)، مقادیر تکراری حذف می‌شوند.

```javascript id="d3m5tv"
const set = new Set([
    10,
    10,
    10
]);

console.log(set.size);
```

خروجی

```text id="y6q8rk"
1
```

اما برای Objectها، هر Object یک مرجع (Reference) مستقل دارد.

```javascript id="f2v7mc"
const set = new Set();

set.add({
    name: "Ali"
});

set.add({
    name: "Ali"
});

console.log(set.size);
```

خروجی

```text id="r7m4qb"
2
```

با وجود اینکه محتوا یکسان است، این دو Object متفاوت محسوب می‌شوند.

---

# چه زمانی از Set استفاده کنیم؟

از Set استفاده کنید زمانی که:

* داده‌های تکراری نباید ذخیره شوند.
* سرعت بررسی وجود یک مقدار اهمیت دارد.
* قصد حذف مقادیر تکراری یک Array را دارید.
* می‌خواهید مجموعه‌ای از شناسه‌ها یا مقادیر یکتا را نگهداری کنید.
* با نقش‌ها، مجوزها یا تگ‌های یکتا کار می‌کنید.

---

# خلاصه

| ویژگی                     | Set        |
| ------------------------- | ---------- |
| حذف خودکار داده‌های تکراری | ✅          |
| ترتیب ورود اعضا           | ✅          |
| اندیس                     | ❌          |
| تعداد اعضا                | `size`     |
| افزودن عضو                | `add()`    |
| حذف عضو                   | `delete()` |
| بررسی وجود عضو            | `has()`    |
| حذف همه اعضا              | `clear()`  |

# بخش ۴

# عملیات روی Set

یکی از مهم‌ترین کاربردهای Set انجام عملیات مجموعه‌ها (Set Operations) است.

این عملیات در ریاضیات، پایگاه داده، الگوریتم‌ها و پروژه‌های واقعی بسیار استفاده می‌شوند.

* Union
* Intersection
* Difference
* Symmetric Difference
* Subset

# Symmetric Difference

## تفاضل متقارن

اعضایی که فقط در یکی از دو Set وجود دارند.

اعضای مشترک حذف می‌شوند.

---

### مثال

```javascript id="f8q1mc"

    1,
    2,
    3
]);

    3,
    4,
    5
]);

const symmetricDifference = new Set([

    ...[...set1].filter(
        value => !set2.has(value)
    ),

    ...[...set2].filter(
        value => !set1.has(value)
    )

]);

console.log(symmetricDifference);
```

خروجی

```text id="y6p4ra"
Set(4) {
    1,
    2,
    4,
    5
}
```

# کاربردهای واقعی Set Operations

این عملیات در پروژه‌های واقعی بسیار کاربرد دارند.

نمونه‌هایی از کاربردها:

* حذف کاربران تکراری
* بررسی مجوزهای کاربران
* مقایسه نقش‌های کاربران
* یافتن محصولات مشترک بین دو فروشگاه
* مقایسه تگ‌های دو مقاله
* تحلیل داده‌های آماری
* همگام‌سازی اطلاعات بین دو منبع داده
* مدیریت کش (Cache)
* سیستم پیشنهاد دوستان
* مدیریت لیست علاقه‌مندی‌ها

# جمع‌بندی بخش چهارم

در این بخش با مهم‌ترین عملیات روی Set آشنا شدید.

اکنون می‌توانید:

* دو Set را با هم ترکیب کنید (Union).
* اعضای مشترک دو Set را پیدا کنید (Intersection).
* اعضای متفاوت را استخراج کنید (Difference).
* تفاضل متقارن دو Set را به دست آورید (Symmetric Difference).
* زیرمجموعه یا ابرمجموعه بودن Setها را بررسی کنید.
* برابری دو Set را تشخیص دهید.
* از این عملیات در سناریوهای واقعی Node.js مانند مدیریت کاربران، نقش‌ها، مجوزها و داده‌های یکتا استفاده کنید.

# نکته ۲۰

## ساختمان داده مناسب را انتخاب کنید

قبل از شروع پیاده‌سازی، مشخص کنید چه نوع داده‌ای دارید.

| نیاز                          | ساختمان داده مناسب |
| ----------------------------- | ------------------ |
| لیست دارای تکرار              | Array              |
| لیست بدون تکرار               | Set                |
| داده‌های کلید و مقدار          | Object             |
| کلیدهای دلخواه با هر نوع داده | Map                |

انتخاب صحیح ساختمان داده باعث می‌شود کد ساده‌تر، سریع‌تر و قابل نگهداری‌تر باشد.

# خلاصه نکات حرفه‌ای

* از Set برای داده‌های یکتا استفاده کنید.
* برای حذف مقادیر تکراری از `new Set()` استفاده کنید.
* از `has()` برای بررسی وجود داده استفاده کنید.
* از `size` به جای `length` استفاده کنید.
* برای استفاده از `map()` و `filter()` ابتدا Set را به Array تبدیل کنید.
* از Method Chaining برای افزایش خوانایی کد استفاده کنید.
* هنگام کار با Objectها به Reference توجه داشته باشید.
* برای داده‌های کلید و مقدار از Map یا Object استفاده کنید.
* قبل از تبدیل به JSON، Set را به Array تبدیل کنید.
* از عملیات Union، Intersection و Difference برای حل مسائل واقعی استفاده کنید.
* برای مدیریت کاربران آنلاین، مجوزها، تگ‌ها و داده‌های یکتا از Set بهره بگیرید.

# پاسخ تمرین ۳۵

```javascript id="m9p4tb"
class UniqueCollection {

    constructor() {
        this.items = new Set();
    }

    add(value) {
        this.items.add(value);
    }

    remove(value) {
        this.items.delete(value);
    }

    has(value) {
        return this.items.has(value);
    }

    clear() {
        this.items.clear();
    }

    size() {
        return this.items.size;
    }

    values() {
        return [...this.items];
    }

}

const users =
    new UniqueCollection();

users.add("Ali");
users.add("Sara");
users.add("Ali");

console.log(
    users.values()
);

console.log(
    users.size()
);
```

توضیح

در این تمرین یک کلاس طراحی شده است که عملیات اصلی Set را در قالب متدهای ساده در اختیار سایر بخش‌های برنامه قرار می‌دهد. این الگو در پروژه‌های واقعی برای مخفی کردن جزئیات پیاده‌سازی و افزایش قابلیت نگهداری کد بسیار کاربردی است.
