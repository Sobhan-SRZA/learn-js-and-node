قبل از این فصل تقریباً تمام ابزارهای لازم برای نوشتن برنامه‌های ساده را یاد گرفته‌اید.

اکنون می‌توانید:

* متغیر تعریف کنید.
* شرط بنویسید.
* حلقه ایجاد کنید.
* تابع بنویسید.
* از Scope و Closure استفاده کنید.
* ورودی بگیرید و خروجی نمایش دهید.

اما هنوز یک مشکل بزرگ وجود دارد.

فرض کنید بخواهید اطلاعات ۱۰۰ کاربر را ذخیره کنید.

آیا باید ۱۰۰ متغیر مختلف تعریف کنید؟

```javascript
const user1 = "Ali";
const user2 = "Sara";
const user3 = "Reza";
...
```

قطعاً نه.

برای حل این مشکل، JavaScript ساختاری به نام **Array (آرایه)** را معرفی می‌کند.

Array یکی از پرکاربردترین ساختارهای داده در تمام زبان‌های برنامه‌نویسی است.

تقریباً هیچ پروژه‌ی واقعی Node.js وجود ندارد که در آن از Array استفاده نشود.

لیست کاربران، پیام‌ها، محصولات، سفارش‌ها، فایل‌ها، لاگ‌ها، نتایج دیتابیس، پاسخ APIها و تقریباً هر مجموعه‌ای از داده‌ها با Array مدیریت می‌شوند.

در این فصل با مفهوم Array آشنا می‌شوید، یاد می‌گیرید چگونه آرایه ایجاد کنید، به عناصر آن دسترسی داشته باشید، داده اضافه یا حذف کنید، عناصر را جستجو کنید و با رایج‌ترین عملیات روی آرایه‌ها کار کنید.

---

# فصل 22 - Array (آرایه)

Array یکی از مهم‌ترین انواع داده در JavaScript است.

به زبان ساده:

> Array مجموعه‌ای از چندین مقدار است که داخل یک متغیر ذخیره می‌شوند.

به جای اینکه ده‌ها متغیر جداگانه بسازیم، همه اطلاعات را داخل یک Array قرار می‌دهیم.

---

# چرا Array؟

بدون Array:

```javascript
const student1 = "Ali";
const student2 = "Sara";
const student3 = "Reza";
```

با Array:

```javascript
const students = ["Ali", "Sara", "Reza"];
```

کد بسیار کوتاه‌تر، خواناتر و مدیریت آن ساده‌تر است.

---

# ایجاد Array

### روش اول (رایج‌ترین)

```javascript
const fruits = ["Apple", "Banana", "Orange"];
```

---

### آرایه اعداد

```javascript
const numbers = [10, 20, 30, 40];
```

---

### آرایه Boolean

```javascript
const values = [true, false, true];
```

---

### آرایه ترکیبی

در JavaScript عناصر آرایه لازم نیست هم‌نوع باشند.

```javascript
const data = [
    "Sobhan",
    20,
    true,
    null
];
```

البته در پروژه‌های واقعی بهتر است عناصر یک آرایه از یک نوع باشند.

---

### آرایه خالی

```javascript
const users = [];
```

بعداً می‌توانیم اطلاعات را به آن اضافه کنیم.

---

### استفاده از Array Constructor

```javascript
const numbers = new Array(1, 2, 3);
```

این روش کمتر استفاده می‌شود.

معمولاً از `[]` استفاده می‌کنیم.

---

# دسترسی به عناصر

هر عنصر یک شماره دارد.

به این شماره:

```text
Index
```

گفته می‌شود.

---

اولین عنصر همیشه شماره صفر دارد.

```text
0
1
2
3
```

---

مثال:

```javascript
const colors = ["Red", "Blue", "Green"];

console.log(colors[0]);
```

خروجی:

```text
Red
```

---

عنصر دوم:

```javascript
console.log(colors[1]);
```

خروجی:

```text
Blue
```

---

عنصر سوم:

```javascript
console.log(colors[2]);
```

خروجی:

```text
Green
```

---

# اگر اندیس وجود نداشته باشد

```javascript
const fruits = ["Apple"];

console.log(fruits[10]);
```

خروجی:

```text
undefined
```

---

# تغییر مقدار

```javascript
const numbers = [10, 20, 30];

numbers[1] = 50;

console.log(numbers);
```

خروجی:

```text
[10, 50, 30]
```

---

# طول آرایه

هر آرایه ویژگی‌ای به نام `length` دارد.

```javascript
const names = ["Ali", "Sara", "Reza"];

console.log(names.length);
```

خروجی:

```text
3
```

---

آخرین عنصر:

```javascript
const names = ["Ali", "Sara", "Reza"];

console.log(names[names.length - 1]);
```

خروجی:

```text
Reza
```

---

# اضافه کردن عنصر

## push()

به انتهای آرایه اضافه می‌کند.

```javascript
const fruits = ["Apple"];

fruits.push("Banana");

console.log(fruits);
```

خروجی:

```text
["Apple", "Banana"]
```

---

چند عنصر:

```javascript
fruits.push("Orange", "Kiwi");
```

---

## unshift()

به ابتدای آرایه اضافه می‌کند.

```javascript
const numbers = [20, 30];

numbers.unshift(10);

console.log(numbers);
```

خروجی:

```text
[10, 20, 30]
```

---

# حذف عنصر

## pop()

آخرین عنصر را حذف می‌کند.

```javascript
const numbers = [10, 20, 30];

numbers.pop();

console.log(numbers);
```

خروجی:

```text
[10, 20]
```

---

مقدار حذف‌شده:

```javascript
const last = numbers.pop();
```

---

## shift()

اولین عنصر را حذف می‌کند.

```javascript
const numbers = [10, 20, 30];

numbers.shift();

console.log(numbers);
```

خروجی:

```text
[20, 30]
```

---

# جستجو

## includes()

بررسی می‌کند که مقدار وجود دارد یا خیر.

```javascript
const users = ["Ali", "Sara"];

console.log(users.includes("Sara"));
```

خروجی:

```text
true
```

---

اگر وجود نداشته باشد:

```javascript
console.log(users.includes("Reza"));
```

خروجی:

```text
false
```

---

## indexOf()

شماره عنصر را برمی‌گرداند.

```javascript
const fruits = ["Apple", "Banana", "Orange"];

console.log(fruits.indexOf("Banana"));
```

خروجی:

```text
1
```

---

اگر پیدا نشود:

```javascript
console.log(fruits.indexOf("Kiwi"));
```

خروجی:

```text
-1
```

# Array و Loop

یکی از مهم‌ترین کاربردهای Array استفاده همراه با حلقه‌ها است.

```javascript
const names = ["Ali", "Sara", "Reza"];

for (let i = 0; i < names.length; i++) {

    console.log(names[i]);

}
```

خروجی:

```text
Ali
Sara
Reza
```

---

استفاده از `for...of`

```javascript
const names = ["Ali", "Sara", "Reza"];

for (const name of names) {

    console.log(name);

}
```

این روش خواناتر است و در بسیاری از مواقع پیشنهاد می‌شود.

---

# آرایه‌های تو در تو

یک Array می‌تواند Array دیگری را نیز در خود نگه دارد.

```javascript
const matrix = [
    [1, 2],
    [3, 4]
];
```

دسترسی:

```javascript
console.log(matrix[0][1]);
```

خروجی:

```text
2
```

---

# Array از Reference Type است

```javascript
const first = ["A", "B"];

const second = first;

second.push("C");

console.log(first);
```

خروجی:

```text
["A", "B", "C"]
```

هر دو متغیر به یک آرایه در حافظه اشاره می‌کنند.

---

# کپی کردن آرایه

روش صحیح:

```javascript
const first = ["A", "B"];

const second = [...first];
```

اکنون دو آرایه مستقل داریم.

در پروژه‌های واقعی Node.js تقریباً همه‌جا از Array استفاده می‌شود.

نمونه‌ها:

* لیست کاربران
* پیام‌ها
* محصولات
* سفارش‌ها
* فایل‌ها
* لاگ‌ها
* پاسخ API
* نتایج دیتابیس
* صف پردازش
* Queue
* Cache

# اشتباهات رایج

### ❌ تصور اینکه شماره اولین عنصر ۱ است

اولین عنصر همیشه اندیس `0` دارد.

---

### ❌ دسترسی خارج از محدوده

```javascript
console.log(array[100]);
```

خروجی:

```text
undefined
```

---

### ❌ استفاده از `delete`

```javascript
delete numbers[1];
```

این کار عنصر را حذف نمی‌کند؛ فقط مقدار آن را `undefined` می‌کند و طول آرایه تغییر نمی‌کند.

---

### ❌ فراموش کردن اینکه Array یک Reference Type است

```javascript
const a = [1, 2];

const b = a;
```

تغییر `b` باعث تغییر `a` نیز می‌شود.

---

### ❌ استفاده از `indexOf()` بدون بررسی `-1`

اگر عنصر پیدا نشود، مقدار `-1` برمی‌گردد.

---

# نکات حرفه‌ای

* همیشه برای ایجاد آرایه از `[]` استفاده کنید.
* برای اضافه کردن عنصر از `push()` استفاده کنید.
* برای حذف عنصر از `pop()` استفاده کنید.
* برای بررسی وجود یک مقدار از `includes()` استفاده کنید.
* برای پیمایش ساده، `for...of` خواناتر از `for` است.
* در صورت نیاز به کپی آرایه از Spread Operator استفاده کنید.
* تا جای ممکن عناصر یک آرایه را هم‌نوع نگه دارید.
