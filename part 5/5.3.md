# فصل ۲۴ - String

رشته‌ها (String) یکی از پرکاربردترین انواع داده در JavaScript هستند. تقریباً تمام برنامه‌هایی که با Node.js توسعه می‌دهید، به نوعی با رشته‌ها سروکار دارند؛ از دریافت اطلاعات کاربران و پردازش فایل‌ها گرفته تا ساخت API، کار با پایگاه داده، تولید گزارش‌ها، مدیریت مسیر فایل‌ها و پردازش متن.

JavaScript مجموعه بزرگی از متدهای داخلی برای کار با رشته‌ها در اختیار شما قرار می‌دهد. این متدها انجام بسیاری از عملیات متداول مانند جستجو، استخراج، جایگزینی، تبدیل حروف، قالب‌بندی و پردازش متن را بسیار ساده می‌کنند.

در این فصل با مهم‌ترین متدهای `String` آشنا خواهید شد، تفاوت آن‌ها را یاد می‌گیرید، با کاربردهای واقعی هر متد آشنا می‌شوید و در پایان با تمرین‌ها و پروژه‌های عملی، نحوه استفاده از آن‌ها را در پروژه‌های Node.js تمرین خواهید کرد.

# بخش ۱

# آشنایی با String و متدهای پایه

رشته (String) یکی از انواع داده‌های اولیه (Primitive Data Types) در JavaScript است.

هر متنی که بین کوتیشن (`' '`)، دابل کوتیشن (`" "`) یا بک‌تیک (`` ` ` ``) قرار بگیرد، یک رشته محسوب می‌شود.

نمونه‌هایی از رشته:

```javascript id="81t4nm"
const firstName = "Ali";

const lastName = 'Ahmadi';

const message = `Hello Node.js`;
```

تمام داده‌های متنی که در برنامه دریافت یا تولید می‌شوند، معمولاً از نوع String هستند.

برای مثال:

* نام کاربران
* ایمیل
* شماره موبایل
* رمز عبور
* مسیر فایل
* آدرس URL
* محتوای فایل‌ها
* پاسخ‌های API
* متن پیام‌ها
* لاگ‌های سیستم

---

# Primitive String

در اکثر مواقع رشته‌ها به صورت Primitive ایجاد می‌شوند.

```javascript id="pr5vzb"
const language = "JavaScript";
```

بررسی نوع داده

```javascript id="1h2o6x"
console.log(typeof language);
```

خروجی

```text id="mjlwmq"
string
```

این روش رایج‌ترین و بهترین روش ایجاد رشته است.

---

# String Object

در JavaScript می‌توان با استفاده از سازنده `String` نیز رشته ایجاد کرد.

```javascript id="f6mhq5"

```

بررسی نوع داده

```javascript id="ns8e76"
console.log(typeof language);
```

خروجی

```text id="tmgbfr"
object
```

در این حالت، متغیر از نوع Object است، نه String.

# متد codePointAt()

این متد مقدار Unicode Code Point کاراکتر را برمی‌گرداند.

برای کاراکترهای معمولی، خروجی آن مشابه `charCodeAt()` است؛ اما برای کاراکترهایی که خارج از محدوده Basic Multilingual Plane قرار دارند (مانند بسیاری از Emojiها)، نتیجه دقیق‌تری ارائه می‌دهد.

---

## مثال

```javascript id="jlwm7b"
const text = "A";

console.log(text.codePointAt(0));
```

خروجی

```text id="jlwm5h"
65
```

---

## مثال با Emoji

```javascript id="jlwm3n"
const emoji = "🚀";

console.log(emoji.charCodeAt(0));

console.log(emoji.codePointAt(0));
```

نمونه خروجی

```text id="jlwm1m"
55357
128640
```

در این مثال مشاهده می‌کنید که `codePointAt()` مقدار واقعی Unicode کاراکتر را برمی‌گرداند، در حالی که `charCodeAt()` تنها اولین بخش از کد UTF-16 را بازمی‌گرداند.

# متد includes()

## includes چیست؟

متد `includes()` بررسی می‌کند که آیا یک رشته شامل مقدار مشخصی هست یا خیر.

خروجی این متد همیشه یک مقدار Boolean است.

* `true`
* `false`

این متد به بزرگی و کوچکی حروف (Case Sensitive) حساس است.

---

## ساختار

```javascript id="n8zs1h"
string.includes(searchString);
```

یا

```javascript id="v4o6sl"
string.includes(searchString, position);
```

---

## مثال اول

```javascript id="6uxy2m"
const text = "Welcome to Node.js";

console.log(
    text.includes("Node")
);
```

خروجی

```text id="5x3pqe"
true
```

---

## مثال دوم

```javascript id="m1nkp8"
console.log(
    text.includes("Express")
);
```

خروجی

```text id="7fp4ad"
false
```

---

## تعیین محل شروع جستجو

```javascript id="ux7nvl"
const text = "JavaScript Java";

console.log(
    text.includes("Java", 5)
);
```

خروجی

```text id="hrm4dw"
true
```

در این مثال جستجو از اندیس ۵ آغاز شده است.

---

## حساس بودن به حروف

```javascript id="w7h4nq"

console.log(
    text.includes("node")
);
```

خروجی

```text id="a6e0tz"

```

---

## جستجوی بدون حساسیت به حروف


# متد normalize()

## normalize چیست؟

گاهی دو رشته از نظر ظاهری یکسان هستند، اما در حافظه به شکل متفاوتی ذخیره شده‌اند.

متد `normalize()` این تفاوت‌ها را از بین می‌برد.

---

## ساختار

```javascript id="h6q3mv"
string.normalize();
```

---

## چرا normalize اهمیت دارد؟

برخی کاراکترهای Unicode را می‌توان به چند روش مختلف نمایش داد.

در ظاهر تفاوتی دیده نمی‌شود، اما JavaScript آن‌ها را متفاوت در نظر می‌گیرد.

---

## مثال

```javascript id="c8j2ak"
const first = "\u00E9";

const second = "\u0065\u0301";

console.log(first === second);
```

خروجی

```text id="y0x8re"
false
```

هر دو رشته حرف **é** را نمایش می‌دهند، اما نمایش داخلی آن‌ها متفاوت است.

---

## استفاده از normalize

```javascript id="l5m7tu"
const first = "\u00E9";

const second = "\u0065\u0301";

console.log(
    first.normalize() === second.normalize()
);
```

خروجی

```text id="p3v9ks"
true
```

---


* NFC
* NFD

در اکثر پروژه‌های Node.js استفاده از `NFC` کافی است.

# تبدیل بین String و Array

در بسیاری از برنامه‌های Node.js لازم است رشته‌ها را به آرایه تبدیل کنیم یا چند رشته را با یکدیگر ترکیب کنیم.

برای مثال:

* پردازش فایل‌های CSV
* دریافت لیست ایمیل‌ها
* تجزیه مسیر فایل‌ها
* پردازش URL
* جدا کردن کلمات یک جمله
* ترکیب متن‌های مختلف

JavaScript برای انجام این کارها متدهای زیر را در اختیار ما قرار داده است.

* `split()`
* `concat()`

---

# متد split()

## split چیست؟

متد `split()` یک رشته را بر اساس جداکننده (Separator) به چند بخش تقسیم می‌کند و خروجی آن یک آرایه (Array) است.

رشته اصلی تغییر نمی‌کند.

---

## ساختار

```javascript id="u3v1na"
string.split(separator);
```

یا

```javascript id="y5q7rm"
string.split(separator, limit);
```

---

# مثال اول

```javascript id="k8m4pd"
const text = "Node.js JavaScript MongoDB";

const result = text.split(" ");

console.log(result);
```

خروجی

```text id="b2t9fx"
    "Node.js",
    "JavaScript",
    "MongoDB"
]
```

در این مثال، رشته بر اساس فاصله (`Space`) به سه قسمت تقسیم شده است.

# متد concat()

## concat چیست؟

متد `concat()` دو یا چند رشته را به یکدیگر متصل می‌کند.

رشته اصلی تغییر نمی‌کند.

---

## ساختار

```javascript id="j4q8vn"
string.concat(value1);
```

یا

```javascript id="x2r5fk"
string.concat(value1, value2, ...);
```

---

# مثال اول

```javascript id="b9m6wd"

const lastName = "Ahmadi";

```

```text id="t7y4ps"
Ali Ahmadi
```

---

# اتصال چند رشته

```text id="k2x7fr"

```

# اتصال چند مقدار


# استفاده از عملگر +

```javascript id="u5m2qa"
const firstName = "Ali";

const lastName = "Ahmadi";

const fullName =
    firstName + " " + lastName;

```

```text id="m1p6tr"

```

# استفاده از Template Literal

در پروژه‌های مدرن Node.js معمولاً از Template Literal استفاده می‌شود.

```javascript id="r7d3wf"

const fullName =
    `${firstName} ${lastName}`;

console.log(fullName);
```

خروجی

```text id="g8n4cy"
Ali Ahmadi
```

# concat یا Template Literal؟

هر دو روش نتیجه یکسانی تولید می‌کنند، اما در پروژه‌های امروزی Template Literal خواناتر و انعطاف‌پذیرتر است.

نمونه:

```javascript id="y6q1pk"
const name = "Sara";
const age = 24;

const message =
    `${name} is ${age} years old.`;

console.log(message);
```

خروجی

```text id="p3k8mv"
Sara is 24 years old.
```

در پروژه‌های مدرن، برای اتصال رشته‌ها معمولاً از **Template Literal** استفاده می‌شود و `concat()` بیشتر برای آشنایی با امکانات استاندارد `String` یا در برخی کدهای قدیمی دیده می‌شود.

# جمع‌بندی بخش پنجم

در این بخش با متدهای تبدیل بین `String` و `Array` آشنا شدید.

اکنون می‌توانید:

* یک رشته را با `split()` به آرایه تبدیل کنید.
* رشته‌ها را بر اساس هر جداکننده دلخواه تقسیم کنید.
* از عبارت‌های منظم برای تقسیم رشته‌ها استفاده کنید.
* تعداد کلمات یک متن را محاسبه کنید.
* بخش‌های مختلف یک مسیر فایل یا URL را استخراج کنید.
* چند رشته را با `concat()` به یکدیگر متصل کنید.
* تفاوت `concat()`، عملگر `+` و **Template Literal** را تشخیص دهید.

در بخش بعدی با روش‌های پیمایش رشته‌ها، Iteratorها و متدهای `entries()`، `keys()` و `values()` آشنا خواهید شد.

# بخش ۶

# پیمایش رشته‌ها (String Iteration)

گاهی لازم است کاراکترهای یک رشته را به ترتیب پیمایش کنیم.

برای مثال:

* شمارش تعداد حروف
* پردازش متن
* اعتبارسنجی اطلاعات
* رمزنگاری
* ساخت Parser
* تحلیل فایل‌های متنی

در JavaScript، رشته‌ها **Iterable** هستند.

این یعنی می‌توان مانند آرایه‌ها روی آن‌ها پیمایش انجام داد.

در این بخش با موارد زیر آشنا می‌شویم.

* Iterator
* `entries()`
* `keys()`
* `values()`

---

# Iterable چیست؟

هر شیئی که بتوان روی عناصر آن به ترتیب حرکت کرد، یک **Iterable** است.

برخی از Iterableهای JavaScript

* String
* Array
* Map
* Set

به همین دلیل می‌توان از `for...of` روی رشته‌ها استفاده کرد.

---

# پیمایش رشته با for...of

ساده‌ترین روش پیمایش یک رشته استفاده از حلقه `for...of` است.

---

## مثال

```javascript id="w2h8km"
const text = "Node";

for (const character of text) {
    console.log(character);
}
```

خروجی

```text id="q4t6ja"
N
o
d
e
```

در هر بار اجرای حلقه، یک کاراکتر از رشته دریافت می‌شود.

---

# پیمایش با اندیس

گاهی علاوه بر مقدار، به شماره هر کاراکتر نیز نیاز داریم.

```javascript id="e7m3pc"
const text = "Node";

for (let i = 0; i < text.length; i++) {
    console.log(i, text[i]);
}
```

خروجی

```text id="r8y1fd"

1 o
2 d
3 e
```

هر Iterator دارای متد `next()` است.

در هر بار فراخوانی `next()` یک مقدار جدید برگردانده می‌شود.

# متد keys()

## keys چیست؟

متد `keys()` Iterator مربوط به تمام اندیس‌های رشته را برمی‌گرداند.

---

## مثال

```javascript id="y3q8nd"
const text = "Node";

for (const key of text.keys()) {
```

```javascript id="q3v8tn"
function analyzeText(text) {
    return {
        characters: text.length,
        words: text.trim().split(/\s+/).length,
        lines: text.split("\n").length,
        spaces: (text.match(/ /g) || []).length,
        firstCharacter: text.at(0),
        lastCharacter: text.at(-1),
        upperCase: text.toUpperCase(),
        lowerCase: text.toLowerCase(),
        hasNumber: /\d/.test(text),
        hasEmail: /\S+@\S+\.\S+/.test(text),
        startsWithSpace: text.startsWith(" "),
        endsWithSpace: text.endsWith(" ")
    };
}

console.log(
    analyzeText("Hello Node.js 123")
);
```

# جمع‌بندی بخش یازدهم

اگر توانستید بیشتر این تمرین‌ها را بدون مراجعه به پاسخ‌ها حل کنید، یعنی مفاهیم اصلی `String` را به خوبی یاد گرفته‌اید.

اکنون می‌توانید:

* انواع متدهای مهم `String` را در پروژه‌های واقعی استفاده کنید.
* رشته‌ها را جستجو، ویرایش، استخراج و قالب‌بندی کنید.
* با استفاده از Template Literal کدهای خواناتر بنویسید.
* ورودی کاربران را پردازش و استانداردسازی کنید.
* از Regular Expression در کنار متدهای `String` برای حل مسائل متداول استفاده کنید.

بخش بعدی شامل **مینی‌پروژه‌های کاربردی** خواهد بود که با استفاده از تمام مباحث این فصل، مهارت خود را در پروژه‌های واقعی تقویت خواهید کرد.

# بخش ۱۲

# مینی‌پروژه‌ها

تا اینجای فصل با تمام متدها و قابلیت‌های مهم `String` آشنا شدید.

این پروژه‌ها بسیار شبیه مسائلی هستند که در پروژه‌های واقعی Node.js با آن‌ها روبه‌رو خواهید شد.

# جمع‌بندی فصل

در این فصل تقریباً تمام متدها و قابلیت‌های مهم `String` که در توسعه برنامه‌های Node.js به‌صورت روزمره استفاده می‌شوند را یاد گرفتید.

اکنون می‌توانید:

* رشته‌ها را ایجاد، مقایسه و پیمایش کنید.
* متن را جستجو، استخراج و ویرایش کنید.
* رشته‌ها را به آرایه تبدیل کنید و برعکس.
* با `Template Literal` رشته‌های پویا و چندخطی بسازید.
* ورودی کاربران را پاک‌سازی و استاندارد کنید.
* از Regular Expression در کنار متدهای `String` استفاده کنید.
* پروژه‌های واقعی مانند ساخت Username، Slug، اعتبارسنجی ایمیل، تحلیل متن و پردازش مسیر فایل را پیاده‌سازی کنید.

پس از یادگیری کامل این فصل، تقریباً تمام ابزارهای موردنیاز برای کار با رشته‌ها در پروژه‌های واقعی Node.js را در اختیار دارید.
