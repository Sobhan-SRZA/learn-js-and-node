# Object

## مقدمه

تقریباً تمام برنامه‌هایی که با Node.js نوشته می‌شوند، بر پایه **Object** هستند.

هر زمان که بخواهید اطلاعات مرتبط را در کنار هم نگهداری کنید، از Object استفاده می‌کنید.

برای مثال:

* اطلاعات کاربران
* محصولات فروشگاه
* تنظیمات برنامه
* پاسخ API
* اطلاعات فایل‌ها
* تنظیمات پایگاه داده
* داده‌های دریافتی از MongoDB

همگی به صورت Object نمایش داده می‌شوند.

به همین دلیل، یادگیری Object یکی از مهم‌ترین مباحث JavaScript برای برنامه‌نویسان Node.js است.

در این فصل ابتدا با ساخت Object آشنا می‌شوید، سپس یاد می‌گیرید چگونه ویژگی‌های آن را ایجاد، ویرایش و حذف کنید، با متدهای مهم `Object` کار کنید، از **Object Destructuring** برای خواندن راحت‌تر داده‌ها استفاده کنید و در نهایت با **Spread Operator** برای کپی و ترکیب Objectها آشنا خواهید شد.

در انتهای فصل نیز اشتباهات رایج، نکات حرفه‌ای، تمرین‌های متنوع، پاسخ‌های تشریحی و چند مینی‌پروژه کاربردی ارائه می‌شود تا بتوانید تمام مفاهیم این فصل را در پروژه‌های واقعی Node.js به کار بگیرید.

# بخش ۱

# آشنایی با Object و ایجاد Object

تقریباً در تمام برنامه‌های Node.js از Object استفاده می‌شود.

اگر قبلاً با Array آشنا شده باشید، می‌دانید که آرایه برای نگهداری مجموعه‌ای از داده‌ها استفاده می‌شود.

اما زمانی که بخواهیم برای هر داده یک نام مشخص داشته باشیم، از **Object** استفاده می‌کنیم.

برای مثال اطلاعات یک کاربر را در نظر بگیرید.

* نام
* سن
* ایمیل
* شماره تلفن
* آدرس

تمام این اطلاعات متعلق به یک شخص هستند؛ بنابراین بهترین انتخاب برای نگهداری آن‌ها یک Object است.

---

# Object چیست؟

Object مجموعه‌ای از داده‌ها است که به صورت **کلید (Key)** و **مقدار (Value)** ذخیره می‌شوند.

هر عضو Object یک **Property** نام دارد.

ساختار کلی

```javascript
{
    key: value
}
```

---

# مثال

```javascript
const user = {
    firstName: "Ali",
    age: 22,
    isAdmin: false
};

console.log(user);
```

خروجی

```text
{
    firstName: "Ali",
    age: 22,
    isAdmin: false
}
```

در این مثال:

| Property    | Value   |
| ----------- | ------- |
| `firstName` | `"Ali"` |
| `age`       | `22`    |
| `isAdmin`   | `false` |

---

# چرا از Object استفاده می‌کنیم؟

فرض کنید بخواهیم اطلاعات یک کاربر را داخل Array ذخیره کنیم.

```javascript
const user = [
    "Ali",
    22,
    false
];
```

بعد از مدتی مشخص نیست هر مقدار مربوط به چیست.

آیا مقدار دوم سن است؟

یا شماره تلفن؟

یا شناسه کاربر؟

اما اگر از Object استفاده کنیم، همه چیز کاملاً مشخص است.

```javascript
const user = {
    firstName: "Ali",
    age: 22,
    isAdmin: false
};
```

خوانایی بسیار بیشتر خواهد بود.

# Object.create()

می‌توان Object جدیدی از روی Object دیگر ایجاد کرد.

```javascript

    country: "Iran"
};

    Object.create(person);

user.name = "Ali";

console.log(user.name);
```

خروجی

```text
Ali
```

این مبحث در فصل Prototype به طور کامل بررسی خواهد شد.

# Constructor Function

```javascript
function User(name, age) {
    this.name = name;
    this.age = age;
}

const user =
    new User("Ali",22);

console.log(user);
```

این روش امروزه معمولاً با Class جایگزین شده است.

# ایجاد Object با Class

```javascript
class User {

    constructor(name) {
        this.name = name;
    }

}

const user =
    new User("Ali");

console.log(user);
```

در فصل Class به طور کامل با این موضوع آشنا خواهید شد.

# نکات مهم

* Object مجموعه‌ای از Propertyها است.
* هر Property از یک Key و یک Value تشکیل شده است.
* مقدار هر Property می‌تواند هر نوع داده‌ای باشد.
* Object می‌تواند شامل Objectهای دیگر باشد.
* Object می‌تواند شامل Array باشد.
* رایج‌ترین روش ساخت Object، استفاده از **Object Literal** است.

# خواندن، ایجاد، ویرایش و حذف Propertyها

بعد از ایجاد یک Object، معمولاً نیاز داریم اطلاعات آن را بخوانیم، ویژگی جدیدی به آن اضافه کنیم، مقدار یک ویژگی را تغییر دهیم یا آن را حذف کنیم.

در این بخش تمام این عملیات را به صورت کامل یاد خواهید گرفت.

# دسترسی به Propertyها

برای خواندن مقدار یک Property دو روش وجود دارد.

* Dot Notation
* Bracket Notation

---

# روش اول

## Dot Notation

رایج‌ترین روش دسترسی به Propertyها استفاده از نقطه (`.`) است.

```javascript id="b8v4pr"
const user = {
    firstName: "Ali",
    age: 22
};

console.log(user.firstName);

console.log(user.age);
```

خروجی

```text id="m5q2tx"
Ali
22
```

این روش زمانی استفاده می‌شود که نام Property مشخص و ثابت باشد.

---

# روش دوم

## Bracket Notation

در این روش نام Property به صورت رشته نوشته می‌شود.

```javascript id="d2k7nv"
const user = {
    firstName: "Ali",
    age: 22
};

console.log(
    user["firstName"]
);

console.log(
    user["age"]
);
```

خروجی

```text id="u9r1pb"
Ali
22
```

# تفاوت Dot و Bracket

| ---------------------- | ---------------------- |

| مناسب Propertyهای ثابت | مناسب Propertyهای پویا |

# خلاصه عملیات روی Propertyها

| عملیات           | نمونه                        |
| ---------------- | ---------------------------- |
| خواندن           | `user.name`                  |
| خواندن پویا      | `user[key]`                  |
| ایجاد            | `user.age = 22`              |
| ویرایش           | `user.age = 30`              |
| حذف              | `delete user.age`            |
| بررسی وجود       | `"age" in user`              |
| بررسی وجود (Own) | `Object.hasOwn(user, "age")` |
| دسترسی امن       | `user.address?.city`         |

---

# نکات مهم

* برای Propertyهای ثابت از **Dot Notation** استفاده کنید.
* برای Propertyهای پویا از **Bracket Notation** استفاده کنید.
* اگر Property وجود نداشته باشد، مقدار `undefined` برگردانده می‌شود.
* عملگر `delete` فقط همان Property را حذف می‌کند.
* برای جلوگیری از خطا هنگام دسترسی به Objectهای تو در تو، از **Optional Chaining (`?.`)** استفاده کنید.
* برای بررسی وجود Property، `Object.hasOwn()` نسبت به `hasOwnProperty()` در کدهای مدرن توصیه می‌شود.

اکنون می‌توانید:

* مقدار Propertyها را بخوانید.
* Property جدید ایجاد کنید.
* مقدار Propertyها را ویرایش کنید.
* Propertyهای اضافی را حذف کنید.
* وجود یک Property را بررسی کنید.
* با استفاده از `?.` به شکل ایمن به Objectهای تو در تو دسترسی پیدا کنید.
* بین `Dot Notation` و `Bracket Notation` در موقعیت مناسب انتخاب درستی داشته باشید.

در بخش بعدی با مهم‌ترین متدهای داخلی شیء `Object` آشنا خواهید شد و یاد می‌گیرید چگونه کلیدها، مقادیر و ورودی‌های یک Object را مدیریت کنید.

# Object Destructuring

تا اینجا برای دسترسی به Propertyهای یک Object از روش‌های زیر استفاده می‌کردیم.


# مزایای Destructuring

* کاهش حجم کد
* افزایش خوانایی
* حذف تکرار
* مناسب برای پارامترهای تابع
* مناسب برای پاسخ API
* مناسب برای تنظیمات برنامه

---

# خلاصه

| قابلیت          | نمونه                                |
| --------------- | ------------------------------------ |
| استخراج مقدار   | `const { name } = user`              |
| تغییر نام       | `const { name: userName } = user`    |
| مقدار پیش‌فرض    | `const { age = 18 } = user`          |
| Object تو در تو | `const { address: { city } } = user` |
| Rest Operator   | `const { name, ...rest } = user`     |

---

# نکات مهم

* نام Property باید با نام موجود در Object یکسان باشد، مگر اینکه از Rename استفاده کنید.
* ترتیب Propertyها در Object Destructuring اهمیتی ندارد.
* مقدار پیش‌فرض فقط زمانی استفاده می‌شود که Property وجود نداشته باشد یا مقدار آن `undefined` باشد.
* استفاده از Destructuring در پارامترهای توابع باعث خوانایی بیشتر کد می‌شود.
* در پروژه‌های Node.js، Destructuring برای دریافت اطلاعات از درخواست‌ها (Request)، پاسخ‌های API و فایل‌های تنظیمات بسیار رایج است.

---

# جمع‌بندی بخش چهارم

در این بخش با **Object Destructuring** آشنا شدید.

اکنون می‌توانید:

* Propertyهای یک Object را به‌سادگی استخراج کنید.
* نام متغیرهای استخراج‌شده را تغییر دهید.
* برای Propertyهای اختیاری مقدار پیش‌فرض تعیین کنید.
* از Objectهای تو در تو مقدار استخراج کنید.
* از Rest Operator برای جمع‌آوری سایر Propertyها استفاده کنید.
* از Destructuring در پارامترهای توابع و کدهای واقعی Node.js استفاده کنید.

در بخش بعدی با **Spread Operator** و **Rest Operator** برای Objectها آشنا خواهید شد و یاد می‌گیرید چگونه Objectها را کپی، ترکیب و مدیریت کنید.

# بخش ۵

# Spread Operator و Rest Operator

در فصل‌های قبل چند بار از عملگر `...` استفاده کردیم.

این عملگر در JavaScript دو کاربرد متفاوت دارد.

* **Spread Operator**
* **Rest Operator**

هر دو از یک علامت (`...`) استفاده می‌کنند اما کاربرد آن‌ها کاملاً متفاوت است.

در این بخش هر دو را به صورت کامل یاد خواهید گرفت.

Spread Operator برای **باز کردن (Expand)** داده‌ها استفاده می‌شود.

# مقایسه Spread و Rest

| Spread             | Rest               |
| ------------------ | ------------------ |
| باز کردن داده‌ها    | جمع‌آوری داده‌ها     |
| سمت راست `=`       | سمت چپ `=`         |
| کپی و ترکیب Object | استخراج Propertyها |

---

# نکات مهم

* `Spread` برای کپی کردن Object استفاده می‌شود.
* `Spread` برای ترکیب چند Object بسیار مناسب است.
* اگر کلیدها تکراری باشند، مقدار آخر جایگزین مقدار قبلی می‌شود.
* `Spread` فقط یک **Shallow Copy** ایجاد می‌کند.
* برای Objectهای تو در تو باید هر سطح را جداگانه کپی کنید.
* `Rest` برای استخراج چند Property و جمع‌آوری بقیه استفاده می‌شود.
* حذف Propertyهای حساس مانند `password` با Rest یکی از رایج‌ترین الگوها در پروژه‌های Node.js است.

---

# تفاوت Shallow Copy و Deep Copy

| ویژگی               | Shallow Copy  | Deep Copy           |
| ------------------- | ------------- | ------------------- |
| سطح اول Object      | ✅ کپی می‌شود   | ✅ کپی می‌شود         |
| Objectهای تو در تو  | ❌ مشترک هستند | ✅ کاملاً مستقل هستند |
| Spread Operator     | ✅             | ❌                   |
| `structuredClone()` | ❌             | ✅                   |

نمونه کپی عمیق با `structuredClone()`:

```javascript id="p6t4mx"
const copy =
    structuredClone(user);
```

این متد در محیط‌های مدرن JavaScript و نسخه‌های جدید Node.js در دسترس است و برای کپی کامل Objectهای تو در تو مناسب است.

---

# جمع‌بندی بخش پنجم

در این بخش با **Spread Operator** و **Rest Operator** آشنا شدید.

اکنون می‌توانید:

* Objectها را کپی کنید.
* چند Object را با یکدیگر ترکیب کنید.
* Propertyهای موجود را هنگام کپی تغییر دهید یا Property جدید اضافه کنید.
* تفاوت بین کپی سطحی (Shallow Copy) و کپی عمیق (Deep Copy) را درک کنید.
* با Rest Operator Propertyهای موردنیاز را استخراج کرده و سایر Propertyها را در یک Object جدید جمع‌آوری کنید.
* از این قابلیت‌ها در سناریوهای واقعی مانند به‌روزرسانی داده‌ها، حذف اطلاعات حساس و مدیریت تنظیمات برنامه استفاده کنید.

در بخش بعدی با **اشتباهات رایج هنگام کار با Object** آشنا خواهید شد و یاد می‌گیرید چگونه از خطاهای متداول در پروژه‌های واقعی جلوگیری کنید.

```javascript
        personal: {
            address: {
                city: {
                    name: "Tehran"
                }
            }
        }
    }
};
```

دسترسی به چنین ساختاری دشوار و نگهداری آن سخت است.

راهکار

تا حد امکان ساختار داده را ساده طراحی کنید.

# اشتباه سیزدهم

## استفاده از مقدار undefined به جای حذف Property

گاهی برنامه‌نویسان تصور می‌کنند این دو کاملاً یکسان هستند.

```javascript
user.age = undefined;
```

و

```javascript
delete user.age;
```

یکسان نیستند.

در حالت اول Property همچنان وجود دارد.

```javascript
console.log(
    "age" in user
);
```

خروجی

```text
true
```

اما بعد از `delete`

```javascript
delete user.age;

console.log(
    "age" in user
);
```

خروجی

```text
false
```

# اشتباه چهاردهم

## تغییر Objectهای Freeze شده

```javascript
const config = {
    port: 3000
};

Object.freeze(config);

config.port = 8080;
```

هیچ تغییری اعمال نمی‌شود (در حالت Strict Mode حتی خطا ایجاد می‌شود).

---

# اشتباه پانزدهم

## فراموش کردن اینکه Object.assign نیز Shallow Copy ایجاد می‌کند

```javascript
const copy =
    Object.assign({}, user);
```

این متد نیز مانند Spread فقط کپی سطحی ایجاد می‌کند.

# خلاصه اشتباهات رایج

| اشتباه                                     | راهکار                                          |
| ------------------------------------------ | ----------------------------------------------- |
| استفاده از `user.key` برای Property پویا   | استفاده از `user[key]`                          |
| عدم بررسی وجود Property                    | استفاده از `?.` یا `Object.hasOwn()`            |
| مقایسه مستقیم Objectها                     | مقایسه Propertyها یا استفاده از مقایسه عمیق     |
| تصور Deep Copy بودن Spread                 | استفاده از `structuredClone()` یا کپی هر سطح    |
| حذف اشتباه Property                        | استفاده صحیح از `delete` یا `null`              |
| استفاده از `hasOwnProperty()` در همه شرایط | استفاده از `Object.hasOwn()`                    |
| تغییر مستقیم Object در تابع                | ایجاد Object جدید با Spread                     |
| استفاده از `for...in` بدون بررسی           | استفاده از `Object.keys()` یا `Object.hasOwn()` |
| استفاده از Array برای داده‌های نام‌گذاری‌شده  | استفاده از Object                               |
| استفاده از نام‌های نامفهوم                  | انتخاب نام‌های واضح                              |
| ایجاد Objectهای بسیار تو در تو             | طراحی ساختار ساده‌تر                             |
| یکسان دانستن `undefined` و `delete`        | درک تفاوت این دو                                |
| تغییر Objectهای Freeze شده                 | عدم تغییر یا ایجاد Object جدید                  |
| تصور Deep Copy بودن `Object.assign()`      | استفاده از Deep Copy در صورت نیاز               |

# جمع‌بندی بخش ششم

در این بخش با متداول‌ترین اشتباهات هنگام کار با Object آشنا شدید.

اکنون می‌دانید:

* چه زمانی از Dot Notation و Bracket Notation استفاده کنید.
* چرا Objectها با `===` به درستی از نظر محتوا مقایسه نمی‌شوند.
* تفاوت بین Shallow Copy و Deep Copy چیست.
* تفاوت `delete` و مقدار `undefined` را درک کنید.
* چگونه از `Object.hasOwn()` و `Optional Chaining` برای نوشتن کدهای مطمئن‌تر استفاده کنید.
* چگونه از تغییر ناخواسته Objectها در توابع و پروژه‌های واقعی جلوگیری کنید.

شناخت این اشتباهات به شما کمک می‌کند کدهایی پایدارتر، خواناتر و قابل‌نگهداری‌تر در پروژه‌های Node.js بنویسید.

# نکات حرفه‌ای (Best Practices)

بعد از یادگیری Object، مرحله بعدی نوشتن کدهای حرفه‌ای و قابل نگهداری است.

در این بخش با نکاتی آشنا می‌شوید که در پروژه‌های واقعی Node.js توسط توسعه‌دهندگان باتجربه استفاده می‌شوند.

# نکته ۱

## تا حد امکان از const استفاده کنید

اشتباه

```javascript
let user = {
    name: "Ali"
};
```

بهتر

```javascript
const user = {
    name: "Ali"
};
```

نکته مهم

`const` از تغییر Reference جلوگیری می‌کند، نه تغییر Propertyها.

```javascript
const user = {
    name: "Ali"
};

user.name = "Sara";

console.log(user);
```

این کد کاملاً صحیح است.

---

# نکته ۲

## از Object Literal استفاده کنید

به جای

```javascript
const user = new Object();
```

بنویسید

```javascript
const user = {};
```

مزایا

* کوتاه‌تر
* خواناتر
* استانداردتر
* رایج‌تر

---

# نکته ۳

## برای Propertyهای ثابت از Dot Notation استفاده کنید

بهتر

```javascript
console.log(user.name);
```

به جای

```javascript
console.log(user["name"]);
```

Dot Notation خواناتر است.

---

# نکته ۴

## فقط برای Propertyهای پویا از Bracket Notation استفاده کنید

```javascript
const key = "email";

console.log(
    user[key]
);
```

---

# نکته ۵

## از نام‌های واضح استفاده کنید

بد

```javascript
const user = {
    a: "Ali",
    b: 22
};
```

خوب

```javascript
const user = {
    firstName: "Ali",
    age: 22
};
```

نام مناسب باعث می‌شود بدون خواندن توضیحات، هدف کد مشخص باشد.

---

# نکته ۶

## از Object Destructuring استفاده کنید

به جای

```javascript
const username =
    user.username;

const email =
    user.email;
```

بنویسید

```javascript
const {
    username,
    email
} = user;
```

این روش خواناتر و کوتاه‌تر است.

---

# نکته ۷

## از Spread برای ایجاد Object جدید استفاده کنید

به جای تغییر مستقیم Object

```javascript
user.age = 30;
```

در بسیاری از مواقع بهتر است

```javascript
const updatedUser = {
    ...user,
    age: 30
};
```

این روش مخصوصاً در برنامه‌های بزرگ و معماری‌های Immutable بسیار کاربرد دارد.

---

# نکته ۸

## از Optional Chaining استفاده کنید

به جای

```javascript
if (
    user &&
    user.address &&
    user.address.city
) {

    console.log(user.address.city);

}
```

بنویسید

```javascript
console.log(
    user.address?.city
);
```

کد بسیار ساده‌تر خواهد شد.

---

# نکته ۹

## از Nullish Coalescing استفاده کنید

```javascript
const city =
    user.city ?? "Unknown";

console.log(city);
```

اگر مقدار `null` یا `undefined` باشد، مقدار پیش‌فرض استفاده می‌شود.

---

# نکته ۱۰

## از Object.keys() برای پیمایش استفاده کنید

به جای

```javascript
for (const key in user) {
    console.log(key);
}
```

بهتر است

```javascript
Object.keys(user)
    .forEach(key => {
        console.log(key);
    });
```

زیرا فقط Propertyهای خود Object را بررسی می‌کند.

---

# نکته ۱۱

## از Object.entries() برای دسترسی همزمان به کلید و مقدار استفاده کنید

```javascript
for (const [key, value] of Object.entries(user)) {
    console.log(key, value);
}
```

این روش خواناتر از استفاده همزمان از `Object.keys()` و دسترسی مجدد به مقدار است.

---

# نکته ۱۲

## برای بررسی وجود Property از Object.hasOwn() استفاده کنید

به جای

```javascript
user.hasOwnProperty("age");
```

بنویسید

```javascript
Object.hasOwn(
    user,
    "age"
);
```

این روش جدیدتر و مطمئن‌تر است.

---

# نکته ۱۳

## اطلاعات حساس را قبل از ارسال حذف کنید

```javascript
    username: "Ali",

    password,
    ...response

```

هرگز اطلاعات حساس را مستقیماً برای Client ارسال نکنید.

# خلاصه نکات حرفه‌ای

* همیشه از `const` استفاده کنید مگر اینکه نیاز به تغییر Reference داشته باشید.
* از Object Literal (`{}`) برای ساخت Object استفاده کنید.
* برای Propertyهای ثابت از Dot Notation استفاده کنید.
* برای Propertyهای پویا از Bracket Notation استفاده کنید.
* نام‌های واضح و استاندارد انتخاب کنید.
* از Destructuring برای استخراج Propertyها استفاده کنید.
* با Spread Object جدید بسازید و از تغییر مستقیم داده‌ها تا حد امکان خودداری کنید.
* از Optional Chaining و Nullish Coalescing برای دسترسی ایمن به داده‌ها استفاده کنید.
* از `Object.entries()` و `Object.keys()` برای پیمایش استفاده کنید.
* از `Object.hasOwn()` برای بررسی وجود Property بهره ببرید.
* اطلاعات حساس مانند رمز عبور را قبل از ارسال حذف کنید.
* برای ثابت نگه داشتن تنظیمات از `Object.freeze()` استفاده کنید.
* از ساختارهای بیش از حد تو در تو پرهیز کنید.
* ترتیب ادغام Objectها را در Spread Operator فراموش نکنید.
* داده‌های ورودی را همیشه اعتبارسنجی کنید.

```javascript
const users = [];

function addUser(user) {
    users.push(user);
}

function updateUser(id, data) {

    const user =
        users.find(
            user => user.id === id
        );

    if (user) {
        Object.assign(user, data);
    }

}

function removeUser(id) {

    const index =
        users.findIndex(
            user => user.id === id
        );

    if (index !== -1) {
        users.splice(index, 1);
    }

}

function printUsers() {
    console.table(users);
}
```

# جمع‌بندی فصل

در این فصل با Object در JavaScript به طور کامل آشنا شدید.

اکنون می‌توانید:

* Object ایجاد کنید.
* Propertyها را بخوانید، اضافه، ویرایش و حذف کنید.
* از متدهای مهم `Object` استفاده کنید.
* با Destructuring داده‌ها را استخراج کنید.
* از Spread و Rest Operator استفاده کنید.
* از `Object.freeze()` و `Object.seal()` بهره ببرید.
* خطاهای رایج را تشخیص دهید.
* بهترین شیوه‌های کار با Object را به کار بگیرید.
* مسائل واقعی را با استفاده از Objectها پیاده‌سازی کنید.

Object یکی از مهم‌ترین ساختمان‌های داده در JavaScript و Node.js است و در ادامه مسیر تقریباً در تمام مباحث مانند توابع، کلاس‌ها، ماژول‌ها، کار با فایل‌ها، درخواست‌های HTTP، پایگاه‌داده و فریم‌ورک‌هایی مانند Express به طور مداوم از آن استفاده خواهید کرد.
