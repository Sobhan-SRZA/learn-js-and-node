# بخش ۵ - ساختمان داده‌ها

در این بخش با مهم‌ترین **ساختمان‌های داده و ساختارهای مورد استفاده در JavaScript** آشنا می‌شویم.

ساختمان داده‌ها به ما کمک می‌کنند اطلاعات را به شکل مناسب ذخیره، مدیریت، جستجو و پردازش کنیم. در این بخش ابتدا با ساختارهای پایه مانند Array، String و Object آشنا می‌شویم و سپس سراغ ساختارهایی مانند Set و Map و ابزارهای کاربردی مانند Date، Math و RegExp می‌رویم.

این مفاهیم در ادامه مسیر یادگیری Node.js، مخصوصاً هنگام کار با داده‌های کاربران، APIها، پایگاه‌های داده و پروژه‌های واقعی، کاربرد بسیار زیادی خواهند داشت.

# 🎯 هدف بخش ۵

در پایان این بخش باید بتوانید:

* Array ایجاد و مدیریت کنید.
* عناصر Array را اضافه، حذف و جستجو کنید.
* از متدهای مهم Array برای پردازش داده‌ها استفاده کنید.
* داده‌های موجود در Array را با `map`، `filter` و `reduce` پردازش کنید.
* از متدهایی مانند `find`، `some` و `every` استفاده کنید.
* Arrayها را مرتب و ویرایش کنید.
* با Stringها کار کنید و متن‌ها را پردازش کنید.
* Object ایجاد و Properties آن را مدیریت کنید.
* از Object Methods استفاده کنید.
* از Destructuring و Spread استفاده کنید.
* با Set و داده‌های یکتا کار کنید.
* از Map برای مدیریت داده‌های Key-Value استفاده کنید.
* تاریخ و زمان را با Date مدیریت کنید.
* از ابزارهای Math برای محاسبات استفاده کنید.
* Regular Expression را برای جستجو و پردازش متن به کار ببرید.
* ساختمان داده‌های مناسب را برای مسائل مختلف انتخاب کنید.
