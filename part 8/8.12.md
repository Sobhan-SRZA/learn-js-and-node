# فصل 62 - URL

## مقدمه

در برنامه‌های Node.js، مخصوصاً هنگام ساخت API، سرورهای HTTP، سیستم‌های احراز هویت و برنامه‌های وب، دائماً با **URL**ها سروکار داریم.

برای مثال:

```
https://example.com/users?id=10&active=true
```

این URL شامل بخش‌های مختلفی است:

* پروتکل (`https`)
* دامنه (`example.com`)
* مسیر (`/users`)
* Query String (`id=10&active=true`)
* Fragment (`#section`)

درک درست ساختار URL برای هر توسعه‌دهنده Node.js ضروری است.

Node.js یک ماژول داخلی به نام **`url`** دارد که برای:

* تجزیه URL
* ساخت URL
* خواندن Query Parameters
* مدیریت مسیرها
* کار با آدرس‌های اینترنتی

استفاده می‌شود.

---

# 62.1 - ماژول URL چیست؟

ماژول `url` یکی از ماژول‌های داخلی Node.js است.

برای استفاده:

```js
const url = require("url");
```

---

# 62.2 - ساختار URL

یک URL معمولی:

```
https://user:pass@example.com:8080/products?id=10#detail
```

اجزای آن:

| بخش      | مقدار       |
| -------- | ----------- |
| Protocol | https       |
| Username | user        |
| Password | pass        |
| Hostname | example.com |
| Port     | 8080        |
| Pathname | /products   |
| Query    | id=10       |
| Hash     | #detail     |

# 62.17 - ساخت URL

می‌توانیم URL را به صورت برنامه‌ای بسازیم.

```js

    new URL(
        "https://example.com"
    );


myURL.pathname =
    "/users";

    "id",
    "100"
);


console.log(
    myURL.toString()
);
```

خروجی:

```
https://example.com/users?id=100
```

# 62.20 - استفاده در HTTP Server

یکی از مهم‌ترین کاربردهای URL:

```js
const http = require("http");


const server =
http.createServer(
(req,res)=>{


const url =
new URL(
    req.url,
    `http://${req.headers.host}`
);


console.log(
    url.pathname
);


res.end("OK");


});


server.listen(3000);
```

# 62.27 - نکات حرفه‌ای

* در پروژه‌های جدید از `new URL()` استفاده کن.
* برای Query Parameters از `URLSearchParams` استفاده کن.
* URLهای ورودی کاربران را Validate کن.
* برای ساخت لینک‌ها از API استاندارد استفاده کن.
* هنگام ساخت HTTP Server همیشه URL کامل ایجاد کن.
* تفاوت `hostname` و `host` را بدان.
* برای داده‌های حساس، اطلاعات را در Query String قرار نده.
* Query String معمولاً در History مرورگر و Logها ذخیره می‌شود.

# 62.31 - پروژه کامل

## ساخت API Router ساده با URL

در این پروژه یک Router کوچک بدون فریمورک می‌سازیم.

ساختار:

```
url-router/

│
├── app.js
```

کد:

```js
const http =
require("http");


const server =
http.createServer(
(req,res)=>{


const url =
new URL(
req.url,
`http://${req.headers.host}`
);


if(
url.pathname === "/users"
){

res.end(
"Users API"
);


}

else if(
url.pathname === "/products"
){

res.end(
"Products API"
);


}

else{

res.statusCode = 404;

res.end(
"Not Found"
);

}


});


server.listen(3000);
```

# جمع‌بندی

ماژول **URL** یکی از ابزارهای ضروری Node.js برای کار با آدرس‌های اینترنتی است. با استفاده از `URL` و `URLSearchParams` می‌توان URLها را به شکل استاندارد تحلیل، ایجاد و مدیریت کرد.

تسلط بر URL برای ساخت HTTP Server، API، Routing و کار با درخواست‌های کاربران ضروری است و پایه بسیاری از فریمورک‌های Node.js مانند Express و Fastify نیز بر همین مفاهیم بنا شده است.
