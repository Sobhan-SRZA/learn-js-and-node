# فصل 57 - Buffer

## مقدمه

در بسیاری از برنامه‌های Node.js با داده‌هایی سروکار داریم که **متن (String)** نیستند.

برای مثال:

* فایل‌های تصویری
* فایل‌های ویدیویی
* فایل‌های PDF
* فایل‌های صوتی
* داده‌های شبکه
* داده‌های دریافتی از Socket
* Streamها
* فایل‌های فشرده

کامپیوتر تمام این اطلاعات را به‌صورت **بایت (Byte)** ذخیره و پردازش می‌کند.

Node.js برای کار با داده‌های باینری، شیئی به نام **Buffer** را در اختیار ما قرار داده است.

تقریباً تمام عملیات مربوط به فایل‌ها، شبکه، Streamها، رمزنگاری و بسیاری از ماژول‌های داخلی Node.js از Buffer استفاده می‌کنند.

---

# 57.1 - Buffer چیست؟

**Buffer** ساختاری برای ذخیره و مدیریت داده‌های باینری در حافظه است.

به بیان ساده:

> Buffer مجموعه‌ای از بایت‌ها (Bytes) است.

هر خانه از Buffer دقیقاً یک بایت (۸ بیت) را نگهداری می‌کند.

---

# 57.2 - چرا به Buffer نیاز داریم؟

رشته‌ها (String) برای متن مناسب هستند.

اما فایل‌های زیر متن نیستند:

* عکس
* فیلم
* موسیقی
* فایل ZIP
* فایل اجرایی
* داده‌های خام شبکه

برای این نوع داده‌ها از Buffer استفاده می‌شود.

---

# 57.3 - ساخت Buffer

```js id="buf01"
const buffer = Buffer.alloc(8);

console.log(buffer);
```

خروجی:

```text id="buf02"
<Buffer 00 00 00 00 00 00 00 00>
```

`Buffer.alloc()` یک Buffer با اندازه مشخص ایجاد می‌کند و تمام بایت‌های آن را با مقدار صفر مقداردهی می‌کند.

---

# 57.4 - ساخت Buffer از داده

```js id="buf03"
const buffer = Buffer.from("Hello");

console.log(buffer);
```

خروجی:

```text id="buf04"
<Buffer 48 65 6c 6c 6f>
```

هر مقدار نمایش‌داده‌شده، نمایش هگزادسیمال (Hexadecimal) یک بایت است.

---

# 57.5 - تبدیل Buffer به String

```js id="buf05"
const buffer = Buffer.from("Node.js");

console.log(buffer.toString());
```

خروجی:

```text id="buf06"
Node.js
```

---

# 57.6 - دسترسی به بایت‌ها

```js id="buf07"
const buffer = Buffer.from("ABC");

console.log(buffer[0]);

console.log(buffer[1]);

console.log(buffer[2]);
```

خروجی:

```text id="buf08"
65
66
67
```

این اعداد کد ASCII حروف هستند.

---

# 57.7 - تغییر مقدار بایت

```js id="buf09"
const buffer = Buffer.from("ABC");

buffer[0] = 90;

console.log(buffer.toString());
```

خروجی:

```text id="buf10"
ZBC
```

---

# 57.8 - اندازه Buffer

```js id="buf11"
const buffer = Buffer.from("Hello");

console.log(buffer.length);
```

خروجی:

```text id="buf12"
5
```

در Buffer، `length` تعداد **بایت‌ها** را نشان می‌دهد، نه تعداد کاراکترها.

---

# 57.9 - Encoding

Buffer از Encodingهای مختلف پشتیبانی می‌کند.

نمونه:

```js id="buf13"
const buffer = Buffer.from("Node", "utf8");
```

Encodingهای رایج:

* utf8
* ascii
* latin1
* base64
* hex

---

# 57.10 - Base64

```js id="buf14"
const buffer = Buffer.from("Hello");

console.log(
    buffer.toString("base64")
);
```

خروجی:

```text id="buf15"
SGVsbG8=
```

برعکس:

```js id="buf16"
const text = Buffer
    .from("SGVsbG8=", "base64")
    .toString();

console.log(text);
```

خروجی:

```text id="buf17"
Hello
```

---

# 57.11 - Hex

```js id="buf18"
const buffer = Buffer.from("ABC");

console.log(
    buffer.toString("hex")
);
```

خروجی:

```text id="buf19"
414243
```

---

# 57.12 - Buffer.allocUnsafe()

```js id="buf20"
const buffer = Buffer.allocUnsafe(8);
```

این متد حافظه را رزرو می‌کند اما آن را با صفر مقداردهی اولیه نمی‌کند.

به همین دلیل ممکن است شامل داده‌های قدیمی موجود در حافظه باشد.

اگر قصد استفاده از `allocUnsafe()` را دارید، باید قبل از خواندن داده‌ها، تمام بخش‌های Buffer را مقداردهی کنید.

---

# 57.13 - کپی Buffer

```js id="buf21"
const source = Buffer.from("Node");

const target = Buffer.alloc(4);

source.copy(target);

console.log(target.toString());
```

---

# 57.14 - اتصال Bufferها

```js id="buf22"
const b1 = Buffer.from("Hello ");

const b2 = Buffer.from("Node.js");

const result = Buffer.concat([b1, b2]);

console.log(result.toString());
```

خروجی:

```text id="buf23"
Hello Node.js
```

---

# 57.15 - مقایسه Bufferها

```js id="buf24"
const b1 = Buffer.from("ABC");

const b2 = Buffer.from("ABC");

console.log(
    b1.equals(b2)
);
```

خروجی:

```text id="buf25"
true
```

---

# 57.16 - Buffer و فایل‌ها

```js id="buf26"
const fs = require("fs");

const buffer = fs.readFileSync("image.png");

console.log(buffer);
```

در این مثال، فایل به‌صورت Buffer در حافظه قرار می‌گیرد.

---

# 57.17 - Buffer و Stream

زمانی که داده از Stream دریافت می‌شود:

```js id="buf27"
stream.on("data", (chunk) => {

});
```

متغیر `chunk` معمولاً یک Buffer است، مگر اینکه Encoding خاصی برای Stream تنظیم شده باشد.

---

# 57.18 - Buffer و شبکه

در Socketها نیز داده‌ها معمولاً به‌صورت Buffer منتقل می‌شوند.

```js id="buf28"
socket.on("data", (buffer) => {

});
```

---

# 57.19 - Buffer و JSON

```js id="buf29"
const obj = {
    name: "Ali"
};

const buffer = Buffer.from(
    JSON.stringify(obj)
);

console.log(buffer.toString());
```

---

# 57.20 - مهم‌ترین متدها

| متد                  | توضیح                            |
| -------------------- | -------------------------------- |
| Buffer.alloc()       | ایجاد Buffer امن                 |
| Buffer.allocUnsafe() | ایجاد Buffer بدون مقداردهی اولیه |
| Buffer.from()        | ساخت Buffer از داده              |
| toString()           | تبدیل به String                  |
| copy()               | کپی Buffer                       |
| concat()             | اتصال چند Buffer                 |
| equals()             | مقایسه دو Buffer                 |

---

# 57.21 - Buffer و Unicode

در UTF-8، همه کاراکترها یک بایت نیستند.

```js id="buf30"
const text = "سلام";

console.log(text.length);

console.log(
    Buffer.from(text).length
);
```

ممکن است خروجی به این شکل باشد:

```text id="buf31"
4
8
```

دلیل آن این است که هر کاراکتر فارسی در UTF-8 معمولاً بیش از یک بایت اشغال می‌کند.

---

# 57.22 - اشتباهات رایج

### 1) اشتباه گرفتن تعداد کاراکتر با تعداد بایت

`buffer.length` تعداد بایت‌ها را برمی‌گرداند، نه تعداد کاراکترها.

---

### 2) استفاده از `allocUnsafe()` بدون مقداردهی

ممکن است داده‌های قبلی حافظه در Buffer باقی مانده باشند.

---

### 3) فراموش کردن Encoding

اگر Encoding مناسب انتخاب نشود، ممکن است داده‌ها به‌درستی تبدیل نشوند.

---

### 4) مقایسه Buffer با `==`

```js id="buf32"
b1 == b2
```

این روش محتوای Buffer را مقایسه نمی‌کند، بلکه مرجع اشیاء را بررسی می‌کند.

روش صحیح:

```js id="buf33"
b1.equals(b2);
```

---

### 5) تبدیل بی‌دلیل بین String و Buffer

هر تبدیل هزینه پردازشی دارد. زمانی که با داده‌های باینری کار می‌کنید، تا حد امکان آن‌ها را به همان صورت Buffer نگه دارید.

---

# 57.23 - نکات حرفه‌ای

* برای ساخت Buffer جدید از `Buffer.alloc()` استفاده کن.
* فقط در شرایط خاص و با احتیاط از `allocUnsafe()` استفاده کن.
* برای فایل‌های بزرگ از Stream به‌جای بارگذاری کامل Buffer استفاده کن.
* هنگام کار با شبکه، Encoding داده‌ها را مشخص کن.
* برای مقایسه Bufferها از `equals()` استفاده کن.
* هنگام کار با داده‌های متنی چندزبانه، تفاوت بین تعداد کاراکتر و تعداد بایت را در نظر بگیر.
* از `Buffer.concat()` برای اتصال چندین Buffer به‌جای تبدیل آن‌ها به String استفاده کن.

# 57.25 - پاسخ تشریحی

## پاسخ تمرین 1

```js id="buf34"
const buffer = Buffer.alloc(10);

console.log(buffer);
```

**توضیح:**
یک Buffer ده‌بایتی ایجاد می‌شود که تمام بایت‌های آن صفر هستند.

---

## پاسخ تمرین 2

```js id="buf35"
const buffer = Buffer.from("Node.js");

console.log(buffer);

console.log(buffer.toString());
```

**توضیح:**
ابتدا رشته به داده باینری تبدیل شده و سپس دوباره به متن تبدیل می‌شود.

---

## پاسخ تمرین 3

```js id="buf36"
const encoded = Buffer
    .from("Hello")
    .toString("base64");

console.log(encoded);

const decoded = Buffer
    .from(encoded, "base64")
    .toString();

console.log(decoded);
```

**توضیح:**
Buffer از تبدیل به Encodingهای مختلف مانند Base64 پشتیبانی می‌کند.

---

## پاسخ تمرین 4

```js id="buf37"
const b1 = Buffer.from("Hello ");

const b2 = Buffer.from("World");

const result = Buffer.concat([b1, b2]);

console.log(result.toString());
```

**توضیح:**
`Buffer.concat()` چند Buffer را بدون نیاز به تبدیل به String به یک Buffer واحد تبدیل می‌کند.

---

## پاسخ تمرین 5

```js id="buf38"
const b1 = Buffer.from("ABC");

const b2 = Buffer.from("ABC");

console.log(
    b1.equals(b2)
);
```

**توضیح:**
متد `equals()` محتوای دو Buffer را با هم مقایسه می‌کند و در این مثال مقدار `true` برمی‌گرداند.

# 57.26 - مینی‌پروژه

## ساخت ابزار رمزگذاری و رمزگشایی Base64

در این پروژه، یک متن را به Base64 تبدیل می‌کنیم و سپس دوباره آن را بازیابی می‌کنیم.

```js id="buf39"
const text = "Welcome to Node.js";

const encoded = Buffer
    .from(text)
    .toString("base64");

console.log("Encoded:");

console.log(encoded);

const decoded = Buffer
    .from(encoded, "base64")
    .toString();

console.log("Decoded:");

console.log(decoded);
```

### خروجی نمونه

```text id="buf40"
Encoded:
V2VsY29tZSB0byBOb2RlLmpz

Decoded:
Welcome to Node.js
```

> **نکته:** Base64 یک روش **رمزنگاری (Encryption)** نیست. این روش فقط داده‌های باینری را به قالب متنی تبدیل می‌کند تا انتقال یا ذخیره‌سازی آن‌ها ساده‌تر شود. هر فردی می‌تواند داده Base64 را دوباره به حالت اولیه برگرداند.

### ایده‌هایی برای توسعه پروژه

* دریافت متن از خط فرمان با `process.argv`
* رمزگذاری فایل‌های متنی
* تبدیل فایل تصویری به Base64
* ذخیره خروجی در فایل
* اضافه کردن امکان تبدیل Hex به Buffer و برعکس
* نمایش اندازه متن و Buffer برای مقایسه تعداد کاراکتر و تعداد بایت

# جمع‌بندی

**Buffer** یکی از مهم‌ترین ساختارهای داده در Node.js برای کار با اطلاعات باینری است. تقریباً تمام عملیات مربوط به فایل‌ها، شبکه، Streamها، رمزنگاری و بسیاری از ماژول‌های داخلی بر پایه Buffer انجام می‌شوند. با یادگیری متدهایی مانند `Buffer.alloc()`، `Buffer.from()`، `toString()`، `concat()` و `equals()` می‌توانید داده‌های باینری را به‌صورت ایمن و کارآمد مدیریت کنید و درک بهتری از نحوه پردازش داده‌ها در Node.js به دست آورید.
