# فصل 60 - Path

## مقدمه

تقریباً تمام برنامه‌های Node.js با فایل‌ها و پوشه‌ها سروکار دارند.

برای مثال:

* خواندن فایل‌های تنظیمات
* ذخیره تصاویر
* ساخت فایل‌های گزارش
* آپلود فایل
* دانلود فایل
* مدیریت پوشه‌ها
* ذخیره اطلاعات کاربران

اما یک مشکل مهم وجود دارد.

مسیر فایل‌ها (File Path) در سیستم‌عامل‌های مختلف متفاوت است.

در ویندوز:

```text
C:\Projects\NodeApp\data\users.json
```

در لینوکس و macOS:

```text
/home/user/NodeApp/data/users.json
```

اگر مسیرها را به صورت دستی بنویسیم، ممکن است برنامه روی همه سیستم‌عامل‌ها به‌درستی کار نکند.

Node.js برای حل این مشکل ماژولی داخلی به نام **Path** ارائه کرده است.

این ماژول به ما کمک می‌کند تا مسیرها را به شکلی استاندارد، ایمن و مستقل از سیستم‌عامل مدیریت کنیم.

---

# 60.1 - ماژول Path

برای استفاده از این ماژول:

```js
const path = require("path");
```

---

# 60.2 - path.join()

پرکاربردترین متد این ماژول:

```js
const file = path.join(
    "users",
    "images",
    "photo.jpg"
);

console.log(file);
```

در ویندوز:

```text
users\images\photo.jpg
```

در لینوکس:

```text
users/images/photo.jpg
```

`join()` جداکننده مناسب سیستم‌عامل را به صورت خودکار انتخاب می‌کند.

---

# 60.3 - ساخت مسیر فایل

```js
const path = require("path");

const file = path.join(
    __dirname,

```

```text
C:\Projects\App\data\users.json
```

---

# 60.4 - path.resolve()

```js
console.log(
    path.resolve("images")
);
```

خروجی:

```text
C:\Projects\App\images
```

اگر چند بخش مسیر را ارسال کنیم:

```js
console.log(
    path.resolve(
        "public",
        "images",
        "logo.png"
    )
);
```

---

# 60.5 - تفاوت join و resolve

```js
path.join("a", "b");
```

خروجی:

```text
a/b
```

اما:

```js
path.resolve("a", "b");
```

خروجی:

```text
C:\Project\a\b
```

**تفاوت اصلی:**

* `join()` بخش‌های مسیر را به هم متصل می‌کند.
* `resolve()` یک مسیر مطلق (Absolute Path) ایجاد می‌کند.

# 60.6 - path.basename()

نام فایل را برمی‌گرداند.

```js
const file = "/home/user/app.js";

console.log(
    path.basename(file)
);
```

خروجی:

```text
app.js
```

حذف پسوند:

```js
console.log(
    path.basename(file, ".js")
);
```

خروجی:

```text
app
```

# 60.9 - path.parse()

```js
const result =
    path.parse(
        "/home/user/file.txt"
    );

console.log(result);
```

خروجی:

```text
{
  root: '/',
  dir: '/home/user',
  base: 'file.txt',
  ext: '.txt',
  name: 'file'
}
```

---

# 60.10 - path.format()

برعکس `parse()` عمل می‌کند.

```js
const file = path.format({

    dir: "/home/user",

    name: "file",

    ext: ".txt"

});

console.log(file);
```

---

# 60.11 - path.normalize()

# 60.17 - استفاده همراه fs

```js
const fs = require("fs");
const path = require("path");

const file = path.join(
    __dirname,
    "data",
    "users.json"
);

fs.readFile(
    file,
    "utf8",
    (err, data) => {

        console.log(data);

    }
);
```

# 60.18 - مسیر فایل جاری

در CommonJS:

```js
console.log(__dirname);

console.log(__filename);
```

در پروژه‌های ES Modules، `__dirname` و `__filename` به صورت پیش‌فرض وجود ندارند و باید با استفاده از `import.meta.url` و توابع مناسب آن‌ها را ایجاد کرد.

---

# 60.19 - مهم‌ترین متدها

| متد        | کاربرد            |
| ---------- | ----------------- |
| join       | اتصال مسیرها      |
| resolve    | ساخت مسیر مطلق    |
| basename   | نام فایل          |
| dirname    | پوشه              |
| extname    | پسوند             |
| parse      | تجزیه مسیر        |
| format     | ساخت مسیر از اجزا |
| normalize  | استانداردسازی     |
| relative   | مسیر نسبی         |
| isAbsolute | بررسی مسیر مطلق   |

# 60.20 - اشتباهات رایج

### 1) ساخت مسیر با رشته‌ها

```js
const file =
    "images/" + filename;
```

این روش ممکن است روی همه سیستم‌عامل‌ها درست کار نکند.

---

### 2) استفاده نکردن از `path.join()`

همیشه مسیرها را با `join()` یا `resolve()` بسازید.

---

### 3) اشتباه گرفتن `join()` و `resolve()`

`resolve()` همیشه مسیر مطلق تولید می‌کند.

---

### 4) وابسته بودن به `/`

جداکننده مسیر در همه سیستم‌عامل‌ها یکسان نیست.

---

### 5) استفاده از `__dirname` در ES Modules

در ES Modules باید از روش مخصوص این نوع ماژول‌ها برای به‌دست آوردن مسیر فایل استفاده شود.

---

# 60.21 - نکات حرفه‌ای

* همیشه از `path.join()` برای ساخت مسیر استفاده کن.
* برای مسیرهای مطلق از `resolve()` استفاده کن.
* از `parse()` برای استخراج اطلاعات فایل استفاده کن.
* مسیرها را هرگز به صورت دستی با `/` یا `\` نساز.
* هنگام کار با `fs`، ماژول `path` را نیز در کنار آن استفاده کن.
* برای اعتبارسنجی مسیرها از `isAbsolute()` و `normalize()` کمک بگیر.
* در پروژه‌های چندسکویی، همیشه مسیرها را مستقل از سیستم‌عامل طراحی کن.

# 60.24 - مینی‌پروژه

## ساخت ابزار تحلیل مسیر فایل

در این پروژه، اطلاعات مختلف یک مسیر را استخراج می‌کنیم.

```js
const path = require("path");

const file = path.join(
    __dirname,
    "images",
    "profile.png"
);

console.log("Full Path:", file);

console.log("Directory:", path.dirname(file));

console.log("File:", path.basename(file));

console.log("Extension:", path.extname(file));

console.log("Parsed:", path.parse(file));
```

نمونه خروجی:

```text
Full Path: C:\Project\images\profile.png

Directory: C:\Project\images

File: profile.png

Extension: .png

Parsed:
{
  root: 'C:\\',
  dir: 'C:\\Project\\images',
  base: 'profile.png',
  ext: '.png',
  name: 'profile'
}
```

## ایده‌هایی برای توسعه پروژه

* بررسی معتبر بودن مسیر ورودی
* نمایش نوع فایل بر اساس پسوند
* تبدیل مسیر نسبی به مطلق
* محاسبه مسیر نسبی بین دو پوشه
* ترکیب این پروژه با ماژول `fs` برای نمایش اطلاعات فایل
* ساخت ابزار CLI برای تحلیل مسیرهای ورودی از `process.argv`

# جمع‌بندی

ماژول **`path`** یکی از مهم‌ترین ماژول‌های داخلی Node.js برای مدیریت مسیر فایل‌ها و پوشه‌ها است. با استفاده از متدهایی مانند `join()`، `resolve()`، `basename()`، `dirname()`، `extname()` و `parse()` می‌توان مسیرها را به صورت استاندارد، ایمن و مستقل از سیستم‌عامل مدیریت کرد. یادگیری این ماژول در کنار `fs` برای توسعه برنامه‌های حرفه‌ای Node.js ضروری است و از بسیاری از خطاهای مربوط به مسیر فایل‌ها جلوگیری می‌کند.
