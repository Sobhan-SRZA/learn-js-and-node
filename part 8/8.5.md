# فصل 55 - EventEmitter

## مقدمه

در فصل قبل با معماری **Event-Driven** آشنا شدیم و یاد گرفتیم که Node.js بر پایه رویدادها (Eventها) طراحی شده است.

اما سؤال مهم این است:

> **چگونه می‌توانیم Eventهای خودمان را در Node.js ایجاد کنیم؟**

پاسخ این سؤال، کلاس **EventEmitter** است.

`EventEmitter` یکی از مهم‌ترین کلاس‌های داخلی Node.js است که بسیاری از ماژول‌های خود Node.js نیز بر اساس آن ساخته شده‌اند؛ مانند:

* Streamها
* HTTP Server
* Process
* Readline
* Net
* TLS
* Child Process

اگر EventEmitter را به خوبی یاد بگیرید، درک بسیاری از بخش‌های Node.js برایتان بسیار ساده‌تر خواهد شد.

---

# 55.1 - EventEmitter چیست؟

`EventEmitter` کلاسی از ماژول `events` است که به ما اجازه می‌دهد:

* Event ایجاد کنیم.
* Listener ثبت کنیم.
* Event ارسال کنیم.
* داده همراه Event ارسال کنیم.
* Listenerها را حذف کنیم.
* فقط یک بار Listener اجرا کنیم.

ابتدا باید آن را وارد پروژه کنیم.

```js
const EventEmitter = require("events");
```

---

# 55.2 - ساخت اولین EventEmitter

```js
const EventEmitter = require("events");

const emitter = new EventEmitter();
```

اکنون شیء `emitter` آماده ثبت و ارسال Event است.

---

# 55.3 - ثبت Listener با `on`

برای گوش دادن به یک Event از متد `on()` استفاده می‌کنیم.

```js
emitter.on("hello", () => {
    console.log("Hello World");
});
```

این کد فقط Listener را ثبت می‌کند و هنوز چیزی اجرا نشده است.

---

# 55.4 - ارسال Event با `emit`

برای اجرای Event از `emit()` استفاده می‌کنیم.

```js
emitter.emit("hello");
```

خروجی:

```text
Hello World
```

---

# 55.5 - ارسال داده به Listener

```js
const EventEmitter = require("events");

const emitter = new EventEmitter();

emitter.on("user", (name) => {
    console.log(`Welcome ${name}`);
});

emitter.emit("user", "Ali");
```

خروجی:

```text
Welcome Ali
```

---

# 55.6 - ارسال چند پارامتر

```js
emitter.on("order", (id, price) => {
    console.log(id);
    console.log(price);
});

emitter.emit("order", 105, 300);
```

---

# 55.7 - ارسال Object

در پروژه‌های واقعی بهتر است به‌جای ارسال تعداد زیادی پارامتر، یک شیء ارسال کنیم.

```js
emitter.on("userCreated", (user) => {
    console.log(user.name);
    console.log(user.email);
});

emitter.emit("userCreated", {
    name: "Sara",
    email: "sara@example.com"
});
```

این روش خواناتر و توسعه‌پذیرتر است.

---

# 55.8 - چند Listener برای یک Event

```js
emitter.on("login", () => {
    console.log("Save Log");
});

emitter.on("login", () => {
    console.log("Send Email");
});

emitter.on("login", () => {
    console.log("Notify Admin");
});

emitter.emit("login");
```

خروجی:

```text
Save Log
Send Email
Notify Admin
```

تمام Listenerها به ترتیب ثبت اجرا می‌شوند.

---

# 55.9 - متد `once`

گاهی Listener فقط یک بار باید اجرا شود.

```js
emitter.once("start", () => {
    console.log("Application Started");
});

emitter.emit("start");

emitter.emit("start");
```

خروجی:

```text
Application Started
```

---

# 55.10 - حذف Listener

```js
function welcome() {
    console.log("Welcome");
}

emitter.on("login", welcome);

emitter.off("login", welcome);

emitter.emit("login");
```

هیچ خروجی نمایش داده نمی‌شود.

---

# 55.11 - حذف همه Listenerها

```js
emitter.removeAllListeners("login");
```

یا:

```js
emitter.removeAllListeners();
```

در حالت دوم، تمام Listenerهای تمام Eventها حذف می‌شوند.

---

# 55.12 - تعداد Listenerها

```js
console.log(
    emitter.listenerCount("login")
);
```

خروجی:

```text
2
```

---

# 55.13 - دریافت نام Eventها

```js
console.log(
    emitter.eventNames()
);
```

خروجی نمونه:

```text
[ 'login', 'logout' ]
```

---

# 55.14 - دریافت Listenerها

```js
console.log(
    emitter.listeners("login")
);
```

آرایه‌ای از Listenerهای مربوط به Event برگردانده می‌شود.

---

# 55.15 - Event خطا

یکی از مهم‌ترین Eventها:

```text
error
```

مثال:

```js
emitter.on("error", (err) => {
    console.error(err.message);
});

emitter.emit(
    "error",
    new Error("Database Error")
);
```

خروجی:

```text
Database Error
```

اگر روی یک `EventEmitter` رویداد `error` منتشر شود و هیچ Listenerی برای آن وجود نداشته باشد، معمولاً خطا به‌صورت مدیریت‌نشده باعث توقف برنامه می‌شود. بنابراین همیشه برای Eventهای خطای مهم Listener مناسب در نظر بگیرید.

---

# 55.16 - ارث‌بری از EventEmitter

```js
const EventEmitter = require("events");

class UserService extends EventEmitter {

    createUser(name) {

        console.log("Creating User...");

        this.emit("created", name);

    }

}
```

استفاده:

```js
const service = new UserService();

service.on("created", (name) => {
    console.log(`${name} Created`);
});

service.createUser("Ali");
```

---

# 55.17 - مثال واقعی

```js
class OrderService extends EventEmitter {

    create(orderId) {

        console.log("Saving Order...");

        this.emit("orderCreated", orderId);

    }

}

const order = new OrderService();

order.on("orderCreated", (id) => {
    console.log(`Order ${id} Saved`);
});

order.on("orderCreated", (id) => {
    console.log(`Email Sent ${id}`);
});

order.on("orderCreated", (id) => {
    console.log(`Invoice Created ${id}`);
});

order.create(5001);
```

---

# 55.18 - متدهای مهم EventEmitter

| متد                  | کاربرد                  |
| -------------------- | ----------------------- |
| on()                 | ثبت Listener            |
| once()               | ثبت Listener یک‌بار مصرف |
| emit()               | ارسال Event             |
| off()                | حذف Listener            |
| removeAllListeners() | حذف همه Listenerها      |
| listenerCount()      | تعداد Listenerها        |
| listeners()          | دریافت Listenerها       |
| eventNames()         | دریافت نام Eventها      |

---

# 55.19 - چه زمانی از EventEmitter استفاده کنیم؟

زمانی که:

* بخش‌های مختلف برنامه مستقل باشند.
* بخواهیم وابستگی بین ماژول‌ها را کاهش دهیم.
* چند عملیات پس از وقوع یک اتفاق انجام شوند.
* سیستم Notification طراحی کنیم.
* سیستم Log بسازیم.
* Queue یا Message Bus ساده ایجاد کنیم.

---

# 55.20 - اشتباهات رایج

### 1) فراموش کردن `emit`

گاهی فقط Listener ثبت می‌شود اما Event هرگز ارسال نمی‌شود.

---

### 2) ارسال Event قبل از ثبت Listener

```js
emitter.emit("login");

emitter.on("login", () => {});
```

در این حالت Listener اجرا نمی‌شود، زیرا هنگام انتشار Event هنوز ثبت نشده است.

---

### 3) ثبت Listenerهای تکراری

ثبت چندباره یک Listener باعث اجرای چندباره آن می‌شود و در برنامه‌های بزرگ می‌تواند به نشت حافظه منجر شود.

---

### 4) نادیده گرفتن Event `error`

برای Eventهای مهم خطا، Listener مناسب تعریف کنید تا از خطاهای مدیریت‌نشده جلوگیری شود.

---

### 5) استفاده بیش از حد از EventEmitter

همه ارتباطات برنامه نباید با Event انجام شوند. استفاده بی‌رویه باعث پیچیده شدن جریان اجرای برنامه می‌شود.

---

# 55.21 - نکات حرفه‌ای

* برای نام Eventها از نام‌های واضح مانند `userCreated` یا `orderPaid` استفاده کن.
* به‌جای ارسال چند پارامتر، یک Object ارسال کن.
* اگر Listener فقط یک بار لازم است، از `once()` استفاده کن.
* در پایان عمر اشیاء یا ماژول‌ها، Listenerهای بدون استفاده را حذف کن.
* منطق اصلی برنامه را داخل Listenerها پخش نکن؛ هر Listener بهتر است یک مسئولیت مشخص داشته باشد.
* از EventEmitter برای ارتباط بین ماژول‌های مستقل استفاده کن، نه برای جایگزین کردن فراخوانی مستقیم توابع.

# 55.23 - پاسخ تشریحی

## پاسخ تمرین 1

```js
const EventEmitter = require("events");

const emitter = new EventEmitter();

emitter.on("signup", (name) => {
    console.log(`Welcome ${name}`);
});

emitter.emit("signup", "Sara");
```

**توضیح:**
ابتدا Listener ثبت شده و سپس با `emit` رویداد اجرا می‌شود.

---

## پاسخ تمرین 2

```js
const EventEmitter = require("events");

const emitter = new EventEmitter();

emitter.on("paymentSuccess", () => {
    console.log("Update Order");
});

emitter.on("paymentSuccess", () => {
    console.log("Send Email");
});

emitter.on("paymentSuccess", () => {
    console.log("Create Invoice");
});

emitter.emit("paymentSuccess");
```

**توضیح:**
یک Event می‌تواند چند Listener داشته باشد که همگی به ترتیب اجرا می‌شوند.

---

## پاسخ تمرین 3

```js
const EventEmitter = require("events");

const emitter = new EventEmitter();

emitter.once("boot", () => {
    console.log("System Started");
});

emitter.emit("boot");
emitter.emit("boot");
```

**توضیح:**
Listener پس از اولین اجرا به‌صورت خودکار حذف می‌شود.

---

## پاسخ تمرین 4

```js
const EventEmitter = require("events");

class ChatRoom extends EventEmitter {

    send(user, message) {

        this.emit("message", {
            user,
            message
        });

    }

}

const room = new ChatRoom();

room.on("message", (data) => {
    console.log(`${data.user}: ${data.message}`);
});

room.send("Ali", "Hello");
```

**توضیح:**
کلاس از `EventEmitter` ارث‌بری کرده و با ارسال Event، سایر بخش‌های برنامه را از پیام جدید مطلع می‌کند.

---

## پاسخ تمرین 5

```js
const EventEmitter = require("events");

class TaskManager extends EventEmitter {

    addTask(title) {
        console.log("Task Added");

        this.emit("taskAdded", title);
    }

}

const manager = new TaskManager();

manager.on("taskAdded", (title) => {
    console.log(`Log: ${title}`);
});

manager.on("taskAdded", (title) => {
    console.log(`${title} successfully created.`);
});

manager.addTask("Learn Node.js");
```

**توضیح:**
کلاس تنها مسئول اضافه کردن وظیفه است و عملیات جانبی مانند ثبت لاگ یا نمایش پیام توسط Listenerهای مستقل انجام می‌شود.

# 55.24 - مینی‌پروژه

## ساخت سیستم مدیریت کاربران با EventEmitter

در این پروژه، یک سرویس مدیریت کاربران طراحی می‌کنیم. هر زمان کاربر جدیدی ایجاد شود، چند بخش مستقل برنامه از طریق Event از این موضوع مطلع می‌شوند.

```js
const EventEmitter = require("events");

class UserService extends EventEmitter {

    createUser(user) {

        console.log("Creating User...");

        this.emit("userCreated", user);

    }

}

const service = new UserService();

service.on("userCreated", (user) => {
    console.log(`Welcome ${user.name}`);
});

service.on("userCreated", (user) => {
    console.log(`Verification email sent to ${user.email}`);
});

service.on("userCreated", (user) => {
    console.log(`Activity logged for ${user.name}`);
});

service.on("userCreated", (user) => {
    console.log(`Creating default profile for ${user.name}`);
});

service.createUser({
    name: "Ali",
    email: "ali@example.com"
});
```

### خروجی

```text
Creating User...
Welcome Ali
Verification email sent to ali@example.com
Activity logged for Ali
Creating default profile for Ali
```

### ایده‌هایی برای توسعه پروژه

* اضافه کردن Event برای حذف کاربر
* اضافه کردن Event برای ورود و خروج کاربران
* ثبت زمان وقوع هر Event
* ذخیره لاگ‌ها در فایل
* ارسال اعلان از طریق WebSocket
* اتصال Eventها به صف پیام (Queue)
* پیاده‌سازی سیستم Notification چندکاناله (ایمیل، پیامک و Push Notification)

# جمع‌بندی

`EventEmitter` یکی از مهم‌ترین کلاس‌های داخلی Node.js و پایه بسیاری از ماژول‌های این محیط است. با استفاده از آن می‌توان سیستم‌های **Event-Driven** طراحی کرد که در آن بخش‌های مختلف برنامه بدون وابستگی مستقیم با یکدیگر ارتباط برقرار می‌کنند. متدهایی مانند `on()`، `emit()`، `once()` و `off()` ابزارهای اصلی این کلاس هستند و استفاده صحیح از آن‌ها باعث می‌شود برنامه‌هایی توسعه‌پذیر، ماژولار و قابل نگهداری طراحی کنید؛ ویژگی‌ای که در پروژه‌های حرفه‌ای Node.js اهمیت بسیار زیادی دارد.
