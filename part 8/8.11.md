# فصل 61 - OS

## مقدمه

هر برنامه‌ای که روی Node.js اجرا می‌شود، روی یک سیستم‌عامل (Operating System) قرار دارد.

برای مثال:

* Windows
* Linux
* macOS

در بسیاری از پروژه‌های واقعی لازم است اطلاعاتی درباره سیستم اجراکننده برنامه داشته باشیم.

برای مثال:

* مقدار حافظه RAM سیستم
* تعداد هسته‌های CPU
* نوع سیستم‌عامل
* معماری پردازنده
* فضای آزاد دیسک
* اطلاعات شبکه
* زمان روشن بودن سیستم
* کاربر فعلی سیستم

Node.js برای دسترسی به این اطلاعات یک ماژول داخلی به نام **`os`** ارائه کرده است.

با استفاده از این ماژول می‌توانیم اطلاعات سیستم را بدون نیاز به کتابخانه خارجی دریافت کنیم.

---

# 61.1 - ماژول OS چیست؟

ماژول `os` یک ماژول داخلی Node.js است که اطلاعات مربوط به سیستم‌عامل را در اختیار برنامه قرار می‌دهد.


# 61.17 - مقایسه اطلاعات Process و OS

دو ماژول مهم Node.js:

| ماژول   | کاربرد                     |
| ------- | -------------------------- |
| process | اطلاعات برنامه در حال اجرا |
| os      | اطلاعات سیستم اجراکننده    |

مثال:

```js
process.memoryUsage();
```

حافظه مصرفی برنامه را می‌دهد.

اما:

```js
os.totalmem();
```

کل حافظه سیستم را نشان می‌دهد.

# 61.20 - اشتباهات رایج

## 1) فرض کردن یک سیستم‌عامل خاص

مثلاً:



## 3) استفاده اشتباه از Load Average

## 4) نمایش اطلاعات حساس

اطلاعاتی مانند:

* نام کاربر
* مسیر Home
* اطلاعات شبکه

نباید بدون دلیل در خروجی عمومی نمایش داده شوند.

## 5) استفاده از اطلاعات سیستم برای تصمیمات ثابت

مثلاً محدود کردن برنامه فقط برای یک CPU خاص، باعث کاهش انعطاف پروژه می‌شود.

# 61.21 - نکات حرفه‌ای

* برای ساخت ابزارهای مانیتورینگ از `os` همراه با `process` استفاده کن.
* مقدار حافظه را همیشه به واحد قابل فهم تبدیل کن.
* برای برنامه‌های Cross Platform به `platform()` و `EOL` توجه کن.
* اطلاعات سیستم را قبل از استفاده اعتبارسنجی کن.
* در سرورها، مصرف حافظه و CPU را به صورت دوره‌ای بررسی کن.
* برای ساخت داشبوردهای Monitoring، اطلاعات `os` را همراه با Stream یا API ارسال کن.
* اطلاعات حساس سیستم را مستقیماً به کاربر نهایی نمایش نده.

# 61.24 - مینی‌پروژه

# ساخت ابزار System Monitor

در این پروژه یک ابزار ساده برای نمایش وضعیت سیستم ایجاد می‌کنیم.

قابلیت‌ها:

* نمایش سیستم‌عامل
* نمایش CPU
* نمایش RAM
* نمایش حافظه آزاد
* نمایش زمان روشن بودن سیستم

---

## کد پروژه

```js
const os = require("os");


function bytesToGB(bytes){

    return (
        bytes /
        1024 /
        1024 /
        1024
    ).toFixed(2);

}


console.log("=== System Monitor ===");


console.log(
    "Platform:",
    os.platform()
);


console.log(
    "Hostname:",
    os.hostname()
);


console.log(
    "CPU Cores:",
    os.cpus().length
);


console.log(
    "Total Memory:",
    bytesToGB(
        os.totalmem()
    ),
    "GB"
);


console.log(
    "Free Memory:",
    bytesToGB(
        os.freemem()
    ),
    "GB"
);


console.log(
    "Uptime:",
    os.uptime(),
    "seconds"
);
```

---

## نمونه خروجی

```text
=== System Monitor ===

Hostname: DESKTOP-PC

CPU Cores: 8

Total Memory: 16 GB

Free Memory: 7 GB

Uptime: 3600 seconds
```

# 61.25 - پروژه توسعه‌ای

## ساخت ابزار مانیتورینگ سرور

یک نسخه پیشرفته‌تر بسازید که:

* هر ۵ ثانیه اطلاعات سیستم را دریافت کند.
* مصرف حافظه را نمایش دهد.
* اطلاعات را داخل فایل Log ذخیره کند.
* با `fs` گزارش‌ها را ذخیره کند.
* با `process` مصرف برنامه را نیز بررسی کند.

ساختار:

```text
system-monitor/

│
├── app.js
│
├── logs/
│   └── system.log
```

# جمع‌بندی

ماژول **OS** یکی از ابزارهای مهم Node.js برای دریافت اطلاعات سیستم‌عامل است. با استفاده از آن می‌توان اطلاعاتی مانند CPU، حافظه RAM، سیستم‌عامل، شبکه، کاربر فعلی و زمان روشن بودن سیستم را دریافت کرد.

در پروژه‌های واقعی، ترکیب `os` با ماژول‌هایی مانند `process`، `fs` و `stream` امکان ساخت ابزارهای مانیتورینگ، سیستم‌های گزارش‌گیری و برنامه‌های مدیریتی حرفه‌ای را فراهم می‌کند.
